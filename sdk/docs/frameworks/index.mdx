## Install the right package

Most frameworks use one package, `c15t`, and import the framework entry point:
`c15t/next`, `c15t/react`, `c15t/vue` (the Nuxt module), `c15t/vue/vue-plugin`
(plain Vue), `c15t/astro`, `c15t/tanstack-start` or `c15t/svelte`.
You do not need `@c15t/nextjs` or `@c15t/react` as well; `c15t` depends on
them.

HTML pages and the
stock UI in JavaScript use `@c15t/browser`. Vendor script helpers are a separate
install, `@c15t/integrations`, in every framework.

Mobile SDKs use native consent engines and have their own installation paths.
They are currently private prereleases. [Mobile availability](/docs/guides/mobile-status)
explains how to obtain the matching Swift, Maven and RN artifacts.

## After the quickstart

A banner on screen does not mean analytics wait for consent. Move existing
scripts into c15t, replace embeds that load on their own, and keep a link to
reopen preferences. Then [verify the integration](/docs/guides/verify-consent).
