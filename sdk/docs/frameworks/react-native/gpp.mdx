---
title: IAB GPP
description: Turn on the IAB Global Privacy Platform string in a React Native or Expo app, so ad SDKs read US National opt-outs and the TCF EU consent string from IABGPP_* keys.
group: frameworks
---

The native engine writes the GPP string for ad SDKs and exposes it to
JavaScript through `useGPPString()`. Turn it on in the Expo plugin or the bare
native metadata.
