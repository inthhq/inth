Pass a `ConsentTheme` to `C15tConsent` to match your app's visual identity.
The native presenter keeps responsibility for drafts, navigation and saves.
Start with the [quickstart](/docs/frameworks/android/quickstart) so the same
screens can be reopened from app settings.

## Choose what to change

| Change | Native setting |
| --- | --- |
| App name and logo above the headline | `brand` |
| Headline and introductory copy | `copy` |
| Colors in light and dark mode | `colors` |
| Card and button corners | `radius` |
| Gutters, section gaps and padding | `spacing` |
| Type sizes and faces | `typography` |
| One part, such as the decision buttons | `slots` |
| Provider name in the attribution | `branding` |
| Entirely app-owned controls | [Headless integration](/docs/frameworks/android/headless) |

## Add your brand

The following theme gives a fictional Pantry app teal links and switches,
10dp corners, a wider page gutter, an 18sp body size, pill-shaped outlined
actions, its own logo and a short headline. The light/dark color pairs
keep the same theme usable in either system appearance.

Create `consent-theme.kt` in your app, using your own package name:

<include src="../../shared/examples/native/examples/consent-demo/android-brand-theme.mdx" />

Put your logo in the app's drawable resources. In the quickstart's
`C15tConsent` call, pass the theme as its `theme` argument. This is a change
to that call, using your own drawable name:

{/* example: fragment */}

```kotlin
C15tConsent(
	privacyPolicyUrl = "https://your-app.example/privacy",
	theme = pantryConsentTheme(R.drawable.your_app_mark),
)
```

Import your app's generated `R` class if the file is outside its namespace.
The logo appears in the app-identity tile. An unreadable explicit resource falls
back to the name's initial. `ConsentTheme.Brand.Hidden` removes the app-identity
area so the headline starts the screen.

## Keep decision buttons equal

`colors.decision` and `colors.textOnDecision` control the fill and label of
both Accept all and Reject all. They intentionally share one treatment, and so
does the `ConsentTheme.Slot.ButtonPrimary` slot. The example changes `primary`
while keeping the stock decision colors. Below 5:1 text contrast in either
appearance, the screens use the stock decision colors instead.

When replacing colors, check text contrast for every affected state in both
appearances. Check the screen at the largest system font scale as well. A
theme value is not a contrast guarantee.

## Set type, spacing and radii

Names that have a web token match it: `colors.primary` is `--c15t-primary`,
`radius.md` is `--c15t-radius-md` and `spacing.lg` is `--c15t-space-lg`.

`typography.fontSize` sets three groups of the Material type scale the screens
use. `sm` sizes bodyMedium, bodySmall and the small labels (14sp by default);
`base` sizes bodyLarge, the titles under it and labelLarge (16sp); `lg` sizes
the first-layer headline (34sp) and the larger titles. Each style keeps its
ratio to its group, and the system font scale still applies. `null` keeps the
Material size. `typography.fontFamily` sets the face of every style except the
headline, which `typography.headlineFont` sets: `HeadlineFont.SansSerif` and
`HeadlineFont.Serif` select system faces, and `HeadlineFont.Custom` accepts a
bundled Compose `FontFamily`.

`spacing` sets the page gutters, section gaps and the footer and notice
padding. A control's own padding stays fixed so its touch target keeps its
size. `radius.md` rounds buttons and cards; `radius.sm` and `radius.lg` follow
it until you set them.

`slots` override one part: `ConsentBannerTitle`, `ConsentBannerDescription`,
`ButtonPrimary` and `ButtonSecondary`, each with `color`, `backgroundColor`,
`borderRadius` and `fontSize`.

## Separate app identity from attribution

`brand` identifies the app. `branding` identifies the consent provider in the
attribution beneath the actions. The built-in providers are
`ConsentTheme.Branding.C15t` and `.Inth`. A custom provider uses
`Branding.Custom(name, markResId)`; its mark is optional. `showsBranding = false`
hides that attribution.

Changing provider attribution does not replace the app's identity. Set `brand`
when you want your app's own name and logo above the headline.

## Set a default through application metadata

An explicit `theme` argument takes precedence over the global
`ConsentTheme.current` and application metadata. Metadata is useful when the
same native presenter is opened through a wrapper.

| Metadata key | Value |
| --- | --- |
| `com.c15t.consent.PRIMARY`, `TEXT_ON_PRIMARY` | `#RRGGBB`, or a comma-separated light,dark pair. |
| `com.c15t.consent.CANVAS`, `SURFACE`, `SURFACE_MUTED` | Screen and card colors. |
| `com.c15t.consent.TEXT`, `TEXT_MUTED` | Main and muted text colors. |
| `com.c15t.consent.DECISION`, `TEXT_ON_DECISION` | Shared Accept/Reject colors. |
| `com.c15t.consent.RADIUS_SM`, `RADIUS_MD`, `RADIUS_LG` | Radii in dp. |
| `com.c15t.consent.SPACE_XS` to `SPACE_XL` | Spacing steps in dp. |
| `com.c15t.consent.FONT_SIZE_SM`, `FONT_SIZE_BASE`, `FONT_SIZE_LG` | Font sizes in sp. |
| `com.c15t.consent.FONT_FAMILY` | A font resource. |
| `com.c15t.consent.BUTTON_PRIMARY_BORDER_RADIUS` | One slot field, as `<SLOT>_<FIELD>`. |
| `com.c15t.consent.HEADLINE_FONT` | `sans`, `serif` or `rounded`; Android maps `rounded` to sans. |
| `com.c15t.consent.BRAND_NAME`, `BRAND_MARK` | App name and drawable resource. |
| `com.c15t.consent.BRAND` | `false` hides app identity. |
| `com.c15t.consent.HEADLINE`, `INTRODUCTION` | First-layer copy. |
| `com.c15t.consent.BRANDING_PROVIDER` | `c15t` or `inth`. |
| `com.c15t.consent.BRANDING_NAME`, `BRANDING_MARK` | Custom provider name and drawable. |
| `com.c15t.consent.BRANDING` | `false` hides provider attribution. |

Keys shortened within a row retain the `com.c15t.consent.` prefix.

## Know where the copy comes from

The stock screens read every label from `@c15t/translations`, in the policy's
translation language: the language `/init` serves, or the `language` in
`NativeConfig.overrides`. Buttons, headings and category names use the same
keys as the web banner, so they read "Accept All", "Reject All" and
"Strictly Necessary". Sentences that only make sense in an app, such as the
category explanations and save errors, are native-only keys in the same
package. A language c15t has no copy for falls back to English. IAB screens
follow the served vendor list's language instead.

`ConsentTheme.Copy` replaces the first-layer headline and introduction. Leave
a field `null` to keep the translated stock copy. A string you set is shown as
given in every language, so pass your own translation for each language you
support. It is not a localization dictionary for the other labels.

IAB purpose and vendor disclosures come from the served authoritative data.
Keep that copy and required policy links intact. Use the
[IAB guide](/docs/guides/mobile-iab) when reviewing an advertising flow.
