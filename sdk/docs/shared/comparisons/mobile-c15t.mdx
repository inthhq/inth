c15t's mobile SDKs are a private prerelease. They are available for private
integration testing, not yet on npm, Maven Central or a tagged Swift package.
[Mobile availability](/docs/guides/mobile-status) tracks publication.

The prerelease has native Swift and Kotlin consent engines with SwiftUI and
Compose screens, a React Native adapter and an Expo config plugin. Because the
engine is native, an analytics or ad SDK can check a gate before JavaScript
starts. It records IAB TCF choices and Additional Consent v2 natively and can
ship a policy resource for a first launch without network. c15t's CMP
registration covers web; mobile validation and Google App certification are
separate work.

Not in the prerelease, and open as pull requests on 10 November 2026: a mode
with no backend and the policy in your code ([#109](https://github.com/inthhq/c15t-private/pull/109)), Google Consent Mode v2
signals on mobile ([#107](https://github.com/inthhq/c15t-private/pull/107)), consent sharing with WebViews ([#114](https://github.com/inthhq/c15t-private/pull/114)), and GPP
([#113](https://github.com/inthhq/c15t-private/pull/113)). There is no Flutter, Unity or TV SDK.
