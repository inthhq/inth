### Vendor details show the standard Features explanation

IAB TCF policy check 14 now requires the standard explanation wherever
Features appear. A vendor's details in the IAB preference centre list each
Feature with its description, followed by the vendor list's standard Features
text. When the vendor list has no standard Features text, the translated
standard text shows instead. Features still have no control.
