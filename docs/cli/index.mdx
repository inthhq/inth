The `inth` command manages your Inth account and resources from the terminal. Use formatted output for interactive work and `--json` for agents and scripts.

Follow [Get started](./getting-started) to use a published package or build from source. Run `inth --version` to identify the installed release. Bundled documentation matches the package that contains it.

## What can I do with the Inth CLI?

- [Sign in](./authentication) with browser approval or an organization API key.
- [Select an organization](./organizations) for your commands or current directory.
- [Manage resources](./commands), including projects, members, API keys, scans, and findings.
- [Automate commands](./automation) with structured help, JSON output, and resumable approval.
- [Configure Inth MCP](./mcp) in your coding client.
- [Install agent skills](./skills) from the bundled catalog or a repository.
- [Use flags and raw API requests](./global-flags).
- [Control telemetry](./telemetry).

## How do I find commands for my installed version?

```sh
inth --help
inth project create --help
inth project create --help --json
inth --version
```

Help describes the installed version, including required flags, supported credentials, scopes, and command effects. Use it when hosted documentation describes a newer release.

Named commands print text by default, even when piped. Add `--json` when another program will read the result.
