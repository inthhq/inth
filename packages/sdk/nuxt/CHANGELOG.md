## @inth/nuxt@0.0.0-alpha.0 (alpha)

### First alpha of the Inth consent SDK

`@inth/sdk` and the framework packages publish as `0.0.0-alpha.0` under the `alpha` dist-tag: `@inth/react`, `@inth/nextjs`, `@inth/tanstack-start`, `@inth/vue`, `@inth/nuxt`, `@inth/svelte`, `@inth/astro`, `@inth/angular` and `@inth/integrations`. Install the package for your framework with the tag, such as `npm install @inth/react@alpha`.
