Enable IAB TCF in your Nuxt app so visitors under an IAB policy receive the
server-rendered IAB banner, preference center, and `window.__tcfapi`.

## Turn on IAB TCF

IAB TCF is off by default. Set `iab` under `inth` in `nuxt.config.ts`; an
empty object enables it:

<include src="../../shared/examples/nuxt/iab-opt-in.mdx" />

With `iab` enabled, `InthProvider` automatically switches to the IAB banner and
preference center whenever the visitor matches an `iab` policy with a CMP ID,
and Inth installs `__tcfapi`. Configure your CMP ID and vendors in your Inth
project. No extra component or stylesheet is needed.

Leaving `iab` unset, `false`, or `{ enabled: false }` keeps IAB off: no
`__tcfapi` is installed and `@inth/sdk/iab` is never loaded or prefetched.

If a visitor matches an `iab` policy returning a vendor list while `iab` is
disabled, Inth throws `IABUnavailableError` (`INTH_IAB_UNAVAILABLE`) because
the standard banner cannot satisfy IAB TCF. SSR fails with status 500, and
browser-resolved pages render Nuxt's error page. Either set `iab` or remove
the `iab` model from that policy. If the policy returns `gvl: null`, IAB stays
off and the policy runs as opt-in. See
[IABUnavailableError troubleshooting](/docs/frameworks/nuxt/troubleshooting#the-page-throws-iabunavailableerror).

Configure `iab` in `nuxt.config.ts` rather than only in `app.config.ts` so
builds prefetch the IAB banner and CMP chunks. `iab` is read once at startup;
`updateAppConfig()` does not toggle it.

To compose surfaces yourself instead of using `InthProvider`, import
[`IABConsentBanner`](/docs/frameworks/nuxt/components/iab-consent-banner) and
[`IABConsentDialog`](/docs/frameworks/nuxt/components/iab-consent-dialog). For
a custom preference center, use `useConsentIabSelection()` and
`useConsentIabSave()`.

## Restrict how vendors use a purpose

Publisher restrictions override a vendor's declared legal basis for a purpose.
Configure them under `inth.iab` (replace placeholder vendor IDs with vendors
from your list whose declarations permit each restriction):

{/* example: fragment */}

```ts title="nuxt.config.ts (partial)"
export default defineNuxtConfig({
	modules: ['@inth/nuxt'],
	inth: {
		iab: {
			publisherRestrictions: [
				// Vendors 10 and 755 may not use purpose 4.
				{ purposeId: 4, restrictionType: 0, vendorIds: [10, 755] },
				// Vendor 755 must use legitimate interest for purpose 7.
				{ purposeId: 7, restrictionType: 2, vendorIds: [755] },
			],
		},
	},
});
```

`iab` also accepts `publisherCountryCode`, a `vendors` allowlist,
`customVendors`, and `cmpVersion`. Omitted fields come from your Inth policy.
The CMP mounts only when the visitor's policy uses the `iab` model.

## Vendor list during server rendering

Server HTML includes the banner's purpose names, vendor count, and a reference
to the Global Vendor List, not the full list. After hydration, the IAB module
fetches the full list before saving a TC String. In default `manifest()` mode,
the consent route serves the versioned list with a one-day public cache. Allow
your consent route or Inth project origin in CSP `connect-src`. See
[Content Security Policy](/docs/frameworks/nuxt/content-security-policy).

## Verify IAB consent

Load a page under your IAB policy and confirm the IAB banner appears. Accept
or reject, then run `__tcfapi('getTCData', 2, console.log)` in the browser
console and confirm a valid TC String is returned.
