## Declare the vendors

Declaring at least one vendor enables per-vendor switches. Built-in
`@inth/integrations` helpers then appear automatically by name, so you only
declare vendors for custom scripts or to override a helper's name or privacy
policy URL.

Declare vendors next to your scripts in `app/consent-scripts.ts`, matching
each script's `vendor` slug:

{/* example: fragment */}

```ts title="app/consent-scripts.ts (partial)"
import type { Vendor } from '@inth/nuxt';

export const vendors: Vendor[] = [
	{
		id: 'x-pixel',
		name: 'X Pixel',
		category: 'marketing',
		privacyPolicyUrl: 'https://x.com/privacy',
	},
];
```

Register them under `inth` in `app/app.config.ts`:

{/* example: fragment */}

```ts title="app/app.config.ts (partial)"
import { scripts, vendors } from './consent-scripts';

export default defineAppConfig({ inth: { scripts, vendors } });
```

Because `vendors` is plain data, `inth.vendors` in `nuxt.config.ts` works too;
the module combines arrays from both files.

`ConsentGate` checks categories only. To gate an iframe by vendor, add
`data-vendor` and use the iframe blocker in
[embeds](/docs/frameworks/nuxt/embeds).

## What the preference dialog shows

`ConsentManager` (rendered by `InthProvider`) and `ConsentWidget` list each
declared vendor under its category with its own switch.

## Build your own vendor switch

The auto-imported `useConsentDraft()` manages category and vendor switches for
a custom preference form. Read `vendors`, update a switch with
`setVendor(id, granted)`, and call `save()`:

{/* example: fragment */}

```vue title="app/components/x-pixel-switch.vue (partial)"
<script setup lang="ts">
const { vendors, setVendor, save } = useConsentDraft();
</script>

<template>
	<input
		type="checkbox"
		:checked="vendors['x-pixel'] ?? true"
		@change="setVendor('x-pixel', ($event.target as HTMLInputElement).checked)"
	/>
	<button type="button" @click="save()">Save</button>
</template>
```

`save()` resolves `{ ok: false }` without saving while `isStale` is `true`.
See [composables](/docs/frameworks/nuxt/composables) for the full draft API.

## Check whether a vendor may run

The auto-imported `useVendorAllowed(id)` returns a computed boolean that is
`true` when the vendor is declared, its category is allowed, and the visitor
has not switched it off:

{/* example: fragment */}

```vue title="app/components/x-pixel-status.vue (partial)"
<script setup lang="ts">
const xPixelAllowed = useVendorAllowed('x-pixel');
</script>
```
