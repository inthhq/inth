Delete cookies and storage keys left behind by a vendor when its category is
denied, using `clearOnRevocation` in `@inth/nuxt`.

## Configure cleanup

Script gating stops new requests, not cookies or storage keys a vendor already
wrote. List the keys each optional category owns under `inth` in
`nuxt.config.ts` so Inth removes them when that category is denied:

{/* example: fragment */}

```ts title="nuxt.config.ts (partial)"
export default defineNuxtConfig({
	inth: {
		clearOnRevocation: {
			measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
			marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
		},
	},
});
```

`clearOnRevocation` is plain data and works in either `nuxt.config.ts` or
`app/app.config.ts`. The module reads it once in the browser after hydration.
