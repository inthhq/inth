Enable a persistent floating button in Nuxt so visitors can reopen privacy
preferences from any page.

## Turn on the trigger in `nuxt.config.ts`

Enable `showTrigger` under `inth` in `nuxt.config.ts` so `InthProvider` renders
the trigger automatically:

{/* example: fragment */}

```ts title="nuxt.config.ts"
export default defineNuxtConfig({
	inth: { showTrigger: true, triggerDefaultPosition: 'bottom-left' },
});
```

`@inth/nuxt` also registers `ConsentDialogTrigger` globally, so you can render
it directly when composing surfaces without `InthProvider`:
