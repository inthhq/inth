Import `IABConsentBanner` directly only when every policy on your site uses
IAB TCF and you compose surfaces yourself instead of mounting `InthProvider`.

## Import the IAB banner into `app.vue`

`InthProvider` renders `IABConsentBanner` automatically when `iab` is enabled
and the visitor matches an IAB policy. To compose it directly, import it from
`@inth/nuxt/components/iab-consent-banner`:

<include src="../../../shared/examples/nuxt/iab-surfaces.mdx" />

Mount this in `app/app.vue` instead of `InthProvider` and enable `inth.iab`
(see [IAB TCF](/docs/frameworks/nuxt/iab)). Visitors under non-IAB policies
see nothing from these components. If `iab` is unset, an IAB policy throws
`IABUnavailableError`.
