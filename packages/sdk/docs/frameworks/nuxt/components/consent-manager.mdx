Import `ConsentManager` when composing consent surfaces yourself, or open it
programmatically via auto-imported `useConsentActiveUI()`.

## Import the dialog when you compose surfaces

`InthProvider` already mounts `ConsentManager` when preferences open. Because
`@inth/nuxt` does not register it globally, import it from
`@inth/nuxt/components/consent-manager` only when composing surfaces without
`InthProvider`:

<include src="../../../shared/examples/nuxt/consent-surfaces.mdx" />

## Open the dialog from your code

Set `activeUI` to `'dialog'` using auto-imported `useConsentActiveUI()`:

{/* example: fragment */}

```ts
const activeUI = useConsentActiveUI();
activeUI.value = 'dialog';
```

For a footer button that automatically hides when the policy offers no
preferences, use
[ConsentDialogLink](/docs/frameworks/nuxt/components/consent-dialog-link).
