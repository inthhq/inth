Embed inline consent controls directly inside a Nuxt privacy or account
settings page using globally registered `ConsentWidget`.

## Add the widget to your privacy page

`@inth/nuxt` registers `ConsentWidget` globally, so render it without an
import:

<include src="../../../shared/examples/nuxt/privacy-page.mdx" />

Keep `InthProvider` in `app/app.vue` so visitors on other routes still see the
banner. In default `manifest()` or `hosted()` mode, SSR renders
`ConsentWidget` with the visitor's stored switches already applied.
