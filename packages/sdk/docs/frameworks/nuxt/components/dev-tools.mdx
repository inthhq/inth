Inspect live consent state, resolved policies, script status, and events in
development using either the built-in Nuxt DevTools tab or the floating
`ConsentDevTools` panel.

## Load DevTools only in development

`@inth/nuxt` does not register `ConsentDevTools` globally. Dynamically import
it from `@inth/nuxt/devtools` behind `import.meta.dev`:

<include src="../../../shared/examples/nuxt/devtools.mdx" />

Render it inside `app/app.vue`. Because `import.meta.dev` evaluates to `false`
in production builds, the panel stays out of production bundles. A static
import ships DevTools to visitors even when hidden with `v-if`.

## Inspect consent in Nuxt DevTools

In development, `@inth/nuxt` adds an **Inth** tab directly to Nuxt DevTools, so
you do not need to mount `ConsentDevTools`. Open Nuxt DevTools with
Shift + Option + D (Shift + Alt + D on Windows and Linux) and select **Inth**
to view consents, scripts, location, policy, IAB state, events, and actions.

Production builds exclude the tab, its `/__inth_devtools__` route, and its
client plugin. To disable the tab in development, set `devtools: false`:

{/* example: fragment */}

```ts title="nuxt.config.ts"
export default defineNuxtConfig({
	modules: ['@inth/nuxt'],
	inth: { devtools: false },
});
```

Event history begins when you first open the tab and persists across tab
switches. Actions taken in the tab update your app's live consent state.

## Verify

Run `nuxt dev`, open the DevTools panel or Nuxt DevTools tab, and check the
Location tab for the server-resolved country. Then run `nuxt build`, start the
production server, and confirm DevTools is absent.
