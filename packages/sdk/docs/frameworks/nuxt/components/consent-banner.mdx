Import `ConsentBanner` directly when composing consent surfaces yourself
instead of using global `InthProvider`.

## Import the banner in place of `InthProvider`

`InthProvider` already renders `ConsentBanner`. Because `@inth/nuxt` does not
register `ConsentBanner` globally, import it from
`@inth/nuxt/components/consent-banner` when you want to set its container in
templates or control placement:

<include src="../../../shared/examples/nuxt/consent-surfaces.mdx" />

Mount this in `app/app.vue` instead of `InthProvider`, alongside
`ConsentManager` so your page links can open the dialog. Statically importing
`ConsentManager` adds it to your main bundle, whereas `InthProvider`
code-splits it. Direct composition does not switch to IAB surfaces under an
IAB policy. The module still writes your `tokens` to `<head>`.

<import src="../../../shared/vue/components/consent-banner.mdx#behavior" />

<import src="../../../shared/vue/components/consent-banner.mdx#props" />

To configure the banner container globally without importing `ConsentBanner`,
set `presentation.prompt` under `inth` in `nuxt.config.ts`. See
[change the banner layout](/docs/frameworks/nuxt/customize#change-the-banner-layout).
