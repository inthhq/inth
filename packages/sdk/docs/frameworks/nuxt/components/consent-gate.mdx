Wrap third-party embeds in globally registered `ConsentGate` so they stay out
of server HTML and the DOM until their consent category is allowed.

## Wrap an embed in `ConsentGate`

Put your embed in the default slot and an optional `placeholder` slot without
needing an import:

<include src="../../../shared/examples/nuxt/embed.mdx" />

The iframe stays absent until `measurement` is granted. The placeholder uses
`ConsentDialogLink` so visitors can open preferences right from the embed
spot.

<import src="../../../shared/vue/components/consent-gate.mdx#behavior" />

## During server rendering

In default `manifest()` or `hosted()` mode, SSR evaluates the visitor's
consent cookie before rendering: visitors who granted the category receive the
iframe in server HTML, while everyone else receives the placeholder. On
prerendered, cached, and `ssr: false` routes, every visitor gets the
placeholder until browser resolution finishes.

## Verify

View page source in a private window and confirm the placeholder renders with
no `youtube-nocookie.com` iframe. Allow the category and save to load the
iframe, then reload and view source to confirm SSR includes it. Withdraw the
category and save to confirm the page reloads without the embed.
