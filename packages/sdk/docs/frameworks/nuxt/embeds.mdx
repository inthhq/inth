Hold back third-party iframes in Nuxt until the visitor allows their consent
category, using either `ConsentGate` or the built-in iframe blocker.

## Pick a method

| Method | Use it when |
| --- | --- |
| `ConsentGate` | You render the iframe in a Vue component and want a placeholder with a button to open preferences. Server HTML respects the visitor's stored choice. |
| Iframe blocker | The iframe comes from raw HTML such as CMS content, or you want no wrapper component. |

Both approaches omit `src` until permission is granted, so the embed host
receives no requests before consent.

## Gate an embed with ConsentGate

Wrap the iframe in the globally registered
[`ConsentGate`](/docs/frameworks/nuxt/components/consent-gate):

<include src="../../shared/examples/nuxt/embed.mdx" />

The iframe stays out of both server HTML and the DOM until `measurement` is
allowed. Until then, `placeholder` renders a message and a
[`ConsentDialogLink`](/docs/frameworks/nuxt/components/consent-dialog-link).
When the visitor withdraws `measurement`, Vue removes the iframe.

Match the category to what the embed does: use `measurement` for YouTube, or
`functionality` or `experience` for maps and chat widgets.

## Gate an iframe with the iframe blocker

`@inth/nuxt` enables the iframe blocker in the browser by default. Replace
`src` with `data-src` and add `data-category`:

{/* example: fragment */}

```vue title="app/components/MapEmbed.vue"
<template>
	<iframe
		data-src="https://www.google.com/maps/embed?pb=YOUR_EMBED_ID"
		data-category="functionality"
		title="Store map"
	/>
</template>
```

Server HTML omits `src`, so nothing loads before hydration. After hydration,
Inth copies `data-src` to `src` when the category is allowed and clears it on
revocation, watching DOM mutations across route changes. While blocked, the
empty `<iframe>` stays in the page. Add `data-vendor` with a vendor ID to also
block the iframe when that vendor is switched off.

Set `iframeBlocker: false` under `inth` to disable the blocker.

## Verify

View page source in a private window under an opt-in policy and confirm no
iframe carries a `src` for `youtube-nocookie.com` or `google.com/maps`, and no
requests appear in the Network tab. Allow the category and save to load the
iframe, then withdraw it and save to confirm the page reloads without the
embed. See the [YouTube](/docs/integrations/youtube) and
[Google Maps](/docs/integrations/google-maps) guides for sizing and titles.
