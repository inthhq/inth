Customize the Inth banner and preference dialog in Nuxt by setting theme
tokens, layout presentation, and component part attributes under `inth` in
`nuxt.config.ts`.

## Pick the right option

| You want to change | Use |
| --- | --- |
| Colors, fonts, radius, spacing, or motion | `tokens` |
| Banner shape, position, button order, or blocking | `presentation` |
| Classes or attributes on a component part | `components` |
| Light or dark palette | `colorScheme` and `theme.dark` |
| Banner and dialog text | Your Inth project's translations |
| Full markup | [Headless](/docs/frameworks/nuxt/headless) |

All of these options are plain data and work directly in `nuxt.config.ts`. See
[customize the interface](/docs/customization/overview) and
[banner designs](/docs/customization/recipes) for five ready-made designs
(`examples/showcase-nuxt-theme` combines them in one Nuxt app).

## Set theme tokens

`tokens` configures Inth's CSS variables using variable names without the
leading `--`:

{/* example: fragment */}

```ts title="nuxt.config.ts"
export default defineNuxtConfig({
	inth: {
		tokens: {
			'inth-primary': '#6943a3',
			'inth-primary-hover': '#533285',
			'inth-radius-lg': '18px',
			'inth-text-on-primary': '#ffffff',
		},
	},
});
```

The Nuxt plugin writes every token (including defaults) into a
`<style id="inth-css-vars">` tag in `<head>` on every page, carrying your
`nonce` if configured. During SSR and prerendering, the tag ships in the first
HTML so the banner paints with your colors right away. Because a `:root` rule
in your own stylesheet can lose on cascade order, set token values through
`tokens`. See [theme tokens](/docs/customization/tokens).

## Change the banner layout

`presentation.prompt` configures the banner's `variant`, `position`, `layout`,
`primaryActions`, `direction`, `uiProfile`, and `blocking`.
`presentation.preferences` sets the same layout fields for the dialog:

{/* example: fragment */}

```ts title="nuxt.config.ts"
export default defineNuxtConfig({
	inth: { presentation: { prompt: { position: 'bottom', variant: 'bar' } } },
});
```

Valid positions depend on `variant`: `bar` accepts `top` or `bottom`; `wall`
accepts `center`; `widget` accepts the four corners; `floating` accepts the
four corners plus `top-center` and `bottom-center`. The policy keeps final
authority: a choice wall always blocks, a notice never blocks, and the policy
restores required buttons omitted from `layout`.

## Style one part of a component

`components` binds Vue attributes (`class`, `style`, not React's `className`)
via `v-bind` to named [component parts](/docs/customization/slots):

{/* example: fragment */}

```ts title="nuxt.config.ts"
export default defineNuxtConfig({
	inth: {
		components: {
			banner: { card: { class: 'brand-consent-card' } },
			trigger: { root: { 'aria-label': 'Cookie settings' } },
		},
	},
});
```

Style the `ConsentGate` placeholder via `components['consent-gate'].root`,
`.title`, and `.button`.

When using Tailwind CSS, put part classes under `inth` in `app/app.config.ts`
rather than `nuxt.config.ts` so Tailwind scans them. The module merges both.
See [Tailwind CSS](/docs/customization/tailwind) and
[class names and CSS-in-JS](/docs/customization/class-names).

## Turn on dark mode

Set `colorScheme` under `inth` in `nuxt.config.ts` to `'light'`, `'dark'`,
`'system'`, or leave it unset to follow a `dark` class on `<html>`. Inth ships
a built-in dark palette, and `theme` (including `theme.dark`) overrides
`tokens` per scheme. For `'dark'` and `'system'`, the module injects an inline
`<head>` script that sets the class before first paint. Set
`colorScheme: null` under `inth` in `nuxt.config.ts` or `app/app.config.ts`
(not inline module options, where Nuxt drops `null`) to manage `inth-dark`
yourself. See [dark mode](/docs/customization/dark-mode).

## Change the copy

Edit banner and dialog text in your Inth project's translations. Add links to
legal pages with `legalLinks` and `bannerLegalLinks`:

{/* example: fragment */}

```ts title="nuxt.config.ts"
export default defineNuxtConfig({
	inth: {
		bannerLegalLinks: ['privacyPolicy'],
		legalLinks: { privacyPolicy: { href: '/privacy' } },
	},
});
```

See [translations](/docs/frameworks/nuxt/translations) and
[copy and translations](/docs/customization/translations).

## Other display options

| Option | What it does |
| --- | --- |
| `showTrigger` | Renders the floating [`ConsentDialogTrigger`](/docs/frameworks/nuxt/components/consent-dialog-trigger) from `InthProvider`. |
| `triggerDefaultPosition`, `triggerSize`, `triggerIcon`, `triggerShowWhen` | Positions and styles the floating trigger. |
| `hideBranding`, `bannerHideBranding`, `dialogHideBranding` | Hides the "Consent by" tag. |
| `disableAnimation` | Disables banner and dialog animations. See [motion and animation](/docs/customization/motion). |
| `consentCategories` | Limits categories shown in preferences within the policy's scope. |

## Check the result

Run `nuxt dev` and open the app in a private window. View page source and
confirm `<style id="inth-css-vars">` contains your token values.
