Serve consent banner and dialog copy in each visitor's language from server
HTML and keep it synced with your Nuxt app's locale switcher.

## Where the text comes from

Banner, dialog, and IAB copy comes from the translations in your Inth project
and arrives with the policy. Edit copy in Inth rather than in Nuxt code;
`@inth/nuxt` has no message override option.

See [copy and translations](/docs/customization/translations) for message keys
and button label guidance.

## How Inth picks the language

The incoming `Accept-Language` header decides:

- In default `manifest()` mode, the Nuxt server reads `Accept-Language` during
  SSR and resolves copy from the bundled or cached manifest so the first HTML
  ships localized with no translations in the browser bundle.
- In `hosted()` mode, SSR forwards `Accept-Language` to Inth's `/v1/consent/init`.
- In `manifest({ resolve: 'browser' })` mode, the browser reads
  `navigator.language` and loads non-English copy on demand from your site.

On prerendered and cached routes, the browser calls `/api/inth/v1/consent/init` after
hydration using its own `Accept-Language` header. When a language has no
translation in your project, the policy's fallback language applies.
Right-to-left languages render with `dir="rtl"` while keeping the banner in
the same corner.

## Follow your site's language

Bind `InthProvider`'s `language` prop to your current locale (such as from
`@nuxtjs/i18n`). Changing the prop stores the locale and re-resolves the
policy to fetch updated copy:

{/* example: fragment */}

```vue
<InthProvider :language="locale" />
```

From a custom language switcher, assign the locale to the auto-imported
`useConsentLanguage()`. Assigning a new language fetches updated copy;
assigning the current language does nothing:

<include src="../../shared/examples/nuxt/language-switcher.mdx" />

The assignment alone loads the new copy. The extra `kernel.commands.init()`
call in the snippet repeats the request and is not required.

## Text that does not come from translations

`ConsentDialogLink` and the `ConsentGate` placeholder read their defaults from
translations (English until init finishes). One option must be localized in
code when your site supports multiple languages:

| Text | Where | How to change it |
| --- | --- | --- |
| "Open privacy settings" | `ConsentDialogTrigger` label | Set `triggerAriaLabel` under `inth`. |

## Verify

Run `curl -H 'Accept-Language: de' <your-url>` against a page under an opt-in
policy and confirm the server HTML shows German copy (if translated in Inth).
Switch locales in the browser and confirm banner and dialog copy updates
without a reload.
