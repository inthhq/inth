Register app-wide callbacks under `inth.callbacks` in `app/app.config.ts` to
react to consent decisions, permission changes, revocation reloads, and
errors.

## Register callbacks

Because callbacks are functions, put them in `app/app.config.ts`, never in
`nuxt.config.ts` (which serializes to JSON and strips functions). Keep your
callbacks in a dedicated module:

<include src="../../shared/examples/nuxt/callbacks.mdx" />

Pass them alongside `scripts` in `app/app.config.ts`:

{/* example: fragment */}

```ts title="app/app.config.ts"
export default defineAppConfig({ inth: { callbacks, scripts } });
```

The module wires callbacks once when its plugin initializes in the browser.

## Available callbacks

| Callback | Runs when | Receives |
| --- | --- | --- |
| `onChoiceRecorded` | A visitor clicks Accept All, Reject All, or Save Settings in stock UI or via `useConsentSave()`. | `snapshot`, `confirmed` (categories covered by the action), and `actionAt` |
| `onPermissionsChanged` | Any effective permission changes value. | `snapshot` and `previous` (permissions before the change) |
| `onBeforeConsentRevocationReload` | A save withdraws a granted category or vendor, right before Inth reloads the page. | `preferences` (permissions after the save) |
| `onError` | A consent command fails, such as a rejected save request. | `error` (message string) |

## onChoiceRecorded or onPermissionsChanged

`onChoiceRecorded` runs only for explicit visitor actions. Use it to track
consent decisions or log opt-in rates.

`onPermissionsChanged` also fires when a stored choice expires, a new policy
applies, or a browser signal such as Global Privacy Control changes without
visitor input. Use it to gate runtime code, not to record user decisions.

Dismissing a notice triggers neither callback because it records no choice and
changes no permission. Subscribe to notice dismissals with
`useConsentKernel().events.on('notice:dismissed', listener)`. See
[a permission is not a recorded choice](/docs/concepts/how-consent-works#a-permission-is-not-a-recorded-choice).

## Before a revocation reload

Because removing a `<script>` tag cannot stop already-running code, Inth
reloads the page after a visitor withdraws a granted category or vendor.
`onBeforeConsentRevocationReload` runs synchronously right before that reload.
Use it for quick vendor shutdown calls; the reload does not wait for async
work. Set `reloadOnConsentRevoked: false` to handle revocation yourself.

## Verify

Open DevTools Console, load a page, and click **Accept All**. Confirm
`onChoiceRecorded` and `onPermissionsChanged` log once. Reload and confirm
neither fires again. Open preferences, withdraw a category, and save to
confirm `onBeforeConsentRevocationReload` runs before the page reloads.
