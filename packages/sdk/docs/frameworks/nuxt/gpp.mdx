Enable `window.__gpp` (GPP 1.1 CMP API) in your Nuxt app so ad tech such as
Prebid.js and Google Ad Manager can read US state privacy signals and TCF EU
consent strings.

## Turn on GPP

Set `gpp: true` under `inth` in `nuxt.config.ts`:

```ts title="nuxt.config.ts"
export default defineNuxtConfig({
	inth: {
		// Loads @inth/sdk/iab/gpp and installs `__gpp` once the app mounts.
		gpp: true,
	},
	modules: ['@inth/nuxt'],
});
```

`@inth/nuxt` lazy-loads `@inth/sdk/iab/gpp` and installs `__gpp` in the
browser after mount, keeping it out of server HTML and out of bundles when
`gpp` is unset. No extra package is needed. Because GPP options are plain
data, `gpp` also works under `inth` in `app/app.config.ts`.

The GPP string follows the policy and location resolved by the module from
your host or CDN location headers. See
[geography headers](/docs/frameworks/nuxt/geography-headers).

To include the TCF EU section for visitors under an `iab` policy, also enable
[IAB TCF](/docs/frameworks/nuxt/iab).
