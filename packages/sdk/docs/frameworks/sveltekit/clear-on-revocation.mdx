## Configure cleanup

Gating stops new requests, but it leaves the cookies and storage keys a vendor
already wrote. List the ones each optional category owns and pass them to
`InthProvider` in `src/routes/+layout.svelte`. When that category is denied,
Inth deletes them:

{/* example: fragment */}

```svelte title="src/routes/+layout.svelte (partial)"
<script lang="ts">
	import type { ConsentManagerOptions } from '@inth/svelte';
	import { InthProvider } from '@inth/svelte/kit';

	const clearOnRevocation: ConsentManagerOptions['clearOnRevocation'] = {
		measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
		marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
	};
</script>

<InthProvider state={data.consent} {scripts} {clearOnRevocation}>
```

The provider reads `clearOnRevocation` once, when it is created. Cleanup runs
in the browser only, never during server rendering. For a shared
runtime, pass it to `createConsentRuntime()` instead, not to a provider that
borrows the runtime.
