Keep third-party iframes out of your TanStack Start pages until the visitor allows their consent category.

## Pick a method

| Method | Use it when |
| --- | --- |
| `ConsentGate` | You render the iframe in a React component and want a placeholder until the visitor allows its category. |
| The iframe blocker | The iframe comes from HTML you do not render with React, such as CMS or Markdown content. |

Both keep `src` off the iframe until consent allows it, preventing requests to the embed host before consent.

## Gate an embed with ConsentGate

Wrap the iframe in `ConsentGate` in any route rendered under `InthProvider`:

<include src="../../shared/examples/tanstack-start/video-embed.mdx" />

Server HTML renders the placeholder, never the iframe, while `measurement` is denied. The placeholder displays a message and a [`ConsentDialogLink`](/docs/frameworks/tanstack-start/components/consent-dialog-link) until the visitor allows `measurement`. If consent is later withdrawn, React unmounts the iframe.

Pick the category matching what the embed does: YouTube uses `measurement` because its player tracks views, while maps and chat widgets usually belong under `functionality` or `experience`. See [ConsentGate](/docs/frameworks/tanstack-start/components/consent-gate).

## Gate an iframe with the iframe blocker

`InthProvider` enables the iframe blocker in the browser by default. Put the URL in `data-src` instead of `src` and add `data-category`:

{/* example: fragment */}

```html title="Markup from your CMS"
<iframe
  data-src="https://www.google.com/maps/embed?pb=YOUR_EMBED_ID"
  data-category="functionality"
  title="Store map"
></iframe>
```

Server HTML ships without `src`, so nothing loads before hydration. After hydration, Inth copies `data-src` to `src` when allowed and clears `src` when revoked, watching the DOM so iframes added during client navigation work too. Add `data-vendor` with a vendor ID to also gate on individual vendor toggles.

To disable the blocker, pass `options={{ iframeBlocker: false }}` on `InthProvider`.

## Verify the embeds

Open the production build in a private window with DevTools open under an opt-in policy.

1. View page source and confirm no iframe has a `src` pointing at `youtube-nocookie.com` or `google.com/maps`, and DevTools Network shows zero requests to them.
2. Allow the embed's category and save. Confirm the iframe loads.
3. Withdraw the category and save. Confirm the page reloads without the embed.

See the [YouTube](/docs/integrations/youtube) and [Google Maps](/docs/integrations/google-maps) guides for responsive sizing and accessible titles.
