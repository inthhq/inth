Let visitors allow a category such as marketing while still disabling individual vendors inside it.

<import src="../../shared/scripts/vendor-consent.mdx#how" />

## Declare the vendors

Declaring a vendor enables vendor switches. Built-in `@inth/integrations` helpers automatically list their vendor by name once switches are active, so declare vendors only for custom scripts or to override a helper's display name and privacy policy URL.

Define `vendors` next to `scripts` in `src/routes/__root.tsx`, matching the `vendor` slug on each script:

{/* example: fragment */}

```ts title="src/routes/__root.tsx (partial)"
import type { Vendor } from '@inth/tanstack-start';

const vendors: Vendor[] = [
	{
		id: 'x-pixel',
		name: 'X Pixel',
		category: 'marketing',
		privacyPolicyUrl: 'https://x.com/privacy',
	},
];
```

Pass `vendors` as a top-level prop on `InthProvider`:

{/* example: fragment */}

```tsx title="src/routes/__root.tsx (partial)"
<InthProvider
	state={consent}
	scripts={scripts}
	vendors={vendors}
>
```

`InthProvider` accepts `vendors` at the top level, not inside `options`.

`ConsentGate` checks a category only. To gate a component on one vendor, check `useVendorAllowed('youtube')` and render when it returns `true`. See [Embeds](/docs/frameworks/tanstack-start/embeds) for the iframe blocker's `data-vendor` attribute.

## What the preference dialog shows

`ConsentDialog` and `ConsentWidget` list each declared vendor under its category with its own switch.

## Build your own vendor switch

`useVendorDraft()` from `@inth/tanstack-start` reads and stages vendor toggles on the same draft used by category switches so one save records both. `useVendorAllowed(id)` returns whether a vendor can run right now: it is declared, its category is allowed, and the visitor has not switched it off.

{/* example: fragment */}

```tsx title="src/components/x-pixel-switch.tsx (partial)"
import { useVendorAllowed, useVendorDraft } from '@inth/tanstack-start';

const { vendors, setVendor, save } = useVendorDraft();
const xPixelAllowed = useVendorAllowed('x-pixel');

<input
  type="checkbox"
  checked={vendors['x-pixel'] ?? true}
  onChange={(event) => setVendor('x-pixel', event.target.checked)}
/>
<button type="button" onClick={() => save()}>Save</button>
```

`save()` resolves `{ ok: false }` without recording anything if the policy or vendor list changed during editing; call `reset()` to reseed. `useDeclaredVendors()` returns the declared list, and `useVendorChoice()` returns the recorded vendor denials or `null` before a choice is recorded. To list vendors under each category in a custom preference center, call `useVendorsListedUnder(category)` from `@inth/tanstack-start/headless`. A vendor known only from a script slug stays listed after being turned off so the visitor can turn it back on.
