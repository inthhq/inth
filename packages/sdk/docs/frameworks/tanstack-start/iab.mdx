Add IAB Transparency and Consent Framework support to a TanStack Start app inside `InthProvider`.

## Before you start

Enable IAB in your Inth project, assign the `iab` model to the relevant policy, and obtain a registered CMP ID from IAB Europe at [register.consensu.org/CMP](https://register.consensu.org/CMP). Every TC String names the CMP that wrote it, so never use an unregistered ID in production.

The IAB components ship with `@inth/tanstack-start` without extra installs. With the quickstart root loader, the server resolves IAB visitors alongside standard visitors using the policy manifest.

## Render the IAB banner and dialog

The built-in `ConsentBanner` and `ConsentDialog` stay closed under the `iab` model. Mount the IAB components inside `InthProvider` next to them:

Render `<IABConsent cmpId={YOUR_CMP_ID} />` in `src/routes/__root.tsx` next to `ConsentBanner`. Checking `useModel()` mounts IAB components only for visitors under an `iab` policy.

The IAB banner and dialog render their own `<style>` elements by default, putting banner styles into server HTML and loading dialog styles on open.

## Load an external stylesheet

On Tailwind CSS 3, or when placing Inth in a named cascade layer, link the base stylesheet followed by the IAB stylesheet in `head()` and set `options={{ styles: false }}` on `InthProvider`:

{/* example: fragment */}

```tsx title="src/routes/__root.tsx (partial)"
import consentCss from '@inth/tanstack-start/styles.css?url';
import iabCss from '@inth/tanstack-start/iab/styles.css?url';

// In head().links:
{ href: consentCss, rel: 'stylesheet' },
{ href: iabCss, rel: 'stylesheet' },

// On InthProvider:
options={{ styles: false }}
```

Tailwind CSS 3 also requires the [PostCSS plugin](/docs/customization/tailwind#set-up-tailwind-css-3).

## Restrict how vendors use a purpose

Publisher restrictions override a vendor's declared legal basis for a purpose. Pass them to `IABProvider` via `publisherRestrictions`. Replace the placeholder vendor IDs below with vendors from your Global Vendor List whose declarations permit each restriction:

{/* example: fragment */}

```tsx title="src/components/iab-consent.tsx"
const publisherRestrictions = [
  // Vendors 10 and 755 may not use purpose 4.
  { purposeId: 4, restrictionType: 0 as const, vendorIds: [10, 755] },
  // Vendor 755 must use legitimate interest for purpose 7.
  { purposeId: 7, restrictionType: 2 as const, vendorIds: [755] },
];

<IABProvider cmpId={cmpId} publisherRestrictions={publisherRestrictions}>
```
