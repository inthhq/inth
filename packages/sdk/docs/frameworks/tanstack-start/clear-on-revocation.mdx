Delete first-party cookies and Web Storage keys owned by an optional category when a visitor revokes consent in TanStack Start.

## Configure cleanup

Gating stops new vendor requests, but leaves behind cookies and storage entries already written. List the keys each optional category owns and pass `clearOnRevocation` as a top-level prop on `InthProvider` in `src/routes/__root.tsx`:

{/* example: fragment */}

```tsx title="src/routes/__root.tsx (partial)"
import type { ClearOnRevocationConfig } from '@inth/tanstack-start';

const clearOnRevocation: ClearOnRevocationConfig = {
	measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
	marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
};

<InthProvider
	state={consent}
	scripts={scripts}
	clearOnRevocation={clearOnRevocation}
>
```

`InthProvider` accepts `clearOnRevocation` at the top level, not inside `options`, and reads it once on mount; remount it to update the list.
