Customize Inth banner and dialog copy in TanStack Start, override messages per language, and switch languages at runtime.

## Where the copy comes from

The banner, dialog, widget, and gate placeholder read from the translations configured in your Inth project. Edit wording in Inth first so copy changes apply without a deploy.

Override copy in code in two places:

- `options.i18n` on `InthProvider` replaces a message everywhere it appears.
- Text props on `ConsentBanner` replace copy on one banner.

See [Copy and translations](/docs/customization/translations) for message keys and merge rules.

## How Inth picks the language

In the [quickstart](/docs/frameworks/tanstack-start/quickstart) setup, the root loader reads the request `Accept-Language` header and resolves policy copy from the bundled manifest on the server, so the banner arrives in the visitor's language in the first HTML.

Override the detected language in one of three places:

- `consentRequestMiddleware({ language })` in `src/start.ts` fixes one language for every request.
- `createConsentStateHandler({ language })` fixes one language for the root loader.
- `resolveConsent({ language })` from `@inth/tanstack-start/server`, inside a custom server function, picks a language per request such as a URL locale.

When consent resolves in the browser, such as on [prerendered and static pages](/docs/frameworks/tanstack-start/rendering#spa-mode-prerendered-pages-and-static-hosts), `/v1/consent/init` sends the browser's `Accept-Language` header. If your project has no translation for the requested language, Inth returns its fallback language.

The banner, dialog, and widget set `dir` from the active language. Right-to-left languages such as Arabic and Hebrew render with `dir="rtl"` while keeping the banner in the same corner.

## Change the copy in code

Define messages in a separate module:

<include src="../../shared/examples/tanstack-start/i18n.mdx" />

Import it in `src/routes/__root.tsx` and pass it under `options` on `InthProvider`:

{/* example: fragment */}

```tsx title="src/routes/__root.tsx"
<InthProvider
  state={consent}
  scripts={scripts}
  options={{ i18n }}
>
```

Import `i18n` in the root route component rather than returning it from a loader or server function so server and browser renders share the same copy without bloating serialized loader data.

For the active language, your messages replace project copy key by key while omitted keys keep your project wording. `InthProvider` reads `i18n` once on mount and logs a development warning if it changes later. `i18n.locale` sets the language (`en` by default) when no server state or Inth project supplies one, such as in `testing()` mode.

## Change one banner's copy

`ConsentBanner` accepts `title`, `description`, `acceptButtonText`, `rejectButtonText`, `customizeButtonText`, and `dismissButtonText`. These props override text in every language, so pass strings already translated for the current page:

{/* example: fragment */}

```tsx
<ConsentBanner
	title="Cookies on this site"
	rejectButtonText="Reject optional"
/>;
```

## Switch the language at runtime

`useSetLanguage()` updates the active language and `useInit()` resolves the policy again to fetch translations for that language:

<include src="../../shared/examples/tanstack-start/language-switcher.mdx" />

Calling `setLanguage()` without `init()` leaves on-screen text unchanged. Your `i18n` overrides for the new language apply on top of the fetched copy. Render the switcher inside `InthProvider`.

If your app manages locale through an i18n library, run the same two calls when the locale changes and pass that locale as `language` to `resolveConsent` so server HTML matches.

## Verify

1. Under a policy showing a banner, run `curl -H 'Accept-Language: de' <your-url>`. If your project translates German, confirm the banner in the HTML is German.
2. Open the page in a browser and confirm any string overridden in `i18n` appears in the banner.
3. Switch languages with your switcher and confirm DevTools Network shows a new `/v1/consent/init` request updating the banner and dialog without reloading.
