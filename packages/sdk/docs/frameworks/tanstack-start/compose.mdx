Build a TanStack Start consent banner with your own markup and design system buttons using `ConsentBanner` compound parts from `@inth/tanstack-start`.

## When to compose

<import src="../../shared/react/compose.mdx#when-to-compose" />

For a banner sharing no markup with the built-in UI, use [headless hooks](/docs/frameworks/tanstack-start/headless). To change a single class, token, or prop, see [Customize](/docs/frameworks/tanstack-start/customize).

## Compose the banner

`CookieBanner` keeps the built-in card, title, and copy while rendering each policy action with your own `BrandButton`:

<include src="../../shared/examples/tanstack-start/compose-button.mdx" />

<include src="../../shared/examples/tanstack-start/compose-banner.mdx" />

`@inth/tanstack-start` re-exports all `@inth/react` components, so `ConsentBanner` and its parts come from the same import as `InthProvider`.

In `src/routes/__root.tsx` from the [quickstart](/docs/frameworks/tanstack-start/quickstart), import `CookieBanner` from `../components/cookie-banner` and render it in place of `ConsentBanner`, next to `ConsentDialog`:

{/* example: fragment */}

```tsx title="src/routes/__root.tsx (partial)"
<InthProvider state={consent} scripts={scripts}>
	<Outlet />
	<CookieBanner />
	<ConsentDialog />
	<footer>
		<ConsentDialogLink>Privacy settings</ConsentDialogLink>
	</footer>
</InthProvider>;
```

Because the root route runs on the server, `CookieBanner` renders in the initial server HTML just like the built-in banner.

`@inth/tanstack-start` exports `ConsentDialog` and `ConsentWidget` with their parts. To import non-deferred dialog parts, import from `@inth/react/components/consent-dialog`. See [ConsentDialog](/docs/frameworks/tanstack-start/components/consent-dialog) and [ConsentWidget](/docs/frameworks/tanstack-start/components/consent-widget) for every part and slot.
