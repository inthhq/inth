Change the colors, typography, layout, button styles, and wording of the Inth banner and dialog in a TanStack Start app.

## Pick the right tool

| Change | Use |
| --- | --- |
| Brand colors, fonts, radius, spacing | [Theme tokens](#change-colors-fonts-and-radius) |
| Which button is filled or outlined | [`consentActions`](#style-the-action-buttons) |
| Banner shape and position | [`ConsentBanner` props or `presentation`](#change-the-banner-shape) |
| One element of a component | [Component parts](#style-one-component-part) |
| Light and dark colors, animation | [Dark mode and motion](#turn-on-dark-mode-and-change-motion) |
| Labels and languages | [Copy and translations](#change-the-copy) |
| Different markup entirely | [Headless](/docs/frameworks/tanstack-start/headless) |

`@inth/tanstack-start`'s `InthProvider` forwards everything under `options` to `@inth/react`'s `InthProvider`, so all React styling options work identically. See [Customization](/docs/customization/overview) and the [design gallery](/docs/customization/recipes) for tested banner designs.

## Load the stylesheet yourself

The [quickstart](/docs/frameworks/tanstack-start/quickstart) root route links no stylesheet: `ConsentBanner`, `ConsentDialog`, and other built-in components render their own `<style>` elements, putting banner CSS directly into the server HTML inside `@layer components` so Tailwind CSS 4 utilities override it cleanly.

Load the stylesheet yourself on Tailwind CSS 3 to place Inth's rules in a named cascade layer. Set `options={{ styles: false }}` on `InthProvider` and link the stylesheet in `head()`:

{/* example: fragment */}

```tsx title="src/routes/__root.tsx (partial)"
import consentCss from '@inth/tanstack-start/styles.css?url';

// In createRootRoute({ head: () => ({ links: [...] }) }):
{ href: consentCss, rel: 'stylesheet' }

// On InthProvider:
options={{ styles: false }}
```

You can also `@import` it at the top of your global stylesheet above `@tailwind` directives. Tailwind CSS 3 also requires the PostCSS plugin; see [Tailwind CSS](/docs/customization/tailwind#set-up-tailwind-css-3) and [Stylesheets and CSS layers](/docs/customization/stylesheets).

## Change colors, fonts and radius

Colors, radii, shadows, typography, and motion come from `--inth-*` CSS variables. Choose one of two approaches:

- **Set the variables in CSS.** Ships zero extra JavaScript to the browser:

  ```css title="src/styles.css"
  :root {
    --inth-primary: #2f6f4e;
    --inth-primary-hover: #24563c;
    --inth-text-on-primary: #fff;
    --inth-radius-lg: 4px;
  }
  ```

- **Render `ConsentTheme` in the root route.** Use this when the theme lives in TypeScript. The root route renders it into the initial server HTML, and the browser also includes the theme generator.

  {/* example: fragment */}

  ```tsx title="src/consent-theme.ts"
  import { defineTheme } from '@inth/tanstack-start';

  export const theme = defineTheme({
    colors: { primary: '#2f6f4e', primaryHover: '#24563c' },
    radius: { lg: '4px' },
  });
  ```

  In `src/routes/__root.tsx`, render `<ConsentTheme theme={theme} />` from `@inth/tanstack-start` inside `<head>`, after `<HeadContent />`.

`ConsentTheme` outranks a plain `:root` rule regardless of load order. If you mix both, use `:root:root` in CSS to beat `ConsentTheme`, or keep all tokens in one place. See [Theme tokens](/docs/customization/tokens).

## Style the action buttons

`consentActions` sets button styling per role: `default`, `primary`, `accept`, `reject`, `customize`, and `dismiss`. Pass it in `InthProvider`'s `options`:

{/* example: fragment */}

```tsx title="src/routes/__root.tsx"
<InthProvider
  state={consent}
  scripts={scripts}
  options={{
    theme: {
      consentActions: {
        primary: { variant: 'primary', mode: 'filled' },
      },
    },
  }}
>
```

`options.theme` reads only `consentActions` and slot styles; token fields passed there are ignored with a development warning.

## Change the banner shape

Pass `variant` (`floating`, `bar`, `widget`, or `wall`) and `position` to `ConsentBanner`, such as `<ConsentBanner variant="bar" position="bottom" />`, or set `options.presentation.prompt` on `InthProvider` for a global default. See [ConsentBanner](/docs/frameworks/tanstack-start/components/consent-banner#variants).

## Style one component part

Configure slots under `options.components` on `InthProvider`, keyed by component and part:

{/* example: fragment */}

```tsx title="src/routes/__root.tsx"
options={{
  components: {
    banner: {
      card: { className: 'rounded-none shadow-none' },
    },
  },
}}
```

See [Component parts](/docs/customization/slots) for all slot keys (`ConsentGate` uses `components['consent-gate'].root`, `.title`, and `.button`) and `noStyle`, and [Class names and CSS-in-JS](/docs/customization/class-names) for styling libraries.

## Turn on dark mode and change motion

Pass the same `colorScheme` to `ConsentTheme` and `InthProvider` `options`. Omit it to follow a `dark` class on `<html>`, and configure dark colors via `theme.dark`. See [Dark mode](/docs/customization/dark-mode).

Set `options.disableAnimation` on `InthProvider` to turn off animations globally, or pass `disableAnimation` to a single banner or dialog. See [Motion and animation](/docs/customization/motion).

## Change the copy

Labels, descriptions, and languages come from your Inth project translations and `options.i18n` on `InthProvider`. For the active language, `i18n.messages` replaces project copy key by key while keeping omitted keys intact. See [Copy and translations](/docs/customization/translations).

## Check the result

Clear site data and reload under a policy showing a banner. View page source: with an awaited loader, the banner appears in server HTML with your classes and, if used, `<style id="inth-theme">`. Inspect the preferences dialog too, check narrow viewports, verify keyboard focus, and test primary button contrast.
