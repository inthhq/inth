Read consent state, open the preference center, and record visitor actions in TanStack Start components with hooks from `@inth/tanstack-start`.

## Read only the state you need

`@inth/tanstack-start` re-exports every hook from `@inth/react`. Each hook reads the runtime from `InthProvider`, so call hooks in any route or component rendered inside `InthProvider`.

{/* example: fragment */}

```tsx title="src/components/optional-feature.tsx"
import { useConsent } from '@inth/tanstack-start';

export function OptionalFeature() {
	const allowed = useConsent('marketing');
	return allowed ? <div>Optional marketing content</div> : null;
}
```

During SSR, hooks read the state resolved by the root loader so server HTML matches the first client render.

## Open the preference dialog

Set the active surface to `'dialog'` from any component inside `InthProvider`:

{/* example: fragment */}

```tsx title="src/components/privacy-menu-item.tsx"
import { useSetActiveUI } from '@inth/tanstack-start';

export function PrivacyMenuItem() {
	const setActiveUI = useSetActiveUI();
	return (
		<button type="button" onClick={() => setActiveUI('dialog')}>
			Cookie preferences
		</button>
	);
}
```

Use `ConsentDialogLink` when you only need a footer or inline button without calling a hook.

## Save from a visitor action

{/* example: fragment */}

```tsx title="src/components/reject-button.tsx"
import { useSaveConsents } from '@inth/tanstack-start';

export function RejectButton() {
	const save = useSaveConsents();
	return (
		<button type="button" onClick={() => void save('none')}>
			Reject optional
		</button>
	);
}
```

## Where hooks do not work

Hooks require React context and cannot run inside loaders, `beforeLoad`, server functions, or server routes. On the server, read request consent state with `resolveConsent` from `@inth/tanstack-start/server`.
