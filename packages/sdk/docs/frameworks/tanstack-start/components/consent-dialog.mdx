Mount `ConsentDialog` once inside `InthProvider`, next to `ConsentBanner`, to provide a modal preference center.

## Render the preference dialog

`ConsentDialog` opens whenever `dialog` becomes the active surface: from the banner's Customize button, `ConsentDialogLink`, `ConsentDialogTrigger`, or your own component via `useSetActiveUI`:

{/* example: fragment */}

```tsx title="src/components/privacy-menu-item.tsx"
import { useSetActiveUI } from '@inth/tanstack-start';

export function PrivacyMenuItem() {
	const setActiveUI = useSetActiveUI();
	return (
		<button type="button" onClick={() => setActiveUI('dialog')}>
			Cookie preferences
		</button>
	);
}
```

Under an `iab` policy, `ConsentDialog` stays closed; mount `IABConsentDialog` from [IAB TCF](/docs/frameworks/tanstack-start/iab). Pass provider options such as `preloadDialog` via `InthProvider`'s `options` prop.
