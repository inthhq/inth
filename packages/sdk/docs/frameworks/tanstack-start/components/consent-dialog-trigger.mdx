Add a draggable floating button or multi-action toolbar inside `InthProvider` so visitors can reopen the preference center from any route.

## Add a floating preferences button

Render `ConsentDialogTrigger` once inside `InthProvider`, next to `ConsentBanner` and `ConsentDialog`:

{/* example: fragment */}

```tsx title="src/routes/__root.tsx"
import { ConsentDialogTrigger } from '@inth/tanstack-start';

// Inside InthProvider, next to ConsentDialog:
<ConsentDialogTrigger showWhen="after-prompt" />;
```

`showWhen="after-prompt"` hides the button while a choice or notice is owed so it never overlaps the banner. It renders nothing until a policy resolves or under a policy that owes no rights.

## Add your own controls with the toolbar

`ConsentDialogTriggerToolbar` combines one built-in preferences action with app-owned controls such as a theme toggle. Import it from `@inth/tanstack-start` and give each action a stable `id`, accessible `label`, `icon`, and `onSelect` callback.
