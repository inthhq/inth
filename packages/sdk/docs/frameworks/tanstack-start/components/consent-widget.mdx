Embed category switches and Save, Accept All, and Reject All actions directly on a TanStack Start privacy or settings route.

## Embed the preference center in a page

`ConsentWidget` renders the preference center inline without a modal. Keep `ConsentDialog` mounted in the root route so the banner's Customize button and footer links still open the modal:

{/* example: fragment */}

```tsx title="src/routes/privacy.tsx"
import { ConsentWidget } from '@inth/tanstack-start';
import { createFileRoute } from '@tanstack/react-router';

const PrivacyPage = () => (
	<main>
		<h1>Privacy</h1>
		<section aria-labelledby="cookie-preferences">
			<h2 id="cookie-preferences">Cookie preferences</h2>
			<ConsentWidget />
		</section>
	</main>
);

export const Route = createFileRoute('/privacy')({ component: PrivacyPage });
```

`ConsentWidget` shares `InthProvider`'s policy, translations, and Inth project connection without a second provider. Import `useConsentDraft` and `ConsentDraftProvider` from `@inth/tanstack-start`.
