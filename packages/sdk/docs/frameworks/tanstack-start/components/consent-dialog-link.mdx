Add an unstyled button to your TanStack Start footer or legal menu so visitors can reopen preferences after closing the banner.

## Reopen preferences from your footer

The [quickstart](/docs/frameworks/tanstack-start/quickstart#resolve-consent-in-the-root-route) renders `ConsentDialogLink` inside the root route footer.

{/* example: fragment */}

```tsx title="src/components/site-footer.tsx"
import { ConsentDialogLink } from '@inth/tanstack-start';

export function SiteFooter() {
	return (
		<footer>
			<a href="/privacy">Privacy policy</a>
			<ConsentDialogLink className="footer-link">
				Privacy settings
			</ConsentDialogLink>
		</footer>
	);
}
```

Render your footer inside `InthProvider` with `ConsentDialog` mounted. `ConsentDialogLink` renders a `<button>` by default; pass `asChild` to render your own link element instead.

To avoid pulling the full adapter into a module that only renders the footer link, import from `@inth/tanstack-start/components/consent-dialog-link`.
