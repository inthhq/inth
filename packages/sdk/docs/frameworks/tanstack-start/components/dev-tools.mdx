## Render DevTools inside `InthProvider` in development

Render `DevTools` from `@inth/react/devtools` inside `InthProvider`, and load it
only in development builds with Vite's `import.meta.env.DEV`:

{/* example: fragment */}

```tsx title="src/components/consent-devtools.tsx"
import { lazy, Suspense } from 'react';

const DevTools = import.meta.env.DEV
	? lazy(() =>
			import('@inth/react/devtools').then(({ DevTools }) => ({
				default: DevTools,
			}))
		)
	: null;

export function ConsentDevTools() {
	return DevTools ? (
		<Suspense fallback={null}>
			<DevTools />
		</Suspense>
	) : null;
}
```

If your app already renders TanStack Devtools, add `inthDevtools()` to its
`plugins` instead, as shown below.
