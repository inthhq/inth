## Render DevTools inside `InthProvider` in development

Render `DevTools` from `@inth/react/devtools` inside `InthProvider`, gated on Vite's `import.meta.env.DEV` so production bundles never include it:

{/* example: fragment */}

```tsx title="src/components/consent-devtools.tsx"
import { lazy, Suspense } from 'react';

const DevTools = import.meta.env.DEV
	? lazy(() =>
			import('@inth/react/devtools').then(({ DevTools }) => ({
				default: DevTools,
			}))
		)
	: null;

export function ConsentDevTools() {
	return DevTools ? (
		<Suspense fallback={null}>
			<DevTools />
		</Suspense>
	) : null;
}
```

If your app already uses TanStack Devtools, register `inthDevtools()` in its `plugins` array instead, as shown below.
