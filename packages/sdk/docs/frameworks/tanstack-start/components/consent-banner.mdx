Render `ConsentBanner` once inside `InthProvider`, next to `ConsentDialog`, so visitors see the right prompt in the initial server HTML.

## Render the banner

The [quickstart](/docs/frameworks/tanstack-start/quickstart#resolve-consent-in-the-root-route) mounts `ConsentBanner` in `src/routes/__root.tsx`. With an awaited root loader, the banner ships in the first HTML for visitors who owe a choice.

{/* example: fragment */}

```tsx title="src/routes/__root.tsx"
import { ConsentBanner } from '@inth/tanstack-start';

// Inside InthProvider:
<ConsentBanner container={{ edge: 'bottom', type: 'banner' }} />;
```

The banner adapts to the active policy rule. A `choice` prompt displays Reject and Accept at equal prominence plus Customize when offered; Customize opens the choices inside the banner. A `notice` prompt displays an "OK" button and an opt-out link, "Do not sell or share my data", that opens the sale-and-sharing rights row inside the banner, where the visitor can opt out. The link never records an opt-out on its own and does not open `OptOutConfirmation` or the dialog. Programmatic calls to `useOptOut()` still opt out in one step. A rule with `prompt: 'none'`, or an unresolved policy, renders nothing.
