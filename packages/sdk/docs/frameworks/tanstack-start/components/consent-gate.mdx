Wrap third-party iframes or widgets in `ConsentGate` so they mount only when their consent category is allowed.

## Gate an embed behind consent

Render `ConsentGate` in any route inside `InthProvider`:

{/* example: fragment */}

```tsx title="src/components/product-video.tsx"
import { ConsentGate } from '@inth/tanstack-start';

export function ProductVideo() {
	return (
		<ConsentGate category="marketing" style={{ aspectRatio: '16 / 9' }}>
			<iframe
				src="https://www.youtube-nocookie.com/embed/VIDEO_ID"
				title="Product tour"
				allowFullScreen
			/>
		</ConsentGate>
	);
}
```

With an awaited root loader, server HTML contains the placeholder when the category is denied, or an empty wrapper when granted so the iframe mounts once after hydration. Ensure the category is included in your policy scope.
