Expose `window.__gpp` in a TanStack Start app so ad tech such as Prebid.js and Google Ad Manager can read US state opt-outs and the TCF EU consent string.

## What GPP does

`ConsentGPP` from `@inth/react/gpp` installs the GPP 1.1 CMP API on `window.__gpp` and keeps its GPP string synchronized with the visitor's consent state.

## Turn on GPP

Render `ConsentGPP` inside `InthProvider` in `src/routes/__root.tsx`:

{/* example: fragment */}

```tsx title="src/routes/__root.tsx"
import { ConsentGPP } from '@inth/react/gpp';

<InthProvider state={consent} scripts={scripts}>
	<ConsentGPP />
	<Outlet />
</InthProvider>;
```

`ConsentGPP` renders no markup. It registers `__gpp` in the browser on mount and removes it on unmount. Apps that do not import `@inth/react/gpp` bundle zero GPP code.

Pass any GPP option below as a prop, such as `<ConsentGPP usFallback="none" />`.

The GPP string follows the policy and location resolved by the root loader. US state codes come from your host's geo headers; see [Geography headers](/docs/frameworks/tanstack-start/geography-headers) if region detection is missing.

To populate the TCF EU section for visitors under an `iab` policy, also configure [IAB TCF](/docs/frameworks/tanstack-start/iab).
