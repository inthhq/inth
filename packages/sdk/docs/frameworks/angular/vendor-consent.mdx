## Declare the vendors

Declaring a vendor turns on vendor switches. Built-in `@inth/integrations`
helpers then list their own vendor by name, so you only declare a vendor for a
script of your own, or to replace a helper's name and privacy policy.

Declare the vendors next to the scripts, using the `vendor` slug each script
already carries:

<include src="../../shared/examples/angular/vendors.mdx" />

Then pass them to `provideInth()` in `src/app/app.config.ts`:

{/* example: fragment */}

```ts title="src/app/app.config.ts (partial)"
provideInth({ mode, scripts, vendors });
```

A new array passed to `ConsentManager.updateOptions({ vendors })` replaces the
declared vendors.

<import src="../../shared/scripts/vendor-consent.mdx#fields" />

<import src="../../shared/scripts/vendor-consent.mdx#targets" />

`<inth-consent-gate>` takes a `vendor` input as well as `category`, and waits
for both: `<inth-consent-gate category="marketing" vendor="x-pixel">`. For an
iframe you do not render, add `data-vendor` and use the iframe blocker; see
[embeds](/docs/frameworks/angular/embeds).

## What the preference dialog shows

`<inth-consent-dialog>` and `<inth-consent-widget>` list each declared vendor
under its category, with its own switch.

## Build your own vendor switch

`ConsentManager` stages vendor switches on the same draft as the category
switches. `selectedVendors()` has one value per declared vendor,
`setSelectedVendor(id, granted)` changes one, and `saveConsents('custom')`
records the draft:

<include src="../../shared/examples/angular/vendor-switch.mdx" />

`saveConsents('custom')` rejects when the policy changed since the draft
started. `vendorChoice().denied` lists the vendors the visitor recorded as
off, and `getDisplayedVendors(category)` returns the vendors to list under one
category. [ConsentManager](/docs/frameworks/angular/services#work-with-the-draft)
covers the draft.

## Check whether a vendor may run

`isVendorAllowed(id)` on `ConsentManager` returns `true` while the vendor may
run: it is declared, its category is allowed and the visitor has not switched
it off. It reads signals, so a template or `computed()` that calls it updates
when consent changes.
