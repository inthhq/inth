Test your Angular consent banner, dialog, widget, gate and IAB surfaces in
TestBed using the Angular CDK harnesses exported by `@inth/angular/testing`.

## Install the CDK

The harnesses require `@angular/cdk/testing` (an optional peer dependency of
`@inth/angular`). Install the CDK major version that matches Angular if it is
not already installed:

<CommandTabs command="@angular/cdk" mode="install" />

## Write a test

This test mounts the banner and dialog under `provideInth()` with `testing()`
so no network requests fire, then drives them with `ConsentBannerHarness` and
`ConsentDialogHarness`:

<include src="../../shared/examples/angular/harness-banner-test.mdx" />

Three setup details matter:

- **A policy rule.** Without `policy`, `testing()` uses the recommended rule
  pack. The explicit rule in the example requires opt-in for every visitor so
  the banner always renders.
- **`await fixture.whenStable()` before querying.** The runtime starts after
  the first render; waiting once lets the banner mount.
- **`disableAnimation: true`.** Removes entrance transitions so assertions
  see the settled state immediately and `getHarnessOrNull` returns `null`
  right after a choice.

Assert on `ConsentManager` as well as the DOM. Checking `has('marketing')`
after `acceptAll()` proves the choice was recorded.

## Find surfaces that render into the body

The banner, dialog, floating trigger and both IAB surfaces portal to `<body>`
outside your component, so query them with
`TestbedHarnessEnvironment.documentRootLoader(fixture)`.

The widget, consent gate, `inth-consent-button` buttons and `inthSwitch`
switches stay inside your component and use
`TestbedHarnessEnvironment.loader(fixture)`.

| Harness | Drives | Loader |
| --- | --- | --- |
| `ConsentBannerHarness` | `<inth-consent-banner>` and the banner in `<inth-provider>` | document root |
| `ConsentDialogHarness` | `<inth-consent-dialog>` | document root |
| `ConsentDialogTriggerHarness` | `<inth-consent-dialog-trigger>` | document root |
| `IABConsentBannerHarness` | `<inth-iab-consent-banner>` | document root |
| `IABConsentDialogHarness` | `<inth-iab-consent-dialog>` | document root |
| `ConsentWidgetHarness` | `<inth-consent-widget>` and the widget inside the dialog | fixture, or `ConsentDialogHarness.getWidget()` |
| `ConsentGateHarness` | `<inth-consent-gate>` | fixture |
| `ConsentButtonHarness` | `<button inth-consent-button>` | fixture |
| `SwitchHarness` | `[inthSwitch]` | fixture, or a surface harness |

A surface harness exists only while that surface is open. Verify a banner is
closed with `getHarnessOrNull`, which returns `null`.

## Harness methods

Every method returns a promise. Action methods click the matching button and
throw if the active policy does not expose that action.

| Harness | Methods |
| --- | --- |
| `ConsentBannerHarness` | `getTitle()`, `getDescription()`, `getPrompt()`, `isBlocking()`, `getVariant()`, `getPosition()`, `getActions()`, `acceptAll()`, `rejectAll()`, `openPreferences()`, `dismiss()` |
| `ConsentDialogHarness` | `getTitle()`, `getDescription()`, `isBlocking()`, `getWidget()`, `close()`, `acceptAll()`, `rejectAll()`, `save()` |
| `ConsentWidgetHarness` | `getCategories()`, `getCategoryTitle(category)`, `getCategorySwitch(category)`, `isCategoryChecked(category)`, `isCategoryDisabled(category)`, `toggleCategory(category)`, `setCategory(category, allowed)`, `getActions()`, `acceptAll()`, `rejectAll()`, `save()` |
| `ConsentDialogTriggerHarness` | `getLabel()`, `openPreferences()` |
| `ConsentGateHarness` | `isPlaceholderShown()`, `getPlaceholderText()`, `canOpenPreferences()`, `openPreferences()`, `getText()`, plus container loader methods |
| `ConsentButtonHarness` | `getText()`, `getAction()`, `isDisabled()`, `click()` |
| `IABConsentBannerHarness` | `getTitle()`, `getDescription()`, `getPurposes()`, `acceptAll()`, `rejectAll()`, `openPreferences()`, `openVendors()` |
| `IABConsentDialogHarness` | `getTitle()`, `getDescription()`, `isBlocking()`, `getSelectedTab()`, `selectTab(tab)`, `getSwitches(filters)`, `close()`, `acceptAll()`, `rejectAll()`, `save()` |
| `SwitchHarness` | `isChecked()`, `isDisabled()`, `getLabel()`, `toggle()`, `check()`, `uncheck()`, `focus()`, `blur()`, `isFocused()` |

`ConsentDialogHarness.close()` presses Escape without recording a choice.
`setCategory()` and `toggleCategory()` edit the draft only until `save()`
runs. `isCategoryChecked()` reads the draft, which can differ from
`ConsentManager.has()` before saving.

## Filter harnesses

Each harness provides `with()` returning a `HarnessPredicate`. All accept
`selector` and `ancestor`, plus these harness-specific filters:

| Harness | Filters |
| --- | --- |
| `ConsentBannerHarness` | `title`, `prompt` (`'choice'` or `'notice'`) |
| `ConsentDialogHarness`, `IABConsentBannerHarness`, `IABConsentDialogHarness` | `title` |
| `ConsentDialogTriggerHarness` | `label` |
| `ConsentButtonHarness` | `text`, `action` |
| `SwitchHarness` | `label`, `checked`, `disabled` |

Text filters take a string or `RegExp`. Distinguish multiple gates with a
class:

{/* example: fragment */}

```ts
const gate = await loader.getHarness(
	ConsentGateHarness.with({ selector: '.video' })
);
```

`ConsentButtonHarness`'s `action` filter reads `data-action` or a static
`action="accept"` attribute. For a dynamically bound `[action]`, filter by
`text` instead.

## Test the consent gate

`ConsentGateHarness` waits one animation frame before reading because the
gate populates one frame after first render. `isPlaceholderShown()` reports
the built-in placeholder. With a custom `inthConsentGatePlaceholder`, read it
with `getText()` or your own harness. `openPreferences()` clicks the built-in
placeholder button to open the dialog.

## Test the IAB surfaces

IAB surfaces render after the IAB chunk and Global Vendor List load, which
`fixture.whenStable()` does not wait for. Pass an inline GVL via
`iab: { cmpId, gvl }` so tests make no network requests, and poll until the
harness mounts:

{/* example: fragment */}

```ts
const banner = await vi.waitFor(async () => {
	const found = await loader.getHarnessOrNull(IABConsentBannerHarness);
	expect(found).not.toBeNull();
	return found!;
});
await banner.acceptAll();
await vi.waitFor(() => expect(consent.iab()?.purposeConsents[1]).toBe(true));
```

The TC string encodes asynchronously after the click, so wait for
`ConsentManager.iab()` to update before asserting.
`IABConsentDialogHarness.getSwitches({ label })` finds a purpose, stack or
special feature switch by label.
