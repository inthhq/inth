All `@inth/angular` components and directives are standalone. Import each
class into the component that renders it and place it below `provideInth()`.
Rendering one without the provider throws `NullInjectorError` for
`ConsentManager`.

## Every component

Core components come from `@inth/angular`. Additional components ship from
dedicated subpaths so pages download only what they render. The dialog body
lazy-loads before first open.

All components use `OnPush` change detection and signals, working with both
zoneless change detection and `zone.js`.

## Styles

No stylesheet import is required. Each stock component injects its rules into
`<head>` as a `<style>` element once per page on first render. Server-rendered
pages include those rules in the HTML, and the dialog loads its styles with
its deferred chunk.

IAB components inject their own sheets only when rendered.

To process styles through Tailwind CSS 3 or a named cascade layer, set
`styles: false` in `provideInth()` and add `@inth/angular/styles.css` (plus
`@inth/angular/iab/styles.css` if using IAB) to `styles` in `angular.json`.
For Tailwind CSS 3, place `@inth/angular/postcss-tailwind3` before
`tailwindcss` in PostCSS. See
[stylesheets and CSS layers](/docs/customization/stylesheets#import-the-stylesheet-yourself).

## When components render nothing

Consent surfaces stay hidden until a policy resolves, and remain hidden when
the policy requires no prompt and exposes no preferences. See
[why the banner may be absent](/docs/concepts/policies#why-the-banner-may-be-absent).

## Shared inputs

| Input | Behavior |
| --- | --- |
| `noStyle` | Drops `inth` classes while keeping markup and behavior. Set on `provideInth()` or per component. |
| `rootClass` | Adds a class to the root element of the widget, the trigger, `<inth-privacy-choices-link>` and the IAB surfaces. The banner and dialog take theme slots instead. |
| `hideBranding` | Hides the "Consent by" tag on the banner, the widget (hidden by default) and the IAB surfaces. The dialog has no tag. |
| `models` | Policy models the surface renders for: `opt-in`, `opt-out`, `iab` and `none`. |
| `legalLinks` | Provider `legalLinks` keys to display, or `null` for none. |
| `disableAnimation` | Disables enter and exit transitions for that surface. |

Use theme slots to target individual parts; see [customize](./customize).
