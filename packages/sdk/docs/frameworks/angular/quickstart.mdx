Add a consent banner and preference dialog to an Angular app. The browser
resolves each visitor's policy after bootstrap, and analytics wait until
consent allows them.

<Prompt title="Add Inth consent to this Angular app" description="Paste into Claude Code, Codex, Cursor or another coding agent at the root of your app.">
  Add Inth consent management to this Angular app.

  1. Check that the app runs Angular 20, 21 or 22 with standalone components. If it uses NgModules or an older Angular version, stop and tell me.
  2. Install `@inth/angular` and `@inth/integrations`. Read `node_modules/@inth/angular/AGENTS.md`, then follow the Angular quickstart it links to, in order. Do not guess the API from memory.
  3. Create `src/scripts.ts`. Move every analytics and marketing script into it with the matching helper from `@inth/integrations`, carrying over each vendor's settings. Remove the old script tags from `index.html`, `angular.json` and SDK imports. If a vendor has no helper, tell me.
  4. In `src/app/app.config.ts`, add `provideInth({ projectUrl, scripts })`. Ask me for my Inth project URL. Keep `provideInth()` in `app.config.ts` so server configs inherit it.
  5. In the root component (`src/app/app.ts`), render `<inth-consent-banner />`, `<inth-consent-dialog />` from `@inth/angular/consent-dialog`, and a footer button with `inthConsentDialogLink`.
  6. Run `ng build` and serve `dist/<app>/browser`. In a private browser window, verify no vendor request fires before consent, rejecting survives a reload, and granting analytics from the footer button loads the vendor.

  Then list the files you changed, any script still outside consent, and how you checked the requests.
</Prompt>

## Prerequisites

- An Angular 20, 21 or 22 app with standalone components (zoneless or
  `zone.js`). For server HTML, add
  [server rendering](/docs/frameworks/angular/rendering) next. Not on
  Angular? See the [framework list](/docs/frameworks).
- An [Inth project](https://inth.com/dashboard/sign-up?framework=angular)
  with your app's origin (such as `http://localhost:4200`) in trusted
  origins.

## Check it works

Run `ng build`, serve `dist/<app>/browser`, and open a private window with
DevTools Network open:

1. Under an opt-in policy, `/v1/consent/init` runs, the banner appears, and no PostHog
   request fires.
2. Click **Reject All** and reload. The banner stays closed and PostHog does
   not load.
3. Click **Privacy settings**, turn on **Analytics** (`measurement`) and
   save. PostHog loads.
4. Turn **Analytics** off and save. The page reloads and PostHog stays
   absent.

If no banner appears, check
[Angular troubleshooting](/docs/frameworks/angular/troubleshooting) and
[verify consent](/docs/guides/verify-consent).
