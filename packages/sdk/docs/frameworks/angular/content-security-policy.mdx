Configure your Content Security Policy headers so Inth's styles, API calls,
vendor scripts and gated embeds work without `unsafe-inline` workarounds.

## Set the policy where you serve the app

Serve the policy through a `Content-Security-Policy` header or a
`<meta http-equiv="Content-Security-Policy">` tag in `index.html`. A
browser-only static Angular app cannot generate a per-request nonce, so allow
each vendor's script host in `script-src`, set `styles: false` in
`provideInth()` and add `@inth/angular/styles.css` to `styles` in
`angular.json`. `'self'` then covers Inth's stylesheet.

A server-rendered app can issue a fresh nonce per response. Angular reads it
from `ngCspNonce` on your root element or from the `CSP_NONCE` token and
applies it to its own `<style>` elements. Angular's `autoCsp` build option
hashes its inline scripts instead. Test your policy against `ng build`
output rather than `ng serve`.

## What Inth adds to the page

Allow each resource Inth or your vendors add:

| Inth does | Directive | Allow |
| --- | --- | --- |
| Requests policies from `/v1/consent/init` and saves choices to `/v1/consent/records` | `connect-src` | Your Inth project origin. `'self'` covers a same-origin route such as `/api/inth`. |
| Inserts a `<script>` for each allowed entry in `scripts` | `script-src` | Each vendor's script host or the provider's `nonce`. |
| Lets vendor scripts load secondary scripts, pixels and API calls | `script-src`, `img-src`, `connect-src` | The hosts each vendor documents. |
| Sets `src` on gated iframes or renders `<inth-consent-gate>` content | `frame-src` | Each embed host, such as `https://www.youtube-nocookie.com`. |
| Injects `<style>` elements into `<head>` | `style-src` | The nonce. With `styles: false` and the imported stylesheet, `'self'`. |
| Writes theme slot `style` objects and dragged trigger positions as `style` attributes | `style-src-attr` | `'unsafe-inline'` if you use slot `style` objects or a draggable trigger. Slot class names and stock styling do not need it. |
| With SSR, injects scripts that start allowed `scripts` and capture early banner clicks | `script-src` | The nonce. |
| Fetches the Global Vendor List under an IAB policy | `connect-src` | The GVL host the policy names when not same-origin. |

The DevTools panel attaches a stylesheet to its shadow root. Keep DevTools
out of production builds (see [Dev tools](./components/dev-tools)) so your
production policy does not need to allow it.

## Pass the nonce to Inth

Inth reads `nonce` from `provideInth()` and falls back to Angular's
`CSP_NONCE`. Apps that already set `ngCspNonce` on the root element need no
extra setup. Otherwise, provide `CSP_NONCE` so Angular and Inth share it:

<include src="../../shared/examples/angular/csp-nonce.mdx" />

The script loader applies that nonce to every `<script>` element it inserts,
both `src` and inline `textContent`. A script-level `nonce` overrides the
provider nonce for that entry.

The nonce covers only elements Inth creates. Allow secondary vendor script
hosts in `script-src`, or use `'strict-dynamic'` (note that `'strict-dynamic'`
causes browsers to ignore host allowlists in `script-src`).

## Verify the policy

Enforce the policy (not report-only), clear site data and check the console:

1. The banner renders styled with no `Refused to` errors for Inth elements,
   `<style data-inth-styles>` or `@inth/angular/styles.css`. Open the
   preference dialog and check again.
2. Allow a category. Its vendor scripts load without `script-src` violations.
3. Save a choice. `POST /v1/consent/records` succeeds without `connect-src` errors.
4. Allow a gated embed's category. The embed loads without `frame-src` errors.
