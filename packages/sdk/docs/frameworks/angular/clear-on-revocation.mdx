## Configure cleanup

Gating stops new requests, but it leaves the cookies and storage keys a vendor
already wrote. List the ones each optional category owns:

<include src="../../shared/examples/angular/clear-on-revocation.mdx" />

Then pass the configuration to `provideInth()` in `src/app/app.config.ts`.
When a category is denied, Inth deletes its entries:

{/* example: fragment */}

```ts title="src/app/app.config.ts (partial)"
provideInth({ mode, scripts, clearOnRevocation });
```

`provideInth()` reads `clearOnRevocation` once, when the application starts;
`updateOptions()` does not change it. For a shared runtime, pass it to
`createConsentRuntime()` instead.
