Enable IAB TCF 2.4 consent in Angular so ad partners can read confirmed TC
Strings through `__tcfapi`.

## Before you turn on IAB TCF

Use IAB TCF when your ad partners require a TC String. You need an IAB policy
in your Inth project and a registered CMP ID. IAB Europe assigns a CMP ID
when a company registers as a CMP
([register.consensu.org/CMP](https://register.consensu.org/CMP)). Every TC
String names the CMP that wrote it, so never ship a demo CMP ID in
production.

`@inth/angular` lazy-loads the TCF add-on from `@inth/sdk/iab`. Apps that do
not set the `iab` option never download it.

`mode`, `scripts` and other options. Replace `registeredCmpId` with your

The IAB banner injects its first-paint rules before rendering, and the IAB
dialog injects its rules when it opens. Each stylesheet attaches once per
page.

To run styles through Tailwind CSS 3 or a named cascade layer, set
`styles: false` in `provideInth()` and add `@inth/angular/styles.css`
followed by `@inth/angular/iab/styles.css` to `styles` in `angular.json`. See
[stylesheets and CSS layers](/docs/customization/stylesheets#import-the-stylesheet-yourself).

| `iab` option | Purpose |
| --- | --- |
| `cmpId` | Your registered CMP ID. Inth can supply it from your project settings instead. |
| `cmpVersion` | Your CMP version written into the TC String. |
| `vendors` | Limit the Global Vendor List to these vendor IDs. |
| `customVendors` | Vendors outside the IAB list with their purposes and data use. |
| `publisherRestrictions` | Override how vendors may use a purpose. |
| `publisherCountryCode` | Your country code written into the TC String. |
| `additionalConsent` | Google Additional Consent settings. |
| `gvl`, `gvlUrl` | Provide the vendor list directly or change its URL. |
| `enabled` | `false` keeps configuration but leaves the add-on unmounted. |

Omit `iab` or pass `iab: false` to keep IAB off. If a visitor's policy uses
the `iab` model and Inth returns a vendor list without `iab` configured,
`ConsentManager.iabUnavailable()` becomes `true` and Angular's `ErrorHandler`
receives an `IABUnavailableError` (code `INTH_IAB_UNAVAILABLE`). Either
configure `iab` or remove the `iab` model from that region's policy. When
`gvl: null` comes back for a request, the policy falls back to opt-in.

[IABConsentBanner](./components/iab-consent-banner) and
[IABConsentDialog](./components/iab-consent-dialog) list each component's
inputs.

Both IAB components stay hidden until an IAB policy resolves for the visitor.

## Read the TCF state

`ConsentManager.iab()` holds live IAB state: the vendor list, purpose and
vendor consents, `isLoadingGVL`, and actions `acceptAll()`, `rejectAll()`,
`setPurposeConsent()`, `setVendorConsent()`, `setSpecialFeatureOptIn()` and
`save()`. It is `null` when IAB is off. Actions queue until the add-on loads;
`whenIABReady()` resolves once ready.
[ConsentManager](./services#read-and-change-iab-tcf-consent) lists every
member.

For a custom IAB banner, `getIABTranslations()` from `@inth/angular/iab`
returns IAB copy with English fallbacks.

## Restrict how vendors use a purpose

Pass publisher restrictions in `iab.publisherRestrictions`, for example
`[{ purposeId: 4, restrictionType: 0, vendorIds: [10, 755] }]` to block
vendors 10 and 755 from using purpose 4. Use vendors from your own list whose
declarations allow each restriction.

## Verify the TCF flow

Accept, reject and save purpose and vendor choices, then run
`__tcfapi('getTCData', 2, console.log)` in the console and verify the TC
String matches your selection. Reload and confirm it persists, and check
actual vendor network requests.
