Render consent category switches inline on a privacy settings page with
`<inth-consent-widget>`.

## Put preferences on a page

`<inth-consent-widget>` renders the same controls used inside
`<inth-consent-dialog>`, without a modal wrapper:

<include src="../../../shared/examples/angular/privacy-page.mdx" />

Mount it on any route. Keep `<inth-consent-dialog>` in your root component if
you also want the banner's Customize button to open a dialog.

## Inputs

| Input | Type | Default | Behavior |
| --- | --- | --- | --- |
| `hideBranding` | `boolean` | `true` | Shows the "Secured by" tag when `false`. |
| `noStyle` | `boolean` | provider `noStyle` | Drops `inth` classes. |
| `rootClass` | `string` | none | Extra class on the inner root element. |

The host element uses `display: contents`, so apply layout classes via
`rootClass` instead of styling the host tag directly.

## Behavior

`<inth-consent-widget>` renders nothing until a policy resolves and requires
consent UI. It lists `consentCategories` within the policy's scope, with
`necessary` always enabled and locked.

Switches initialize from the visitor's recorded choice (or preselected /
opt-out defaults before a choice) and update a shared unsaved draft. Save
records the draft; Accept and Reject record every category at once.

Declared vendors appear under their category with individual switches (not
shown under IAB policies). If the policy changes while edits are unsaved, the
widget shows an alert with a **Review preferences** button and blocks saving
the stale draft until reviewed.

## Accessibility

- Category controls use `role="switch"` labelled by category title.
- Category headers are buttons with `aria-expanded`.
- The stale-policy warning uses `role="alert"`.
- The root sets `dir` from the active language.

## Style the widget

`<inth-consent-widget>` reads `consentWidget`, `consentWidgetAccordion`,
`consentWidgetFooter`, `consentWidgetFooterSubGroup` and `consentWidgetTag`
theme slots. The root carries `data-testid="consent-widget-root"`, and each
row carries `data-testid="consent-widget-accordion-item-<category>"`.
