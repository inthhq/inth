Render the IAB TCF 2.4 first-layer consent banner for visitors under an IAB
policy with `<inth-iab-consent-banner>`.

## Show the TCF banner

`<inth-iab-consent-banner>` lists TCF purposes, special features and partner
counts from the Global Vendor List, with Accept all, Reject all and Customize
actions. Render it next to `<inth-consent-banner>`, which handles visitors
outside IAB regions:

<include src="../../../shared/examples/angular/iab-surfaces.mdx" />

Configure the `iab` option on `provideInth()` first; see [IAB TCF](../iab).

## Inputs

| Input | Type | Default | Behavior |
| --- | --- | --- | --- |
| `primaryButton` | `'accept'`, `'reject'` or `'customize'` | `'customize'` | Button given primary styling. |
| `hideBranding` | `boolean` | `false` | Hides the "Secured by" tag. |
| `models` | `Model[]` | `['iab']` | Policy models rendered by this banner. |
| `noStyle` | `boolean` | provider `noStyle` | Drops `inth` classes. |
| `disableAnimation` | `boolean` | provider value | Disables enter and exit transitions. |
| `scrollLock`, `trapFocus` | `boolean` | provider value | Lock page scroll or trap focus while open. Policy presentation can still enforce blocking. |
| `rootClass` | `string` | none | Extra class on the root element. |

Copy comes from IAB translations in the visitor's language. Use
`getIABTranslations()` from `@inth/angular/iab` for custom IAB banners.

## Behavior

- Stays hidden until an IAB policy resolves and the Global Vendor List loads.
- Accept all and Reject all record TCF consent, write the TC String and close
  immediately. The banner reopens only if recording failed locally (such as a
  missing GVL).
- Customize opens `<inth-iab-consent-dialog>` on the purposes tab; the
  partners link opens it on the vendors tab.
- `__tcfapi` becomes available once the TCF add-on loads regardless of banner
  visibility.

## Accessibility

Renders as a `region` labelled by its `<h2>` title, or a modal `dialog` with
`aria-modal="true"` when blocking. All actions are native `<button>`
elements.

## Style the banner

Injects its own CSS into `<head>` on mount. With `styles: false`, add
`@inth/angular/iab/styles.css` after `@inth/angular/styles.css` in
`angular.json`. Reads `iabConsentBanner`, `iabConsentBannerCard`,
`iabConsentBannerHeader`, `iabConsentBannerFooter`, `iabConsentBannerTag` and
`iabConsentBannerOverlay` theme slots. Action buttons carry
`data-testid="iab-consent-banner-accept-button"`,
`data-testid="iab-consent-banner-reject-button"` and
`data-testid="iab-consent-banner-customize-button"`.
