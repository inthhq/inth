Mount the Inth DevTools panel in development to inspect consent state, gated
scripts, resolved policies, IAB state and events in real time.

## Add the panel

Render `<inth-consent-dev-tools>` anywhere below `provideInth()`:

<include src="../../../shared/examples/angular/dev-tools.mdx" />

The panel mounts inside its own shadow root on `<body>` in the browser and
does nothing on the server.

Alternatively, register it via `provideInthDevTools()` after `provideInth()`:

<include src="../../../shared/examples/angular/dev-tools-provider.mdx" />

## What the panel shows

| Tab | Shows |
| --- | --- |
| `consents` | Effective permissions and recorded choice per category, with test switches. |
| `scripts` | Each registered script and its loading state. |
| `location` | Resolved country, region and language, with overrides to test other regions. |
| `policy` | Resolved policy rule, model, prompt, scope and rights. |
| `iab` | Live TCF state when IAB is active. |
| `events` | Consent runtime and script lifecycle events. |
| `actions` | Controls to open surfaces, reset drafts, clear records and re-resolve policy. |

Clearing records calls `ConsentManager.clearRecords()`, respecting custom
`storageConfig`. Location overrides affect the current page only.

## Inputs

`provideInthDevTools()` accepts the same fields as an options object:

| Input | Type | Default | Behavior |
| --- | --- | --- | --- |
| `position` | `'bottom-right'`, `'bottom-left'`, `'top-right'` or `'top-left'` | `'bottom-right'` | Corner for the launcher button. |
| `defaultOpen` | `boolean` | `false` | Opens the panel on load. |
| `defaultTab` | tab name | `'consents'` | Initial active tab. |
| `maxEvents` | `number` | `100` | Maximum events retained in the `events` tab. |
| `getConsentCategories` | `() => AllConsentNames[]` | `ConsentManager.consentCategories()` | Categories listed in `consents`. |
| `getPresentation` | `() => ConsentPresentation` | provider `presentation` | Presentation used for diagnostics. |
| `clearRecords` | `() => void` | `ConsentManager.clearRecords()` | Custom clear handler. |
| `shadow` | `boolean` | `true` | `false` mounts outside a shadow root and puts styles in `<head>`. |

## Open DevTools from the consent trigger

When `<inth-consent-dialog-trigger>` is visible, it merges into a two-button
toolbar with DevTools and hides the separate launcher so one control occupies
the corner.

## Keep it out of production

Never ship DevTools to visitors because it can clear consent and spoof
location. In the component example, `@defer` puts `ConsentDevTools` in a
separate chunk loaded only in development. With `provideInthDevTools()`, swap
in a development-only file via `fileReplacements` in `angular.json` so
production bundles omit it.

## Verify it

Run `ng serve` and confirm the DevTools launcher opens and matches the
banner's state. Run `ng build` and verify no DevTools chunk loads in
production.
