Render the IAB TCF 2.4 preference center with Purposes and Vendors tabs in
Angular using `<inth-iab-consent-dialog>`.

## Show the TCF preference center

Render `<inth-iab-consent-dialog>` alongside `<inth-iab-consent-banner>` so
the banner's Customize button and footer preferences links can open it:

<include src="../../../shared/examples/angular/iab-surfaces.mdx" />

## Inputs

| Input | Type | Default | Behavior |
| --- | --- | --- | --- |
| `open` | `boolean` | follows consent state | Controlled visibility. Bind `[(open)]` so Escape, close and actions update it. |
| `initialTab` | `'purposes'` or `'vendors'` | `'purposes'` | Initial active tab. |
| `hideBranding` | `boolean` | `false` | Hides the "Consent by" tag. |
| `models` | `Model[]` | `['iab']` | Policy models handled. |
| `noStyle` | `boolean` | provider `noStyle` | Drops `inth` classes. |
| `disableAnimation` | `boolean` | provider value | Skips backdrop fade-in. |
| `rootClass` | `string` | none | Extra class on the dialog card. |

`openChange` emits `false` on Escape, close button click, after saving,
accepting or rejecting, or if the dialog chunk fails to load:

```html
<inth-iab-consent-dialog [(open)]="preferencesOpen" />
```

## Behavior

- Opens when `activeUI` is `'dialog'` under an IAB policy, so
  `inthConsentDialogLink` automatically opens this dialog for IAB visitors
  and `<inth-consent-dialog>` for everyone else.
- Lazy-loads its body chunk on first open (prefetched during idle time). If
  loading fails, the next open retries and the banner restores in the
  meantime.
- Switches update purpose consent, legitimate interest, special feature
  opt-ins and vendor consent; Save encodes a new TC String.
- While the Global Vendor List loads, `ConsentManager.iab()?.isLoadingGVL` is
  `true`.

## Accessibility

Renders as a `dialog` labelled by its title with a localized close button
(`common.close`). Escape closes it. Blocking mode (default) traps focus and
locks scroll. Purposes and Vendors tabs support keyboard navigation.

## Style the dialog

Injects its CSS when opened. With `styles: false`, include both
`@inth/angular/styles.css` and `@inth/angular/iab/styles.css` in
`angular.json`. Reads `iabConsentDialog`, `iabConsentDialogCard`,
`iabConsentDialogHeader`, `iabConsentDialogFooter`, `iabConsentDialogTag` and
`iabConsentDialogOverlay` theme slots. The root carries
`data-testid="iab-consent-dialog-root"`.
