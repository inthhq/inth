Turn any `<button>` into an Inth consent action with stock button styling
using `button[inth-consent-button]`.

## Add consent buttons to your own markup

Import `ConsentButton` and apply `inth-consent-button` to your `<button>`
elements:

<include src="../../../shared/examples/angular/consent-buttons.mdx" />

Use it in a custom banner or on a privacy page. Write the button label
yourself.

## Inputs

| Input | Type | Default | Behavior |
| --- | --- | --- | --- |
| `action` | `'accept'`, `'reject'`, `'save'`, `'customize'` or `'dismiss'` | required | Action to run on click. |
| `variant` | `'primary'` or `'neutral'` | `'neutral'` | Applies `buttonPrimary` or `buttonSecondary` styling. |
| `mode` | `'filled'`, `'stroke'`, `'lighter'` or `'ghost'` | `'stroke'` | Fill style. |
| `size` | `'medium'`, `'small'`, `'xsmall'` or `'xxsmall'` | `'small'` | Button size. |
| `noStyle` | `boolean` | provider `noStyle` | Drops `inth` classes. |

## What each action records

| `action` | Effect |
| --- | --- |
| `accept` | Grants every category in the policy scope and closes the surface (`saveConsents('all')`). |
| `reject` | Keeps only necessary categories and closes the surface (`saveConsents('necessary')`). |
| `save` | Records the preference draft (`saveConsents('custom')`). |
| `customize` | Opens the preference dialog without recording a choice. |
| `dismiss` | Records notice dismissal without granting consent. |

`action="customize"` prefetches the deferred dialog during idle time and on
hover or focus. Calling `event.preventDefault()` in a prior click handler
cancels the action.

`ConsentButton` does not enforce policy button rules. Use
[`HeadlessConsent`](../headless) when building a custom banner so you render
only the actions the policy requires.

## Verify it

Clear site data and click each button. Accept and Reject close the banner and
populate `ConsentManager.explicitChoice()`; Customize opens the dialog
without saving.
