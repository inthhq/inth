Add a fixed, draggable corner button that reopens the preference dialog on
every page using `<inth-consent-dialog-trigger>`.

## Add a floating privacy button

Import `ConsentDialogTrigger` and render it beside `<inth-consent-dialog>`:

{/* example: fragment */}

```html
<inth-consent-dialog />
<inth-consent-dialog-trigger defaultPosition="bottom-left" size="sm" />
```

`<inth-consent-dialog [showTrigger]="true" />` renders the same button only
after the dialog chunk loads. Rendering `<inth-consent-dialog-trigger>`
directly shows it from the first render.

## Inputs and outputs

| Input or output | Type | Default | Behavior |
| --- | --- | --- | --- |
| `defaultPosition` | `'bottom-right'`, `'bottom-left'`, `'top-right'` or `'top-left'` | `'bottom-right'` | Starting viewport corner. |
| `persistPosition` | `boolean` | `true` | Saves the dragged corner in `localStorage`. |
| `showWhen` | `'always'` or `'never'` | `'always'` | `'never'` hides the button. |
| `size` | `'sm'`, `'md'` or `'lg'` | `'md'` | Button size. |
| `label` | `string` | Resolved opt-out link title or `trigger.label` translation | Accessible `aria-label`. Under an opt-out rule with the `opt-out` right, defaults to the resolved opt-out link title and activating the trigger records an opt-out in one click and opens `<inth-opt-out-confirmation>`. |
| `noStyle` | `boolean` | `false` | Drops `inth` classes, including fixed positioning. Does not inherit provider `noStyle`. |
| `rootClass` | `string` | none | Extra class on the button. |
| `(triggerClick)` | `MouseEvent` | | Fires before opening the dialog. Call `$event.preventDefault()` to cancel. |
| `(positionChange)` | corner | | Fires after dragging snaps the button to another corner. |

## Behavior

- Renders only when the policy offers preference management, and hides while
  the dialog is open.
- Pointer dragging snaps to the nearest corner without opening the dialog; a
  click opens it.
- Portals into `<body>` via `inthPortal` to avoid parent clipping.
- Prefetches the deferred dialog chunk during idle time and on hover or
  focus.
- When `<inth-consent-dev-tools>` is mounted, combines into a two-button
  toolbar; see [Dev tools](./dev-tools).

## Accessibility

Renders as `<button type="button">` with `aria-label` because it shows only
an icon. Pass a localized `label` and choose a `defaultPosition` that does
not cover other controls for keyboard users.

## Style the trigger

The button carries `data-testid="consent-dialog-trigger"`,
`data-inth-trigger="true"` and `data-inth-rights`. It reads
`consentDialogTrigger` and `consentDialogTriggerIcon` theme slots and
`--inth-*` tokens; see [theme tokens](/docs/customization/tokens).
