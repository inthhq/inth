Render third-party embeds or widgets only while their consent category is
allowed, and show a placeholder otherwise, with `<inth-consent-gate>`.

## Gate an embed

Import `ConsentGate` and the template directives you use:

<include src="../../../shared/examples/angular/youtube-embed.mdx" />

The gate reads `ConsentManager.effectivePermissions()[category]` (same as
`has(category)`). Under an opt-out policy that can be `true` before any
choice, and Global Privacy Control can override a grant. Withdrawing the
category destroys the gated content without a page reload.

## Inputs and templates

| Input or template | Type | Default | Behavior |
| --- | --- | --- | --- |
| `category` | `AllConsentNames` | required | Required category, such as `'measurement'` or `'marketing'`. |
| `vendor` | `string` | none | Optional vendor ID; waits for both category and `isVendorAllowed(vendor)`. |
| `noStyle` | `boolean` | provider `noStyle` | Drops `inth` classes from the built-in placeholder. |
| `ng-template[inthConsentGateContent]` | template | none | Gated content created only while allowed. |
| `ng-template[inthConsentGatePlaceholder]` | template | built-in placeholder | Custom placeholder shown while denied. |

Without `inthConsentGateContent`, projected children instantiate with the
parent view even while hidden (an `<iframe>` does not load, but child
components still construct). Always use the content template for components
with side effects.

The placeholder template receives `$implicit` and `category`, plus
`openDialog` to open the preference dialog:

{/* example: fragment */}

```html
<ng-template inthConsentGatePlaceholder let-category let-open="openDialog">
	<p>Allow {{ category }} to load this video.</p>
	<button type="button" (click)="open()">Choose video permissions</button>
</ng-template>
```

## Server rendering

The host element renders empty on the server and fills one frame after the
first browser render. For gated content in the initial server HTML, use
[`*inthIfConsent`](../embeds#render-content-only-while-consent-holds).

## The built-in placeholder

The built-in placeholder displays `consentGate.title` and a button labelled
with `consentGate.actionButton` (replacing `{category}` with the translated
category name). Clicking the button opens `<inth-consent-dialog>`, so keep
the dialog rendered. When a policy blocks the category completely, the button
is omitted.

`<inth-consent-gate>` does not add its category to the preference dialog; keep
the category in your policy scope and `consentCategories`.

## Accessibility

Provide a descriptive `title` on gated iframes and offer an alternative link
or text for visitors who decline.

## Style the placeholder

Apply sizing classes such as `aspect-ratio` directly on `<inth-consent-gate>`
so replacing the placeholder causes no layout shift.

Style the built-in placeholder via `consentGate`, `consentGateTitle` and
`consentGateButton` in `theme.slots` (`consentGateButton` layers over
`buttonPrimary`). Elements carry `data-testid="consent-gate-placeholder"`,
`data-testid="consent-gate-title"` and `data-testid="consent-gate-button"`.
