Expose `window.__gpp` (GPP 1.1 CMP API) in your Angular app so ad tech such
as Prebid.js and Google Ad Manager can read US privacy opt-outs and the TCF
EU consent string.

## Turn on GPP

Add `gpp` to `provideInth()` in `src/app/app.config.ts`, keeping your
existing `mode`, `scripts` and other options:

{/* example: fragment */}

```ts title="src/app/app.config.ts (partial)"
provideInth({ mode, scripts, gpp: true });
```

`gpp: true` or `gpp: {}` uses defaults. Pass an object to configure options,
such as `gpp: { usFallback: 'none' }`. Omit `gpp` or pass `gpp: false` to
leave it off.

`@inth/angular` lazy-loads GPP from `@inth/sdk/iab/gpp` through a dynamic
import, so apps without `gpp` never download it. The runtime installs `__gpp`
in the browser once the chunk loads and removes it on app destroy.

The US section follows the policy and location your Inth project resolves. In
`testing()` mode, pass the location through `overrides`, such as
`overrides: { country: 'US', region: 'CA' }`.

The TCF EU section requires IAB TCF as well; see
[IAB TCF](/docs/frameworks/angular/iab).

With an external `runtime`, `provideInth()` ignores `gpp`. Pass `gpp` and
`loadGPP: () => import('@inth/angular/gpp')` to `createConsentRuntime()`
instead.
