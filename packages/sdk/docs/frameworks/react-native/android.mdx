The React Native Android adapter depends on versioned `com.inth` Maven artifacts: `inth-core` (policy and consent state), `inth-android` (platform storage, transport, and lifecycle), and `inth-consent-ui` (Compose screens). Follow [Bare React Native](/docs/frameworks/react-native/bare) or [Expo and EAS](/docs/frameworks/react-native/expo) for app configuration. For standalone Kotlin apps, choose Android in the [framework list](/docs/frameworks).

## Resolve the native modules

Prerelease Android artifacts use group `com.inth` and version `3.0.0-alpha.1` (`inth-core` JVM JAR, `inth-android` AAR, and `inth-consent-ui` AAR). Keep all three on the exact native version pinned by `@inth/react-native`, regardless of the npm package semver.

Configure your supplied Maven repository in Gradle dependency resolution and pass credentials through your build environment (never in manifests or app code). Minimum floors are Android API 24, compile SDK 36 (37 for RN 0.87, RN 0.88, and Expo 58), and JDK 17. Keep your host's compatible Gradle, AGP, and Kotlin versions; see [Compatibility and updates](/docs/frameworks/react-native/platform-support).

## Install before SDK startup

When owning native installation, call `InthAndroid.install` before initializing optional SDKs or React Native, replacing the placeholder URL with your Inth project URL:

<include src="../../shared/examples/native/examples/consent-demo/android-install.mdx" />

`InthAndroid.install` configures persistence, HTTP transport, and foreground/reconnect refresh, then hydrates saved choices synchronously. Keep one kernel per process. Standard apps can use `InthInitializer` manifest metadata (`com.inth.BACKEND_URL`) instead of calling `install` manually.

Disable vendor auto-initializers that can fire before `Application.onCreate`. Keep `android.permission.INTERNET`, and include `ACCESS_NETWORK_STATE` for reconnect retries alongside launch and foreground retries. Treat storage and policy failures as closed optional gates.

## Keep gates current

`Inth.decision` distinguishes `PENDING`, `DENIED`, and `GRANTED`. Retain a `gate` or `gateDecision` subscription and close it when its owner ends so withdrawal stops optional collection immediately.

In `NativeConfig`, `backendUrl` must be your Inth project URL (any other host throws). Use `bundledPolicy` (or `com.inth.POLICY_RESOURCE`) for offline first launches; the installer replays queued saves on foreground and reconnect.

## Present Compose screens

Access the installed kernel via `Inth.current` (returns `null` before bootstrap). Mount `InthConsent(privacyPolicyUrl = ...)` in Compose or call `attachConsent(privacyPolicyUrl)` after `setContentView` in a View-based Activity. Both share `ConsentPrompt` and present an owed choice by default (`autoPresent = false` defers to `ConsentPrompt.current?.presentPrompt()`). When native code presents the prompt, pass `autoPresent={false}` to JavaScript's `InthProvider` so only one side presents it. Configure appearance via `ConsentTheme` (see [Customize](/docs/frameworks/react-native/customize)).
