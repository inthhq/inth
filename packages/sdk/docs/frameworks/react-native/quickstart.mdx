Add native SwiftUI and Compose consent screens, durable preference storage, and React hooks to React Native or Expo. Choices live in the native engine so optional SDKs can check consent before JavaScript boots.

## Before you start

- React Native `0.83.x` through `0.88.x` (New Architecture, React `>=19.2.0 <19.4.0`) or Expo SDK 55 through 58 with a custom native build (Expo Go is unsupported). Target RN 0.88 or Expo 58 for new apps; see [compatibility](/docs/frameworks/react-native/platform-support).
- iOS 16.4+ and Android API 24+.
- An [Inth project](https://inth.com) with regional policies, your categories (`measurement`, `marketing`), its HTTPS project URL (`https://your-project.inth.app`), and your HTTPS privacy policy URL.
- Private prerelease `@inth/react-native` tarball and Android Maven access; see [mobile availability](/docs/guides/mobile-status).

## Install the package

Install the tarball in your app directory (`@inth/react-native` is separate from `@inth/sdk`):

```sh
npm install /absolute/path/to/inth-react-native.tgz
```

## Configure the native app

Configure your Inth project URL natively so the engine initializes before React mounts, then return here:

| App type | Setup guide |
| --- | --- |
| Expo | [Expo and EAS](/docs/frameworks/react-native/expo): add the config plugin and build a native binary. |
| Bare React Native | [Bare React Native](/docs/frameworks/react-native/bare): link CocoaPods, add Maven, and set metadata. |

Mobile connects to Inth hosted projects only; see [Configuration](/docs/frameworks/react-native/configuration) for URL rules and `dryRun`.

## Check that it works

Build a native binary and test under an opt-in policy:

1. Fresh install: prompt opens; optional collection stays off.
2. Tap **Reject all** and relaunch: refusal persists; prompt stays closed.
3. Open **Privacy settings**, enable measurement, and save: gate opens.
4. Disable measurement and save: gate closes and collection stops.

`committed` confirms durable local storage; backend delivery can finish after reconnect. See [Commands and outcomes](/docs/frameworks/react-native/usage) and [Verify mobile consent](/docs/guides/mobile-verify).
