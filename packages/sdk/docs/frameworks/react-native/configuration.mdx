Configure the consent engine natively before React boots, using the config plugin in Expo or native metadata in bare React Native. `InthProvider` attaches to the installed engine and takes no backend or policy prop.

## Set your Inth project URL

The mobile SDKs connect to Inth hosted projects only. Set `projectUrl` to the project URL from your Inth dashboard. The app fetches policy from that project and sends consent records to it.

`projectUrl` normalizes these forms to `https://your-project.inth.app` (trimming surrounding whitespace):

| Input | Result |
| --- | --- |
| `https://your-project.inth.app` | Used as written. |
| `your-project.inth.app` | Missing scheme defaults to `https`. |
| `https://your-project.inth.app/` | Trailing slashes removed. |
| `HTTPS://Your-Project.Inth.App` | Scheme and host lowercased. |

Prebuild and native launch reject every other form (other hosts, `http`, ports, paths, queries, fragments, or credentials) with an error quoting your value:

{/* example: fragment */}

```txt
projectUrl must be the project URL from your Inth dashboard, such as https://your-project.inth.app. Got "https://consent.example.com": the host must be a project host under inth.app.
```

`projectUrl` is public binary configuration; keep credentials out of it.

### Replace removed options

`mode` and `initURL` were removed. Prebuild stops and points to the replacement:

| Removed option | Replacement |
| --- | --- |
| `mode: 'hosted'` | Remove it. Hosted Inth is the only mode. |
| `mode: 'offline'` | Use `dryRun: true` in development and CI, or `bundleManifest` / `policy` for offline production launches. |
| `mode: 'custom'` | Set `autoBootstrap: false` and install natively before React Native starts. |
| `initURL` | Remove it. The app fetches policy from `projectUrl`. |

## Use dryRun in development and CI

Set `dryRun: true` to run prompts, storage, SDK gates, and consent signals (`IABTCF_*`, `IABGPP_*`, Consent Mode) locally while dropping outgoing consent records. `useIdentify()` and `logout()` change local state only, and saves succeed with nothing queued. The app still fetches live policy from `/v1/consent/init` unless paired with a bundled manifest or in-code `policy`:

{/* example: fragment */}

```ts title="app.config.ts"
{
	projectUrl: 'https://your-project.inth.app',
	dryRun: process.env.INTH_DRY_RUN === '1',
}
```

Release builds refuse `dryRun`, leaving no engine installed (every read answers deny-all). Because prebuild does not know the upcoming build type, the plugin warns once and native code enforces it at launch:

| Platform | Release check | Refusal log |
| --- | --- | --- |
| iOS | Compiled without `DEBUG` | Console: `INTH_CONFIGURATION_DRY_RUN` |
| Android | `FLAG_DEBUGGABLE` is off | Logcat tag `inth` |

Leave `dryRun` unset in release builds. In debug builds with `dryRun: true`, `projectUrl` also accepts any `https` URL or `http` on `localhost`, `127.0.0.1`, or `[::1]` with a port and path (credentials, queries, and fragments stay refused).

## Set Expo options

See [Configure the plugin](/docs/frameworks/react-native/expo#configure-the-plugin) for a complete `app.config.ts`. Supported plugin options:

| Option | Purpose |
| --- | --- |
| `projectUrl` | Required. Project URL from your Inth dashboard ([rules](#set-your-inth-project-url)). |
| `dryRun` | Development and CI switch that drops consent records (default `false`; see [dryRun](#use-dryrun-in-development-and-ci)). |
| `domain` | Domain reported with subject writes. |
| `consentCategories` | Optional app category scope. |
| `vendors` | Optional IAB disclosure scope. |
| `iab` | Optional IAB TCF CMP identity and publisher settings ([details](#turn-on-iab-tcf)). |
| `gpp` | Optional IAB GPP string and `IABGPP_*` keys ([IAB GPP](/docs/frameworks/react-native/gpp)). |
| `policyResource` | Build-exported policy JSON path relative to the Expo project. |
| `bundleManifest` | Fetch and embed the manifest at prebuild with `c15t mobile-manifest` ([offline guide](/docs/frameworks/react-native/offline#bundle-the-manifest-at-build-time)). |
| `policy` | In-code `PolicyRule` list resolved on-device without `/v1/consent/init` (cannot mix with `policyResource`, `bundleManifest`, or `iab`; see [define the policy in code](/docs/frameworks/react-native/offline#define-the-policy-in-code)). |
| `androidMavenRepository` | Build-time Maven URL and credential env var names (pass names, never secret values). |
| `autoBootstrap` | Install natively on launch (default `true`; set `false` for app-owned installation). |
| `forceGPC` | GPC signal override for staging or test builds. |
| `enableAppTrackingTransparency` | Enable Apple ATT declarations (default `false`). |
| `trackingUsageDescription` | Plain-text ATT explanation (required when ATT is enabled). |
| `trackingMarkdownUsageDescription` | Optional expanded EU ATT copy. |
| `trackingMarkdownUsageDescriptionLocalizations` | Locale map for expanded ATT copy. |
| `skAdNetworkIdentifiers` | Native SKAdNetwork IDs when ATT is enabled. |
| `privacyTrackingDomains` | Native tracking domains when ATT is enabled. |

## Set bare RN metadata

Use these keys when configuring bare React Native (see [Bare React Native](/docs/frameworks/react-native/bare) for full file examples):

| Expo option | iOS `Info.plist` key | Android `<meta-data>` key |
| --- | --- | --- |
| `projectUrl` | `com.inth.backend.url` | `com.inth.BACKEND_URL` |
| `dryRun` | `com.inth.dryRun` (Boolean) | `com.inth.DRY_RUN` |
| `domain` | `com.inth.backend.domain` | `com.inth.BACKEND_DOMAIN` |
| `consentCategories` | `com.inth.categories` (string array) | `com.inth.CATEGORIES` (comma-separated) |
| `vendors` | `com.inth.vendors` | `com.inth.VENDORS` (comma-separated) |
| `policyResource` | `com.inth.policy.resource` | `com.inth.POLICY_RESOURCE` |
| `forceGPC` | `com.inth.forceGPC` | `com.inth.FORCE_GPC` |
| `iab` | `com.inth.iab.*` (below) | `com.inth.IAB_*` (below) |
| `autoBootstrap: false` | `com.inth.reactnative.AutoBootstrap` | `com.inth.reactnative.AUTO_BOOTSTRAP` |

Remove retired metadata keys (Expo prebuild deletes them automatically):

| Retired key | Replacement |
| --- | --- |
| `com.inth.backend.mode` (iOS), `com.inth.MODE` (Android) | Remove for hosted; use `com.inth.dryRun` / `com.inth.DRY_RUN` in debug builds. |
| `com.inth.backend.initUrl` (iOS), `com.inth.BACKEND_INIT_URL` (Android) | Remove. Policy always loads from `projectUrl`. |

Builds containing retired keys fail to start the engine (iOS logs `INTH_CONFIGURATION_RETIRED`, Android logs under `inth`), leaving every read deny-all until removed.

## Declare the categories your app uses

Valid category IDs are `necessary`, `functionality`, `experience`, `measurement`, and `marketing`. App declarations narrow scope and never grant permission. Omit `consentCategories` to follow the policy's full scope (empty arrays are rejected). Read `snapshot.consentCategories` when rendering custom controls.

Similarly, `vendors` narrows served IAB disclosures (must be non-empty when set) without enabling IAB or installing CMP identity.

## Turn on IAB TCF

Configure `iab` in Expo or the matching native keys in bare React Native so startup enables IAB TCF, writes `IABTCF_CmpSdkID` and `IABTCF_CmpSdkVersion`, and lets the native presenter save IAB choices:

| Expo `iab` field | iOS `Info.plist` key | Android metadata | Requirement |
| --- | --- | --- | --- |
| `cmpId` | `com.inth.iab.cmpId` (integer) | `com.inth.IAB_CMP_ID` | Required. IAB-registered CMP ID (`2` to `4095`). |
| `cmpVersion` | `com.inth.iab.cmpVersion` (integer) | `com.inth.IAB_CMP_VERSION` | Required. Internal CMP version (`0` to `4095`). |
| `publisherCountryCode` | `com.inth.iab.publisherCountryCode` | `com.inth.IAB_PUBLISHER_COUNTRY_CODE` | Required. Two-letter ISO code (such as `DE`). |
| `consentScreen` | `com.inth.iab.consentScreen` (integer) | `com.inth.IAB_CONSENT_SCREEN` | Optional. `0` to `63` (default `1`). |

Expo fails prebuild on missing or out-of-range values. In bare builds, incomplete or invalid keys log an error and start the engine without IAB (`iab-unavailable` on IAB saves). Configure an IAB policy in your Inth project and rebuild after editing these keys. For publisher restrictions or custom purposes, install the engine natively; see [Mobile IAB and ads](/docs/frameworks/react-native/iab).

## Preview a regional policy

Call the setter from `useSetOverrides()` with `country`, `region`, `language`, or `gpc` in debug menus to test regional rules without recording a choice. Omitted fields remain unchanged; `null` clears an override. `snapshot.privacySignals.gpc.active` reflects the effective GPC state. Remove overrides before shipping.

## Add a policy for offline startup

Embed a build-time manifest via `bundleManifest` or `policyResource` (or matching native metadata) so fresh offline installs can prompt and queue choices until reconnect. See [Mobile offline consent](/docs/frameworks/react-native/offline).

## Let your app install the engine

Set `autoBootstrap: false` in brownfield apps or apps owning native initialization. Call `InthApple.install` (iOS) or `InthAndroid.install` (Android) once before React Native and optional SDKs start, then attach the RN adapter. See [Native startup and SDK gates](/docs/frameworks/react-native/native-behaviour) and [Mobile IAB and ads](/docs/frameworks/react-native/iab).
