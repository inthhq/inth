Follow this guide if your React Native project manages its own `ios` and `android` folders. It configures the native consent engine before React boots, then wires `InthProvider` in JavaScript. For Expo prebuild apps, use [Expo and EAS](/docs/frameworks/react-native/expo).

## Before you start

Confirm your app uses the New Architecture and meets the versions in [Compatibility and updates](/docs/frameworks/react-native/platform-support). Install the private prerelease tarball from your app directory:

```sh
npm install /absolute/path/to/inth-react-native.tgz
```

Have your Inth project URL and HTTPS privacy policy URL ready (see [Before you start](/docs/frameworks/react-native/quickstart#before-you-start)). The mobile SDK connects to Inth hosted projects only; see [Configuration](/docs/frameworks/react-native/configuration) for every metadata key and `dryRun`.

## Set up iOS

### Link the native module

Install pods from `ios/`:

```sh
cd ios
bundle exec pod install
```

Open the generated `.xcworkspace` in Xcode. Autolinking picks up `InthReactNative.podspec`, which compiles the vendored native core, Apple services, and SwiftUI screens. Do not link standalone SwiftPM `InthCore` or `InthApple` products alongside it, or your app will run two competing consent authorities.

If your project centralizes repositories in `settings.gradle`, place the block there with the `com.inth` group filter intact. Let the React Native adapter pin the native `com.inth` artifact version rather than adding separate versions manually.

## Add the React root

Wrap `App.tsx` in `InthProvider` with your HTTPS privacy policy URL as shown in [Add the consent provider](/docs/frameworks/react-native/quickstart#add-the-consent-provider).

Disable vendor auto-initializers and add [native startup gates](/docs/frameworks/react-native/native-behaviour) for any native SDK that starts before React. If you use Google Analytics for Firebase, deny its four Consent Mode defaults in `firebase.json` (see [Deny Consent Mode signals by default](/docs/integrations/firebase-analytics#deny-consent-mode-signals-by-default)).

## Build and verify

Build each platform from your app directory after native changes (a Metro reload is not enough):

```sh
npx react-native run-ios
npx react-native run-android
```

Verify fresh prompts, Reject all across restarts, Privacy settings reopening, and SDK start/stop behavior using the [quickstart checklist](/docs/frameworks/react-native/quickstart#check-that-it-works).

## Own native installation directly

Automatic startup handles standard category consent and IAB CMP metadata from [Turn on IAB TCF](/docs/frameworks/react-native/configuration#turn-on-iab-tcf). In brownfield apps or apps requiring IAB publisher restrictions or custom purposes, disable automatic startup and install the engine natively before React Native boots:

- **iOS.** Set `com.inth.reactnative.AutoBootstrap` to `false`, call `InthApple.install(InthAppleConfiguration(backendURL:))` from the `InthReactNative` module with `configuration.platform = "rn"`, and attach via `InthReactNativeBootstrap.install(core)`.
- **Android.** Set `com.inth.reactnative.AUTO_BOOTSTRAP` to `false`, call `InthAndroid.install` before starting the React host, and set `platform = InthProtocol.PLATFORM_REACT_NATIVE` in `NativeConfig`.

See [Mobile IAB and ads](/docs/guides/mobile-iab) for native CMP and publisher configuration.
