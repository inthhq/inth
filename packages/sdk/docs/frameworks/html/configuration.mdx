Configure advanced Inth script tag options on plain HTML pages through a
queued `config` call before `inth.js` runs.

## Pass options before the tag

Queue `config` in an inline `<script>` ahead of the deferred `inth.js` tag:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', {
    legalLinks: { privacyPolicy: { href: '/privacy' } },
    ui: { banner: { legalLinks: ['privacyPolicy'] } },
    reloadOnConsentRevoked: true,
  }]);
</script>
<script
  src="https://your-project.inth.app/inth.js"
  defer
></script>
```

Later `config` calls override earlier ones, and all override tag attributes.
`ui`, `ui.banner` and `ui.dialog` merge shallowly key by key; other options
replace earlier values. Calling `config` after startup logs a warning and
does nothing; see [how options merge](/docs/frameworks/html/api#how-options-merge).

## Which attribute sets which option

| Attribute | Option |
| --- | --- |
| `data-project-url` | `projectUrl` |
| `data-mode` | `mode` |
| `data-manifest-url` | `manifestUrl` |
| `data-policy` | `policy` (`inth.testing.js` only) |
| `data-categories` | `consentCategories` |
| `data-country`, `data-region`, `data-language` | `overrides.country`, `overrides.region`, `overrides.language` |
| `data-privacy-policy-url`, `data-cookie-policy-url`, `data-terms-url` | `legalLinks`, `ui.banner.legalLinks`, `ui.dialog.legalLinks` |
| `data-color-scheme` | `ui.colorScheme` |
| `data-trigger` | `ui.trigger: true` |
| `data-hide-branding` | `ui.banner.hideBranding`, `ui.dialog.hideBranding` |
| `data-opt-out-link` | `presentation.optOutLink` |
| `data-shadow="false"` | `ui.shadow: false` |
| `data-no-ui` | `ui: false` |
| `data-nonce` or tag `nonce` | `nonce` |

## Store the consent cookie across subdomains

By default Inth stores choices in cookie and `localStorage` key `inth` on the
current host for 365 days. Share consent across subdomains with
`storageConfig`:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', {
    storageConfig: { crossSubdomain: true, defaultExpiryDays: 180 },
  }]);
</script>
```

`crossSubdomain` targets the root domain; `defaultDomain` (such as
`'.example.com'`) sets an explicit domain and takes precedence. Use identical
settings on every subdomain. See
[keep open tabs in step](/docs/concepts/consent-state#keep-open-tabs-in-step).

## Turn consent management off

`enabled: false` grants all categories, hides consent UI and runs all scripts
immediately. Use only for internal previews, never for real visitors.
