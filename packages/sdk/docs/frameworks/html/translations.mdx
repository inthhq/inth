Control the language and wording of the Inth banner and preference dialog on
a plain HTML site.

## Where the copy comes from

The script tag bundles English only. Other languages load according to mode:

| Mode | Where the copy comes from |
| --- | --- |
| Hosted (`data-project-url` or `<projectUrl>/inth.js`) | Your Inth project. Inth picks the language from the browser or `data-language` and returns its copy with the policy. |
| Manifest | The manifest's translations for the visitor's language. |
| Testing (`inth.testing.js`) | English, plus languages supplied in `i18n.messages`. |

In every mode, `i18n.messages` overrides matching keys for the active
language. Direct strings in `ui.banner` (such as `title` or
`acceptButtonText`) override translations in every language.

## Pick the language

In hosted and manifest modes, Inth follows the visitor's browser language.
Force a specific language with `data-language`:

{/* example: fragment */}

```html
<script
  src="https://your-project.inth.app/inth.js"
  data-language="de"
  defer
></script>
```

Multilingual sites can print each page's locale into `data-language` from
their CMS template.

To switch languages at runtime, call `inth.setLanguage('fr')`. In hosted
mode, Inth fetches French copy and re-renders. With `inth.testing.js`,
`setLanguage()` switches to any language defined in `i18n.messages`; see
[add a language on a test page](#add-a-language-on-a-test-page).

## Change the wording

Override specific keys in a queued `config` call; omitted keys keep their
default text:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', {
    i18n: {
      locale: 'en',
      messages: {
        en: {
          common: { acceptAll: 'Accept', rejectAll: 'Reject optional' },
          cookieBanner: { title: 'Cookies on this site' },
        },
      },
    },
  }]);
</script>
```

Inth matches the exact language code first, then its primary language
(`de-AT` falls back to `de`). A key overrides your Inth project's copy only
when your text differs from the built-in wording for that language, so
dashboard edits remain visible for keys you did not customize.

## Add a language on a test page

With `inth.testing.js`, queue `i18n` before the script tag to supply
translations over the English defaults:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', {
    i18n: {
      locale: 'de',
      messages: {
        de: {
          common: {
            acceptAll: 'Alle akzeptieren',
            rejectAll: 'Alle ablehnen',
            customize: 'Anpassen',
            save: 'Einstellungen speichern',
            acknowledge: 'OK',
          },
          cookieBanner: {
            title: 'Wir respektieren Ihre Privatsphäre',
            description: 'Diese Website verwendet Cookies, um Ihr Erlebnis zu verbessern.',
          },
        },
      },
    },
  }]);
</script>
```

Omitted keys stay in English. Provide one entry per language you test so
`data-language` and `inth.setLanguage()` switch between them.

## Message keys the stock UI reads

| Key | Where it shows |
| --- | --- |
| `cookieBanner.title`, `cookieBanner.description` | Choice banner heading and body. |
| `cookieBanner.noticeTitle`, `cookieBanner.noticeDescription` | Notice banner heading and body. |
| `common.acceptAll`, `common.rejectAll`, `common.customize` | Banner and dialog buttons. |
| `common.acknowledge` | Notice dismiss button. |
| `common.save` | Dialog save button. |
| `common.securedBy` | "Consent by" tag. |
| `consentManagerDialog.title`, `consentManagerDialog.description` | Dialog heading and body. |
| `consentTypes.<category>.title`, `consentTypes.<category>.description` | Each category row in the dialog. |
| `legalLinks.privacyPolicy`, `legalLinks.cookiePolicy`, `legalLinks.termsOfService` | Legal link labels when no explicit `label` is set. |
| `rights.optOut`, `rights.privacyChoices`, `rights.californiaPrivacyChoices`, `rights.preferences` | Rights button under opt-out policies and the "Manage preferences" link in the opt-out confirmation view. `rights.privacyChoices` and `rights.californiaPrivacyChoices` always render with the California Privacy Protection Agency opt-out icon. |
| `optOut.statusRequest`, `optOut.statusSignal`, `optOut.description`, `optOut.done`, `optOut.lockedByGpc`, `optOut.lockedByAccount` | Opt-out confirmation view, honored status line in preferences, and GPC and account lock notices below restricted categories. |

Set the floating trigger's accessible label per page via
`ui.trigger.ariaLabel`.

## Right-to-left languages

For right-to-left languages such as Hebrew or Arabic, the banner and dialog
set `dir="rtl"` while staying in their configured corner. Check wrapping and
button order after switching. See
[copy and translations](/docs/customization/translations).

## Check it works

1. Set your browser language to German and open the page in a private window
   to verify German copy loads from Inth.
2. Add `data-language="fr"` and reload to confirm French copy renders.
3. Open the preference dialog and confirm headings, categories and buttons
   match the banner's language.
