Customize the stock script tag banner and dialog using theme tokens, shadow
root CSS, layout options, legal links or your own HTML.

## See the designs

See the [design gallery](/docs/customization/recipes) for five tested banner
designs, including a custom bottom bar built on the headless script tag.

## Change colors, radius and fonts

Queue a `config` call with `ui.theme` before `inth.js`:

<include src="../../shared/examples/html/theme.mdx" />

Place the block in `<head>`. Because `inth.js` uses `defer`, inline scripts
run before it starts. `theme` uses the same token object as every Inth
package; [theme tokens](/docs/customization/tokens) lists every token. The
banner, preference dialog and floating trigger all share these tokens.

## Add CSS inside the shadow root

By default the UI renders inside a shadow root with its own stylesheet so
site CSS cannot break the banner. Pass extra rules in `ui.css` to append them
after the bundled stylesheet inside the shadow root:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', {
    ui: { css: '[data-testid="consent-banner-card"] { border: 3px solid #6943a3; }' },
  }]);
</script>
```

Target parts by `data-testid`. To apply classes from an external stylesheet
such as Tailwind, set `ui.theme.slots` and pass `ui.stylesheetUrls` into the
shadow root, or target parts from page CSS with
`[data-inth-ui]::part(consentBannerCard)`. See
[class names and CSS-in-JS](/docs/customization/class-names),
[Tailwind CSS](/docs/customization/tailwind) and
[component parts](/docs/customization/slots).

## Style it with your own stylesheet

Add `data-shadow="false"` to the script tag (or `ui: { shadow: false }`) to
render into the page DOM so page CSS applies directly:

{/* example: fragment */}

```css
[data-inth-ui] [data-testid="consent-banner-card"] {
  border: 3px solid #6943a3;
}
```

In light DOM, Inth's rules sit in `@layer components`, so unlayered site
rules (including Tailwind 3 preflight or global `button {}` styles) override
them. Keep the shadow root if your site uses Tailwind 3 or aggressive resets.
Set `ui: { shadow: false, noStyle: true }` to drop stock styles completely
while keeping `data-testid` hooks, or `ui: { shadow: false, styles: false }`
to serve `dist/inth.css` as an external stylesheet.

## Change the banner's shape and position

Configure `presentation.prompt`:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', {
    presentation: { prompt: { variant: 'bar', position: 'bottom' } },
  }]);
</script>
```

| `variant` | Positions |
| --- | --- |
| `floating` (default) | `bottom-left` (default), `bottom-right`, `top-left`, `top-right`, `bottom-center`, `top-center` |
| `bar` | `bottom` (default), `top` |
| `widget` | `bottom-right` (default), `bottom-left`, `top-left`, `top-right` |
| `wall` | `center` |

See [banner layout](/docs/frameworks/html/components/banner#change-the-layout)
for button grouping. Where presentation conflicts with policy rules, the
policy wins; see
[keep behavior and appearance separate](/docs/customization/overview#keep-behavior-and-appearance-separate).

## Change the copy and language

Override single banner strings with `ui.banner.title`, `description`,
`acceptButtonText`, `rejectButtonText` or `customizeButtonText`; see
[banner text](/docs/frameworks/html/components/banner#change-the-text). For
shared wording and languages, see
[translations](/docs/frameworks/html/translations).

The script bundles English only; other languages load from your Inth project,
manifest or `i18n` messages. Add `data-language="de"` on the tag to force a
language.

## Show legal links

Add `data-privacy-policy-url`, `data-cookie-policy-url` or `data-terms-url`
to the tag to display links on both surfaces. To pick different links per
surface, configure `legalLinks` in `config` and pass arrays to
`ui.banner.legalLinks` and `ui.dialog.legalLinks` (`null` or `[]` hides
them).

Add `data-hide-branding` to remove the "Consent by" tag from both surfaces.

## Set dark mode and animation

`data-color-scheme` accepts `light`, `dark`, `system` (default), or `none`
(follows a `dark` or `inth-dark` class on `<html>`). See
[dark mode](/docs/customization/dark-mode) for `ui.theme.dark` tokens.

`data-disable-animation` disables banner and dialog transitions. By default,
Inth respects `prefers-reduced-motion`; see
[motion and animation](/docs/customization/motion).

## Build your own banner

Load `inth.headless.js` instead of `inth.js` to render custom HTML while
keeping policy resolution, storage, script gating and `data-inth-action`
buttons. See [headless](/docs/frameworks/html/headless).

## Check it works

1. Open the page in a private window and verify your colors and radius apply.
2. Open the preference dialog (and floating trigger if enabled) to confirm
   shared tokens apply.
3. Toggle OS light/dark mode and confirm `data-color-scheme="system"`
   updates.
