Add a consent banner, preference dialog and script gating to a plain HTML
site, CMS theme or static site generator with one `<script>` tag and no build
step.

<Prompt title="Add Inth consent to this HTML site" description="Paste into Claude Code, Codex, Cursor or another coding agent at the root of your site.">
  Add Inth consent management to this HTML site using the script tag.

  1. Check that the site serves HTML templates without a framework adapter (Next.js, React, Vue, Svelte, Astro, Angular). If it uses one of those frameworks, stop and tell me.
  2. If `@inth/sdk` is installed locally, read `node_modules/@inth/sdk/AGENTS.md` and follow the HTML quickstart. Otherwise follow this HTML script tag setup directly without guessing API names.
  3. Ask me for my Inth project URL, using `https://example-inth.inth.app` only for a demo. Add `<script src="<projectUrl>/inth.js" defer></script>` to the shared `<head>` rendered by every page.
  4. Find every analytics, marketing and ad script tag across templates. Change each to `<script type="text/plain" data-inth-category="measurement">` (or `marketing`) and remove any duplicate active loaders.
  5. For third-party iframes (YouTube, Google Maps), move `src` to `data-src` and add `data-category`.
  6. Add `<a href="#inth-preferences">Privacy settings</a>` to the shared footer.
  7. Open the site in a private window with DevTools Network open. Confirm no vendor request fires before consent, rejecting survives a reload, and granting analytics from Privacy settings loads the vendor.

  Then list the files you changed, any script still outside consent, and how you checked the requests.
</Prompt>

## Prerequisites

- Access to your shared `<head>` and footer templates. Using a bundler or UI
  framework? See the [framework list](/docs/frameworks).
- An [Inth project](https://inth.com/dashboard/sign-up?framework=html) with
  your site's origin in trusted origins.

## Add the script tag

Paste this tag into your shared `<head>`. Replace
`https://your-project.inth.app` with your Inth project URL (or
`https://example-inth.inth.app` for a demo) and keep `/inth.js` on the end:

<include src="../../shared/examples/html/script-tag.mdx" />

Inth serves `inth.js` preconfigured for your project, so no
`data-project-url` attribute is needed. `inth.js` fetches `/v1/consent/init`, displays
the banner, handles Accept or Reject clicks, and loads `inth.hosted.js` in
the background. See
[how inth.js loads inth.hosted.js](/docs/frameworks/html/attributes-and-api#how-inthjs-loads-inthhostedjs)
and [Install on your platform](/docs/frameworks/html/platforms) for
WordPress, Webflow, Shopify, Squarespace, Wix, Framer, Ghost, Hugo, Eleventy
and Jekyll.

## Gate your vendor scripts

Change each vendor `<script>` tag to `type="text/plain"` and add
`data-inth-category`:

<include src="../../shared/examples/html/vendor-scripts.mdx" />

Remove any active duplicate copy added by a theme or plugin. Use
`measurement` for analytics and `marketing` for ads; see
[consent categories](/docs/concepts/consent-categories),
[gated scripts](/docs/frameworks/html/components/gated-script) and
[scripts](/docs/frameworks/html/scripts).

## Gate embeds

Move an iframe's `src` to `data-src` and add `data-category`:

<include src="../../shared/examples/html/embed.mdx" />

Inth copies `data-src` to `src` once allowed and removes `src` on revocation.
Hide empty iframes in CSS; see [embeds](/docs/frameworks/html/embeds).

## Check it works

Open the published page in a private window with DevTools Network open:

1. Under an opt-in policy, the banner appears, no `posthog` requests fire,
   and the YouTube iframe has no `src`.
2. Click **Reject All** and reload. The banner stays closed and PostHog does
   not load.
3. Click **Privacy settings**, turn on **Analytics** (`measurement`) and
   save. PostHog and YouTube load.
4. Turn **Analytics** off and save. The page reloads and neither loads again.

If no banner appears, check
[HTML troubleshooting](/docs/frameworks/html/troubleshooting) and
[verify consent](/docs/guides/verify-consent).

## Other ways to run the tag

| Setup | How to load it |
| --- | --- |
| Pinned CDN version | Load `https://cdn.jsdelivr.net/npm/@inth/sdk@<version>/lib/browser/dist/inth.js` with `data-project-url` and `defer` (keep companion files in the same folder if mirroring). |
| Manifest mode | Use `inth.headless.js`, `inth.iab.js`, or `@inth/sdk`; see [choose a mode](/docs/frameworks/html/attributes-and-api#choose-a-mode). |
| Test pages | Load `inth.testing.js` without `data-project-url` (never deploy to production). |
