Turn any HTML button into an Inth consent control using `data-inth-action`
with zero custom JavaScript.

## Wire a button without code

Add `data-inth-action` to an element:

{/* example: fragment */}

```html
<button type="button" data-inth-action="customize">Cookie settings</button>
```

Works across `inth.js`, `inth.testing.js`, `inth.headless.js`, `inth.iab.js`
and `init()` from `@inth/sdk`.

## Actions

Unknown values are ignored. `accept` and `reject` close the active surface
immediately and send the choice to Inth in the background.

## How clicks are matched

Inth delegates clicks on `document`, so:

- buttons added dynamically after page load work automatically;
- clicks on nested elements (such as an icon inside the button) trigger the
  action;
- Inth calls `preventDefault()`, preventing link navigation and form
  submission.

## Only record choices from visitor clicks

`accept` and `reject` record legal consent choices. Place them on clearly
labelled buttons the visitor intentionally clicks, never triggered via
`element.click()` or hidden inside broader clickable containers.

Use `customize` for "Cookie settings" controls that only open the preference
dialog. Use `opt-out` for a "Do Not Sell or Share My Personal Information" or
"Your Privacy Choices" link so one click records the opt-out under an opt-out
policy and shows a confirmation view. Under any other policy, `opt-out` opens
the preference dialog.

## Build a banner from action buttons

With the [headless build](/docs/frameworks/html/headless), combine
`data-inth-action` buttons (`accept`, `reject`, `customize`, `dismiss`) with
the `ui` event to build a custom banner.

## Accessibility

Inth adds no ARIA role or keyboard behavior. Always use a native `<button>`
for actions so keyboard users can focus and trigger them with Enter or Space.

## Check it works

1. Add a `data-inth-action="reject"` button and open the page in a private
   window.
2. Click the button. The banner closes and DevTools Network shows `POST /v1/consent/records`.
3. Reload. The banner stays closed.
