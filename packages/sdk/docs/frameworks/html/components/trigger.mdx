Display a fixed, draggable corner button that reopens the preference dialog
from any page using `data-trigger`.

## Add the trigger

Add `data-trigger` to the `inth.js` script tag:

{/* example: fragment */}

```html
<script
  src="https://your-project.inth.app/inth.js"
  data-trigger
  defer
></script>
```

The trigger is off by default (`data-trigger="false"` keeps it off). For
sites with a legal footer, a
[preferences link](/docs/frameworks/html/components/preferences-link) offers
the same access without a floating overlay.

## Set its corner, size and visibility

Configure options under `ui.trigger` in a queued `config` call:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', {
    ui: {
      trigger: {
        position: 'bottom-left',
        size: 'sm',
        showWhen: 'after-consent',
        ariaLabel: 'Cookie settings',
      },
    },
  }]);
</script>
```

## When it shows

The trigger hides while the banner or dialog is open. With
`showWhen: 'after-consent'`, it stays hidden until the visitor answers the
initial prompt.

## Drag it to another corner

Visitors can drag the trigger to snap it to another corner. Inth saves the
dragged corner in `localStorage` under `inth-trigger-position`, overriding
`position` on future visits unless `persistPosition: false` is set. Dragging
does not open the dialog; clicking or pressing Enter or Space opens it.

## Keyboard and screen readers

The trigger is an icon-only native `<button>`, so `ariaLabel` provides its
accessible name. Translate `ariaLabel` into the page's language. Because the
UI host appends to `<body>`, the trigger sits at the end of the page tab
order.

## Open DevTools from it

When the [DevTools tag](/docs/frameworks/html/dev-tools) is loaded, the
trigger expands into a two-button toolbar pairing preferences and DevTools
in the same corner.

## Style it

Shared theme tokens apply automatically. In `ui.css`, select
`[data-testid="consent-dialog-trigger"]` (`data-position` and `data-size`
reflect the active corner and size).

## Check it works

1. Accept or reject in the banner. The trigger appears in its corner.
2. Click it. The preference dialog opens and the trigger hides.
3. Drag it to another corner and reload. It stays in the new corner.
4. Tab to the trigger and press Enter to open the dialog.
