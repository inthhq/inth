The preference dialog rendered by `inth.js` lets visitors review and toggle
individual consent categories and vendors without extra markup.

## What the dialog shows

The dialog stays closed until opened by:

- the banner's **Customize** button;
- a [`data-inth-action="customize"` button](/docs/frameworks/html/components/action-buttons);
- a [link to `#inth-preferences`](/docs/frameworks/html/components/preferences-link);
- the [floating trigger](/docs/frameworks/html/components/trigger);
- `inth.openDialog()` in JavaScript.

Opening the dialog records nothing and changes no permissions.

## Which categories it lists

`necessary` appears first (always on, locked), followed by optional
categories used on the page within the policy's scope:

- categories referenced on `<script type="text/plain" data-inth-category>`,
  `<iframe data-category>`, `scripts` entries and network blocker rules;
- categories listed in `data-categories` on the tag or `consentCategories` in
  `config`.

If the page declares no categories, the dialog lists every category in the
policy scope. Use `data-categories` when a tag manager or external script
needs a category not present in page tags:

{/* example: fragment */}

```html
<script
  src="https://your-project.inth.app/inth.js"
  data-categories="measurement,marketing"
  defer
></script>
```

See [consent categories](/docs/concepts/consent-categories) and
[vendor consent](/docs/frameworks/html/vendor-consent).

## What the switches start at

Each switch initializes in this precedence order:

1. unsaved changes toggled while this dialog is open;
2. the visitor's recorded choice;
3. `presentation.preferences.defaults`, if configured;
4. on under opt-out or preselected policy categories, otherwise off.

Closing without saving discards unsaved switch changes.

## Buttons

The dialog displays Reject All, Accept All and Save Settings. All three are
policy-required and close both the dialog and any underlying banner. Layout
options live under `presentation.preferences`.

## Options

<import src="../../../shared/browser/client-options.mdx#dialog" />

Setting `ui: { dialog: false }` disables the stock dialog. Use it only when
rendering your own dialog with [headless](/docs/frameworks/html/headless).

## Keyboard and screen readers

- Renders as `role="dialog"` with `aria-labelledby` and `aria-describedby`.
- Blocking by default (focus trap and scroll lock); disable with
  `presentation.preferences.blocking: false`.
- Escape closes without saving and restores the banner if a choice is still
  due. Clicking the backdrop does not close it.
- Each category header expands its description and pairs with a
  `role="switch"` control (`necessary` is disabled).
- Sets `lang` and `dir` from the resolved language.

## Style it

Shared theme tokens apply automatically (see
[customize](/docs/frameworks/html/customize)). Target specific parts in
`ui.css` by `data-testid`:

| `data-testid` | Element |
| --- | --- |
| `consent-dialog-root` | Dialog element. |
| `consent-dialog-card`, `consent-dialog-header`, `consent-dialog-content` | Card and inner sections. |
| `consent-dialog-title`, `consent-dialog-description` | Heading and description. |
| `consent-widget-accordion-item-<category>` | Category row (for example, `measurement`). |
| `consent-widget-switch-<category>` | Category switch. |
| `consent-widget-vendor-list-<category>` | Category vendor list. |
| `consent-widget-vendor-switch-<category>-<vendor>` | Individual vendor switch. |
| `consent-widget-footer` | Button row. |
| `consent-widget-footer-accept-all-button`, `consent-widget-reject-button`, `consent-widget-footer-save-button` | Action buttons. |
| `consent-dialog-branding` | "Secured by" tag. |
| `consent-dialog-overlay` | Backdrop. |

## Check it works

1. Click a **Privacy settings** link. The dialog opens with focus on its
   first control.
2. Enable **Analytics** (`measurement`) only and click **Save Settings**.
   Measurement vendors load while marketing stays blocked.
3. Reopen the dialog and confirm **Analytics** is on and **Marketing** is
   off.
4. Toggle **Marketing** on, press Escape and reopen. **Marketing** remains
   off.
