Hold third-party `<script>` tags inert until their consent category is
allowed using `type="text/plain"` and `data-inth-category`.

## Make a script wait for consent

Change the vendor tag's `type` to `text/plain` and add `data-inth-category`.
Browsers ignore `text/plain` scripts until Inth replaces them with an active
copy once consent allows that category:

<include src="../../../shared/examples/html/gated-scripts.mdx" />

Both external (`src`) and inline snippets work. Remove the original active
copy of each vendor tag so it cannot run before consent.

## Attributes

| Attribute | Required | What it does |
| --- | --- | --- |
| `type="text/plain"` | Yes | Stops the browser from executing the script until activated. |
| `data-inth-category` | Yes | Category name: `necessary`, `functionality`, `experience`, `measurement` or `marketing`. |
| `data-inth-vendor` | No | Vendor slug; tag also waits if the visitor turned this vendor off. See [vendor consent](/docs/frameworks/html/vendor-consent). |
| `src` | No | External script URL. Without `src`, Inth executes the inline body. |
| `async` | No | Loads in parallel without blocking subsequent gated tags. |
| `data-inth-activated` | Set by Inth | `true` once run, `invalid` for an unknown category, `untrusted` if missing a required CSP nonce. Do not set manually. |

`necessary` tags run immediately when Inth starts. Unknown category names log
a console warning and never run.

## What Inth copies to the new tag

The activated `<script>` preserves `src`, `async`, `defer`, `crossorigin`,
`referrerpolicy`, `id`, `nonce`, all other `data-*` attributes and inline
code, replacing `type` with `data-inth-activated="true"`. Other attributes
such as `class` or `fetchpriority` are not copied.

Copying `nonce` keeps nonce-based CSP working. `defer` has no effect on
dynamically inserted scripts, so rely on page order below.

## Load order

Inth activates permitted tags in document order:

- External tags without `async` finish loading (or failing) before the next
  gated tag runs, so inline snippets after a library tag can safely call it.
- External tags with `async` start loading without blocking subsequent tags.
- Tags granted later run in page order among themselves.

For example, GA4's library tag and inline config tag stay ordered when you
leave `async` off the first tag:

{/* example: fragment */}

```html
<script type="text/plain" data-inth-category="measurement" src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXX"></script>
<script type="text/plain" data-inth-category="measurement">
  window.dataLayer = window.dataLayer || [];
  function gtag() { dataLayer.push(arguments); }
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXX');
</script>
```

## When Inth looks for tags

- On startup (immediately running tags already allowed for returning
  visitors).
- After any permission change (accept, save or policy resolution).
- When a new gated tag is inserted dynamically into the DOM.

Each tag executes at most once per page load.

## Gated tags on a page with a nonce

When the Inth script tag carries a `nonce` or `data-nonce`, Inth executes
only gated tags carrying the exact same `nonce`:

{/* example: fragment */}

```html
<script nonce="RANDOM_PER_RESPONSE" type="text/plain" data-inth-category="measurement">
  // The vendor's snippet
</script>
```

Gated tags missing the matching nonce are skipped, logged with a warning,
marked `data-inth-activated="untrusted"`, and excluded from dialog
categories. This prevents injected markup from executing when a visitor
grants consent. See
[Content Security Policy](/docs/frameworks/html/content-security-policy).

## The categories reach the dialog

Inth adds every valid gated tag's category to the
[preference dialog](/docs/frameworks/html/components/dialog) within the
policy scope.

## What happens when a visitor withdraws permission

When a visitor turns off an allowed category, Inth saves the choice and
reloads the page so gated tags start inert again. See
[what happens when a visitor withdraws permission](/docs/frameworks/html/scripts#what-happens-when-a-visitor-withdraws-permission).

## When to use config scripts instead

Use a `scripts` entry in `config` when you need `onLoad`, `onError` or
`onConsentChange` callbacks; see
[load a script with callbacks](/docs/frameworks/html/scripts#load-a-script-with-callbacks).

## Check it works

Open the page in a private window with DevTools Network open:

1. Filter for the vendor domain. Nothing loads before a choice.
2. Allow the category. The request fires and the element gains
   `data-inth-activated="true"` with no `type`.
3. Reload. The vendor loads immediately from stored consent.
