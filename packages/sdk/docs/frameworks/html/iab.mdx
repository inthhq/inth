Enable IAB TCF 2.4 on a plain HTML page with `inth.iab.js` so ad partners can
read confirmed TC Strings through `window.__tcfapi`.

## Load the IAB build

Replace `inth.js` with `inth.iab.js` when your policy uses IAB TCF. It
bundles the CMP, TC String encoder, IAB banner and purpose/vendor preference
dialog. Standard `inth.js` and `inth.headless.js` omit IAB code and throw
`IABUnavailableError` (`INTH_IAB_UNAVAILABLE`) if a policy resolves the `iab`
model:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', {
    iab: { cmpId: YOUR_CMP_ID, vendors: [1, 2, 755] },
    legalLinks: {
      privacyPolicy: { href: '/privacy' },
      cookiePolicy: { href: '/cookies' },
    },
    ui: {
      banner: { legalLinks: ['privacyPolicy', 'cookiePolicy'] },
      dialog: { legalLinks: ['privacyPolicy'] },
    },
  }]);
</script>
<script
  src="https://your-project.inth.app/inth.iab.js"
  defer
></script>
```

Replace `YOUR_CMP_ID` with the CMP ID IAB Europe assigned your company at
[registration](https://register.consensu.org/CMP), or configure `cmpId` and
your vendor allowlist in your Inth project settings. Never ship a demo CMP ID
in production.

Load only one Inth script bundle per page (`inth.iab.js` throws if another
bundle loaded first). Outside IAB regions, `inth.iab.js` renders the standard
banner. If the Global Vendor List fails to load, the IAB banner shows an
error and keeps confirm buttons disabled.

## Confirm IAB choices from your code

`inth.acceptAll()` and `inth.rejectAll()` confirm through the CMP under IAB.
For granular changes, edit the CMP handle draft and call `saveIAB()`:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['onInit', async (client) => {
    await client.ready();
    const cmp = client.runtime.iab;
    if (!cmp) return;
    await cmp.whenReady?.();
    cmp.setPurposeConsent(1, true);
    cmp.setVendorConsent(755, true);
    const result = await client.saveIAB();
    if (!result.ok) client.openDialog();
  }]);
</script>
```

`cmp` also provides `setPurposeLegitimateInterest`,
`setVendorLegitimateInterest` and `setSpecialFeatureOptIn`. Category-only
`inth.save({ ... })` fails under an IAB policy because it cannot encode a TC
String. The CMP installs `window.__tcfapi`, and `inth.dispose()` removes it.

## How the stock dialog groups choices

In the stock preference dialog, toggling a purpose updates vendors declaring
that purpose on a consent basis, toggling legitimate interest updates
legitimate-interest vendors, and toggling a stack covers its consent
purposes. The Vendors tab adds search and per-vendor disclosures from the
Global Vendor List. Direct `runtime.iab` setters modify only the single flag
you pass.

## Style and word the IAB UI

`inth.iab.js` uses the same `ui.theme`, `ui.css` and `ui.shadow` options; see
[customize](/docs/frameworks/html/customize). With `shadow: false` and
external stylesheets, load both `dist/inth.css` and `dist/inth.iab.css`.

The IAB banner always retains branding; `ui.dialog.hideBranding` hides it in
the preference dialog. Banner text options accept `{partnerCount}` in
`description`, and `ui.iab` accepts `loadErrorText`, `saveErrorText` and
`moreVendorsText`. Pass `ui: false` to render a custom IAB UI against the
client.

## Try it locally

Build `@inth/sdk`, update `projectUrl` in
`internals/fixtures/script-tag/iab.html`, run
`bun run --cwd internals/fixtures/script-tag dev` and open `/iab` (replace
the demo CMP ID before deploying).
