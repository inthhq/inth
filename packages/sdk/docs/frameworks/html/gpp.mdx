Add `inth.gpp.js` to a plain HTML page to install `window.__gpp` (GPP 1.1 CMP
API) and keep its GPP string synced with visitor choices.

## Load the GPP script

Include `inth.gpp.js` alongside `inth.js`, `inth.testing.js`,
`inth.headless.js` or `inth.iab.js`:

{/* example: fragment */}

```html
<script src="https://cdn.jsdelivr.net/npm/@inth/sdk/lib/browser/dist/inth.gpp.js"></script>
<script
  src="https://your-project.inth.app/inth.js"
  defer
></script>
```

Loading `inth.gpp.js` enables GPP with defaults and immediately installs a
`__gpp` stub so early ad tags queue safely. Load it without `defer` ahead of
ad tags (its order relative to `inth.js` does not matter), pinned to the same
`@inth/sdk` version. Pages that omit `inth.gpp.js` download zero GPP code.

## Change the GPP options

Queue a `gpp` object in `config`:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', {
    gpp: { usFallback: 'none' },
  }]);
</script>
```

Pass `gpp: false` to disable GPP and remove its stub. `inth.dispose()` also
removes `__gpp`. To include the TCF EU section under an `iab` policy, load
`inth.iab.js` instead of `inth.js`; see [IAB TCF](/docs/frameworks/html/iab).
