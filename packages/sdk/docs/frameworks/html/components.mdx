The Inth script tag (`inth.js`) renders three UI surfaces automatically and
wires four HTML attribute hooks you can place anywhere in your markup.

## What the script tag puts on your page

| Component | What it is | Page |
| --- | --- | --- |
| Banner | First prompt: a Card, Banner or Drawer with the actions the policy requires. | [Banner](/docs/frameworks/html/components/banner) |
| Preference dialog | Category and vendor list where visitors adjust choices. | [Preference dialog](/docs/frameworks/html/components/dialog) |
| Floating trigger | Optional corner button that reopens the dialog. | [Floating trigger](/docs/frameworks/html/components/trigger) |
| `data-inth-action` buttons | Custom buttons that accept, reject, open the dialog or show the banner. | [Action buttons](/docs/frameworks/html/components/action-buttons) |
| `#inth-preferences` links | Links that reopen the preference dialog with no JavaScript. | [Preferences link](/docs/frameworks/html/components/preferences-link) |
| `<script type="text/plain">` | Vendor script held until its category is allowed. | [Gated scripts](/docs/frameworks/html/components/gated-script) |
| `<iframe data-src>` | Embed held until its category is allowed. | [Embeds](/docs/frameworks/html/embeds) |
| DevTools panel | Debugging panel loaded via a second script tag. | [DevTools](/docs/frameworks/html/dev-tools) |

`inth.headless.js` keeps the four HTML hooks and omits the three stock
surfaces so your page renders its own UI; see
[headless](/docs/frameworks/html/headless). `inth.iab.js` swaps in IAB TCF
banner and dialog surfaces under an IAB policy; see
[IAB TCF](/docs/frameworks/html/iab).

## Where the surfaces render

The banner, dialog and trigger mount inside a single `<div data-inth-ui>`
element appended to `<body>`. By default it uses a shadow root with its own
stylesheet so site CSS does not interfere with the consent UI. See
[customize](/docs/frameworks/html/customize) to configure tokens, shadow CSS
or light DOM rendering.

When the script tag sits in `<head>`, policy resolution starts immediately
and surfaces mount once the document finishes parsing.

## Which surface shows

Inth picks the active surface from the resolved policy and stored choice:

- **Banner.** Renders when the policy requires a choice or notice and the
  visitor has not answered it.
- **Dialog.** Opens only when triggered by the banner's Customize button, an
  action button, a `#inth-preferences` link, the floating trigger or
  `inth.openDialog()`.
- **Trigger.** Appears while neither the banner nor the dialog is open.

Saving a choice closes the active surface immediately. Listen to the `ui`
event to observe surface transitions; see
[events and callbacks](/docs/frameworks/html/callbacks).
