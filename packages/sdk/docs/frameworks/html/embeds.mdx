Hold YouTube videos, maps and other third-party iframes on a plain HTML page
until their consent category is allowed.

## Gate an iframe

Move the iframe's URL from `src` to `data-src` and set `data-category`. Inth
populates `src` once the category is allowed:

<include src="../../shared/examples/html/embed.mdx" />

Without `src`, the iframe sends no request and sets no cookies until the
visitor allows the category. Include a descriptive `title` on every embed.

## Attributes

| Attribute | What it does |
| --- | --- |
| `data-src` | Embed URL copied to `src` when allowed (`http:` and `https:` only; relative URLs resolve against the page). |
| `data-category` | Category name. Unknown names log a warning and keep the iframe blocked. |
| `data-vendor` | Optional vendor slug for vendor-level consent; see [vendor consent](/docs/frameworks/html/vendor-consent). |
| `data-inth-paused` | Set by Inth when removing an existing `src`. Do not set manually. |

Iframes without `data-category` or `data-vendor` are untouched.

## Show a placeholder

Inth renders no placeholder for blocked iframes. Place your own markup next
to the iframe and toggle visibility with CSS:

{/* example: fragment */}

```html
<div class="embed">
  <iframe data-src="…" data-category="measurement" title="YouTube video"></iframe>
  <div class="placeholder">
    <p>Allow measurement to load this YouTube video.</p>
    <a href="#inth-preferences">Choose video permissions</a>
  </div>
</div>
```

{/* example: fragment */}

```css
.embed iframe:not([src]) { display: none; }
.embed iframe[src] + .placeholder { display: none; }
```

The `#inth-preferences` link opens the preference dialog; see
[preferences link](/docs/frameworks/html/components/preferences-link).

## What happens on withdrawal

When a visitor turns off the category, Inth removes `src` and restores
`data-src`, unloading the embed, and reloads the page by default.

Always author gated iframes with `data-src` instead of `src`. An iframe with
a plain `src` starts loading before `inth.js` runs.

## Iframes added later

Inth observes the document, so iframes added dynamically by CMS widgets,
scripts or client routers such as Turbo are gated automatically.

## Configure the iframe blocker

The iframe blocker runs by default in every `@inth/sdk` build. Override it
via a queued `config` call:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', { iframeBlocker: false }]);
</script>
```

| Value | Effect |
| --- | --- |
| omitted or `{}` | Automatically gates every iframe with `data-category` or `data-vendor`, including dynamic additions. |
| `{ disableAutomaticBlocking: true }` | Skips automatic scanning; updates iframes only when you call `inth.processIframes()`. See [check iframes yourself](#check-iframes-yourself). |
| `false` | Disables the blocker completely; `data-src` iframes never load. |

Categories found on gated iframes are added to the preference dialog.

## Check iframes yourself

With `iframeBlocker: { disableAutomaticBlocking: true }`, call
`inth.processIframes()` after policy resolution, after inserting iframes and
on consent changes:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', { iframeBlocker: { disableAutomaticBlocking: true } }]);
  inth.push(['processIframes']);
  inth.push(['on', 'consent', () => inth.processIframes()]);
</script>
```

Queued `processIframes` calls wait until the policy resolves.

## Vendor embeds

[Integration guides](/docs/integrations/overview) include an HTML tab for
YouTube, Google Maps and other embeds. `youtube-nocookie.com` still contacts
Google on load, so gate it like any other embed.

## Check it works

Open the page in a private window with DevTools Network open:

1. Before choosing, the iframe has no `src`, no request hits the embed host,
   and the placeholder shows.
2. Allow the category. `src` populates, the embed loads and the placeholder
   hides.
3. Turn the category off. The page reloads and the embed stays unloaded.
