Inspect consent state, gated scripts, resolved policies and events on any
plain HTML page by adding `inth.devtools.js` during development.

## Add the panel

Include `inth.devtools.js` beside `inth.js` while debugging:

{/* example: fragment */}

```html
<script
  src="https://cdn.jsdelivr.net/npm/@inth/sdk/lib/browser/dist/inth.devtools.js"
  data-open
  data-tab="location"
  defer
></script>
```

Tag order does not matter: loaded first it queues on `window.inth`; loaded
after it mounts immediately (or after `inth.init()` with `data-manual`).

| Attribute | What it does |
| --- | --- |
| `data-open` | Opens the panel on load (`data-open="false"` keeps it closed). |
| `data-tab` | Initial tab: `consents`, `scripts`, `location`, `policy`, `iab`, `events` or `actions`. |
| `data-position` | Corner: `bottom-right`, `bottom-left`, `top-right` or `top-left`. |

The panel mounts inside its own shadow root so site styles do not affect it.

## Open DevTools from the trigger

When `data-trigger` is enabled, the floating trigger merges into a two-button
toolbar with DevTools and hides the standalone launcher until the banner or
dialog hides the trigger. With `inth.headless.js`, DevTools keeps its own
launcher.

## What each tab shows

| Tab | Shows |
| --- | --- |
| Consents | Current permissions with switches and real save/accept/reject buttons. |
| Scripts | Configured scripts and their status, plus a DOM scan of scripts and iframes. |
| Location | Country, region, language and GPC overrides with **Apply and refresh** and **Clear overrides**. |
| Policy | Resolved policy rule and required prompt. |
| IAB | Purposes, vendors and TC String when running `inth.iab.js`. |
| Events | Chronological consent event log. |
| Actions | **Show banner**, **Open preferences** and **Clear stored records**. |

The Scripts tab DOM scan lists elements in the page; always verify actual
network blocking in DevTools Network.

## Use it from the console

Access the mounted instance at `inth.devtools`. Call `inth.devtools.destroy()`
or `inth.dispose()` to unmount it.

## Test another country

Open the Location tab, enter a country such as `DE` or `US` with region `CA`,
and click **Apply and refresh** to test regional policies without a VPN.
Overrides reset on reload.

## Keep it out of production

Remove `inth.devtools.js` before publishing or render it only on staging
builds. It exposes internal consent state and injects a `<style>` element
that a strict [Content Security Policy](/docs/frameworks/html/content-security-policy)
blocks.

## Check it works

1. Add the tag and reload; confirm the panel opens on your chosen tab.
2. Click **Accept All** in the banner; verify the save appears in Events and
   categories turn allowed in Consents.
3. Remove the tag and reload; confirm no panel renders and `inth.devtools` is
   `null`.
