Find where to add the Inth script tag, gated vendor snippets and privacy
settings link in common CMS platforms, page builders and static site
generators.

## What every platform needs

Every platform needs three pieces:

| Piece | Where it goes |
| --- | --- |
| The Inth script tag from the [quickstart](/docs/frameworks/html/quickstart#add-the-script-tag) | The shared `<head>` rendered on every page. |
| Each vendor snippet changed to `type="text/plain"` | Wherever the vendor instructs, removing any active duplicate. |
| A link to `#inth-preferences` | The shared footer or legal navigation menu. |

A page missing the tag has no consent state and its vendor scripts run
unchecked. After publishing, verify pages across every template (home, blog,
product).

## WordPress

Add the tag to your child theme's `header.php` right before `</head>` so
parent theme updates do not overwrite it. For a block theme without
`header.php`, hook `wp_head` in the child theme's `functions.php`:

{/* example: fragment */}

```php
add_action('wp_head', function () {
  echo '<script src="https://your-project.inth.app/inth.js" defer></script>';
}, 1);
```

Priority `1` outputs the tag ahead of other plugins. Replace the URL with
your Inth project URL.

If an analytics or marketing plugin prints active tags you cannot change to
`text/plain`, disable its script output and paste a gated tag instead, or
hold its requests with a
[network blocker](/docs/frameworks/html/network-blocker) rule. Add a custom
link to `#inth-preferences` in your footer menu.

## Webflow

Paste the tag in Site settings, Custom code, Head code. Place gated vendor
snippets there or inside an Embed element, and add `#inth-preferences` to
your footer component. Publish after each edit; custom code does not run in
the Designer.

## Shopify

Edit your theme and paste the tag in `layout/theme.liquid` before `</head>`.
Add `#inth-preferences` to your footer navigation. Checkout pages do not
render `theme.liquid`.

Check page source after publishing and disable tracking in any Shopify apps
that inject tags outside your theme.

## Squarespace

Paste the tag in Settings, Developer Tools, Code Injection, Header (plan
dependent) and add `#inth-preferences` to your footer.

## Wix

Add the tag under Settings, Custom Code in the `<head>` on all pages
(requires a connected domain), and add a footer link to `#inth-preferences`.

## Framer

Paste the tag in Site Settings, General, Custom Code (`<head>`), add a footer
link to `#inth-preferences`, and publish.

## Ghost

Paste the tag in Settings, Code injection, Site header, and add a
`#inth-preferences` item to Secondary navigation for the footer.

## Hugo

Add the tag to the `<head>` layout (`layouts/_default/baseof.html` or a head
partial). Copy theme files into your site's `layouts/` directory before
editing so theme updates do not overwrite them.

## Eleventy

Add the tag to the base layout in `_includes` extended by every page.

## Jekyll

Add the tag to `_includes/head.html` or `_layouts/default.html`, copying
theme layouts into your repository first.

## Plain HTML and server includes

Add the tag to each page's `<head>` or your shared server header include.

## Tag managers

Do not load `inth.js` through Google Tag Manager or another tag manager. The
tag manager runs before Inth can decide permissions and requires consent
itself. Load `inth.js` directly in `<head>` and gate the tag manager snippet
like any other vendor; see
[Google Consent Mode and tag managers](/docs/frameworks/html/scripts#google-consent-mode-and-tag-managers).

## Caching and optimization plugins

Script optimizers that combine, rewrite or delay JavaScript can break
`type="text/plain"` tags or delay `inth.js` until user interaction. Exclude
`inth.js` and every tag carrying `data-inth-category` from script
optimization, then check published page source to confirm gated tags keep
`type="text/plain"`.

Full-page HTML caching is safe because the tag resolves visitor choices in
the browser.

## Check it works

Open a page from each template in a private window with DevTools Network open:

1. The banner appears and no vendor domain requests fire before a choice.
2. Click **Reject All** and navigate to another page. The banner stays closed.
3. Click the footer's privacy settings link. The preference dialog opens.
4. View page source: one Inth script tag is present, and vendor snippets use
   `type="text/plain"`.
