## Configure cleanup

Gating stops new requests without removing cookies and storage keys a vendor
already wrote. List what each optional category owns in a queued `config`
call before `inth.js`. When a category is denied, Inth deletes its entries:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', {
    clearOnRevocation: {
      measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
      marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
    },
  }]);
</script>
```

Place this before the `inth.js` script tag. Inth reads `clearOnRevocation`
once at startup.
