Control Inth programmatically on a plain HTML page through `window.inth`,
before or after the script tag loads.

## Call Inth before and after the tag loads

`window.inth` is the single global the script tag uses. Before `inth.js`
executes, initialize it as an array and push `[method, ...args]` tuples:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', { legalLinks: { privacyPolicy: { href: '/privacy' } } }]);
  inth.push(['on', 'ui', (surface) => console.log('surface:', surface)]);
</script>
```

When the script tag runs, it replaces the array with the API object and
replays queued calls in order. Never overwrite `window.inth = [[...]]`, which
drops calls queued by earlier scripts or DevTools. `inth.push([...])` keeps
working after load using the same queue rules and returns the number of calls
accepted.

### Which calls you can queue

| Queued method | When it runs |
| --- | --- |
| `config`, `init`, `on`, `onInit` | Immediately in queue order as the bundle loads. |
| `subscribe` | Once the client instance exists. |
| `acceptAll`, `rejectAll`, `save`, `dismissNotice`, `saveIAB`, `showBanner`, `openDialog`, `closeDialog`, `setLanguage`, `identify`, `mountUI`, `processIframes` | In queue order once the policy resolves (so a queued `openDialog` stays open instead of being overwritten by the banner). |
| Reads and unknown methods (`getSnapshot`, `has`, `hasConsented`, `isVendorAllowed`, `ready`, `dispose`) | Skipped with a console warning. Call them inside `onInit` or after `ready()`. |

Errors thrown by a queued call log via `console.error` without blocking later
queued calls.

### How options merge

Later sources win in this order:

1. `data-*` attributes on the script tag.
2. Queued `config` calls in order.
3. Options passed to `inth.init()` (with `data-manual`).

`ui`, `ui.banner` and `ui.dialog` merge shallowly key by key; all other
options replace earlier values. Calling `config` after the client starts logs
a warning and does nothing.

## Start Inth yourself

Add `data-manual` to the script tag so Inth installs `window.inth` and waits
for your page to call `inth.init()`:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  document.addEventListener('DOMContentLoaded', () => {
    inth.push(['init', { overrides: { country: document.body.dataset.country } }]);
  });
</script>
```

`init()` merges tag attributes, queued `config` calls and its own options,
starts the client and returns it (or a proxy on `inth.js` before
`inth.hosted.js` arrives; use `inth.onInit()` for the full client). See
[how inth.js loads inth.hosted.js](/docs/frameworks/html/attributes-and-api#how-inthjs-loads-inthhostedjs).
Direct state reads or writes before `init()` throw `call inth.init() first`.
After `inth.dispose()`, calling `inth.init()` starts a fresh client.

## Read state

| Method | Returns | Use it for |
| --- | --- | --- |
| `ready()` | `Promise<ConsentSnapshot>` | Wait for policy resolution. Safe before `init()`. |
| `has(category)` | `boolean` | Check whether a category or condition (`{ and: ['measurement', 'marketing'] }`) is allowed now. |
| `hasConsented()` | `boolean` | Check whether the visitor answered the prompt. |
| `getSnapshot()` | `ConsentSnapshot` | Full state: permissions, recorded choice, policy, prompt and active surface. |
| `subscribe(listener)` | unsubscribe function | Run `listener(snapshot)` on every state change. |
| `isVendorAllowed(id)` | `boolean` | `true` when vendor is declared, its category is allowed and it is not switched off. |
| `getDeclaredVendors()` | `Vendor[]` | Merged vendors from `vendors`, Inth, scripts, gated tags and iframes (empty under IAB). |
| `getVendorChoice()` | vendor decision or `null` | Vendors switched off by the visitor (`denied`). |
| `on(event, listener)` | unsubscribe function | Listen to `ready`, `consent`, `ui` or `error`. Safe before `init()`. See [events and callbacks](/docs/frameworks/html/callbacks). |

### A permission is not a recorded choice

`has('measurement')` and `snapshot.effectivePermissions` tell you whether
code may run now (which can be `true` before any choice under opt-out).
`hasConsented()` and `snapshot.explicitChoice` tell you what the visitor
explicitly chose. Wait for `inth.ready()` before reading at page load. See
[a permission is not a recorded choice](/docs/concepts/how-consent-works#a-permission-is-not-a-recorded-choice).

## Record a choice

Call these only from user interactions, never automatically on page load:

| Method | What it records |
| --- | --- |
| `acceptAll()` | Allows every category offered (under IAB, confirms declared vendor processing; optional categories without declared consent purposes stay denied). See [categories under an IAB policy](/docs/concepts/consent-state#categories-under-an-iab-policy). |
| `rejectAll()` | Denies every optional category offered. |
| `save(choices)` | Saves named categories (`{ measurement: true, marketing: false }`) and optional `vendors` map. Fails under IAB; use `saveIAB()`. |
| `saveIAB()` | Confirms IAB purpose and vendor choices (`inth.iab.js` only). See [IAB TCF](/docs/frameworks/html/iab). |
| `dismissNotice()` | Acknowledges a notice without granting consent. |
| `identify(user)` | Links the consent record to `{ externalId, identityProvider?, identityToken? }`, where `identityToken` verifies the link on the server. |

Save methods resolve with `{ ok }`. Choices apply and surfaces close
immediately; failed network requests retry in the background.

## Show and hide the UI

| Method | What it does |
| --- | --- |
| `showBanner()` | Opens the banner without recording anything. |
| `openDialog()` | Opens the preference dialog without recording anything. |
| `closeDialog()` | Closes the dialog (or banner), restoring the banner if a choice is still due. |
| `setLanguage(code)` | Switches language and re-renders copy; see [translations](/docs/frameworks/html/translations). |
| `mountUI(options?)` | Remounts the stock UI with new options. Throws in `inth.headless.js`. |

In `inth.headless.js`, `showBanner`, `openDialog` and `closeDialog` still
update the `ui` event for your custom UI.

## Lifecycle

| Method | What it does |
| --- | --- |
| `config(options)` | Adds options before startup. See [configuration](/docs/frameworks/html/configuration). |
| `init(options?)` | Starts the client when using `data-manual`. |
| `onInit(listener)` | Invokes `listener(client)` once ready (or immediately if started). Returns a cancel function. |
| `push(...calls)` | Executes `[method, ...args]` calls via the queue rules above. |
| `processIframes()` | Updates gated iframes when `iframeBlocker: { disableAutomaticBlocking: true }`. See [check iframes yourself](/docs/frameworks/html/embeds#check-iframes-yourself). |
| `dispose()` | Unmounts UI, DevTools, listeners, blockers and loaded script tags. |

## Properties

| Property | What it holds |
| --- | --- |
| `version` | `@inth/sdk` version string. |
| `pkg` | Bundle identifier: `@inth/sdk`, `@inth/sdk/testing`, `@inth/sdk/headless` or `@inth/sdk/iab-client`. |
| `mode` | `'hosted'`, `'manifest'`, `'testing'` or `'custom'` once started, else `null`. |
| `client` | Active client instance (`kernel`, `runtime`, `options`, `consentCategories`, `ui`, `setOverrides()`), or `null`. |
| `devtools` | DevTools instance once `inth.devtools.js` mounts, else `null`. |
| `hosted`, `manifest` | Transport factories (`inth.js` exports `hosted`; headless and IAB export both). |
| `testing` | `inth.testing.js` only: `inth.testing({ policy })`. |

Call `inth.client.setOverrides({ country, region, language, gpc })` to
override location, language or GPC during debugging.

## Check it works

1. Run `await inth.ready()` in the console and verify `resolution.status` is
   `'matched'`.
2. Check `inth.has('measurement')` and `inth.hasConsented()` before and after
   clicking **Reject All** under an opt-in policy: `hasConsented()` becomes
   `true` while `has('measurement')` stays `false`.
3. Run `inth.push(['openDialog'])` and confirm the dialog opens.
