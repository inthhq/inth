Hold vendor scripts on a plain HTML page until their consent category is
allowed, run lifecycle callbacks, and handle withdrawal cleanly.

## Choose how to gate a script

| Form | Use it when |
| --- | --- |
| `<script type="text/plain" data-inth-category>` in HTML | You paste a vendor snippet into a theme, CMS field or page builder with no JavaScript. |
| A `scripts` entry in a queued `config` call | You need callbacks on load, error or consent change. |

Both wait for the same permission and register their category in the
preference dialog. Gate iframes with [embeds](/docs/frameworks/html/embeds)
and `fetch` calls with the
[network blocker](/docs/frameworks/html/network-blocker).

## Gate a pasted snippet

Change the vendor tag to `type="text/plain"` and add `data-inth-category`:

{/* example: fragment */}

```html
<script type="text/plain" data-inth-category="measurement">
  // The vendor's snippet, unchanged
</script>
<script type="text/plain" data-inth-category="marketing" src="https://vendor.example/tag.js"></script>
```

When your Inth script tag carries a CSP nonce, add the same `nonce` to each
gated tag or Inth skips it; see
[gated tags on a page with a nonce](/docs/frameworks/html/components/gated-script#gated-tags-on-a-page-with-a-nonce).
The [quickstart](/docs/frameworks/html/quickstart#gate-your-vendor-scripts)
shows PostHog, and
[gated scripts](/docs/frameworks/html/components/gated-script) covers load
order, copied attributes and dynamically added tags.

## What happens when a visitor withdraws permission

A script that has already executed cannot be unloaded. When a visitor turns
off a previously allowed category through preferences or a one-click opt-out,
Inth records the change and reloads the page so gated tags start inert again.
Privacy signals and backend-synced opt-outs do not reload. Granting a category
never reloads.

To handle withdrawal yourself, such as calling a vendor's opt-out API, set
`reloadOnConsentRevoked: false` in `config`. `callbacks.onBeforeConsentRevocationReload`
runs right before a reload if you need to flush state; see
[events and callbacks](/docs/frameworks/html/callbacks).

## Load a script with callbacks

Queue a `config` call with `scripts` before the script tag:

{/* example: fragment */}

```html
<script>
  window.inth = window.inth || [];
  inth.push(['config', {
    scripts: [
      {
        id: 'analytics',
        src: 'https://analytics.example/sdk.js',
        category: 'measurement',
        onLoad: () => window.analytics.track('page_view'),
        onConsentChange: ({ hasConsent }) => {
          if (!hasConsent) window.analytics.optOut();
        },
      },
    ],
  }]);
</script>
```

Inth appends the script to `<head>` once `measurement` is allowed and removes
the element on revocation.

| Field | What it does |
| --- | --- |
| `id` | Unique, stable script name. Required. |
| `category` | Required category or condition such as `{ and: ['measurement', 'marketing'] }`. |
| `src` or `textContent` | Script URL or inline code. Required unless `callbackOnly` is `true` or returns `true`. |
| `callbackOnly` | `true` or a zero-argument predicate skips inserting a `<script>` element and runs callbacks only. |
| `alwaysLoad` | Loads regardless of consent. Use only for tags that manage consent themselves. |
| `persistAfterConsentRevoked` | `true` keeps the element after withdrawal; `'loaded'` keeps only completed loads. |
| `target` | `'head'` (default) or `'body'`. |
| `async`, `defer`, `nonce`, `fetchPriority`, `attributes` | Attributes on the inserted `<script>`. Defaults to the Inth tag's nonce if omitted. |
| `anonymizeId` | Gives the element a random `id` (default `true`). |
| `vendor` | Vendor slug for vendor-level consent; see [vendor consent](/docs/frameworks/html/vendor-consent). |
| `onBeforeLoad`, `onLoad`, `onError` | Run before load, after load or on failure. |
| `onConsentChange` | Runs whenever consent for this script changes, receiving `{ hasConsent, consents }`. |
| `onDispose` | Runs when the script is removed or Inth disposes. |

Every callback receives `id`, `elementId`, `hasConsent`, `consents` and
`element` (when present).

`@inth/integrations` helpers are ES modules for bundled apps. On a plain HTML
page, paste the vendor's snippet into a `text/plain` tag.

## Clear cookies when permission is withdrawn

Gating stops new requests without deleting cookies a vendor already wrote.
Add `clearOnRevocation` to `config` to remove named cookies and storage keys
when their category is denied; see
[clear on revocation](/docs/frameworks/html/clear-on-revocation).

## Google Consent Mode and tag managers

The plain HTML script tag does not emit Google Consent Mode signals
automatically. Gate Google's snippet as a `text/plain` tag so nothing fires
before consent; [gated scripts](/docs/frameworks/html/components/gated-script#load-order)
shows GA4's two tags in order.

If you require Consent Mode signals before opt-in, load Google ungated and
push updates from the `consent` event ahead of Google's tags:

```html
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag() { dataLayer.push(arguments); }
  gtag('consent', 'default', {
    analytics_storage: 'denied',
    ad_storage: 'denied',
    ad_user_data: 'denied',
    ad_personalization: 'denied',
  });
  window.inth = window.inth || [];
  inth.push(['on', 'consent', (snapshot) => {
    const allowed = snapshot.effectivePermissions;
    const state = (granted) => (granted ? 'granted' : 'denied');
    gtag('consent', 'update', {
      analytics_storage: state(allowed.measurement),
      ad_storage: state(allowed.marketing),
      ad_user_data: state(allowed.marketing),
      ad_personalization: state(allowed.marketing),
    });
  }]);
</script>
```

Consent Mode sends cookieless pings to Google before a choice with optional
types denied. Choose the approach your policy requires. Vendor pages under
[integrations](/docs/integrations/overview) include an HTML tab for no-build
setups.

## Check it works

Open the page in a private window with DevTools Network open:

1. Filter for each vendor domain. Nothing loads before a choice.
2. Allow one category. Only that category's vendors load and `onLoad` fires.
3. Turn the category off. The page reloads and the vendor stays absent.
