Pass a `ConsentTheme` to `InthConsent` (or `attachConsent`) to match Inth's native screens to your app while the native presenter handles drafts, navigation, and saves. Start with the [Android quickstart](/docs/frameworks/android/quickstart) so Privacy settings stay reachable.

## Choose what to change

| Customization | Native setting |
| --- | --- |
| App name and logo above the headline | `brand` |
| Headline and introductory copy | `copy` |
| Light and dark colors | `colors` |
| Card and button corner radii | `radius` |
| Page gutters, section gaps, and padding | `spacing` |
| Type sizes and font families | `typography` |
| Per-part overrides (such as decision buttons) | `slots` |
| Provider attribution name and mark | `branding` |
| First-layer container (`page`, `sheet`, or `prompt`) | `firstLayer` |
| Stock color palette (`system` or `c15t`) | `appearance` |
| Save Settings button placement | `savePlacement` |
| Fully app-owned controls | [Build your own UI](/docs/frameworks/android/headless) |

## Add your brand

Create `consent-theme.kt` in your app (updating the package name) to configure light and dark colors, radii, gutters, typography, slot overrides, your logo, and first-layer copy:

<include src="../../shared/examples/native/examples/consent-demo/android-brand-theme.mdx" />

Add your logo to drawable resources and pass the theme to `InthConsent`:

{/* example: fragment */}

```kotlin
InthConsent(
	privacyPolicyUrl = "https://your-app.example/privacy",
	theme = pantryConsentTheme(R.drawable.your_app_mark),
)
```

Import your app's generated `R` class if this file sits in another package. An unreadable drawable falls back to the app name's initial. Pass `ConsentTheme.Brand.Hidden` to omit the app-identity header.

## Keep decision buttons equal

`colors.decision`, `colors.textOnDecision`, and `ConsentTheme.Slot.ButtonPrimary` apply equally to Accept all and Reject all. If custom button colors drop below 5:1 text contrast in either appearance, the screens fall back to stock decision colors. Always verify text contrast in light mode, dark mode, and at the largest system font scale.

## Set typography, spacing, and radii

Token names match web tokens: `colors.primary` maps to `--inth-primary`, `radius.md` maps to `--inth-radius-md`, and `spacing.lg` maps to `--inth-space-lg`.

`typography.fontSize` configures three Material type groups while preserving relative style ratios and system font scaling (`null` keeps the Material default):

- `sm`: `bodyMedium`, `bodySmall`, and small labels (14sp default).
- `base`: `bodyLarge`, sub-titles, and `labelLarge` (16sp default).
- `lg`: first-layer headline (34sp default) and larger titles.

`typography.fontFamily` sets every style except the headline. `typography.headlineFont` sets the headline to `HeadlineFont.SansSerif`, `HeadlineFont.Serif`, or a bundled Compose `FontFamily` via `HeadlineFont.Custom`.

`spacing` controls page gutters, section gaps, and footer/notice padding without shrinking touch targets. `radius.md` rounds buttons and cards (`radius.sm` and `radius.lg` inherit it until set). `slots` (`ConsentBannerTitle`, `ConsentBannerDescription`, `ButtonPrimary`, `ButtonSecondary`) override `color`, `backgroundColor`, `borderRadius`, and `fontSize` for one part.

## Place Save Settings

```kotlin
ConsentTheme.current = ConsentTheme(savePlacement = ConsentTheme.SavePlacement.Bottom)
```

Privacy Settings pins Reject All and Accept All together at the bottom. Save sits in the top app bar by default to leave more room for the list. Set `Bottom` to render a full-width Save Settings button below them; large font scales always move Save to the bottom.

## Choose a first-layer layout

```kotlin
ConsentTheme.current = ConsentTheme(firstLayer = ConsentTheme.FirstLayer.Sheet)
```

Every layout shows the same copy, partner link, and equal Accept all and Reject all actions:

| Layout | Behavior |
| --- | --- |
| `page` | Full-screen page (default). |
| `sheet` | Floating bottom sheet over a dimmed app background. |
| `prompt` | Centered alert-style card over a dimmed app background. |

Privacy Settings opened from Customize always fills the screen. At accessibility font sizes, every layout becomes `page` so decisions follow text in one scroll. Under an IAB TCF policy on wide windows such as tablets, `sheet` and `prompt` expand to `page`.

`appearance` picks the stock palette. `system` (default) uses platform backgrounds and text colors with your app theme's `colorPrimary` accent, centers the page, and falls back to your app name and icon whenever `brand` fields are unset. Accept all and Reject all darken your accent until white text reaches 5:1 contrast. `c15t` applies the warm paper and ink palette. `sheet` and `prompt` always use system colors and draw Accept all and Reject all as tinted surfaces rather than `ButtonPrimary` fills. Explicit colors always win.

## Separate app identity from attribution

`brand` identifies your app above the headline. `branding` identifies the consent provider beneath the actions: `ConsentTheme.Branding.Inth` (default), `ConsentTheme.Branding.C15t`, or `ConsentTheme.Branding.Custom(name, markResId)`. Set `showsBranding = false` to hide provider attribution.

## Configure via application metadata

An explicit `theme` argument takes priority over `ConsentTheme.current` and manifest metadata. Every shortened key below retains the `com.inth.consent.` prefix:

| Metadata key | Value |
| --- | --- |
| `com.inth.consent.PRIMARY`, `TEXT_ON_PRIMARY` | `#RRGGBB` or comma-separated `light,dark` pair |
| `com.inth.consent.CANVAS`, `SURFACE`, `SURFACE_MUTED` | Screen and card colors |
| `com.inth.consent.TEXT`, `TEXT_MUTED` | Primary and muted text colors |
| `com.inth.consent.DECISION`, `TEXT_ON_DECISION` | Shared Accept/Reject colors |
| `com.inth.consent.RADIUS_SM`, `RADIUS_MD`, `RADIUS_LG` | Radii in dp |
| `com.inth.consent.SPACE_XS` to `SPACE_XL` | Spacing steps in dp |
| `com.inth.consent.FONT_SIZE_SM`, `FONT_SIZE_BASE`, `FONT_SIZE_LG` | Font sizes in sp |
| `com.inth.consent.FONT_FAMILY` | Font resource name |
| `com.inth.consent.BUTTON_PRIMARY_BORDER_RADIUS` | Slot field as `<SLOT>_<FIELD>` |
| `com.inth.consent.HEADLINE_FONT` | `sans`, `serif`, or `rounded` (mapped to sans on Android) |
| `com.inth.consent.BRAND_NAME`, `BRAND_MARK` | App name and drawable resource |
| `com.inth.consent.BRAND` | `false` hides app identity |
| `com.inth.consent.HEADLINE`, `INTRODUCTION` | First-layer copy |
| `com.inth.consent.FIRST_LAYER` | `page`, `sheet`, or `prompt` |
| `com.inth.consent.APPEARANCE` | `system` or `c15t` |
| `com.inth.consent.SAVE_PLACEMENT` | `top` or `bottom` |
| `com.inth.consent.BRANDING_PROVIDER` | `inth` or `c15t` |
| `com.inth.consent.BRANDING_NAME`, `BRANDING_MARK` | Custom provider name and drawable |
| `com.inth.consent.BRANDING` | `false` hides provider attribution |

## Know where copy comes from

Stock screens read labels from `@inth/sdk/translations` using the policy's served language (or `NativeConfig.overrides.language`), falling back to English if unavailable. IAB screens follow the served vendor list's language.

`ConsentTheme.Copy` overrides only the first-layer headline and introduction. Leave fields `null` to keep translated stock copy; strings you set render verbatim in every language. Keep authoritative IAB vendor disclosures and policy links intact, and review [Mobile IAB and ads](/docs/guides/mobile-iab) before shipping advertising flows.
