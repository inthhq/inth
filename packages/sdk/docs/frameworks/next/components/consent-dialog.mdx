## Open the preference center

`ConsentDialog` is the full consent manager: "Your Privacy Choices". Render it once inside
`InthProvider` in your [App Router](/docs/frameworks/next/app-router) root
layout or [Pages Router](/docs/frameworks/next/pages-router) `pages/_app.tsx`:

<include src="../../../shared/examples/nextjs/quickstart-layout.mdx" />

`ConsentDialog` renders nothing on the server and mounts through a portal after
hydration.

Open it from any Client Component inside `InthProvider` with `useSetActiveUI()`:

{/* example: fragment */}

```tsx title="components/privacy-menu-item.tsx"
'use client';

import { useSetActiveUI } from '@inth/nextjs';

export function PrivacyMenuItem() {
	const setActiveUI = useSetActiveUI();
	return (
		<button type="button" onClick={() => setActiveUI('dialog')}>
			Cookie preferences
		</button>
	);
}
```

For footer links and floating controls, see
[PrivacyChoicesLink](./privacy-choices-link),
[ConsentDialogLink](./consent-dialog-link) and
[ConsentDialogTrigger](./consent-dialog-trigger). For IAB TCF policies, mount
`IABConsentDialog` from [IAB TCF](/docs/frameworks/next/iab) instead (this
dialog stays closed under the `iab` model).
