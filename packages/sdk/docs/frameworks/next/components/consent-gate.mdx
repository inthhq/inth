## Gate an embed behind consent

`ConsentGate` mounts its children only while a consent category is granted and
renders a placeholder with a button to open `ConsentDialog` otherwise. Wrap any
iframe or widget inside a Client Component under `InthProvider` from your
[App Router](/docs/frameworks/next/app-router) or
[Pages Router](/docs/frameworks/next/pages-router) setup:

{/* example: fragment */}

```tsx title="components/product-video.tsx"
'use client';

import { ConsentGate } from '@inth/nextjs';

export function ProductVideo() {
	return (
		<ConsentGate category="marketing" className="video-frame">
			<iframe
				src="https://www.youtube-nocookie.com/embed/dQw4w9WgXcQ"
				title="Product tour"
				loading="lazy"
				allowFullScreen
				style={{ width: '100%', aspectRatio: '16 / 9', border: 0 }}
			/>
		</ConsentGate>
	);
}
```

Import `ProductVideo` into any Server Component or page. `ConsentGate`
registers its category in the preference center on mount, does not read the
clock during SSR (so static and `cacheComponents: true` pages stay prerendered
without an extra `Suspense` boundary), and should be given `className` or
`style` dimensions to prevent layout shift.

How SSR HTML renders depends on your layout:

- **Streamed App Router and static layouts:** server HTML renders the
  placeholder; the iframe mounts after hydration if allowed.
- **[Awaited App Router](/docs/frameworks/next/app-router#render-the-banner-in-the-server-html)
  and [Pages Router](../pages-router) SSR:** denied categories render the
  placeholder in server HTML, while granted categories render an empty wrapper
  and mount the iframe after hydration so streamed iframes never load twice.
  Browser `navigator.globalPrivacyControl` is re-checked on hydration.
