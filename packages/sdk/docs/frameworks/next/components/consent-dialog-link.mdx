## Reopen the preference center from your footer

`ConsentDialogLink` renders an unstyled `<button>` that opens `ConsentDialog`.
Mount it inside `InthProvider` from your
[App Router](/docs/frameworks/next/app-router) or
[Pages Router](/docs/frameworks/next/pages-router) setup so visitors can change
preferences after the banner closes:

{/* example: fragment */}

```tsx title="components/site-footer.tsx"
'use client';

import { ConsentDialogLink } from '@inth/nextjs';
import Link from 'next/link';

export function SiteFooter() {
	return (
		<footer>
			<nav aria-label="Legal">
				<Link href="/privacy">Privacy policy</Link>
				<Link href="/terms">Terms</Link>
				<ConsentDialogLink className="footer-link">
					Privacy settings
				</ConsentDialogLink>
			</nav>
		</footer>
	);
}
```

Render `SiteFooter` inside `InthProvider` in your root layout (which stays a
Server Component) or `pages/_app.tsx`. Import from
`@inth/nextjs/components/consent-dialog-link` if a module needs only the link
without loading the rest of the adapter.

Pass `asChild` to reuse an existing link element:

```tsx
<ConsentDialogLink asChild>
	<a href="#cookie-preferences">Manage cookies</a>
</ConsentDialogLink>;
```
