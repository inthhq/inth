## Add DevTools to `InthProvider` in development

Lazy-load `DevTools` from `@inth/nextjs/devtools` with `next/dynamic` and
`ssr: false` so it never ships in production bundles:

{/* example: fragment */}

```tsx title="components/consent-dev-tools.tsx"
'use client';

import dynamic from 'next/dynamic';

const DevTools =
	process.env.NODE_ENV === 'development'
		? dynamic(
				() => import('@inth/nextjs/devtools').then(({ DevTools }) => DevTools),
				{ ssr: false }
			)
		: () => null;

export function ConsentDevTools() {
	return <DevTools />;
}
```

Render `<ConsentDevTools />` inside `InthProvider` in your root layout or
`pages/_app.tsx` alongside the banner and dialog.
