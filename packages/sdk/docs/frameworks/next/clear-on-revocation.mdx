## Configure cleanup

Script gating prevents new requests, but leaves cookies and Web Storage keys a
vendor already wrote. Declare the keys each optional category owns in
`inth.config.ts` so Inth deletes them whenever that category is denied:

{/* example: fragment */}

```ts title="inth.config.ts"
import { defineConsentConfig } from '@inth/nextjs';

export default defineConsentConfig({
	clearOnRevocation: {
		measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
		marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
	},
});
```

Keep `clearOnRevocation` at the top level alongside `scripts`, not inside
`options`. A `clearOnRevocation` prop on `InthProvider` overrides the config
value. It is read once when `InthProvider` mounts.
