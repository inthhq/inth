## Declare the vendors

Declaring at least one vendor enables per-vendor switches. Built-in
`@inth/integrations` helpers expose their own vendor metadata automatically, so
declare entries only for custom scripts or to override a helper's name or
privacy policy URL. Add `vendors` at the top level of `inth.config.ts`
alongside `scripts` (a `vendors` prop on `InthProvider` overrides the config):

{/* example: fragment */}

```ts title="inth.config.ts"
import { defineConsentConfig } from '@inth/nextjs';

export default defineConsentConfig({
	vendors: [
		{
			id: 'x-pixel',
			name: 'X Pixel',
			category: 'marketing',
			privacyPolicyUrl: 'https://x.com/privacy',
		},
	],
});
```

`ConsentGate` checks a category only. To gate a component on a single vendor,
check `useVendorAllowed('youtube')`. For raw iframes, use `data-vendor` with
the iframe blocker in [Embeds](/docs/frameworks/next/embeds).

## What the preference dialog shows

`ConsentDialog` and `ConsentWidget` list each declared vendor with its own
toggle under its category.

## Build your own vendor switch

Use `useVendorDraft()` and `useVendorAllowed(id)` from `@inth/nextjs` to stage
and save vendor toggles alongside category switches:

{/* example: fragment */}

```tsx title="components/x-pixel-switch.tsx (partial)"
'use client';

import { useVendorAllowed, useVendorDraft } from '@inth/nextjs';

const { vendors, setVendor, save } = useVendorDraft();
const xPixelAllowed = useVendorAllowed('x-pixel');

<input
  type="checkbox"
  checked={vendors['x-pixel'] ?? true}
  onChange={(event) => setVendor('x-pixel', event.target.checked)}
/>
<button type="button" onClick={() => save()}>Save</button>
```

`save()` resolves `{ ok: false }` if the policy or vendor list changed mid-edit
(call `reset()` to retry). Use `useDeclaredVendors()` and `useVendorChoice()`
to inspect declared vendors and saved decisions, and
`useVendorsListedUnder(category)` from `@inth/nextjs/headless` to list a
category's vendors in a custom preference center.
