Customize Inth's banner, dialog and buttons in Next.js with theme tokens, slot
classes, banner variants and dark mode. See the
[design gallery](/docs/customization/recipes) for five ready-to-copy banner
recipes (import the same components from `@inth/nextjs`).

## Load the stylesheet yourself

By default, stock components render their own `<style>` elements, so you import
no stylesheet. With Tailwind CSS 3, load the stylesheet yourself so Inth's
rules sit in a named cascade layer. Disable inline styles in `inth.config.ts`:

{/* example: fragment */}

```ts title="inth.config.ts"
import { defineConsentConfig } from '@inth/nextjs';

export default defineConsentConfig({ options: { styles: false } });
```

Import `@inth/nextjs/styles.css` once in your global stylesheet:

{/* example: fragment */}

```css title="styles/globals.css"
@import '@inth/nextjs/styles.css';
```

## Style the action buttons

<import src="../../shared/react/styling/overview.mdx#token-roles" />

`ConsentTheme` emits CSS tokens only. Because components read `consentActions`
in the browser, pass that theme through `options.theme` in `inth.config.ts`
alongside your existing `scripts`:

{/* example: fragment */}

```ts title="lib/theme.ts (partial)"
export const actionTheme = defineTheme({
	consentActions: {
		primary: { variant: 'primary', mode: 'filled' },
		dismiss: { variant: 'neutral', mode: 'stroke' },
	},
});
```

{/* example: fragment */}

```ts title="inth.config.ts"
import { defineConsentConfig } from '@inth/nextjs';

import { actionTheme } from './lib/theme';

export default defineConsentConfig({ options: { theme: actionTheme } });
```

## Change the banner's shape

Read the active policy in a Client Component to switch containers per region (see
[ConsentBanner containers](/docs/frameworks/next/components/consent-banner#containers)):

{/* example: fragment */}

```tsx title="components/regional-banner.tsx"
'use client';

import { ConsentBanner, usePolicyRule } from '@inth/nextjs';

export function RegionalBanner() {
	const policy = usePolicyRule();
	return (
		<ConsentBanner
			container={
				policy?.prompt === 'notice'
					? { edge: 'bottom', type: 'banner' }
					: { position: 'start', type: 'card' }
			}
		/>
	);
}
```

To target specific parts with Tailwind or custom classes, pass slot overrides
under `options.components.banner`:

```ts
const bannerSlots = {
	root: { className: 'group' },
	card: { className: 'group-data-[variant=notice]:rounded-none' },
	rightLink: {
		className: 'underline-offset-4 data-[right=opt-out]:text-red-700',
	},
};

// In options.components:
// banner: bannerSlots
```

## Turn on dark mode and change motion

Pass the same `colorScheme` to `ConsentTheme` and `InthProvider`'s `options`, or
leave it unset to follow a `dark` class on `<html>` (such as `next-themes`).
See [Dark mode](/docs/customization/dark-mode). Turn off animations globally
with `options.disableAnimation` or per component on `ConsentBanner` and
`ConsentDialog`; see [Motion and animation](/docs/customization/motion).

## Check the result

Open the page in a private window and confirm your colors, radius and button
styles appear. Customizing never alters consent behavior or records a choice.
See [Customize the interface](/docs/customization/overview) for the full guide.
