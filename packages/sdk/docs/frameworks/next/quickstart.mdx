Add a consent banner to a Next.js App Router app. Your server resolves each
visitor's consent in the same response as the page, and analytics wait until
consent allows them.

<Prompt title="Add Inth consent to this Next.js app" description="Paste into Claude Code, Codex, Cursor or another coding agent at the root of your app.">
  Add Inth consent management to this Next.js App Router app.

  1. Check that the app uses the App Router on a Next.js server. If it uses the Pages Router, `output: 'export'` or cached pages, stop and tell me.
  2. Install `@inth/nextjs` and `@inth/integrations`. Read `node_modules/@inth/nextjs/AGENTS.md`, then follow the Next.js quickstart it links to, in order. Do not guess the API from memory.
  3. Set `NEXT_PUBLIC_INTH_PROJECT_URL` in `.env.local`. Ask me for my project URL, and use `https://example-inth.inth.app` only for a demo. `NEXT_PUBLIC_INTH_PROJECT_URL` wins over any legacy `NEXT_PUBLIC_C15T_BACKEND_URL`.
  4. Wrap the Next.js config in `withConsentManifest` from `@inth/nextjs/build`. Add nothing to `.gitignore`.
  5. Create `inth.config.ts` at the project root. Move every analytics and marketing script into it with the matching helper from `@inth/integrations`, carry over vendor settings such as PostHog's `region` or `apiHost`, and remove old loaders (`next/script`, `@next/third-parties`, tag managers). If a vendor has no helper, tell me.
  6. In the root layout, render `InthProvider` with `state={resolveConsent()}` (not awaited), plus `ConsentBanner`, `ConsentDialog` and a footer `ConsentDialogLink`. Do not add `'use client'`, and mount a single `InthProvider` in the root layout.
  7. Run `next build` and `next start`. In a browser, verify no vendor request fires before consent, rejecting survives a reload, and granting analytics loads PostHog.

  List the files changed, any script still outside consent, and how you checked the requests.
</Prompt>

## Prerequisites

- A Next.js App Router app on a server. Using Pages Router, `output: 'export'` or cached pages? See [Use another router or deployment](#use-another-router-or-deployment). Other frameworks are in the [framework list](/docs/frameworks).
- An [Inth project](https://inth.com/dashboard/sign-up?framework=next) with your origin in trusted origins.

## Install the SDK

<CommandTabs command="@inth/nextjs @inth/integrations" mode="install" />

Components render their own styles. On Tailwind CSS 3, [load the stylesheet yourself](/docs/frameworks/next/customize#load-the-stylesheet-yourself).

## Set the project URL

Add your project URL to `.env.local` and your host's build settings:

```sh title=".env.local"
NEXT_PUBLIC_INTH_PROJECT_URL=https://example-inth.inth.app
```

`https://example-inth.inth.app` is a public demo project. Rebuild after changing it. `NEXT_PUBLIC_INTH_PROJECT_URL` wins over legacy `NEXT_PUBLIC_C15T_BACKEND_URL` (used as a fallback when unset).

Render `InthProvider` in your root layout with `resolveConsent()` unawaited:

<include src="../../shared/examples/nextjs/quickstart-layout.mdx" />

Mount one `InthProvider` in the root layout without `'use client'`. Unawaited `resolveConsent()` streams the page while blocking optional categories until resolved. For server-rendered banner HTML, see [App Router](/docs/frameworks/next/app-router#render-the-banner-in-the-server-html).

## Check it works

Run `next build && next start` and open a private window with DevTools Network open:

1. Under an opt-in policy, the banner shows with no PostHog or `/v1/consent/init` request.
2. Click **Reject All** and reload. The banner stays closed and PostHog stays blocked.
3. Open **Privacy settings**, enable **Analytics**, and save. PostHog loads and `POST /v1/consent/records` succeeds.
4. Disable **Analytics** and save. The page reloads without PostHog.

No banner? Test EU rules locally with `resolveConsent({ country: 'DE' })`, then remove it. See [why is there no banner](/docs/guides/troubleshooting#why-is-there-no-banner), [Next.js troubleshooting](/docs/frameworks/next/troubleshooting) and [verify consent](/docs/guides/verify-consent).
