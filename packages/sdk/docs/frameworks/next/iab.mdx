## Prepare the IAB configuration

<import src="../../shared/react/iab/overview.mdx#prepare" />

Import `IABProvider`, `IABConsentBanner` and `IABConsentDialog` from
`@inth/react/iab` (there is no `@inth/nextjs/iab` JS entry point) and render
this Client Component inside `InthProvider` from your
[App Router](/docs/frameworks/next/app-router) or
[Pages Router](/docs/frameworks/next/pages-router) setup. Both components
render their own inline styles by default.

## Load an external stylesheet

On Tailwind CSS 3, or to place Inth styles in a named cascade layer, set
`options: { styles: false }` in `inth.config.ts` and import both stylesheets in
order from your global stylesheet:

{/* example: fragment */}

```css title="styles/globals.css"
@import '@inth/nextjs/styles.css';
@import '@inth/nextjs/iab/styles.css';
```

Tailwind CSS 3 also requires the
[PostCSS plugin](/docs/customization/tailwind#set-up-tailwind-css-3).
