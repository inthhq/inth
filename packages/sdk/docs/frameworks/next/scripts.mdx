Add vendor scripts to `inth.config.ts`, control loading and revocation, send
consent-aware analytics events, and replace `@next/third-parties`.

## Install the script helpers

The [App Router](/docs/frameworks/next/app-router),
[Pages Router](/docs/frameworks/next/pages-router) and
[static export](/docs/frameworks/next/static-export) guides already register
PostHog. Install `@inth/integrations` if it is not installed yet:

<CommandTabs command="@inth/integrations" mode="install" />

Adding scripts requires no changes to `next.config.ts` or your layout. Scripts
wait until the browser has a resolved policy and the required category is
allowed.

<include src="../../shared/next-consent-wrapper.mdx" />

## Register several vendors

Pass every helper in the same `scripts` array in `inth.config.ts`:

{/* example: fragment */}

```ts title="inth.config.ts"
import { googleTagManager } from '@inth/integrations/google-tag-manager';
import { metaPixel } from '@inth/integrations/meta-pixel';
import { defineConsentConfig } from '@inth/nextjs';

export default defineConsentConfig({
	scripts: [
		googleTagManager({ id: 'GTM-XXXXXXX' }),
		metaPixel({ pixelId: 'YOUR_PIXEL_ID' }),
	],
});
```

Each helper applies its own consent rules: Meta Pixel waits for `marketing`,
while Google Tag Manager follows the
[Consent Mode contract](/docs/integrations/google-tag-manager). Remove old
snippets from layouts, `pages/_document.tsx` or tag managers so each vendor
loads once, and omit any helper whose ID is empty.

## Check loading and revocation behavior

- **Per-vendor contracts.** Standard scripts wait for their category, while
  helpers with `alwaysLoad` can load an SDK before consent using the vendor's
  consent API. Check each helper's guide in
  [Integrations](/docs/integrations/overview), and use
  [Custom integrations](/docs/integrations/building-integrations) for unlisted
  vendors.
- **Revocation reloads.** Removing a `<script>` element does not stop code
  already running, so `InthProvider` reloads the page when a visitor turns off a
  granted category. See
  [reload after revocation](/docs/frameworks/next/components/inth-provider#reload-after-revocation).
- **Embeds and network calls.** Gate iframes with
  [Embeds](/docs/frameworks/next/embeds) and hold direct `fetch`/XHR beacons
  with the [Network blocker](/docs/frameworks/next/network-blocker).
- **Per-vendor switches and storage cleanup.** Let visitors toggle individual
  vendors with [Vendor consent](/docs/frameworks/next/vendor-consent), and wipe
  first-party cookies or storage keys on denial with
  [Clear on revocation](/docs/frameworks/next/clear-on-revocation).

## Migrate from `@next/third-parties`

Components from `@next/third-parties/google` inject scripts and iframes during
render without checking consent or sending Consent Mode signals. Replace each
export, then uninstall `@next/third-parties`.

| `@next/third-parties/google` | Inth replacement |
| --- | --- |
| `<GoogleAnalytics gaId="G-XXXXXXXXXX" />` | `gtag({ id: 'G-XXXXXXXXXX', category: 'measurement' })` from `@inth/integrations/google-tag` |
| `<GoogleTagManager gtmId="GTM-XXXXXXX" />` | `googleTagManager({ id: 'GTM-XXXXXXX' })` from `@inth/integrations/google-tag-manager` |
| `sendGAEvent(...args)` | `window.gtag?.(...args)` |
| `sendGTMEvent(data)` | `window.dataLayer?.push(data)` |
| `<YouTubeEmbed videoid="VIDEO_ID" />` | `ConsentGate` around a `youtube-nocookie.com` iframe ([YouTube](/docs/integrations/youtube)) |
| `<GoogleMapsEmbed apiKey="API_KEY" mode="place" />` | `ConsentGate` around a Maps Embed API iframe ([Google Maps](/docs/integrations/google-maps)) |

### Replace GoogleAnalytics and GoogleTagManager

Remove the components from `app/layout.tsx`, `pages/_app.tsx` or
`pages/_document.tsx` and add the matching helpers to `inth.config.ts` (if GA4
already runs inside GTM, register `googleTagManager` only):

<include src="../../shared/examples/nextjs/third-parties-scripts.mdx" />

| `@next/third-parties` prop | Inth option |
| --- | --- |
| `gaId` | `id` on `gtag` |
| `debugMode` | `config: { debug_mode: true }` on `gtag` |
| `dataLayerName` on `GoogleAnalytics` | Not supported (`gtag` uses `window.dataLayer`) |
| `gtmId` | `id` on `googleTagManager` |
| `dataLayerName` on `GoogleTagManager` | `dataLayer` on `googleTagManager` |
| `dataLayer` | Seed before container load; see [keep initial data layer values](#keep-initial-data-layer-values) |
| `auth`, `preview`, `gtmScriptUrl` | Use a [custom integration](/docs/integrations/building-integrations) |
| `nonce` | `options={{ nonce }}` on `InthProvider` ([Content Security Policy](/docs/frameworks/next/content-security-policy)) |

### Keep initial data layer values

To make initial `dataLayer` values available to GTM startup triggers before
Inth loads the container, seed the queue with a `beforeInteractive` script in
`app/layout.tsx` (or `pages/_document.tsx`):

{/* example: fragment */}

```tsx title="app/layout.tsx (partial)"
import Script from 'next/script';
import type { ReactNode } from 'react';

const initialDataLayer = { pageType: 'product' };

export default function RootLayout({ children }: { children: ReactNode }) {
	return (
		<html lang="en">
			<body>
				<Script id="gtm-initial-data-layer" strategy="beforeInteractive">
					{`window.dataLayer = window.dataLayer || [];
window.dataLayer.push(${JSON.stringify(initialDataLayer)});`}
				</Script>
				{children}
			</body>
		</html>
	);
}
```

`googleTagManager` preserves the existing array, so your object lands before
Consent Mode `default` and `gtm.js`. This sends nothing to Google and works
with `loadMode: 'after-consent'`. Pass `nonce` to `Script` under CSP.

<import src="../../shared/scripts/google-load-mode.mdx#choose" />

### Move sendGAEvent and sendGTMEvent calls

Removing `<GoogleAnalytics />` breaks `sendGAEvent`. Replace both helpers with
direct browser calls (or `window[customDataLayerName]?.push(...)` for custom
GTM data layers):

{/* example: fragment */}

```ts
// Before
sendGAEvent('event', 'sign_up', { method: 'email' });
sendGTMEvent({ event: 'sign_up', method: 'email' });

// After
window.gtag?.('event', 'sign_up', { method: 'email' });
window.dataLayer?.push({ event: 'sign_up', method: 'email' });
```

To fan out one event to every allowed integration, use
[`useEventDispatcher()`](#send-your-own-analytics-events).

### Replace YouTubeEmbed and GoogleMapsEmbed

`YouTubeEmbed` contacts `cdn.jsdelivr.net` and YouTube before consent, and
`GoogleMapsEmbed` loads its iframe immediately. Wrap a plain iframe in
`ConsentGate` instead:

<include src="../../shared/examples/nextjs/video-embed.mdx" />

Map `videoid`, `params` and `playlabel` to the iframe `src` and `title`. For
Maps, keep the `https://www.google.com/maps/embed/v1/<mode>` URL and all query
parameters from `GoogleMapsEmbed`. See [YouTube](/docs/integrations/youtube)
and [Google Maps](/docs/integrations/google-maps).

Remove all `@next/third-parties` imports, uninstall the package, and confirm in
a private window that no requests hit `googletagmanager.com` (with
`loadMode: 'after-consent'`), `cdn.jsdelivr.net`, YouTube or Google Maps before
consent.

## Send your own analytics events

`useEventDispatcher()` from `@inth/nextjs` dispatches events only when
`measurement` is allowed. Track App Router pageviews by watching `usePathname()`
and `useSearchParams()`:

<include src="../../shared/examples/nextjs/analytics-events.mdx" />

Call `events.track('sign_up', { method: 'email' })` in event handlers.
`pageview` sends only to integrations listed in `pageviews`, and the first call
records the initial path without double-sending. See
[send events only to allowed integrations](/docs/integrations/overview#send-events-only-to-allowed-integrations).

## Verify the integration

Open your production build in a private window with DevTools Network open:

1. Under an opt-in policy, confirm no vendor requests fire before consent.
2. Open **Privacy settings** and enable **Analytics** (`measurement`) only:
   analytics load while marketing vendors stay blocked.
3. Reject, reload and confirm no vendor loads.
4. Revoke a granted category and confirm the page reloads with that vendor
   blocked.

See [Verify consent](/docs/guides/verify-consent) for the full release
checklist.
