## Read only the state you need

Import hooks from `@inth/nextjs` and call them in Client Components rendered
inside `InthProvider` from your
[App Router](/docs/frameworks/next/app-router) or
[Pages Router](/docs/frameworks/next/pages-router) setup:

{/* example: fragment */}

```tsx title="components/optional-feature.tsx"
'use client';

import { useConsent } from '@inth/nextjs';

export function OptionalFeature() {
	const allowed = useConsent('marketing');
	return allowed ? <div>Optional marketing content</div> : null;
}
```

## Save from a visitor action

Render this Client Component inside `InthProvider`:

{/* example: fragment */}

```tsx title="components/reject-button.tsx"
'use client';

import { useSaveConsents } from '@inth/nextjs';

export function RejectButton() {
	const save = useSaveConsents();
	return (
		<button type="button" onClick={() => void save('none')}>
			Reject optional
		</button>
	);
}
```
