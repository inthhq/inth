Add Inth to a Next.js app built with `output: 'export'`. Because a static
export has no Next.js server or API routes, the browser calls your Inth project
directly after the page loads.

## Prerequisites

- An [Inth project](https://inth.com) with your exported site's origin added to
  its trusted origins.

## Set the project URL and config

Add your absolute Inth project URL (including any path prefix) to `.env.local`
and your host's build settings. Do not use a relative path like `/api/inth`,
because static hosts have no consent route:

```sh title=".env.local"
NEXT_PUBLIC_INTH_PROJECT_URL=https://your-project.inth.app
```

`NEXT_PUBLIC_INTH_PROJECT_URL` wins over any legacy `NEXT_PUBLIC_C15T_BACKEND_URL`, which is read as a fallback if unset.

Create `inth.config.ts` at the project root with `mode: hosted()` and register
your `scripts` as shown in the
[quickstart](/docs/frameworks/next/quickstart#add-the-consent-config):

Exported HTML is identical for every visitor. After hydration, the browser
restores any stored choice and calls `${projectUrl}/v1/consent/init`, which detects
visitor geography from the request to Inth. Until policy resolves, optional
categories stay denied and the banner stays hidden.

## Test the exported files

Run `next build` and serve `out/` with a static file server (`next dev` can
mask accidental API route dependencies), then test in a private window:

1. Confirm DevTools Network shows `/v1/consent/init` and `/v1/consent/records` requests to your Inth
   origin and no failed `/api/inth` requests.
2. Under an opt-in policy, confirm the banner appears and no PostHog request
   fires. Click **Reject All**, reload, and confirm PostHog stays blocked.
3. Open **Privacy settings** and enable **Analytics** (`measurement`). PostHog
   loads.
4. Block your Inth origin in DevTools and reload in a fresh session: no banner
   appears and no vendor loads.

A CORS error means your exported site's origin is missing from your Inth
project's trusted origins. See [Verify consent](/docs/guides/verify-consent)
for the full checklist.

## Other static options

- **Same-origin URL:** requires a reverse proxy at your hosting provider.
- **Browser manifest resolution:** set
  `mode: manifest({ resolve: 'browser', manifestUrl })` with an absolute
  `manifestUrl` (location-based policies still need `geoUrl` or fall back to
  `/v1/consent/init`). For custom build-time bundles, see
  [static manifest helpers](/docs/frameworks/next/data-fetching-reference#static-manifest-helpers).
- **Tests without a backend:** use `testing()`, which throws in production; see
  [testing configuration](/docs/frameworks/next/data-fetching-reference#testing-configuration).
