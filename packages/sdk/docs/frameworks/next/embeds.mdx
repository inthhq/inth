Hold back YouTube players, maps and other third-party iframes until the visitor
allows their consent category so no embed host receives requests before
consent.

## Pick a method

| Method | Use it when |
| --- | --- |
| `ConsentGate` | You render the iframe in React and want a built-in placeholder with a button to open preferences. |
| Iframe blocker | The iframe comes from raw HTML, Markdown or a CMS. |

## Gate an embed with ConsentGate

Wrap the iframe in `ConsentGate` inside a Client Component:

<include src="../../shared/examples/nextjs/video-embed.mdx" />

Import `VideoEmbed` into any Server Component or page under `InthProvider`. Pick
a category that matches the embed (`measurement` for YouTube; `functionality`
or `experience` for maps or chat). See
[ConsentGate](/docs/frameworks/next/components/consent-gate) for SSR behavior,
placeholders and props.

## Gate an iframe with the iframe blocker

`InthProvider` runs the iframe blocker by default. Replace `src` with `data-src`
and add `data-category` (plus optional `data-vendor` for per-vendor blocking):

{/* example: fragment */}

```html title="Markup from your CMS"
<iframe
  data-src="https://www.google.com/maps/embed?pb=YOUR_EMBED_ID"
  data-category="functionality"
  title="Store map"
></iframe>
```

Because server HTML omits `src`, nothing loads before hydration. After
hydration, Inth copies `data-src` to `src` when allowed, strips it on
revocation, and watches DOM mutations across client-side navigations. Pass
`options={{ iframeBlocker: false }}` on `InthProvider` to disable it.

## Verify the embeds

Open your production build in a private window under an opt-in policy:

1. View page source and DevTools Network: no iframe has a third-party `src` and
   no request hits `youtube-nocookie.com` or `google.com/maps`.
2. Grant the embed's category and save: the iframe loads.
3. Revoke the category and save: the page reloads without the embed.

See [YouTube](/docs/integrations/youtube) and
[Google Maps](/docs/integrations/google-maps) for embed sizing and titles.
