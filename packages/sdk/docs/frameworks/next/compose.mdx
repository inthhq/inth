## Compose the banner

`CookieBanner` keeps the stock card and policy copy while rendering each policy
action with your own button component:

<include src="../../shared/examples/nextjs/compose-button.mdx" />

<include src="../../shared/examples/nextjs/compose-banner.mdx" />

Add `'use client'` because Server Components cannot access properties on a
Client Component (`ConsentBanner.Root`) or pass functions (`renderAction`).

Render `CookieBanner` inside
[InthProvider](/docs/frameworks/next/components/inth-provider) in place of
`ConsentBanner`, either in your App Router root layout
([quickstart](/docs/frameworks/next/quickstart#resolve-consent-in-the-root-layout))
or in `pages/_app.tsx`:

{/* example: fragment */}

```tsx title="app/layout.tsx (partial)"
<InthProvider state={resolveConsent()}>
	{children}
	<CookieBanner />
	<ConsentDialog />
	<footer>
		<ConsentDialogLink>Privacy settings</ConsentDialogLink>
	</footer>
</InthProvider>;
```

import non-deferred dialog parts in a Client Component, import from
`@inth/react/components/consent-dialog`. See
[ConsentDialog](/docs/frameworks/next/components/consent-dialog) and
[ConsentWidget](/docs/frameworks/next/components/consent-widget).
