## When to go headless

<import src="../../shared/react/headless.mdx#when-to-go-headless" />

Before rendering custom UI, check `useModel()` from `@inth/nextjs`: it returns
`null` while unresolved and `'none'` when no consent UI is owed.

## Minimal example

Render this Client Component inside `InthProvider` from your
[App Router](/docs/frameworks/next/app-router) or
[Pages Router](/docs/frameworks/next/pages-router) setup in place of
`ConsentBanner`, keeping `ConsentDialog` and a persistent preferences link:

{/* example: fragment */}

```tsx title="components/consent-banner.tsx"
'use client';

import {
	StreamedConsentSurface,
	useBannerCopy,
	useConsentLabels,
	useHeadlessConsentUI,
} from '@inth/nextjs/headless';

function BannerContent() {
	const { banner, performAction, openDialog } = useHeadlessConsentUI();
	const { title, description } = useBannerCopy();
	const labels = useConsentLabels();

	if (!banner.isVisible) {
		return null;
	}

	return (
		<section role="region" aria-label={title}>
			<h2>{title}</h2>
			<p>{description}</p>
			{banner.preferenceControls.map((right) => (
				<button key={right} type="button" onClick={openDialog}>
					{labels.preferenceControls[right]}
				</button>
			))}
			{banner.actionGroups.map((group) => (
				<div key={group.join('-')}>
					{group.map((action) => (
						<button
							key={action}
							type="button"
							data-primary={banner.primaryActions.includes(action) || undefined}
							onClick={() => performAction(action)}
						>
							{labels.actions[action]}
						</button>
					))}
				</div>
			))}
		</section>
	);
}

export function Banner() {
	return (
		<StreamedConsentSurface>
			<BannerContent />
		</StreamedConsentSurface>
	);
}
```

With the
[streamed layout](/docs/frameworks/next/rendering#stream-or-await-consent-in-the-app-router),
`StreamedConsentSurface` waits inside its own `Suspense` boundary so your
custom banner arrives before hydration like the stock banner (call the hooks
inside it, not above it). With an awaited layout, it renders its children
directly.
