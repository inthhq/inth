Install `window.__gpp` (GPP 1.1) in a Next.js app with `ConsentGPP` from
`@inth/react/gpp` so Prebid.js, Google Ad Manager and other ad tech can read
US privacy opt-outs and EU TCF strings.

## Turn on GPP

Render `ConsentGPP` inside `InthProvider` in your
[App Router](/docs/frameworks/next/app-router) root layout or
[Pages Router](/docs/frameworks/next/pages-router) `pages/_app.tsx`:

{/* example: fragment */}

```tsx title="app/layout.tsx (partial)"
import { ConsentGPP } from '@inth/react/gpp';

<InthProvider state={resolveConsent()}>
	<ConsentGPP />
	{children}
	<ConsentBanner />
	<ConsentDialog />
</InthProvider>;
```

`ConsentGPP` renders nothing, installs `window.__gpp` on mount in the browser,
removes it on unmount, and accepts plain props from Server Components (such as
`<ConsentGPP usFallback="none" />`). Apps that do not import `@inth/react/gpp`
bundle no GPP code.

The GPP string follows the policy and location resolved by `resolveConsent()`.
Check [Geography headers](/docs/frameworks/next/geography-headers) if US state
headers are missing, and set up [IAB TCF](/docs/frameworks/next/iab) to include
the TCF EU section under `iab` policies.
