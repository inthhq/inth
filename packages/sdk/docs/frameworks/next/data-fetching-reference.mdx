API reference for `@inth/nextjs` configuration, server helpers, route handlers
and static manifests. Requires Next.js 15 or 16 (`next ^15.0.0 || ^16.0.0`).
See [Rendering and deployment](/docs/frameworks/next/rendering) to pick a setup.

## Config reference

Export `defineConsentConfig()` as default from `inth.config.ts` at the project
root. `withConsentManifest` wires it into `InthProvider`, `resolveConsent`,
`withConsentProps`, `createConsentRoute` and `createPagesConsentRoute`. The
browser bundle includes this file, so never put secrets in it.

| Property | Default | Behavior |
| --- | --- | --- |
| `projectUrl` | `NEXT_PUBLIC_INTH_PROJECT_URL` (`NEXT_PUBLIC_C15T_BACKEND_URL` fallback) | Absolute Inth base URL (`/v1/consent/records`, `/v1/consent/manifest`, `/v1/consent/init`). Avoid `/`-relative paths in production to prevent `Host`-header spoofing. |
| `mode` | `manifest()` | `manifest()` or `hosted()` from `@inth/nextjs`, or `testing()` from `@inth/nextjs/testing` ([consent modes](/docs/concepts/modes)). |
| `routePrefix` | none | Catch-all consent route path (for example `/api/inth`). Browser init calls `${routePrefix}/v1/consent/init` instead of `${projectUrl}/v1/consent/init`. |
| `proxy` | `false` | Routes browser saves through `routePrefix` (pair with `createConsentRoute({ proxy: true })`). Requires `routePrefix` ([Performance](/docs/frameworks/next/optimization#keep-browser-consent-requests-on-your-origin)). |
| `journey` | `'page'` | Journey scope (`'page'`, `'tab'` or `false`), shared by `resolveConsent` and `InthProvider`. |
| `scripts`, `vendors`, `clearOnRevocation`, `networkBlocker`, `persistence`, `scriptLoader`, `options` | none | Browser options. Matching props on `InthProvider` override them. |

On the server and during builds, `defineConsentConfig` returns a frozen object
and throws `TypeError` on invalid config (browser bundles skip validation):

| Error message | Cause |
| --- | --- |
| `@inth/nextjs: defineConsentConfig expects an object.` | Non-object argument. |
| ``@inth/nextjs: manifest() needs a backend URL: ... Set NEXT_PUBLIC_INTH_PROJECT_URL at build time, or `projectUrl` in inth.config.ts.`` | Missing URL outside `testing()`. |
| ``@inth/nextjs: defineConsentConfig `projectUrl` must be an absolute http(s) URL or a `/`-relative path, received "...".`` | Protocol-relative or bare URL on `projectUrl`, `routePrefix`, `mode.manifestUrl` or `mode.geoUrl`. |
| ``@inth/nextjs: `routePrefix` can't be '/': a consent route at the site root would catch every page. Use a path such as '/api/inth'.`` | `routePrefix` is `'/'`. |
| ``@inth/nextjs: defineConsentConfig `mode` must be manifest() or hosted() from @inth/nextjs, or testing() from @inth/nextjs/testing. Pass a transport through InthProvider `options.mode`.`` | Invalid `mode` value. |
| ``@inth/nextjs: defineConsentConfig `journey` must be 'page', 'tab' or false.`` | Invalid `journey` value. |
| ``@inth/nextjs: `proxy` sends saves through the consent route, so it needs `routePrefix`.`` | `proxy: true` without `routePrefix`. |

### Do I need the consent route?

Only when some pages render without server state (static, ISR or `'use cache'`
pages in App Router, or Pages Router pages without `withConsentProps`). Set
`routePrefix: '/api/inth'` in `inth.config.ts` and mount:

The route answers `GET ${routePrefix}/v1/consent/init` using the bundled manifest plus
request location headers, and `GET ${routePrefix}/v1/consent/manifest` for
`manifest({ resolve: 'browser' })`. Without `routePrefix`, browser init calls
`${projectUrl}/v1/consent/init`.

### Mode combinations

| Config | Server render | Browser initialization |
| --- | --- | --- |
| `manifest()` + `routePrefix` | Resolves snapshot locally | Calls `${routePrefix}/v1/consent/init` |
| `manifest()` without `routePrefix` | Resolves snapshot locally | Calls `${projectUrl}/v1/consent/init` |
| `manifest({ resolve: 'browser' })` | Resolves snapshot locally | Lazy-loads resolver, fetches `${routePrefix}/v1/consent/manifest` else `${projectUrl}/v1/consent/manifest` |
| `manifest({ source: 'runtime' })` | Fetches and caches `${projectUrl}/v1/consent/manifest` | Same as `manifest()` |
| `hosted()` | Calls `${projectUrl}/v1/consent/init` | Calls `${projectUrl}/v1/consent/init` |
| `testing()` | No policy request | Resolves local test rules |

All modes except `testing()` post choices to `${projectUrl}/v1/consent/records`. The
browser loads only the active mode's code
([first-load JS by mode](/docs/concepts/modes#what-each-mode-adds-to-first-load-javascript)).
To use per-request `/v1/consent/init` instead of manifests, set `mode: hosted()` (see
[client-side initialization](/docs/frameworks/next/client-side#configure-the-backend-and-the-mode))
and remove the consent route unless `proxy: true` uses it.

## Server helper options

`@inth/nextjs/server` exports `resolveConsent` for the App Router (reading
`next/headers` and calling `await connection()` before reading the clock).
`@inth/nextjs/pages` exports `resolveConsent({ req, ... })` and
`withConsentProps`.

### `resolveConsent` options

| Option | Default | Behavior |
| --- | --- | --- |
| `config` | `inth.config.ts` | Override config; explicit options still win. |
| `projectUrl` | mode, config, or env var | Inth base URL (`${projectUrl}/v1/consent/init` in `hosted()`). |
| `manifestUrl` | mode's absolute URL else `${projectUrl}/v1/consent/manifest` | Forces manifest resolution via in-process cache. Ignores `/`-relative mode URLs. |
| `snapshot` | build snapshot | Resolves directly without fetching or refreshing. |
| `fetch` | `globalThis.fetch` | Custom fetch; preserve `next: { revalidate: 300 }` (manifests) and `cache: 'no-store'` (`/v1/consent/init`). Keeps IAB GVL inline. |
| `forwardHeaders` | `[]` | Incoming headers copied over `https`/loopback (never `cookie` or `forwarded`/`x-forwarded-*`). |
| `trustForwardedHeaders` | `false` | Resolves relative URLs from `forwarded`/`x-forwarded-*` and sends `x-forwarded-for`. Use only behind a trusted proxy. |
| `onError` | none | Receives upstream and `ManifestUnavailableError` errors (defaults to `console.warn` outside production). |
| `timeoutMs` | `500` | Wait budget (ms) before returning baseline state. `false`/`Infinity` waits for the 5 s manifest timeout or `fetch`. |
| `journey` | config `journey` | Must match `InthProvider`. |
| `experiment` | none | Active [banner experiment](/docs/guides/banner-experiments) arm. |
| `waitUntil` | none | Keeps session reports, refreshes and timed-out fetches alive (pass `(task) => after(() => task)` in App Router). |
| `now` | `Date.now()` | Timestamp for validating stored records. |
| `cookieName` | `inth` | Consent cookie name; must match client `storageConfig.storageKey`. |
| `country`, `language` | header detection | Override detected country or `accept-language`. |
| `request` | `next/headers` | Custom `{ cookies(), headers() }` adapter (App Router only). |

`resolveConsent` throws only if `request` rejects or `onError` throws. Network,
timeout, non-2xx and URL errors return baseline state (records, geography,
language and GPC, no policy) so the page renders with optional categories
denied and the browser retries. A 200 response with
`policyResolution.status: 'failed'` is preserved and keeps UI hidden.

### Caching, self-fetch protection and headers

- **Manifest cache:** concurrent misses coalesce (5 s upstream timeout), failed
  misses back off 1 s to 5 s (`ManifestUnavailableError` with
  `reason: 'backoff'`), and stale copies serve only within
  `stale-while-revalidate`. App Router also passes `next: { revalidate: 300 }`
  to the Data Cache; Pages Router uses in-process cache only.
- **Self-fetch guard:** `resolveConsent` refuses to fetch its own `routePrefix`
  and returns baseline state. Keep `projectUrl` absolute and use
  [`proxy: true`](/docs/frameworks/next/optimization#keep-browser-consent-requests-on-your-origin).
- **Forwarded headers:** manifest requests forward only `forwardHeaders`.
  `/v1/consent/init` forwards `x-inth-country`, `x-inth-region`, `accept-language`,
  `sec-gpc`, `user-agent` and any experiment arm; over `https`/loopback it adds
  the `cookieName` cookie, `forwardHeaders` and (with `trustForwardedHeaders`)
  `x-forwarded-for`.
- **Inline snapshots:** never refresh at runtime, though `iab` policies with an
  `iab.gvl` reference still fetch the Global Vendor List.

### Cookie-only state

With `mode: testing()` or no project URL, `resolveConsent` makes no network
calls and returns a serializable `ConsentState` containing `initialRecords`,
`initialPrivacySignals.gpc`, `now` and any detected `initialOverrides`
(`country`, `region`, `language`). Only `now`, `cookieName`, `country`,
`language` and `request` apply.

### Pages Router differences

`withConsentProps(getServerSideProps?, options?)` resolves consent in parallel
with your handler, preserves `redirect`/`notFound`, strips `undefined` via JSON
round-trip and injects `props.consent`. Calling `resolveConsent({ req })`
directly requires your own `JSON.parse(JSON.stringify(result))`. Use
`createPagesRequestContext(req)` in custom Node servers or test harnesses:

{/* example: fragment */}

```ts title="server/consent.ts"
import type { IncomingMessage } from 'node:http';

import { createPagesRequestContext } from '@inth/nextjs/pages';
import { resolveConsent } from '@inth/nextjs/server';

export function resolveRequestConsent(req: IncomingMessage) {
	return resolveConsent({ request: createPagesRequestContext(req) });
}
```

## Route handler options

`createConsentRoute(options?)` from `@inth/nextjs/api` exports `GET` for
`/v1/consent/init` and `/v1/consent/manifest` (404 for other paths). With `proxy: true`, it also
exports `POST`, `PATCH`, `PUT`, `DELETE` and `OPTIONS` to forward `/v1/consent/records`,
`/v1/consent/sessions`, `/v1/subjects/:id/link`, `health` and `status` to Inth.

| Option | Default | Behavior |
| --- | --- | --- |
| `config` | `inth.config.ts` | Override config object. |
| `projectUrl`, `manifestUrl` | config or env var | Upstream URLs (`manifestUrl` takes precedence over `projectUrl`). |
| `snapshot` | build snapshot | Serves `/v1/consent/manifest` and resolves `/v1/consent/init` without upstream fetches. |
| `proxy` | `false` | Forwards consent endpoints to Inth; pair with `proxy: true` in `inth.config.ts`. |
| `manifestRevalidateSeconds` | `300` | Data Cache TTL in seconds (`false` disables). |
| `fetch`, `fetchGvl` | built-in | Custom fetchers (default `fetchGvl` caches in-process with a 5 s timeout when `iab.enabled` and matched rule is `iab`). |
| `trustForwardedHeaders` | `false` | Reads `forwarded`/`x-forwarded-*` behind a trusted proxy. |
| `onBackgroundRevalidate` | none | Receives background refresh and session report promises; wire to `after`/`waitUntil` ([Performance](/docs/frameworks/next/optimization#configure-manifest-cache-refresh)). |

Handler behavior:

- `GET ${routePrefix}/v1/consent/init` sends `cache-control: private, no-store` and
  `x-inth-policy-contract: 1`. Query params (`country`, `region`, `gpc`,
  `contract`) override `x-inth-*` headers. Mismatched contracts return
  `policyResolution.status: 'failed'` (`reason: 'unsupported-contract'`).
- `GET ${routePrefix}/v1/consent/manifest` returns `200` JSON directly from a snapshot;
  under runtime fetching it forwards `cache-control`, `etag`, `last-modified`,
  `content-language`, computes `age`, supports `If-None-Match` (`304`) and
  forwards only a valid lower-cased `language` query param.
- On runtime manifest `404` or initial failure, `/v1/consent/init` falls back to
  `${projectUrl}/v1/consent/init`. Filter IAB vendors on the server so banners do not wait
  for the full GVL.
- `createPagesConsentRoute(options?, param?)` from `@inth/nextjs/pages` accepts
  the same options for `pages/api/inth/[...inth].ts` (`param` defaults to
  `'inth'`, returning `405` with `allow: GET` for non-`GET`/`HEAD` without
  `proxy: true`).

## Manifest request resolution

In [App Router](/docs/frameworks/next/app-router) and
[Pages Router](/docs/frameworks/next/pages-router): (1) `next build` bundles
`/v1/consent/manifest` (or runtime mode fetches/caches it), (2) `resolveConsent()`
resolves locally from headers and cookies, (3) `InthProvider` hydrates with that
`state`, (4) pages without server state call `${routePrefix}/v1/consent/init` (else
`${projectUrl}/v1/consent/init`), and (5) saves post to `${projectUrl}/v1/consent/records`.

## Static manifest helpers

`@inth/nextjs/static` exports `createStaticManifestModule({ manifestUrl })`,
`loadStaticManifest`, `createStaticConsentResolver({ manifest, geo, geoUrl })`
and `resolveUnknownLocationInit(manifest, { language, gpc })` for custom
`output: 'export'` transports. Unknown locations use the manifest's fallback or
default rule (failing with `insufficient-inputs` if neither exists). Never bake
build-machine cookies or location into static HTML. For standard static exports,
follow [Static export](/docs/frameworks/next/static-export) or set
`mode: manifest({ resolve: 'browser', manifestUrl })`.

## Geography and privacy signals

Server resolution reads `cf-ipcountry`, `x-vercel-ip-country`,
`cf-region-code`, `x-vercel-ip-country-region`, `accept-language` and
`sec-gpc`. Overrides (`x-inth-country`, `x-inth-region`, `x-inth-gpc`) win and
must only be set by trusted infrastructure. Missing headers stay unknown; Inth
never infers location from the server IP.

## Testing configuration

Set `mode: testing()` from `@inth/nextjs/testing` in `inth.config.ts` for tests
without a project URL or network requests (throws in production; pass
`testing({ policy })` for custom rules):

{/* example: fragment */}

```ts title="inth.config.ts"
import { defineConsentConfig } from '@inth/nextjs';
import { testing } from '@inth/nextjs/testing';

export default defineConsentConfig({ mode: testing() });
```

Without `inth.config.ts` or a project URL, `InthProvider` throws; see
[troubleshooting](/docs/frameworks/next/troubleshooting#inthnextjs-projecturl-is-required).

### Authenticated hosted vendor lists

When `hosted()` `resolveConsent()` forwards cookies, `forwardHeaders` or uses a
custom `fetch`, it keeps the IAB GVL inline in server state because browsers
cannot replay private fetches. Expose public lists via `routePrefix` for
smaller HTML.
