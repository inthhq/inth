Resolve consent purely in the browser using `hosted()` mode. Every page can
stay static, the HTML is identical for all visitors, and the browser calls
`${projectUrl}/v1/consent/init` after hydration.

Use this setup when you want the fewest files and do not need the banner in
server HTML. For server resolution with zero `/v1/consent/init` calls, use the
[App Router](/docs/frameworks/next/app-router) or
[Pages Router](/docs/frameworks/next/pages-router) guide. For
`output: 'export'`, see [Static export](/docs/frameworks/next/static-export).
[Rendering and deployment](/docs/frameworks/next/rendering) compares all paths.

Until policy resolves, optional categories stay denied and the banner stays
hidden.

## Configure the backend and the mode

Create an [Inth project](https://inth.com), configure its policy rules and add
your site's origin to its trusted origins. Then install the SDK:

<CommandTabs command="@inth/nextjs @inth/integrations" mode="install" />

Set `NEXT_PUBLIC_INTH_PROJECT_URL` (including any path prefix) in `.env.local`
and your host's build settings:

```sh title=".env.local"
NEXT_PUBLIC_INTH_PROJECT_URL=https://your-project.inth.app
```

`NEXT_PUBLIC_INTH_PROJECT_URL` wins over any legacy `NEXT_PUBLIC_C15T_BACKEND_URL`, which is read as a fallback if unset.

Create `inth.config.ts` at the project root with `mode: hosted()`, and add your
`scripts` as shown in the
[quickstart](/docs/frameworks/next/quickstart#add-the-consent-config) (keep
secrets out of this file):

<include src="../../shared/examples/nextjs/client-side-config.mdx" />

Wrap `next.config.ts` in `withConsentManifest` so the SDK locates
`inth.config.ts` (it skips the manifest download in `hosted()` mode):

<include src="../../shared/examples/nextjs/next-config.mdx" />

## Verify browser initialization

Open your production build in a private window with DevTools open:

1. Confirm the browser calls `${projectUrl}/v1/consent/init` once, shows the banner and
   sends no PostHog request.
2. Click **Reject All**, reload, and confirm the banner stays closed and
   PostHog stays blocked.
3. Open **Privacy settings**, confirm the rejection is selected, and enable
   **Analytics** (`measurement`) so PostHog loads.
4. Block your Inth domain in DevTools and reload in a fresh session: no banner
   appears and no vendor loads.
