## Install the right package

Install the one package for your framework: `@inth/nextjs`,
`@inth/tanstack-start`, `@inth/react`, `@inth/nuxt`, `@inth/vue`,
`@inth/astro`, `@inth/svelte` or `@inth/angular`. Each one brings in
`@inth/sdk`, and you import everything from the framework package, so you
never install `@inth/sdk` yourself.

HTML pages and the stock UI in JavaScript use `@inth/sdk`. Vendor script helpers are a separate
install, `@inth/integrations`, in every framework.

Mobile SDKs use native consent engines and have their own installation paths.
They are currently private prereleases. [Mobile availability](/docs/guides/mobile-status)
explains how to obtain the matching Swift, Maven and RN artifacts.

## After the quickstart

A banner on screen does not mean analytics wait for consent. Move existing
scripts into Inth, replace embeds that load on their own, and keep a link to
reopen preferences. Then [verify the integration](/docs/guides/verify-consent).
