Pick the package for your framework. Every web framework package includes
`@inth/sdk`, so install only the adapter and import everything from it. Install
`@inth/integrations` separately for vendor script helpers.

## Pick your framework

| Framework | Package | Guide |
| --- | --- | --- |
| Next.js | `@inth/nextjs` | [Next.js quickstart](/docs/frameworks/next/quickstart) |
| TanStack Start | `@inth/tanstack-start` | [TanStack Start quickstart](/docs/frameworks/tanstack-start/quickstart) |
| React | `@inth/react` | [React quickstart](/docs/frameworks/react/quickstart) |
| Nuxt | `@inth/nuxt` | [Nuxt quickstart](/docs/frameworks/nuxt/quickstart) |
| Vue | `@inth/vue` | [Vue quickstart](/docs/frameworks/vue/quickstart) |
| Astro | `@inth/astro` | [Astro quickstart](/docs/frameworks/astro/quickstart) |
| Svelte | `@inth/svelte` | [Svelte quickstart](/docs/frameworks/svelte/quickstart) |
| SvelteKit | `@inth/svelte` | [SvelteKit quickstart](/docs/frameworks/sveltekit/quickstart) |
| Angular 20, 21 or 22 | `@inth/angular` | [Angular quickstart](/docs/frameworks/angular/quickstart) |
| HTML, CMS or static site generator | `@inth/sdk` via script tag | [HTML quickstart](/docs/frameworks/html/quickstart) |
| JavaScript with a bundler | `@inth/sdk` | [JavaScript quickstart](/docs/frameworks/javascript/quickstart) |
| Server code on Node.js, Vercel Functions or Workers | `@inth/node` | [Node.js quickstart](/docs/node/quickstart) |
| React Native or Expo dev builds | `@inth/react-native` | [React Native quickstart](/docs/frameworks/react-native/quickstart) |
| SwiftUI or UIKit | Swift package `inth` | [Swift quickstart](/docs/frameworks/swift/quickstart) |
| Kotlin Android | `com.inth` native artifacts | [Android quickstart](/docs/frameworks/android/quickstart) |

Not sure which path fits your rendering mode? See
[Choose your setup](/docs/concepts/choose-your-setup). Mobile SDKs are private
prereleases; see [Mobile availability](/docs/guides/mobile-status) for artifact
access.

## After the quickstart

Move existing analytics and marketing scripts into Inth, gate embeds that load
on their own, keep a link to reopen preferences, and run through
[Verify consent](/docs/guides/verify-consent).
