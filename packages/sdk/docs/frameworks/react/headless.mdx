Build a fully custom consent banner or embed gate in React using hooks from `@inth/react/headless`.

## When to go headless

<import src="../../shared/react/headless.mdx#when-to-go-headless" />

Check for an active policy before rendering custom surfaces. `useModel()` from `@inth/react` returns `null` before a rule resolves and `'none'` when no consent UI is owed; the built-in components render nothing in both states.
