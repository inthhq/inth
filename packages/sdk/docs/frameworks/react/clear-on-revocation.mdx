Delete first-party cookies and Web Storage keys owned by an optional category when a visitor revokes consent in React.

## Configure cleanup

Gating stops new vendor requests, but leaves behind cookies and storage entries already written. List the keys each optional category owns in `InthProvider` options so Inth deletes them when that category is denied:

{/* example: fragment */}

```tsx title="src/consent.tsx (partial)"
import type { ClearOnRevocationConfig } from '@inth/react';

const clearOnRevocation: ClearOnRevocationConfig = {
  measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
  marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
};

<InthProvider options={{ mode, scripts, clearOnRevocation }}>
```

`InthProvider` reads `clearOnRevocation` once on mount; remount it to update the list. A provider borrowing an external `runtime` ignores this option; pass `clearOnRevocation` to `createConsentRuntime({ clearOnRevocation })` instead.
