Expose `window.__gpp` in a React app so ad tech such as Prebid.js and Google Ad Manager can read US state privacy signals and the TCF EU consent string.

## What GPP does

`ConsentGPP` from `@inth/react/gpp` installs the GPP 1.1 CMP API on `window.__gpp` and keeps its GPP string synchronized with the visitor's consent state.

## Turn on GPP

Render `ConsentGPP` inside `InthProvider`:

{/* example: fragment */}

```tsx title="src/consent.tsx"
import { ConsentGPP } from '@inth/react/gpp';

<InthProvider options={{ mode, scripts }}>
	<ConsentGPP />
	{children}
</InthProvider>;
```

`ConsentGPP` renders no markup. It registers `__gpp` on mount and removes it on unmount. Because it lives on the `@inth/react/gpp` subpath, apps that do not import it bundle zero GPP code, and no extra package install is required.

Pass any GPP option below as a prop, such as `<ConsentGPP usFallback="none" />`. It works identically when `InthProvider` uses an external `runtime`.

The GPP string follows the policy and location resolved by your Inth project. In `testing()` mode, pass the state explicitly with `overrides: { country: 'US', region: 'CA' }`.

To populate the TCF EU section for visitors under an `iab` policy, also configure [IAB TCF](/docs/frameworks/react/iab).
