Add IAB Transparency and Consent Framework support to a React app with `@inth/react/iab`.

## Prepare the IAB configuration

<import src="../../shared/react/iab/overview.mdx#prepare" />

Import the IAB components from `@inth/react/iab` and mount them inside your existing `InthProvider` from `@inth/react`.

The IAB banner and dialog render their own `<style>` elements by default, so leave `styles` enabled and omit CSS imports:

<include src="../../shared/examples/react/iab-consent.mdx" />

<import src="../../shared/react/iab/overview.mdx#configure" />

## Load an external stylesheet

On Tailwind CSS 3, or when placing Inth in a named cascade layer, import `@inth/react/styles.css` followed by `@inth/react/iab/styles.css` in your entry module and set `styles: false` on `InthProvider`:

{/* example: fragment */}

```tsx title="src/consent.tsx (partial)"
import '@inth/react/styles.css';
import '@inth/react/iab/styles.css';

// In the InthProvider options:
styles: false,
```

Tailwind CSS 3 also requires the [PostCSS plugin](/docs/customization/tailwind#set-up-tailwind-css-3).
