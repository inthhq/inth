Build a React consent banner with your own markup and design system buttons using `ConsentBanner` compound parts from `@inth/react`.

## When to compose

<import src="../../shared/react/compose.mdx#when-to-compose" />

For a banner sharing no markup with the built-in UI, use [headless hooks](/docs/frameworks/react/headless). To change a single class, token, or prop, see [customize](/docs/frameworks/react/customize).

## Compose the banner

`CookieBanner` keeps the built-in card, title, and copy while rendering each policy action with your own `BrandButton`:

<include src="../../shared/examples/storybook-react/compose-button.mdx" />

<include src="../../shared/examples/storybook-react/compose-banner.mdx" />

All parts read from the nearest `InthProvider`. In `src/consent.tsx` from the [quickstart](/docs/frameworks/react/quickstart), import `CookieBanner` and render it instead of `ConsentBanner`, next to `ConsentDialog`:

{/* example: fragment */}

```tsx title="src/consent.tsx (partial)"
<InthProvider options={{ mode, scripts }}>
	{children}
	<CookieBanner />
	<ConsentDialog />
	<footer>
		<ConsentDialogLink>Privacy settings</ConsentDialogLink>
	</footer>
</InthProvider>;
```
