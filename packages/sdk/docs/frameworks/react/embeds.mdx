Keep third-party iframes out of your React page until the visitor allows their consent category.

## Pick a method

| Method | Use it when |
| --- | --- |
| `ConsentGate` | You render the iframe in a React component and want a placeholder until the visitor allows its category. |
| The iframe blocker | The iframe comes from HTML you do not render with React, such as CMS or Markdown content. |

Both keep `src` off the iframe until consent allows it, preventing requests to the embed host before consent.

## Gate an embed with ConsentGate

Wrap the iframe in `ConsentGate` anywhere inside `InthProvider`:

<include src="../../shared/examples/react/video-embed.mdx" />

React keeps the iframe out of the DOM until the visitor allows `measurement`, rendering the `placeholder` with a [`ConsentDialogLink`](/docs/frameworks/react/components/consent-dialog-link) in its place. If the visitor withdraws `measurement`, React unmounts the iframe.

Choose the category that matches what the embed does. The example uses `measurement` for YouTube because its player tracks views; a map or chat widget usually belongs under `functionality` or `experience`. See [ConsentGate](/docs/frameworks/react/components/consent-gate) for the built-in placeholder and all props.

## Gate an iframe with the iframe blocker

`InthProvider` enables the iframe blocker by default. Put the URL in `data-src` instead of `src` and add `data-category`:

{/* example: fragment */}

```html title="Markup from your CMS"
<iframe
  data-src="https://www.google.com/maps/embed?pb=YOUR_EMBED_ID"
  data-category="functionality"
  title="Store map"
></iframe>
```

Inth copies `data-src` to `src` when the category is allowed and clears `src` when revoked. It observes the DOM so dynamically inserted iframes work too. Add `data-vendor` with a vendor ID to also block the iframe when the visitor turns that vendor off.

To disable the iframe blocker, set `iframeBlocker: false` in `InthProvider` options.

## Verify the embeds

Open the production build in a private window with DevTools open under an opt-in policy.

1. Confirm no iframe has a `src` pointing at `youtube-nocookie.com` or `google.com/maps`, and DevTools Network shows zero requests to them.
2. Allow the embed's category and save. Confirm the iframe loads.
3. Withdraw the category and save. Confirm the page reloads without the embed.

See the [YouTube](/docs/integrations/youtube) and [Google Maps](/docs/integrations/google-maps) guides for responsive sizing and accessible titles.
