Mount one `InthProvider` at your React app root to manage policy resolution, stored consent choices, and consent-gated scripts.

## Mount one provider

The [quickstart](/docs/frameworks/react/quickstart) mounts `InthProvider` alongside the banner, dialog, and footer preferences link in `src/consent.tsx`:

<include src="../../../shared/examples/react/consent.mdx" />

Passing `projectUrl` (or `mode: hosted()`) resolves each visitor's policy from `/v1/consent/init` on your Inth project and saves choices to `/v1/consent/records`. `consentManifest()` reads the URL from `VITE_INTH_PROJECT_URL` (falling back to `VITE_C15T_BACKEND_URL` if unset). To resolve a build-time snapshot in the browser instead, pass `manifest()` from `@inth/react`; see [Rendering](/docs/frameworks/react/rendering#bundle-the-policy-at-build-time). Next.js and TanStack Start export their own `InthProvider` that wraps `@inth/react`'s `InthProvider` with server-resolved state.

## Provider options

Keep `InthProvider` mounted across route navigation. It reads `mode`, `prefetch`, `persistence`, `storageConfig`, `clearOnRevocation`, `i18n`, and `experiment` once on mount and logs a development warning if those options change; remount the provider to update them. `scripts`, `vendors`, `networkBlocker`, `iframeBlocker`, `consentCategories`, `overrides`, `user`, `callbacks`, and `enabled` update live when changed.

| Option | Purpose |
| --- | --- |
| `projectUrl` | Your Inth project URL. Uses `hosted()` mode when `mode` is omitted |
| `mode` | Optional. Omitted or `hosted()` calls `/v1/consent/init` on your Inth project; `manifest()` resolves a build-time snapshot; `testing()` from `@inth/react/testing` runs offline for tests. See [Consent modes](/docs/concepts/modes) |
| `prefetch` | Server-resolved state, or a promise of it, from a framework adapter's server helper |
| `scripts` | Consent-gated vendor scripts. See [Scripts](/docs/frameworks/react/scripts) |
| `vendors` | Vendors listed under their category with individual switches. See [Vendor consent](/docs/frameworks/react/vendor-consent) |
| `scriptLoader` | Options for the script loader module |
| `networkBlocker` | Rules holding `fetch` and `XMLHttpRequest` calls until their category is allowed, or `false` |
| `iframeBlocker` | Gates DOM iframes carrying `data-category`. Enabled by default; pass `false` to disable |
| `persistence` | Stores the visitor's choice in a cookie and `localStorage`. Enabled by default |
| `storageConfig` | Storage key and cookie settings for the stored choice |
| `clearOnRevocation` | Cookies and storage keys deleted when a category is denied |
| `reloadOnConsentRevoked` | Reloads the page after a save or one-click opt-out revokes a granted category or vendor. Privacy signals and backend-synced opt-outs do not reload. Defaults to `true` |
| `consentCategories` | Categories offered in the preference dialog alongside script categories, within policy scope |
| `overrides` | Forces country, region, or language for testing |
| `user` | Links consent records to a signed-in user |
| `callbacks` | Choice, permission, error, and revocation-reload hooks |
| `i18n` | Languages and message overrides |
| `legalLinks` | Privacy policy and other legal links rendered in the banner and dialog |
| `theme` | `consentActions` and slot styles. Put CSS tokens in `ConsentTheme`; see [Customize](/docs/frameworks/react/customize) |
| `components` | Slot attributes per component part |
| `presentation` | Banner and dialog variant, position, and blocking |
| `experiment` | A/B test of `presentation`, read once on mount. See [Banner experiments](/docs/guides/banner-experiments) |
| `journey` | Random ID linking `/v1/consent/init` to the save that follows. See [Data fetching](/docs/concepts/data-fetching#link-an-init-to-the-save-that-follows) |
| `colorScheme` | `'light'`, `'dark'`, `'system'`, or `null` to leave the `inth-dark` class untouched |
| `noStyle`, `disableAnimation` | Drops built-in styles or turns off animations |
| `preloadDialog` | Controls when the deferred `ConsentDialog` downloads: `'idle'` (default) or `'intent'`. See [ConsentDialog](/docs/frameworks/react/components/consent-dialog#behavior) |
| `nonce` | Content Security Policy nonce applied to Inth `<script>` and `<style>` elements |
| `enabled` | Set `false` only to deliberately bypass consent enforcement |

`enabled: false` grants all categories and suppresses consent UI. Never use it to silence initialization errors or hide a banner in production.

## Observe changes without inventing choices

`onChoiceRecorded` fires on explicit accept, reject, and save actions. `onPermissionsChanged` fires for any effective permission change, including policy updates, expiry, and privacy signals. Hydration and notice dismissal never create explicit choices.

To manage the runtime externally, pass it via the `runtime` prop. The owner starts and disposes it; `InthProvider` never starts or disposes a borrowed runtime. Passing a different `runtime` moves the provider and its hooks to the new kernel without disposing the previous one; switch or unmount the provider before disposing an old runtime. Switching between a borrowed runtime and a provider-created runtime requires remounting. Pending IAB `save()` calls reject with `AbortError` if the provider unmounts or switches runtimes before the IAB handle is ready. See [How consent works](/docs/concepts/how-consent-works#a-permission-is-not-a-recorded-choice) and [Choose your setup](/docs/concepts/choose-your-setup).

## Reload after revocation

Removing a `<script>` tag cannot stop vendor listeners, timers, or widgets already running in memory. When an accept, reject, or save turns off a previously granted category or vendor, `InthProvider` reloads the page after the save request finishes and calls `onBeforeConsentRevocationReload` right before reloading.

Expiry, policy changes, and privacy signals do not reload the page. Set `reloadOnConsentRevoked: false` only when every gated vendor cleanly stops itself on revocation.

## Clear data when consent is denied

Configure `options.clearOnRevocation` to list cookies, `localStorage` keys, and `sessionStorage` keys per optional category. Inth clears denied categories once policy resolves and whenever a category transitions from allowed to denied. This option is read once on mount. See [Clear on revocation](/docs/frameworks/react/clear-on-revocation).
