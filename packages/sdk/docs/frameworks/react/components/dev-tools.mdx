## Render DevTools in development builds

Render `DevTools` inside `InthProvider` using a development-only dynamic import so production bundles never include it. In Vite, gate the import on `import.meta.env.DEV`; in webpack or other bundlers, use your bundler's compile-time development flag such as `process.env.NODE_ENV === 'development'`.

{/* example: fragment */}

```tsx title="src/consent-devtools.tsx"
import { lazy, Suspense } from 'react';

const DevTools = import.meta.env.DEV
	? lazy(() =>
			import('@inth/react/devtools').then(({ DevTools }) => ({
				default: DevTools,
			}))
		)
	: null;

export function ConsentDevTools() {
	return DevTools ? (
		<Suspense fallback={null}>
			<DevTools />
		</Suspense>
	) : null;
}
```

Render `<ConsentDevTools />` inside `InthProvider` from your [quickstart](/docs/frameworks/react/quickstart), next to `ConsentBanner`.
