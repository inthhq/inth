Embed category switches and Save, Accept All, and Reject All actions directly inside a React privacy or settings page.

## Embed the preference center inline

`ConsentWidget` renders the preference center in page flow without a modal, title, backdrop, or portal. Render it inside `InthProvider` from the [quickstart](../quickstart), and keep `ConsentDialog` mounted so the banner's Customize button and footer links still open the modal:

```tsx title="src/pages/privacy.tsx"
import { ConsentWidget } from '@inth/react';

export function PrivacyPage() {
	return (
		<main>
			<h1>Privacy</h1>
			<p>Choose which optional categories this site may use.</p>
			<section aria-labelledby="cookie-preferences">
				<h2 id="cookie-preferences">Cookie preferences</h2>
				<ConsentWidget />
			</section>
		</main>
	);
}
```

`ConsentWidget` shares the nearest provider's policy, translations, and transport. It needs no second `InthProvider` and never alters the active banner or dialog state on its own.
