Wrap third-party iframes or widgets in `ConsentGate` so they mount only when their consent category is allowed.

## Gate an embed behind consent

Render `ConsentGate` anywhere inside `InthProvider` from the [quickstart](../quickstart), alongside `ConsentDialog` so the placeholder button can open preferences:

```tsx title="src/product-video.tsx"
import { ConsentGate } from '@inth/react';

export function ProductVideo() {
	return (
		<ConsentGate category="marketing" className="video-frame">
			<iframe
				src="https://www.youtube-nocookie.com/embed/dQw4w9WgXcQ"
				title="Product tour"
				loading="lazy"
				allowFullScreen
				style={{ width: '100%', aspectRatio: '16 / 9', border: 0 }}
			/>
		</ConsentGate>
	);
}
```

Ensure `marketing` is in your policy scope. If you set a non-empty `options.consentCategories` array on `InthProvider`, include `marketing` there too so the preference center lists it. `ConsentGate` does not add categories to `options.consentCategories`.

The placeholder uses the translated category title. Set `className` or `style` on `ConsentGate` to reserve the embed's dimensions and prevent layout shift when the embed loads.
