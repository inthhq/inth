Add an unstyled button in your React footer or legal menu so visitors can reopen the preference center after closing the banner.

## Reopen the preference center from your footer

`ConsentDialogLink` requires a mounted `ConsentDialog` inside the same `InthProvider`. The [quickstart](../quickstart) mounts both.

```tsx title="src/site-footer.tsx"
import { ConsentDialogLink } from '@inth/react';

export function SiteFooter() {
	return (
		<footer>
			<nav aria-label="Legal">
				<a href="/privacy">Privacy policy</a>
				<a href="/terms">Terms</a>
				<ConsentDialogLink className="footer-link">
					Privacy settings
				</ConsentDialogLink>
			</nav>
		</footer>
	);
}
```

Render `SiteFooter` inside the `Consent` wrapper from your quickstart. Because `ConsentDialogLink` renders a `<button>`, reset button chrome in `.footer-link` if your footer styles target anchors only.

To wrap your own link element instead, pass `asChild`:

```tsx
<ConsentDialogLink asChild>
	<a href="#cookie-preferences">Manage cookies</a>
</ConsentDialogLink>;
```
