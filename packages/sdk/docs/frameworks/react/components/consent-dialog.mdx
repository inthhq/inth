Mount `ConsentDialog` once inside `InthProvider`, next to `ConsentBanner`. It is the full consent manager: "Your Privacy Choices".

## Open the preference center

`ConsentDialog` opens whenever `dialog` becomes the active surface: from `PrivacyChoicesLink`, `ConsentDialogLink`, `ConsentDialogTrigger`, or your own code.

<include src="../../../shared/examples/react/consent.mdx" />

To open the dialog from a custom button or menu item, call `useSetActiveUI`:

```tsx
import { useSetActiveUI } from '@inth/react';

export function PrivacyMenuItem() {
	const setActiveUI = useSetActiveUI();
	return (
		<button type="button" onClick={() => setActiveUI('dialog')}>
			Cookie preferences
		</button>
	);
}
```

Use [PrivacyChoicesLink](./privacy-choices-link) or [ConsentDialogLink](./consent-dialog-link) for footer links with `data-inth-rights`, or [ConsentDialogTrigger](./consent-dialog-trigger) for a floating corner button. Under an IAB policy, mount `IABConsentDialog` from the [IAB TCF guide](/docs/frameworks/react/iab) because `ConsentDialog` stays closed under the `iab` model.
