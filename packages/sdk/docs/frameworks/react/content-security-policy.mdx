Run Inth in a React app under a strict Content Security Policy by allowing your Inth project origin, vendor hosts, and optional per-request nonces.

## What Inth adds to the page

A React app using Inth adds these elements and requests, each needing a matching CSP directive:

| What | Directive |
| --- | --- |
| `<style>` elements rendered by the banner, dialog, and other built-in components | `style-src` with a nonce |
| `@inth/react/styles.css`, only when imported with `styles: false` | `style-src 'self'` |
| `<style id="inth-theme">`, when rendering `ConsentTheme` | `style-src` with a nonce or hash |
| `<script>` elements created by the script loader for `scripts` entries | `script-src` with each vendor host, or a nonce |
| Inline `<script>` added by `consentManifest()` to `index.html` for early `/v1/consent/init` | `script-src` with a nonce or hash |
| Inline `<script>` rendered before SSR banner buttons to queue pre-hydration taps | `script-src` with a nonce or hash |
| Browser requests to `/v1/consent/init` and `/v1/consent/records` on your Inth project | `connect-src` with your Inth project origin |
| Iframes inside `ConsentGate`, plus frames, images, and requests loaded by vendors | `frame-src`, `img-src`, and `connect-src` per vendor |

In client-rendered React apps, components apply inline styles via React DOM properties, which CSP does not block.

## Allow your Inth project

In `hosted()` mode, the browser calls `GET {url}/v1/consent/init` on each page load and `POST {url}/v1/consent/records` when a visitor saves a choice. In `manifest()` mode, it calls `POST {url}/v1/consent/records`, and `GET {url}/v1/consent/init` only when the policy needs an unknown location. Add your Inth project origin to `connect-src`:

```txt title="Content-Security-Policy (partial)"
connect-src 'self' https://<your-project-host>;
```

When you proxy requests through a same-origin path such as `/api/inth`, `'self'` covers it.

Under an IAB TCF policy, the browser also fetches the Global Vendor List from the URL configured by the policy. Allow that host in `connect-src` when using [IAB TCF](/docs/frameworks/react/iab).

## Allow vendor scripts

Inth inserts a `<script>` element for each `scripts` entry once its category is allowed. Add each vendor's script host to `script-src`, and its API or beacon hosts to `connect-src` and `img-src`. Tag managers that inject additional scripts need those hosts too, or `'strict-dynamic'` with a nonce.

A `scripts` entry with inline `textContent` needs a nonce or hash in `script-src`.

## Use a nonce

A nonce only protects a page when generated fresh per response. On a static host serving identical HTML to everyone, use host allowlists. Use a nonce when a server renders or rewrites `index.html` per request.

Pass the nonce as `options.nonce` on `InthProvider`. Inth stamps it onto every `<script>` the script loader creates and every `<style>` rendered by built-in components. A `nonce` on an individual `scripts` entry overrides `options.nonce` for that script.

In Vite, set `html.cspNonce` to a placeholder in `vite.config.ts` and replace it on every server response. Vite outputs `<meta property="csp-nonce" nonce="...">` and stamps the early `/v1/consent/init` script automatically. Read it in `src/consent.tsx`:

{/* example: fragment */}

```tsx title="src/consent.tsx (partial)"
const nonce =
  document.querySelector<HTMLMetaElement>('meta[property="csp-nonce"]')
    ?.nonce || undefined;

<InthProvider options={{ mode, scripts, nonce }}>
```

If you render `ConsentTheme`, pass the same nonce: `<ConsentTheme theme={theme} nonce={nonce} />`.

`InthProvider` reads `options.nonce` once on mount. Server-rendered React apps such as React Router framework mode read the nonce from the request and pass it the same way.

On a static host, allow the early `/v1/consent/init` script using the hash shown in the browser's `Refused to execute inline script` error. If CSP blocks that early script, the app sends `/v1/consent/init` normally once React mounts.

## Allow Inth's style elements

Built-in components render Inth's rules as `<style>` elements. Under a `style-src` without `'unsafe-inline'`, pick one option:

- Pass `options.nonce` to `InthProvider` as in [Use a nonce](#use-a-nonce). Components then render `<style>` inline with the nonce instead of letting React 19 hoist them into `<head>` without it.
- Set `styles: false` in provider options and import `@inth/react/styles.css` from your bundle, which `style-src 'self'` allows.

## Allow the theme style element

`ConsentTheme` renders theme tokens inside `<style id="inth-theme">`. Without a nonce, a `style-src` lacking `'unsafe-inline'` blocks it and the banner falls back to default tokens. Because its contents depend only on your theme, you can allow it by hash:

1. Load the page with CSP enforced.
2. Copy the `sha256-...` hash from the `Refused to apply inline style` console error.
3. Add that hash to `style-src` and redeploy.

Recompute the hash whenever your theme changes, or define the `--inth-*` tokens directly in your own CSS file as [Customize](/docs/frameworks/react/customize) shows.

## Allow embeds and the dev server

Add every gated iframe host to `frame-src`, such as `https://www.youtube-nocookie.com` for YouTube embeds inside `ConsentGate`.

Vite's dev server injects un-nonced `<style>` tags and the DevTools panel injects its own styles, so always test your CSP against a production build.

## Verify

Build the app, serve it with the policy enforced rather than report-only, and open DevTools under an opt-in policy.

1. Confirm the banner renders with your theme colors and the console shows zero `Refused to` errors for Inth, your project URL, or vendors.
2. Before a choice, confirm DevTools Network shows zero vendor requests.
3. Click **Accept All**. Confirm vendor scripts load with `inth-` IDs. When using nonces, inspect each `<script>` element's `.nonce` property in the console because browsers blank `getAttribute('nonce')`.
4. Confirm the `POST` to `/v1/consent/records` succeeds; a `connect-src` error means your Inth project origin is missing.
5. Reload and confirm the banner stays closed while allowed vendors load cleanly.
