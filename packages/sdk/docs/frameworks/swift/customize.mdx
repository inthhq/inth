Pass a `ConsentTheme` to style Inth's native consent screens in SwiftUI and UIKit while the native presenter handles drafts, saving, and navigation.

## Set your app's theme

Create `AppConsentTheme.swift` in your app target to set your app identity, light and dark colors, spacing, typography, slot overrides, and attribution:

<include src="../../shared/examples/native/core-swift/AppleInstallation/swift-app-theme.mdx" />

Replace `My app` with your app name and add an `AppPrivacyMark` asset to your asset catalog (or pass an existing asset name). Write an introduction that matches the categories in your policy.

Pass the theme to `.inth` from the [Swift quickstart](/docs/frameworks/swift/quickstart):

<include src="../../shared/examples/native/core-swift/AppleInstallation/swift-themed-root.mdx" />

`ConsentRootViewController` accepts the same `theme` argument in UIKit. `colors.primary` styles switches, links, and Save, while Accept all and Reject all always share `colors.decision` and `colors.textOnDecision`.

## Choose what to change

| Setting | Purpose |
| --- | --- |
| `brand.name`, `brand.markImageName` | App name and mark above the headline |
| `brand = .hidden` | Hide the app identity header |
| `copy.headline`, `copy.introduction` | First-layer headline and body text |
| `colors.canvas`, `surface`, `surfaceMuted` | Page, card, and secondary backgrounds |
| `colors.text`, `textMuted` | Primary and supporting text |
| `colors.primary`, `textOnPrimary` | Links, switches, and Save action |
| `colors.decision`, `textOnDecision` | Shared fill and label for Accept all and Reject all |
| `radius.md` | Card and button radius (`radius.sm` and `radius.lg` inherit it until set) |
| `spacing.xs` to `spacing.xl` | Page gutters, section gaps, and padding |
| `typography.fontSize.sm`, `.base`, `.lg` | Supporting, body, and headline sizes (`nil` keeps the system style) |
| `typography.fontFamily` | Bundled font for every text role except the headline |
| `typography.headlineFont` | System sans, serif, rounded, or a bundled headline font |
| `slots` | Overrides for `.consentBannerTitle`, `.consentBannerDescription`, `.buttonPrimary`, or `.buttonSecondary` |
| `branding` | `.inth` (default), `.c15t`, or `.custom(name:markImageName:)` provider attribution |
| `showsBranding` | Toggle provider attribution visibility |
| `firstLayer` | `.page`, `.sheet`, or `.prompt` container for the initial choice |
| `appearance` | `.system` (default) or `.c15t` stock color palette |
| `savePlacement` | `.top` (default) or `.bottom` position for Save in Privacy Settings |

## Place Save Settings

```swift
ConsentTheme.current = ConsentTheme(savePlacement: .bottom)
```

Privacy Settings pins Reject All and Accept All together at the bottom. By default, Save sits in the trailing navigation bar to leave more room for the list. Setting `.bottom` places a full-width Save Settings button below the other two actions. At accessibility text sizes, Save always moves to the bottom.

## Choose a first-layer layout

```swift
ConsentTheme.current = ConsentTheme(firstLayer: .sheet)
```

Every container renders the same copy, partner link, and equal Accept all and Reject all actions:

| Layout | Behavior |
| --- | --- |
| `page` | Full-screen page (default). |
| `sheet` | Floating bottom sheet over a dimmed app background. |
| `prompt` | Centered alert-style card over a dimmed app background. |

Privacy Settings opened from Customize always fills the screen. At accessibility text sizes, every layout switches to `page` so decisions scroll naturally after the text. Under an IAB TCF policy on wide windows such as iPad, `sheet` and `prompt` expand to `page`.

`appearance` picks the base palette. `system` (default) uses platform backgrounds, text colors, and your app's `AccentColor` bundle asset (falling back to system blue), centers the page, and falls back to your app name and icon whenever `brand` fields are unset. Accept all and Reject all darken your accent color until white text reaches 5:1 contrast. `c15t` applies the warm paper and ink palette. `sheet` and `prompt` always use system colors and draw Accept all and Reject all as tinted surfaces rather than `buttonPrimary` fills. Explicit colors you set always win.

Token names match web tokens (`primary` maps to `--inth-primary`, `radius.md` maps to `--inth-radius-md`). `typography.fontSize` scales grouped styles (`sm` for subheadline/footnote/caption, `base` for body/headline, `lg` for large title) while preserving Dynamic Type scaling. `spacing` leaves control padding untouched to protect tap targets. Slot fields (`color`, `backgroundColor`, `borderRadius`, `fontSize`) override one part; `buttonPrimary` falls back to stock decision colors if contrast drops below 5:1.

`ConsentThemeColor` takes sRGB `0xRRGGBB` values for `light` and `dark` (omitting `dark` reuses `light`). Always check contrast in both modes. Hiding app identity with `.hidden` does not hide provider attribution.

## Configure via Info.plist

Without an explicit modifier theme, the presenter reads `ConsentTheme.current` overlaid with `Info.plist` keys. Set `ConsentTheme.current` once at launch before constructing the root view. An explicit modifier theme takes highest priority.

| `Info.plist` key | Value |
| --- | --- |
| `com.inth.consent.brandName` | App name |
| `com.inth.consent.brandMark` | Image asset name |
| `com.inth.consent.primary` | `#RRGGBB` or `#RRGGBB,#RRGGBB` for `light,dark` |
| `com.inth.consent.textOnPrimary` | Label color in the same format |
| `com.inth.consent.radiusMd`, `spaceLg`, `fontSizeBase` | Point value (other steps follow the same pattern) |
| `com.inth.consent.buttonPrimary.borderRadius` | Slot override as `<slot>.<field>` |
| `com.inth.consent.headline` | First-layer headline |
| `com.inth.consent.introduction` | First-layer introduction |
| `com.inth.consent.firstLayer` | `page`, `sheet`, or `prompt` |
| `com.inth.consent.appearance` | `system` or `c15t` |
| `com.inth.consent.savePlacement` | `top` or `bottom` |
| `com.inth.consent.brandingProvider` | `inth` or `c15t` |
| `com.inth.consent.branding` | Native Boolean controlling provider attribution |

Use a native Boolean for `com.inth.consent.branding`, not the string `"false"`. See `ConsentTheme.InfoPlistKey` for the complete list of keys.

## Account for language and screen size

Stock screens pull labels from `@inth/sdk/translations` using the policy's served language (or `overrides.language` in `InthAppleConfiguration`), falling back to English if unavailable. IAB screens follow the served vendor list's language.

`ConsentTheme.Copy` overrides only the first-layer headline and introduction. Leave fields `nil` to keep translated stock copy; any string you pass displays verbatim in every language.

The presenter adapts to Dynamic Type, safe areas, and window geometry, placing compact attribution beside the actions when side-column space permits and falling back inline otherwise. Test light mode, dark mode, largest Dynamic Type sizes, compact and wide windows, and VoiceOver after theme changes. For custom layouts or controls, use [Build your own UI](/docs/frameworks/swift/headless).
