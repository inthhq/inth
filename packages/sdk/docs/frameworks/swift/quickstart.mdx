Add a native consent prompt and Privacy settings entry to a SwiftUI app with one view modifier. Inth loads policy from your project, stores choices in Keychain, and opens native screens when a choice is owed. For UIKit apps, see [UIKit](/docs/frameworks/swift/uikit).

## Before you start

- iOS 16.4+ and Xcode with Swift 5.9+.
- An [Inth project](https://inth.com) with regional policies, `measurement` and `marketing` categories, and its HTTPS project URL (`https://your-project.inth.app`).
- Your app's HTTPS privacy policy URL.
- Private prerelease source access; see [mobile availability](/docs/frameworks/swift/availability).

## Add the Swift package

In Xcode, open **File > Add Package Dependencies > Add Local** and select your Inth checkout root (`inth` package). Link `InthCore` (state and gates), `InthApple` (Keychain, transport, lifecycle), and `InthConsentUI` (stock SwiftUI screens) to your app target. Keep simulator signing enabled so Keychain checks succeed.

## Add the consent prompt

Replace your SwiftUI `App` entry point (or add `.inth` to your root view) and update both URLs:

<include src="../../shared/examples/native/core-swift/AppleInstallation/swift-quickstart-app.mdx" />

The modifier installs one shared engine, hydrates saved choices synchronously, and presents an owed prompt once policy resolves. Locked Keychain launches keep optional SDKs off and retry on unlock.

Pass your Inth project URL to `backendURL` (other hosts throw `invalidBackendURL`). Set `configuration.dryRun = true` inside `#if DEBUG` to drop outgoing records in development and CI (release builds throw `dryRunInReleaseBuild`):

{/* example: fragment */}

```swift
var configuration = InthAppleConfiguration(
    backendURL: "https://your-project.inth.app",
    consentCategories: [.necessary, .measurement, .marketing]
)
#if DEBUG
configuration.dryRun = true
#endif
```

Pass `autoPresent: false` to call `ConsentPrompt.current?.presentPrompt()` yourself. With `NSUserTrackingUsageDescription` in `Info.plist`, the modifier requests ATT after consent closes if marketing was granted.

## Gate optional SDKs

Disable vendor auto-start, install Inth in `App.init` with `try? InthApple.install(configuration)`, and start optional SDKs only when `decision(for: .measurement)` is `.granted`. Retain a gate subscription from [Build your own UI](/docs/frameworks/swift/headless) so withdrawals stop collection.

## Check it works

Run under an opt-in policy:

1. Fresh launch: prompt opens; measurement stays off.
2. Tap **Reject all** and relaunch: prompt stays closed; measurement stays off.
3. Open **Privacy settings**, enable measurement, and save: settings show it enabled.
4. Disable measurement, save, and relaunch: it stays off.

Local saves queue backend delivery; complete [Verify mobile consent](/docs/frameworks/swift/verify) before release.
