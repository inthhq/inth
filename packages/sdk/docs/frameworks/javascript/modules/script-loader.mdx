Reference for the script loader module that inserts vendor `<script>` tags
when consent allows them and removes them on withdrawal.

## What the script loader does

`@inth/sdk` and `createConsentRuntime` create a script loader automatically
from their `scripts` option. Call `createScriptLoader` directly only when
managing a manual kernel. See [scripts](/docs/frameworks/javascript/scripts)
and [integrations](/docs/integrations/overview).

## Script fields

| Field | Type | Default | What it does |
| --- | --- | --- | --- |
| `id` | `string` | required | Unique, stable identifier. |
| `category` | category or condition | required | Required category or condition such as `{ and: ['measurement', 'marketing'] }`. |
| `src` | `string` | none | External script URL. |
| `resourceKey` | `string` | `id` | Shared DOM element identity across registrations while keeping independent callbacks. |
| `textContent` | `string` | none | Inline JavaScript code. |
| `callbackOnly` | `boolean` or `() => boolean` | `false` | Skips DOM insertion and runs callbacks only (keep predicates side-effect-free and server-safe). |
| `alwaysLoad` | `boolean` | `false` | Loads immediately regardless of consent (for tags managing consent internally). |
| `observeConsentBeforeLoad` | `boolean` | `false` | Fires `onConsentChange` during initial denial and before load. |
| `persistAfterConsentRevoked` | `boolean` or `'loaded'` | `false` | `true` keeps the tag on withdrawal; `'loaded'` keeps only completed loads. |
| `persistAfterDispose` | `boolean` | `false` | Retains an inserted element after removal or disposal while releasing callbacks. |
| `target` | `'head' \| 'body'` | `'head'` | Insertion target. |
| `async`, `defer` | `boolean` | none | Script loading attributes. |
| `nonce` | `string` | runtime `nonce` | CSP nonce for this element. |
| `fetchPriority` | `'high' \| 'low' \| 'auto'` | none | Fetch priority hint. |
| `attributes` | `Record<string, string>` | none | Extra attributes on the `<script>` element. |
| `anonymizeId` | `boolean` | `true` | Assigns a random `id` attribute. |
| `vendor` | `string` | none | Vendor slug for non-IAB vendor consent. |
| `vendorId`, `iabPurposes`, `iabLegIntPurposes`, `iabSpecialFeatures` | IAB IDs | none | Evaluated against the TC String under IAB policies. |

## Lifecycle callbacks

Each callback receives `{ id, elementId, hasConsent, consents, element?, error?, vendor? }`:

| Callback | When it runs |
| --- | --- |
| `onBeforeLoad` | Before each load attempt (must be idempotent). |
| `onLoad` | After the script finishes loading. |
| `onError` | When loading fails. |
| `onConsentChange` | On consent updates after load (or before load when `observeConsentBeforeLoad` is `true`). |
| `onDispose` | When removed from config or when the loader disposes. |

Consent withdrawal does not call `onDispose`. With
`reloadOnConsentRevoked: false`, use `onConsentChange` to call the vendor's
opt-out API.

Shared elements (via `resourceKey`) deliver `onLoad`/`onError` to every
active registration and remove the DOM element only when the last owning
loader releases it (unless `persistAfterDispose` is set).

## Update the list

`loader.updateScripts(next)` reconciles the active script list immediately:

- Unchanged DOM scripts (same `id`, source/code, attributes and `onDispose`
  reference) keep their element without reloading.
- Changing source, inline code, attributes or `onDispose` disposes the prior
  registration and reloads.
- Callback-only scripts with `onDispose` are tracked by object identity.
- Removed scripts release their elements (unless shared or
  `persistAfterDispose`).

Re-entrant updates settle after the current pass and halt after 100 passes.
Call `loader.getLoadedScriptIds()` to inspect loaded script IDs.

## Check it works

1. Filter DevTools Network for the vendor host: nothing loads before consent.
2. Allow the category: the script loads in `<head>` with a randomized `id`
   and `onLoad` fires.
3. With `reloadOnConsentRevoked: false`, withdraw the category:
   `onConsentChange` fires with `hasConsent: false` and the element removes.
