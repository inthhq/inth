Install `window.__gpp` (GPP 1.1 CMP API) in a JavaScript app with `mountGPP()`
so ad tech such as Prebid.js and Google Ad Manager can read US privacy
opt-outs and the TCF EU string.

## Turn on GPP

Pass the client returned by `init()` to `mountGPP()`:

<include src="../../shared/examples/javascript/gpp.mdx" />

Apps that do not import `@inth/sdk/gpp` bundle zero GPP code. Pass optional
GPP settings as the second argument (for example,
`mountGPP(consent, { usFallback: 'none' })`). Call `gpp.dispose()` before
`consent.dispose()` when tearing down.

With `testing()` mode, supply a US location via `overrides`, such as
`overrides: { country: 'US', region: 'CA' }`. To include the TCF EU section
under an `iab` policy, also enable [IAB TCF](/docs/frameworks/javascript/iab).

## Use GPP with your own runtime

Configure `gpp` and `loadGPP` on `createConsentRuntime()`:

{/* example: fragment */}

```ts title="src/consent-runtime.ts"
import { hosted } from '@inth/sdk/engine';
import { createConsentRuntime } from '@inth/sdk/runtime';

const runtime = createConsentRuntime({
	gpp: true,
	loadGPP: () => import('@inth/sdk/iab/gpp'),
	projectUrl: 'https://your-project.inth.app',
});
runtime.start();
```

On a manual kernel, call `createGPP({ kernel })` from `@inth/sdk/iab/gpp`.
Both `mountGPP()` and `createGPP()` throw if another CMP already owns `__gpp`.
