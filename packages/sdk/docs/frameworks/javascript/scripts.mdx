Register vendor scripts so they load only after consent allows their category,
dispatch analytics events safely, and control revocation behavior.

## Register scripts where you start Inth

Pass `scripts` to whichever API starts Inth, using `@inth/integrations`
helpers or custom script objects:

| Setup | Where `scripts` goes |
| --- | --- |
| `@inth/sdk` | `init({ scripts, ... })`, as in the [quickstart](/docs/frameworks/javascript/quickstart#start-inth). |
| `@inth/sdk/runtime` | `createConsentRuntime({ mode, scripts })`, as in [headless](/docs/frameworks/javascript/headless#create-the-runtime). |
| Your own kernel | `createScriptLoader({ kernel, scripts })`. See [script loader](/docs/frameworks/javascript/modules/script-loader#attach-the-loader-to-your-own-kernel). |

Each [integration guide](/docs/integrations/overview) lists the helper for
one vendor. For a vendor without a helper, define a script object directly:

{/* example: fragment */}

```ts
const scripts = [
	{
		id: 'analytics',
		src: 'https://analytics.example/sdk.js',
		category: 'measurement',
		onLoad: () => window.analytics?.track('page_view'),
	},
];
```

See [script loader](/docs/frameworks/javascript/modules/script-loader) for
every field and lifecycle callback.

## When the script loader downloads

In npm builds of `@inth/sdk`, the script loader and network blocker share a
lazy chunk that loads only when `scripts` is non-empty or `networkBlocker`
has rules. To start that fetch earlier, add a `<link rel="modulepreload" fetchpriority="low">`
for the emitted chunk matching `@inth/sdk/lib/core/dist/modules/loader-and-blocker.js`
(listed in Vite's `.vite/manifest.json` when `build.manifest` is enabled).
The script-tag build (`inth.js`) bundles the loader directly.

## Gate a snippet in your HTML

`@inth/sdk` also executes `<script type="text/plain" data-inth-category>`
tags in `index.html` in document order once allowed. With
`createConsentRuntime` or a manual kernel, call
`activateGatedScripts(snapshot)` from `@inth/sdk` yourself.

When `nonce` is set, `@inth/sdk` activates only gated tags carrying the same
`nonce`, marking others `data-inth-activated="untrusted"`. Pass `{ nonce }` as
the third argument to `activateGatedScripts`; see
[Content Security Policy](/docs/frameworks/javascript/content-security-policy).

## When a visitor withdraws permission

Because already-executed scripts cannot be unloaded, `@inth/sdk` and
`createConsentRuntime` reload the page after a visitor withdraws a previously
allowed category, whether through preferences or a one-click opt-out. The
reload waits up to one second for in-flight consent, opt-out and lift
requests; requests use `keepalive` and replay from the stored queue on the
next page if they have not settled in time. Privacy signals and backend-synced
opt-outs do not reload. Allowing a category never reloads.

Set `reloadOnConsentRevoked: false` to handle withdrawal yourself (for
example via a vendor's opt-out API in `onConsentChange`). Use
`callbacks.onBeforeConsentRevocationReload` for synchronous cleanup right
before reload. On a manual kernel, add `watchRevocationReload` from
`@inth/sdk/engine` if you want automatic reloads.

## Keep one owner per vendor

Use stable script IDs and remove duplicate `<script>` tags or direct SDK
imports. Ordinary scripts wait for permission; helpers using `alwaysLoad`
load immediately and forward consent signals to the vendor's API. Initialize
`init()` or your runtime once per page so vendors never load twice.

## Let visitors turn off one vendor

To allow visitors to turn off individual vendors inside an allowed category,
declare `vendors` on `init()` or `createConsentRuntime`; see
[vendor consent](/docs/frameworks/javascript/vendor-consent).

## Clear stored tracking data

Gating stops future requests without removing cookies or storage already
written. Configure
[clear on revocation](/docs/frameworks/javascript/clear-on-revocation) to
delete them when a category is denied.

## Check it works

Open the app in a private window with DevTools Network open:

1. Filter for each vendor host. Nothing loads before a choice.
2. Allow one category. Only that category's vendors load.
3. Withdraw it. The page reloads and the vendor stays absent.
