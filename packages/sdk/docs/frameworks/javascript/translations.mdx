Control the language and wording of Inth's consent banner and preference
dialog in a bundled JavaScript app.

## Where the copy comes from

`@inth/sdk` bundles English only. Other languages load based on your
transport:

| Transport | Where the copy comes from |
| --- | --- |
| Hosted | Your Inth project picks the language from `Accept-Language` or your `language` override and returns its copy with the policy. |
| Manifest | The manifest's translations for the visitor's language. |
| Testing | English, plus `locale` and `messages` passed in `i18n`. |

In every mode, `i18n.messages` overrides matching keys for the active
language. Direct `ui.banner` text fields (`title`, `acceptButtonText`, etc.)
override translations in every language.

With `hosted()` or `manifest()`, your `i18n.messages` for the visitor's
language override the project's or manifest's copy key by key (exact locale
first, then primary language such as `de` for `de-AT`). A key overrides Inth
only when your text differs from the built-in wording for that language, so
dashboard edits remain visible for unchanged keys. For non-English languages,
import `@inth/sdk/translations/all` so Inth recognizes its stock wording.

`testing()` is used in the snippet above for brevity; it is for tests only
and throws in production builds.

## Switch language at runtime

Call `consent.setLanguage('fr')` on `@inth/sdk` to update the language
override, re-resolve the policy and re-render the UI. On a runtime or kernel,
call `kernel.set.language('fr')` followed by `kernel.commands.init()`.

To match your app's active locale on first render, pass
`overrides: { language: 'fr' }`. With `testing()`, `setLanguage()` switches
between languages supplied in `i18n.messages`.

## Use Inth's bundled translations

`@inth/sdk/translations/all` exports `baseTranslations` covering more than 30
languages:

{/* example: fragment */}

```ts
import { baseTranslations } from '@inth/sdk/translations/all';

init({ i18n: { locale: 'de', messages: { de: baseTranslations.de } } });
```

Because `baseTranslations` bundles all languages, import individual language
subpaths such as `@inth/sdk/translations/de` when you only need a few.

## Message keys the stock UI reads

| Key | Where it shows |
| --- | --- |
| `cookieBanner.title`, `cookieBanner.description` | Choice banner heading and body. |
| `cookieBanner.noticeTitle`, `cookieBanner.noticeDescription` | Notice banner heading and body. |
| `common.acceptAll`, `common.rejectAll`, `common.customize` | Banner and dialog buttons. |
| `common.acknowledge` | Notice dismiss button. |
| `common.save` | Dialog save button. |
| `common.securedBy` | "Secured by" tag. |
| `consentManagerDialog.title`, `consentManagerDialog.description` | Dialog heading and body. |
| `consentTypes.<category>.title`, `consentTypes.<category>.description` | Category row title and description. |
| `legalLinks.privacyPolicy`, `legalLinks.cookiePolicy`, `legalLinks.termsOfService` | Legal link labels. |
| `rights.optOut`, `rights.privacyChoices`, `rights.californiaPrivacyChoices`, `rights.preferences` | Rights button added under opt-out policies and the "Manage preferences" link in the opt-out confirmation view. `rights.privacyChoices` and `rights.californiaPrivacyChoices` always render with the California Privacy Protection Agency opt-out icon. |
| `optOut.statusRequest`, `optOut.statusSignal`, `optOut.receiptBrowser`, `optOut.receiptAccount`, `optOut.receiptBrowserWithRights`, `optOut.receiptAccountWithRights`, `optOut.rightsSaleAndShare`, `optOut.rightsSaleAndTargetedAds`, `optOut.rightsAll`, `optOut.recordedLabel`, `optOut.referenceLabel`, `optOut.description`, `optOut.done`, `optOut.lockedByGpc`, `optOut.lockedByAccount` | Opt-out confirmation receipt, honored status line in preferences, and GPC and account lock notices below restricted categories. |

Headless UIs read the same object from `snapshot.translations`.

## Right-to-left languages

Right-to-left languages such as Hebrew or Arabic automatically set `dir="rtl"`
on the stock banner and dialog while keeping the configured corner. See
[copy and translations](/docs/customization/translations).

## Check it works

1. Set your browser language to German and open the app in a private window;
   confirm German copy loads.
2. Call `consent.setLanguage('fr')` and verify the banner switches to French.
3. Open the preference dialog and verify headings, categories and buttons
   match.
