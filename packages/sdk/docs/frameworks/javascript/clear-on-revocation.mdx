## Configure cleanup

Gating stops new requests without deleting cookies and storage keys a vendor
already wrote. Pass `clearOnRevocation` to `init()` or
`createConsentRuntime()` so Inth deletes them whenever a category is denied:

{/* example: fragment */}

```ts title="src/main.ts (partial)"
init({
	mode: manifest(),
	scripts,
	clearOnRevocation: {
		measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
		marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
	},
});
```

Both `init()` and `createConsentRuntime()` read `clearOnRevocation` once at
creation time.

## Attach cleanup to your own kernel

When assembling modules manually, attach cleanup in the browser after
persistence and the script loader:

<include src="../../shared/examples/javascript/clear-on-revocation.mdx" />

`createClearOnRevocation({ kernel, config, storageConfig? })` returns
`{ dispose }`. Pass the same `storageConfig` used by persistence so custom
`storageKey` records stay protected. Do not attach it separately if `init()`
or `createConsentRuntime()` already sets `clearOnRevocation`.
