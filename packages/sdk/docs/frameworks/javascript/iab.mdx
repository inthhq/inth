Enable IAB TCF 2.4 in a JavaScript app using `@inth/sdk/iab-client` for the
stock IAB UI or `createIAB` from `@inth/sdk/iab` for a headless runtime or
kernel.

## Use the IAB build of @inth/sdk

Import `init` from `@inth/sdk/iab-client` instead of `@inth/sdk` to include
the CMP, TC String encoder, IAB banner and purpose/vendor dialog. The plain
entry excludes IAB code and throws `IABUnavailableError`
(`INTH_IAB_UNAVAILABLE`) when a policy resolves the `iab` model (as does
`@inth/sdk/iab-client` with `iab: false`):

```ts title="src/main.ts"
import { init, manifest } from '@inth/sdk/iab-client';

const consent = init({
	mode: manifest(),
	iab: { cmpId: YOUR_CMP_ID, vendors: [1, 2, 755] },
});

await consent.ready();
const cmp = consent.runtime.iab;
if (cmp) {
	await cmp.whenReady?.();
	cmp.setPurposeConsent(1, true);
	cmp.setVendorConsent(755, true);
	const result = await consent.saveIAB();
	if (!result.ok) consent.openDialog();
}
```

Replace `YOUR_CMP_ID` with your registered IAB Europe CMP ID. `acceptAll()`
and `rejectAll()` confirm through the CMP under an IAB policy, while
category-only `save({ ... })` fails; use `saveIAB()`. Outside IAB regions,
`@inth/sdk/iab-client` renders the standard banner. With `shadow: false`,
import both `@inth/sdk/styles.css` and `@inth/sdk/iab/styles.css`.

## Attach the module to your kernel

Import `createIAB` from `@inth/sdk/iab` to attach the CMP directly to an
existing kernel:

```ts
import { createIAB } from '@inth/sdk/iab';

function attachIAB(
	kernel: Parameters<typeof createIAB>[0]['kernel'],
	cmpId: number
) {
	return createIAB({ kernel, cmpId });
}
```

Register your own CMP ID with IAB Europe
([register.consensu.org/CMP](https://register.consensu.org/CMP)); `createIAB`
throws unless `cmpId` is an integer between 2 and 4095, and never ship a demo
ID in production. The module installs `window.__tcfapi`, manages vendor data
and encodes TC Strings without rendering UI.

To expose the TC String alongside US state opt-outs through `__gpp`, add
[IAB GPP](/docs/frameworks/javascript/gpp).

## Restrict how vendors use a purpose

Pass publisher restrictions in `publisherRestrictions` to override a vendor's
declared legal basis for a purpose:

{/* example: fragment */}

```ts
import { createIAB } from '@inth/sdk/iab';

function attachIAB(
	kernel: Parameters<typeof createIAB>[0]['kernel'],
	cmpId: number
) {
	return createIAB({
		kernel,
		cmpId,
		publisherRestrictions: [
			// Vendors 10 and 755 may not use purpose 4.
			{ purposeId: 4, restrictionType: 0, vendorIds: [10, 755] },
			// Vendor 755 must use legitimate interest for purpose 7.
			{ purposeId: 7, restrictionType: 2, vendorIds: [755] },
		],
	});
}
```

## Own the lifecycle

Dispose the IAB handle before disposing its kernel. On a shared runtime, pass
IAB configuration through `createConsentRuntime` instead of creating separate
IAB modules per UI root, and await lazy readiness before calling CMP actions.

Test the encoded TC String, `__tcfapi` responses and actual vendor network
requests before deploying.

## Server-rendered vendor data

SSR integrations serialize a compact `gvlReference` (`url`, `language`,
`vendorListVersion`) and banner summary instead of embedding the full Global
Vendor List in HTML. Configure vendor allowlists on the server so the initial
banner renders without waiting for a client GVL fetch; adding a client-only
`vendors` allowlist makes the banner wait for the full GVL.

The IAB module fetches the full GVL on mount in the browser. Early Accept and
Reject clicks wait for the list before encoding a TC String; failed fetches
keep the banner visible and retry on the next action. Version mismatches
require a fresh init response or reload.

SSR manifest init handlers serve versioned public GVL responses with
`public, max-age=86400` (returning `409` if the version is no longer
available). Same-origin routes (such as `/api/inth`) need `'self'` in CSP
`connect-src`; direct manifest or hosted GVL references need their origin in
`connect-src`. An explicit inline `gvl` option takes precedence (including
`gvl: null` to disable IAB).
