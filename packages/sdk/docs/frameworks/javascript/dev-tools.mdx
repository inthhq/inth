Inspect consent state, gated scripts, resolved policies, IAB state and events
in a JavaScript app during development using `@inth/sdk/devtools`.

## Mount the panel with @inth/sdk

Mount DevTools against the client returned by `init()` behind your bundler's
development flag:

<include src="../../shared/examples/javascript/devtools.mdx" />

`defaultTab` sets the initial tab: `consents`, `scripts`, `location`,
`policy`, `iab`, `events` or `actions`. Use the Location tab to override
country, region, language or GPC and test regional policies without a VPN.

## Open DevTools from the trigger

When `ui.trigger` is enabled, the floating trigger adds a DevTools button
alongside its own and hides the separate launcher until the banner or dialog
hides the trigger. Calling `destroy()` restores the single button. An
embedded panel (`embedded: true`) leaves the trigger unchanged.

## Mount the panel with a runtime or kernel

For [`createConsentRuntime`](/docs/frameworks/javascript/headless) or a
manual kernel, mount DevTools with `createDevTools` from `@inth/sdk/devtools`:

<include src="../../shared/examples/javascript/runtime-devtools.mdx" />

Pass `getConsentCategories` if your custom UI displays a subset of categories
different from the policy scope. Call `tools.destroy()` on teardown (it does
not dispose the kernel). Pass `container` and `embedded: true` to host the
panel inside another devtools UI or same-origin iframe.

## Keep it out of production

Guard the dynamic import with `import.meta.env.DEV` (Vite) or
`process.env.NODE_ENV !== 'production'` (Webpack/other bundlers) so the panel
is stripped from production bundles. Never ship DevTools to visitors.

## Inspect scripts and IAB

The Scripts tab lists loaders registered on the kernel (`blocked`, `loading`,
`loaded`, `failed`, `retained`). The DOM page scan lists elements only; check
DevTools Network to verify requests.

The IAB tab reads the existing IAB module on the kernel without mounting a
second CMP. Editing switches updates live choices, and saving encodes a new
TC String through the configured transport.
