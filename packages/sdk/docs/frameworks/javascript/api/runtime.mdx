Reference for `createConsentRuntime`, the framework-agnostic runtime behind
every Inth adapter.

## What the runtime owns

`createConsentRuntime` creates a
[consent kernel](/docs/frameworks/javascript/api/kernel) and wires
persistence, script loading, iframe blocking, revocation reload, callbacks
and optional network blocking, clear-on-revocation and IAB. It renders no UI.
See [choose a headless API](/docs/frameworks/javascript/headless#choose-a-headless-api).

<include src="../../../shared/examples/javascript/runtime.mdx" />

Construction has no side effects and reads no storage until `start()` runs,
so the module is safe to import on the server.

## Options

| Option | Type | Default | What it does |
| --- | --- | --- | --- |
| `projectUrl` | `string` | required | Your Inth project URL. Not needed with `mode: testing()` or `enabled: false`. |
| `mode` | `hosted()`, `manifest()` or `testing()` | `hosted()` | Policy source (`testing()` comes from `@inth/sdk/testing` and throws in production). See [transports](/docs/frameworks/javascript/transports). |
| `scripts` | `Script[]` | none | Consent-gated vendor scripts; see [script loader](/docs/frameworks/javascript/modules/script-loader). |
| `consentCategories` | category names | inferred | Categories offered alongside discovered ones within policy scope. |
| `networkBlocker` | `{ rules, enabled?, logBlockedRequests?, onRequestBlocked? }` or `false` | off | Holds matching `fetch` and XHR calls until allowed; see [network blocker](/docs/frameworks/javascript/modules/network-blocker). |
| `iframeBlocker` | `{ disableAutomaticBlocking? }` or `false` | on | Gates `<iframe data-src data-category>`; see [iframe blocker](/docs/frameworks/javascript/modules/iframe-blocker). |
| `clearOnRevocation` | cookies and storage keys per category | off | Deletes named browser data when denied (read once); see [clear on revocation](/docs/frameworks/javascript/clear-on-revocation). |
| `persistence` | `boolean` or `{ storageConfig?, skipHydration?, sync? }` | `true` | Persists choices in cookie and `localStorage` with cross-tab sync (`false` keeps in memory only); see [persistence](/docs/frameworks/javascript/modules/persistence). |
| `storageConfig` | `{ storageKey?, crossSubdomain?, defaultDomain?, defaultExpiryDays? }` | key `inth`, 365 days | Cookie and `localStorage` naming and lifetime. |
| `reloadOnConsentRevoked` | `boolean` | `true` | Reloads the page after an accept, reject, save or one-click opt-out turns off a granted category or vendor, once the request finishes. Privacy signals and backend-synced opt-outs do not reload. |
| `callbacks` | `{ onChoiceRecorded?, onPermissionsChanged?, onError?, onBeforeConsentRevocationReload? }` | none | Lifecycle hooks; see [callbacks](/docs/frameworks/javascript/callbacks). |
| `overrides` | `{ country?, region?, language?, gpc? }` | none | Explicit policy inputs. |
| `prefetch` | kernel config | none | Server-resolved init answer (`start()` skips `/v1/consent/init` unless `initialPolicyPending` is set). |
| `i18n` | `{ locale?, messages }` | English | Initial locale and key-by-key copy overrides; see [translations](/docs/frameworks/javascript/translations). |
| `presentation` | `{ prompt?, preferences? }` | none | Layout and blocking hints for `resolveConsentPresentation`. |
| `journey` | `'page'`, `'tab'` or `false` | `'page'` | Links `/v1/consent/init` to subsequent saves; see [session reports](/docs/concepts/data-fetching#link-an-init-to-the-save-that-follows). |
| `user` | `{ externalId, identityProvider? }` | none | Identified visitor metadata. |
| `vendors` | `Vendor[]` | none | Declared vendors for non-IAB vendor consent. |
| `nonce` | `string` | none | CSP nonce stamped on inserted `<script>` tags (script-level `nonce` overrides). |
| `scriptLoader` | `{ onDebug? }` | none | `onDebug` receives script loader lifecycle events (read at start). |
| `iab` | IAB options or `false` | none | CMP settings (requires `createIAB`). |
| `createIAB` | `createIAB` from `@inth/sdk/iab` | none | IAB module factory. |
| `consentSource` | `{ getPermissions, subscribe, openPreferences }` | none | Delegates authority to an external CMP or `webViewConsentSource()`; see Consent in WebViews in the Swift, Android, or React Native docs. Read once. |
| `enabled` | `boolean` | `true` | `false` grants all categories, skips init and loads all scripts immediately. |
| `windowDebug` | `boolean` | `true` | Exposes `window.inth` debug info (`version`, `pkg`, `mode`) on `start()`. |
| `pkg` | `string` | `'@inth/sdk/engine'` | Package name reported on `window.inth`. |

## What start and dispose do

`runtime.start()` mounts in order:

1. `window.inth` debug object (unless `windowDebug: false`);
2. persistence (restores stored choices);
3. policy resolution (adopts resolved `prefetch` or sends `/v1/consent/init`);
4. script loader (when `scripts` is non-empty);
5. network blocker (when configured);
6. iframe blocker (unless `iframeBlocker: false`);
7. IAB module (when `iab` and `createIAB` are set);
8. clear-on-revocation (when configured).

`start()` is a no-op without `document` and idempotent after the first call.
In client-only apps, call `start()` before rendering; in SSR apps, call it
after hydration so initial HTML matches. Network blocker and
clear-on-revocation lazy-load only when configured, with matching network
requests held from construction until resolved.

`runtime.dispose()` tears down modules in reverse order and disposes the
kernel (disposing before `start()` blocks any held requests).

## Runtime handle

| Member | What it does |
| --- | --- |
| `kernel` | Underlying consent kernel. |
| `start()`, `dispose()` | Mount and unmount browser side effects. |
| `started` | `true` after `start()` until `dispose()`. |
| `identify(user)` | Links consent record to a user (errors route to `onError`). |
| `setOverrides(overrides)` | Merges location, language and GPC overrides (`undefined` clears a key). |
| `reinit()` | Re-runs `/v1/consent/init` (no-op while disabled). |
| `setLanguage(code)` | Switches language and re-runs `/v1/consent/init` if changed. |
| `processIframes()` | Applies consent to gated iframes when `disableAutomaticBlocking: true`. |
| `reconcileStorage()` | Re-reads storage for cross-tab or external cookie changes; returns whether state changed. |
| `clearRecords()` | Deletes stored choices and resets records, keeping `subjectId` and dropping queued saves. |
| `consentCategories` | `necessary` plus active scope categories in canonical order. |
| `setConsentCategories(categories)` | Replaces configured categories (`undefined` clears). |
| `experiment` | Active experiment config from `prefetch` or `experiment` option. |
| `iab` | Active CMP handle under IAB, or `null`. |
| `subscribe(listener)` | Fires when `iab` (or `kernel`/`enabled` on provider runtimes) changes; returns unsubscribe. |

## Runtime for a framework provider

Framework providers whose props can change use
`createConsentProviderRuntime(options, modules)` from
`@inth/sdk/runtime/provider`, adding:

| Member | What it does |
| --- | --- |
| `update(options)` | Diffs full option sets and applies only changed fields; returns a promise settling once applied. |
| `setEnabled(enabled)` | Toggles between the real kernel and a permissive no-UI kernel. |
| `enabled` | Current enabled state. |
| `kernel` | Active kernel (swaps when `enabled` toggles). |

`update()` applies changes to `enabled`, `user`, `overrides`,
`consentCategories`, `vendors`, `scripts`, `networkBlocker`, `iframeBlocker`,
`callbacks` and `reloadOnConsentRevoked`. Static startup options (`mode`,
`i18n`, `experiment`, `persistence`, `storageConfig`, `nonce`) are read once
and log a dev warning if changed.

To support streamed server promises for `prefetch`, include `streamPrefetch`
(from `@inth/sdk/runtime`) or `lazyStreamPrefetch` (from
`@inth/sdk/runtime/provider`) in `modules`.

Use `onDemandRuntimeModules` from `@inth/sdk/runtime/on-demand` to lazy-load
script loader, network blocker, clear-on-revocation and consent source
modules in separate chunks:

{/* example: fragment */}

```ts
import { watchRevocationReload } from '@inth/sdk/engine';
import { createIframeBlocker } from '@inth/sdk/modules/iframe-blocker';
import { createPersistence } from '@inth/sdk/modules/persistence';
import { createWindowDebug } from '@inth/sdk/modules/window-debug';
import { onDemandRuntimeModules } from '@inth/sdk/runtime/on-demand';
import { createConsentProviderRuntime } from '@inth/sdk/runtime/provider';

const runtime = createConsentProviderRuntime(options, {
	...onDemandRuntimeModules,
	createIframeBlocker,
	createPersistence,
	createWindowDebug,
	watchRevocationReload,
});
```

When mixing static and on-demand modules (such as static script loader with
on-demand network blocker), import individual factories from
`@inth/sdk/runtime/on-demand-factories` (`scriptLoaderOnDemand`,
`networkBlockerOnDemand`, `clearOnRevocationOnDemand`,
`connectConsentSourceOnDemand`) with `createConsentRuntimeWith`:

{/* example: fragment */}

```ts
import { watchRevocationReload } from '@inth/sdk/engine';
import { createIframeBlocker } from '@inth/sdk/modules/iframe-blocker';
import { createPersistence } from '@inth/sdk/modules/persistence';
import { createScriptLoader } from '@inth/sdk/modules/script-loader';
import { createWindowDebug } from '@inth/sdk/modules/window-debug';
import { createConsentRuntimeWith } from '@inth/sdk/runtime/on-demand';
import {
	clearOnRevocationOnDemand,
	connectConsentSourceOnDemand,
	networkBlockerOnDemand,
} from '@inth/sdk/runtime/on-demand-factories';

const runtime = createConsentRuntimeWith(options, {
	connectConsentSource: connectConsentSourceOnDemand,
	createClearOnRevocation: clearOnRevocationOnDemand,
	createIframeBlocker,
	createNetworkBlocker: networkBlockerOnDemand,
	createPersistence,
	createScriptLoader,
	createWindowDebug,
	watchRevocationReload,
});
runtime.start();
```

## Other exports

| Export from `@inth/sdk/runtime` | What it does |
| --- | --- |
| `createLazyIABFactory(loader)` | Wraps `() => import('@inth/sdk/iab')` for lazy IAB loading. |
| `isIABConfigured(iab)` | Checks whether `iab` config enables IAB. |
| `wireRuntimeCallbacks({ kernel, callbacks })` | Attaches callbacks to a manual kernel; returns disposer. |
| `createConsentProviderRuntime(options, modules)` | Provider runtime with `update()` and `setEnabled()`. |
| `defaultRuntimeModules` | Default module bundle used by `createConsentRuntime`. |
| `lazyRuntimeModule(load)` | Wraps a module factory in a dynamic `import()` on first use. |
| `streamPrefetch` | Enables promise `prefetch` handling on provider runtimes. |
| `mountRuntimeIAB` | Mounts the IAB CMP once the kernel receives `cmpId`. |

## Check it works

1. Subscribe to `runtime.kernel` before calling `runtime.start()`.
2. Call `start()` in the browser; confirm `/v1/consent/init` resolves and
   `resolution.status` becomes `'matched'`.
3. Call `runtime.kernel.commands.save('none')` from a button; verify
   `POST /v1/consent/records` fires and persists across reload.
4. Call `runtime.dispose()` and verify inserted script tags are removed.
