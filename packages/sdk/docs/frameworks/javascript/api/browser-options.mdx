Reference for all options passed to `init()` and `createConsentClient()` in
`@inth/sdk`, `@inth/sdk/headless` and `@inth/sdk/iab-client`.

## Pass options to init

<include src="../../../shared/examples/javascript/init.mdx" />

`projectUrl` is required unless `mode` is `testing()` or `enabled` is
`false`. `mode` is optional (`manifest()` or `hosted()` from the same entry,
or `testing()` from `@inth/sdk/testing`). Options are read once at creation;
call `mountUI()` to update UI options, or dispose and recreate the client to
change anything else.

`@inth/sdk/hosted` accepts the same UI, gating and lifecycle options while
restricting connection options to hosted mode; see
[choose a bundle for one mode](/docs/frameworks/javascript/api/browser#choose-a-bundle-for-one-mode).

## Options the client passes to the runtime

`@inth/sdk` constructs a
[consent runtime](/docs/frameworks/javascript/api/runtime) internally and
forwards every option above (including `nonce`, `persistence`, `scriptLoader`
and `vendors`). `@inth/sdk/iab-client` supplies `createIAB`, and the client
disables `windowDebug` on the runtime so `window.inth` is not overwritten.
