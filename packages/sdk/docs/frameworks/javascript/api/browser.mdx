Reference for the `@inth/sdk` browser client in bundled JavaScript apps.

## Entry points

| Import | What it gives you |
| --- | --- |
| `@inth/sdk` | `init`, `createConsentClient`, `mountConsentUI`, stock banner, dialog and trigger (`projectUrl` required; optional `mode`: `manifest()` or `hosted()`). |
| `@inth/sdk/hosted` | Stock UI and client for hosted mode only (excludes manifest transport code). |
| `@inth/sdk/testing` | `testing()` mode for tests (throws in production builds). |
| `@inth/sdk/headless` | Browser client with no stock UI or CSS (`mountUI()` throws). |
| `@inth/sdk/iab-client` | Client with IAB TCF CMP, IAB banner and dialog; see [IAB TCF](/docs/frameworks/javascript/iab). |
| `@inth/sdk/devtools` | `mountDevTools(client, options)`; see [DevTools](/docs/frameworks/javascript/dev-tools). |
| `@inth/sdk/styles.css`, `@inth/sdk/iab/styles.css` | Stylesheets for `ui: { shadow: false, styles: false }`. |

<CommandTabs command="@inth/sdk" mode="install" />

In ES module builds, the preference dialog loads as a separate chunk during
browser idle time once the banner or trigger mounts, or when opened. Use only
one client entry per page so loaders and blockers do not run twice.

### Choose a bundle for one mode

Use `@inth/sdk/hosted` when your app always calls `/v1/consent/init` and you want to
exclude manifest transport code:

| Entry | Accepted configuration | Throws on |
| --- | --- | --- |
| `@inth/sdk` | `projectUrl` and optional `mode`: `hosted()`, `manifest()` or `testing()` from `@inth/sdk/testing`. | Missing `projectUrl` (unless `testing()` or `enabled: false`); string mode names like `'hosted'`. |
| `@inth/sdk/hosted` | `projectUrl`, optional `mode: 'hosted'` or `hosted()`. | Missing `projectUrl`; other modes; `manifest` or `manifestUrl`. |

Use `@inth/sdk/iab-client` for IAB TCF.

## Start the client

`init(options)` creates and immediately starts the client:

<include src="../../../shared/examples/javascript/init.mdx" />

`createConsentClient(options)` creates the client without reading storage,
making requests or touching the DOM so you can call `client.start()` later:

{/* example: fragment */}

```ts
import { createConsentClient, manifest } from '@inth/sdk';

export const consent = createConsentClient({ mode: manifest(), scripts });
```

`start()` restores stored choices, resolves the policy, starts loaders and
blockers, wires page hooks and mounts the UI (waiting for `DOMContentLoaded`
if `<body>` is not ready). Subsequent `start()` calls are no-ops. See
[options](/docs/frameworks/javascript/api/browser-options).

## Read state

| Member | Returns | Use it for |
| --- | --- | --- |
| `ready()` | `Promise<ConsentSnapshot>` | Wait for policy resolution before checking returning-visitor choices. |
| `has(condition)` | `boolean` | Whether a category or condition (`{ or: ['measurement', 'marketing'] }`) is allowed now. |
| `hasConsented()` | `boolean` | Whether the visitor answered the prompt. |
| `getSnapshot()` | `ConsentSnapshot` | Full frozen state; see [snapshot reference](/docs/frameworks/javascript/api/snapshot). |
| `subscribe(listener)` | `() => void` | Receive each new snapshot; returns an unsubscribe function. |
| `on(event, listener)` | `() => void` | Listen to `ready`, `consent`, `ui` or `error`. |
| `consentCategories` | `AllConsentNames[]` | Categories displayed in canonical order (`necessary`, `functionality`, `measurement`, `experience`, `marketing`) within policy scope. |

Gate code on `has()` / `effectivePermissions`; report visitor decisions from
`hasConsented()` / `explicitChoice`. See
[a permission is not a recorded choice](/docs/concepts/how-consent-works#a-permission-is-not-a-recorded-choice).

## Record a choice

Call these only from user interactions:

| Method | Returns | What it records |
| --- | --- | --- |
| `acceptAll()` | `Promise<SaveResult>` | Allows all offered categories (under IAB, confirms declared vendor processing; categories without declared consent purposes stay denied). See [categories under an IAB policy](/docs/concepts/consent-state#categories-under-an-iab-policy). |
| `rejectAll()` | `Promise<SaveResult>` | Denies every optional category offered. |
| `save(consents)` | `Promise<SaveResult>` | Saves named categories (`{ measurement: true }`). Resolves `{ ok: false }` under IAB; use `saveIAB()`. |
| `saveIAB()` | `Promise<SaveResult>` | Confirms IAB choices on `runtime.iab` (IAB entry only). |
| `dismissNotice()` | `Promise<NoticeDismissResult>` | Acknowledges a notice without granting consent. |
| `optOut()` | `Promise<OptOutResult>` | Under an opt-out policy, records a durable opt-out in one step. When it turns off a category that was allowed and `reloadOnConsentRevoked` is enabled, it waits up to one second for the opt-out request, reloads the page, and shows the confirmation view once on the new page. Otherwise it opens the confirmation view without waiting on the network. Under any other policy, opens the preference dialog and resolves `{ ok: false, reason: 'not-available' }`. |
| `identify(user)` | `Promise<void>` | Links the consent record to `{ externalId, identityProvider?, identityToken? }`, where `identityToken` verifies the link on the server. Failures emit `error`. |

Saves apply locally and close the active surface before the network request
finishes. Failed requests set `SaveResult.ok` to `false` and retry in the
background.

## Control the UI

| Method | What it does |
| --- | --- |
| `showBanner()`, `openDialog()`, `closeDialog()` | Switch active UI surface without recording consent. |
| `setLanguage(code)` | Updates language and re-resolves copy; see [translations](/docs/frameworks/javascript/translations). |
| `setOverrides(overrides)` | Merges `country`, `region`, `language` and `gpc` overrides (`undefined` clears a key). |
| `mountUI(options?)` | Unmounts and remounts stock UI with new options (throws in headless entry). |
| `processIframes()` | Updates gated iframes when `iframeBlocker: { disableAutomaticBlocking: true }`; see [check iframes on demand](/docs/frameworks/javascript/modules/iframe-blocker#check-iframes-on-demand). |
| `ui` | Mounted UI handle (`host`, `root`, `update()`, `destroy()`), or `null`. |

## Lifecycle and internals

| Member | What it is |
| --- | --- |
| `start()` | Starts the client (`init()` calls it automatically). |
| `started` | `true` while started and not disposed. |
| `dispose()` | Tears down UI, listeners, blockers, loaded script tags and runtime. |
| `options` | Resolved client options. |
| `mode` | `'hosted'`, `'manifest'`, `'testing'` or `'custom'`. |
| `runtime` | Underlying [consent runtime](/docs/frameworks/javascript/api/runtime) (`runtime.iab` holds the CMP under IAB). |
| `kernel` | Underlying [consent kernel](/docs/frameworks/javascript/api/kernel). |

Do not attach duplicate script loaders, network blockers or iframe blockers
to `client.kernel`.

## Page hooks

| Markup | What it does |
| --- | --- |
| `<button data-inth-action="...">` | Runs the action on click. |
| Link ending in `#inth-preferences` | Opens the preference dialog. |
| `<script type="text/plain" data-inth-category="...">` | Runs the script in document order once allowed. |
| `<iframe data-src="..." data-category="...">` | Populates `src` once allowed. |

## Helper exports

| Export | What it does |
| --- | --- |
| `hosted`, `manifest` | Mode factories; see [transports](/docs/frameworks/javascript/transports). |
| `manifestNeedsLocation(manifest)` | Returns whether regional rules require location to resolve without `/v1/consent/init`. |
| `activateGatedScripts(snapshot, root?, options?)` | Activates allowed `text/plain` tags under `root` (`options.nonce` enforces nonce matching). |
| `mountConsentUI(client, options?)` | Mounts stock UI for a client. |
| `ACTION_ATTRIBUTE`, `PREFERENCES_HASH`, `CATEGORY_ATTRIBUTE`, `ACTIVATED_ATTRIBUTE` | `'data-inth-action'`, `'#inth-preferences'`, `'data-inth-category'` and `'data-inth-activated'`. |
| `version` | Package version string. |

TypeScript exports include `ConsentClient`, `ConsentClientOptions`,
`ConsentUIOptions`, `ConsentBannerOptions`, `ConsentDialogOptions`,
`ConsentTriggerOptions`, `ConsentClientEventMap`, `ConsentSnapshot`,
`ConsentState` and `HostedConsentClientOptions` (from `@inth/sdk/hosted`).

## Check it works

1. Run `await consent.ready()` and confirm `resolution.status === 'matched'`.
2. Click **Reject All** and verify `consent.hasConsented()` is `true` while
   `consent.has('measurement')` is `false`.
3. Call `consent.openDialog()` and confirm **Analytics** (`measurement`) is
   off.
