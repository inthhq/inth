Reference for the low-level consent kernel that holds state, runs async
commands and emits lifecycle events across every JavaScript setup.

## Get a kernel

- `consent.kernel` from `init()` in `@inth/sdk`.
- `runtime.kernel` from `createConsentRuntime` in `@inth/sdk/runtime`.
- A manually constructed kernel; see
  [create a kernel yourself](#create-a-kernel-yourself).

The kernel alone renders no UI, loads no scripts and touches no storage.

{/* example: fragment */}

```ts
const unsubscribe = kernel.subscribe((snapshot) => {
	console.log(snapshot.resolution.status, snapshot.effectivePermissions);
});
```

## Read state

| Member | Returns | What it does |
| --- | --- | --- |
| `getSnapshot()` | `ConsentSnapshot` | Current frozen state; see [snapshot reference](/docs/frameworks/javascript/api/snapshot). |
| `subscribe(listener)` | `() => void` | Invokes `listener(snapshot)` on every state change. |
| `getServerSnapshot()` | `ConsentSnapshot` | Initial snapshot for SSR hydration matching. |
| `refresh(now?)` | `ConsentSnapshot` | Re-evaluates expiration at `now` and returns the updated snapshot. |

Unchanged snapshot slices keep referential identity (`===`).

## Choose commands by intent

Commands are asynchronous and are the only way to record choices:

| Command | Returns | Effect |
| --- | --- | --- |
| `commands.init()` | `Promise<{ ok, error? }>` | Resolves the policy via transport (retries failures in background). |
| `commands.save('all')` | `Promise<SaveResult>` | Grants every category in scope. |
| `commands.save('none')` | `Promise<SaveResult>` | Denies every optional category in scope. |
| `commands.save({ marketing: false })` | `Promise<SaveResult>` | Records named categories only. |
| `commands.save()` | `Promise<SaveResult>` | Records staged draft (falling back to current choice or policy defaults). |
| `commands.dismissNotice()` | `Promise<NoticeDismissResult>` | Acknowledges a notice without granting consent. |
| `commands.optOut(context?)` | `Promise<OptOutResult>` | Records a durable opt-out at once without touching `explicitChoice`, then sends it through the save queue when the transport supports opt-outs. Starts with `rights: []` until the backend returns the rights for the visitor's location, or with all three rights when the transport has no `optOut` method or the backend answers `404`. Switches off `marketing` and `measurement` in scope. Works under any `opt-out` policy and returns `{ ok: false, reason: 'not-available' }` under other models. |
| `commands.optIn(context?)` | `Promise<OptInResult>` | Lifts an opt-out when GPC is not active. Clears a device-held opt-out at once and queues a lift request. For an account-held opt-out (`heldBy` is `'person'` or `'both'`), sends a lift with the current user's identity token and waits for the answer; clears the record when the backend returns `optOut: null`, and otherwise returns `{ ok: false, reason: 'held-by-account' }`. |
| `commands.identify(user)` | `Promise<void>` | Links record to `{ externalId, identityProvider?, identityToken? }` (where `identityToken` verifies the link on the server), applies any effective opt-out returned in the link answer, and loads that subject's server record. |

`save(input, context)` accepts `context.categories` to scope bulk actions and
`context.vendors` for vendor-level switches. Saves commit locally and notify
subscribers before the network request finishes, queuing failed requests for
retry. See [when a choice is saved](/docs/concepts/consent-state#when-a-choice-is-saved).

## Change inputs and UI state

`set` methods run synchronously and never record consent:

| Setter | What it changes |
| --- | --- |
| `set.activeUI('banner' \| 'dialog' \| 'none')` | Active UI surface. |
| `set.draft(values)` | Staged values confirmed by `commands.save()`. |
| `set.overrides({ country, region, language, gpc })` | Merges decision overrides (`undefined` clears a key); follow with `commands.init()`. |
| `set.language(code)` | Language override. |
| `set.privacySignals({ gpc })` | Sets detected GPC signal (such as from `Sec-GPC` on the server). |
| `set.consentCategories(categories)` | Replaces configured categories (discovered ones stay). |
| `set.registerConsentCategories(categories)` | Registers categories discovered by integrations. |
| `set.vendors(patch, options?)` | Merges declared vendors. |
| `set.subjectId(id)` | Updates subject ID (`null` generates a new one with persistence). |
| `set.iab(patch)` | Internal setter used by the IAB module. |

## Apply stored records

Pass validated records (for example from
`readStoredRecordsFromCookieHeader()`) as `initialRecords` to
`createConsentKernel()`. In the browser,
[`createPersistence()`](/docs/frameworks/javascript/modules/persistence)
hydrates storage and syncs tabs automatically.

## Events

`kernel.events.on(type, listener)` returns an unsubscribe function:

| Event | Fields | When |
| --- | --- | --- |
| `init:applied` | `snapshot` | Policy resolved from transport or prefetch. |
| `init:failed` | `error`, `attempt`, `nextRetryMs` | Init failed (`nextRetryMs` is `null` after final attempt). |
| `choice:recorded` | `snapshot`, `confirmed`, `actionAt` | Visitor recorded categories. |
| `permissions:changed` | `snapshot`, `previous` | Effective permissions changed for any reason. |
| `notice:dismissed` | `snapshot`, `dismissal` | Notice acknowledged. |
| `opt-out:recorded` | `snapshot`, `optOut`, `actionAt`, `uiSource?` | Durable opt-out recorded from `commands.optOut()`, a detected GPC signal, or a save under an `opt-out` policy that refuses `marketing` (or `measurement` when `marketing` is not in scope). |
| `opt-out:lifted` | `snapshot`, `actionAt`, `uiSource?` | Durable opt-out lifted from `commands.optIn()` or a save under any model that grants `marketing` (or `measurement` when `marketing` is not in scope). |
| `opt-out:synced` | `snapshot`, `optOut` | Backend's effective opt-out replaced the local record after an opt-out, lift, save or `identify` answer, or a `404` filled an empty local `rights` list with all three rights. Emits no network request. |
| `vendors:recorded` | `snapshot`, `actionAt` | Vendor denials changed. |
| `vendors:set` | `snapshot` | Declared vendors changed. |
| `overrides:set` | `snapshot` | Decision overrides changed. |
| `user:identified` | `snapshot` | `identify()` linked a user. |
| `subject:resolved` | `snapshot`, `previousSubjectId?` | Subject ID resolved to a canonical ID. |
| `iab:set` | `snapshot` | IAB state updated. |
| `records:cleared` | none | Stored records cleared. |
| `save:replayed` | `subjectId`, `ok`, `rejected?` | Queued save replayed. |
| `command:init:started`, `command:save:started` | none | Command started. |
| `command:init:completed`, `command:save:completed` | `result` | Command finished. |
| `command:error` | `command`, `error` | Command failed. |

Use `choice:recorded` for visitor decisions and `permissions:changed` to gate
code; see [callbacks](/docs/frameworks/javascript/callbacks).

## How listeners are notified

`subscribe()` and `events.on()` listeners run synchronously in registration
order with the frozen snapshot. Throwing listeners report via `reportError`
in browsers (or `console.error` on servers) without stopping sibling
listeners. Nested mutations deliver in order and halt after 100 recursive
passes to prevent infinite loops.

## Create a kernel yourself

Prefer `init()` or `createConsentRuntime()` unless you need manual control
over every module:

Attach only the modules you need and dispose them before the kernel:

| Module | Entry point | Page |
| --- | --- | --- |
| Persistence | `@inth/sdk/modules/persistence` | [Persistence](/docs/frameworks/javascript/modules/persistence) |
| Script loader | `@inth/sdk/modules/script-loader` | [Script loader](/docs/frameworks/javascript/modules/script-loader) |
| Network blocker | `@inth/sdk/modules/network-blocker` | [Network blocker](/docs/frameworks/javascript/modules/network-blocker) |
| Iframe blocker | `@inth/sdk/modules/iframe-blocker` | [Iframe blocker](/docs/frameworks/javascript/modules/iframe-blocker) |
| Clear on revocation | `@inth/sdk/modules/clear-on-revocation` | [Clear on revocation](/docs/frameworks/javascript/clear-on-revocation) |
| Reload after withdrawal | `watchRevocationReload` from `@inth/sdk/engine` | Reloads page after withdrawal; returns disposer |

`createConsentKernel(config)` takes a `transport` instance (such as
`createHostedTransport({ projectUrl })` from `@inth/sdk/engine`) plus:

| Field | What it does |
| --- | --- |
| `transport` | Implements `init`, `save`, `optOut`, `liftOptOut`, `identify` and `loadSubjectRecord`. |
| `consentCategories` | Categories offered within policy scope. |
| `initialOverrides`, `initialUser` | Initial overrides and user identity. |
| `initialRecords`, `initialPolicyResolution` | Pre-resolved records and policy from SSR. |
| `initialTranslations`, `translationOverrides` | Base copy and per-language key overrides. |
| `initRetry` | Retry config (`{ maxAttempts, baseDelayMs, maxDelayMs }` or `false`; defaults to 5 attempts, skipping HTTP 402). |
| `now` | Fixed clock timestamp so SSR and hydration agree. |

## Check it works

1. Subscribe and call `commands.init()`; confirm `policyPending` becomes
   `false` and `resolution.status` becomes `'matched'`.
2. Listen to `events.on('choice:recorded', ...)` and confirm it fires on
   accept/reject/save, not on reload.
3. Call `kernel.dispose()` and verify retries stop while `getSnapshot()`
   still reads state.
