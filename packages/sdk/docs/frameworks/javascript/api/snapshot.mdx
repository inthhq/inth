Reference for every field on the frozen `ConsentSnapshot` returned by
`kernel.getSnapshot()`, `consent.getSnapshot()` and `subscribe` listeners.

## Read a snapshot

Unchanged slices keep the same object reference, so compare with `===` to
skip unnecessary work:

{/* example: fragment */}

```ts
let previous = kernel.getSnapshot();
kernel.subscribe((next) => {
	if (next.effectivePermissions !== previous.effectivePermissions) {
		updateGates(next.effectivePermissions);
	}
	previous = next;
});
```

## May this run now?

| Field | Type | What it holds |
| --- | --- | --- |
| `effectivePermissions` | `Record<category, boolean>` | Current permission per category (may be `true` before a choice under opt-out). |
| `restrictions` | per category list of `'explicit-denial'`, `'strict-scope'` or `'gpc'` | Why a category is denied. |
| `privacySignals.gpc` | `{ detected, override, active }` | Browser Global Privacy Control signal, override and active state. |
| `nextDeadline` | `number \| null` | Epoch ms when a choice or notice expires next. |

## What did the visitor decide?

| Field | Type | What it holds |
| --- | --- | --- |
| `explicitChoice` | `{ version, categories } \| null` | Recorded decision per category (`value`, `confirmedAt`), or `null` if none. |
| `noticeDismissal` | `{ dismissedAt, fingerprint } \| null` | Notice acknowledgement timestamp (not a consent grant). |
| `vendorChoice` | `{ denied, confirmedAt } \| null` | Vendors switched off outside IAB. |
| `subject` | `{ subjectId?, externalId?, identityProvider? } \| null` | Consent subject identity (`subjectId` alone is not a decision). |

Gate code on permissions; report visitor decisions from recorded choices. See
[a permission is not a recorded choice](/docs/concepts/how-consent-works#a-permission-is-not-a-recorded-choice).

## What does the policy require?

| Field | Type | What it holds |
| --- | --- | --- |
| `promptRequirement` | `{ kind: 'choice' \| 'notice', reason } \| { kind: 'none' }` | Pending interaction (`reason`: `'missing'`, `'expired'` or `'policy-changed'`). |
| `resolution` | `{ status, policy }` | Resolution status (`'matched'`, `'no-match'`, `'failed'`, `'unconfigured'`). |
| `policyPending` | `boolean` | `true` until first transport response (keep UI hidden while `true`). |
| `policyRule` | resolved rule | Active rule (or strict opt-in fallback while pending/failed). |
| `model` | `'opt-in' \| 'opt-out' \| 'iab' \| 'none'` | Active permission model. |
| `consentCategories` | category list or `null` | Configured/discovered categories (`null` means full policy scope). |
| `evaluationPolicy` | object | Validated policy projection for DevTools and debugging. |

Verify `resolution.status === 'matched'` before treating `policyRule` as the
visitor's resolved policy.

## What should the UI show?

| Field | Type | What it holds |
| --- | --- | --- |
| `activeUI` | `'banner' \| 'dialog' \| 'none' \| null` | Surface to render. |
| `translations` | `{ language, translations } \| null` | Active language copy. |
| `branding` | `'c15t' \| 'inth' \| 'consent' \| null` | Brand name for the "Secured by" tag. |

## Context and bookkeeping

| Field | What it holds |
| --- | --- |
| `overrides` | Active country, region, language and GPC overrides. |
| `location` | Country and region reported by Inth. |
| `user` | Identified user metadata, if any. |
| `policySnapshotToken` | Signed token returned on saves to validate the policy version. |
| `iab` | Live IAB state under an IAB policy, or `null`. |
| `vendors` | Declared vendors, or `null`. |
| `revision` | Monotonic counter incremented on every snapshot update. |
| `evaluatedAt` | Epoch ms when this snapshot was evaluated. |

## Check it works

1. Log `getSnapshot()` after `ready()`; confirm `resolution.status` is
   `'matched'`, `policyPending` is `false` and `explicitChoice` is `null` for
   a new visitor.
2. Accept all and log again; confirm `explicitChoice.categories` is populated
   and `promptRequirement.kind` is `'none'`.
