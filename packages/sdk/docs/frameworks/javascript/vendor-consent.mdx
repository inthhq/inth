## Declare the vendors and record a switch

Declaring a vendor turns on vendor switches. Built-in `@inth/integrations`
helpers then list their own vendor by name, so declare a vendor only for
custom scripts or to replace a helper's name and privacy policy.

With `createConsentRuntime`, declare the vendors and render switches in your
[headless UI](/docs/frameworks/javascript/headless). The stock preference
dialog mounted by `init()` renders vendor switches automatically:

<include src="../../shared/examples/javascript/vendor-consent.mdx" />

Pass `vendors` next to `scripts`:

{/* example: fragment */}

```ts title="src/consent-runtime.ts (partial)"
import { vendors } from './vendor-consent';

export const runtime = createConsentRuntime({
	projectUrl: 'https://your-project.inth.app',
	scripts,
	vendors,
});
```

`init()` from `@inth/sdk` takes the same `vendors` option and exposes the
runtime as `client.runtime`. `isVendorAllowed(snapshot, id)` from
`@inth/sdk/engine` backs `canVendorRun()`.

<import src="../../shared/scripts/vendor-consent.mdx#undeclared" />

Call `saveVendorSwitch(runtime, 'x-pixel', false)` from your switch change
handler, or save categories and vendors together:

{/* example: fragment */}

```ts
await runtime.kernel.commands.save({
	marketing: true,
	measurement: true,
	vendors: { 'x-pixel': false },
});
```

To stage vendor switches alongside category switches before saving, use a
[preference draft](/docs/frameworks/javascript/headless#build-a-preference-form-with-a-draft):
`draft.setVendor(id, granted)` stages a vendor and `draft.reset()` clears it.
Read declared vendors from `runtime.kernel.getSnapshot().vendors?.declared`
and recorded denials from `vendorChoice`.

## Verify vendor consent

Test your production build in a private window with DevTools Network filtered
to `ads-twitter.com`:

1. Register `xPixel()` and declare `x-pixel`. Allow marketing; `uwt.js`
   loads.
2. Switch X Pixel off. Inth reloads the page; `uwt.js` stays absent while
   other marketing scripts load.
3. Reload again. `canVendorRun(runtime, 'x-pixel')` returns `false`.
4. Call `runtime.kernel.commands.save('all')`. `uwt.js` loads again.
