Render your own consent banner and preference dialog in plain JavaScript, or
connect a framework without a dedicated adapter such as Solid, using
`createConsentRuntime`.

## Choose a headless API

| API | Use it when |
| --- | --- |
| `createConsentRuntime` from `@inth/sdk/runtime` | You render your own UI, connect a framework like Solid, or share consent state across modules. Covered on this page. |
| `init` from `@inth/sdk/headless` | You want the `@inth/sdk` client API (`data-inth-action`, `on('ui', ...)`, `acceptAll()`) without stock UI or CSS. |
| `createConsentKernel` from `@inth/sdk/engine` | You wire every module manually; see [create a kernel yourself](/docs/frameworks/javascript/api/kernel#create-a-kernel-yourself). |

`createConsentRuntime` wires the kernel, persistence, script loader, iframe
blocker, revocation reload, and optional network blocker, clear-on-revocation
and IAB. See the
[createConsentRuntime reference](/docs/frameworks/javascript/api/runtime).

## Render the banner from the snapshot

Read current state via `runtime.kernel.getSnapshot()` and subscribe via
`runtime.kernel.subscribe(listener)`. See the
[snapshot reference](/docs/frameworks/javascript/api/snapshot) for every
field:

| Field | What it tells your UI |
| --- | --- |
| `policyPending`, `resolution.status` | Wait until `resolution.status === 'matched'` before rendering consent UI. |
| `activeUI` | Active surface: `'banner'`, `'dialog'` or `'none'`. |
| `promptRequirement.kind` | `'choice'`, `'notice'` or `'none'`. |
| `policyRule.scope` | Categories offered in preferences. |
| `effectivePermissions` | Current permission per category (use to gate features). |
| `explicitChoice` | Recorded visitor choice, if any. |

`resolveConsentPresentation` from `@inth/sdk/engine` computes the exact
buttons and order required by the policy:

<include src="../../shared/examples/javascript/actions.mdx" />

`kernel.set.activeUI()` opens or closes surfaces without saving.
`kernel.commands.save()` records `'all'`, `'none'` or a category map such as
`{ measurement: true }`. `dismissNotice()` records notice acknowledgement
without granting consent.

Use `resolveActionLabels`, `resolvePreferenceControlLabels`, `resolveOptOutLink`,
`resolveOptOutCopy`, `resolveOptOutReceiptSentence` and `resolvePromptCopy` from
`@inth/sdk/engine`, `@inth/sdk/surface-state` or `@inth/sdk/headless` with
`snapshot.translations?.translations` to get localized copy with English
fallbacks. `resolveOptOutLink` resolves `'do-not-sell'`, `'privacy-choices'`
or `'california-privacy-choices'` and returns
`{ variant: 'privacy-choices', label, icon: 'cppa-opt-out' }` for both
"Privacy Choices" forms.

`resolveOptOutLink` returns data and renders nothing. When the result carries
`icon: 'cppa-opt-out'`, your own markup must render the California Privacy
Protection Agency opt-out icon next to the label, because neither Privacy
Choices title may appear without it. Get the icon from `@inth/sdk/ui/utils`:
`cppaOptOutIconSvg()` returns it as an `<svg>` string, and `CPPA_OPT_OUT_ICON`
holds its view box and paths for a framework that builds the element itself.

<include src="../../shared/privacy-choices-link.mdx" />

`resolveOptOutCopy` returns the opt-out
confirmation and lock-reason copy. `resolveOptOutState(snapshot)` derives what
an opt-out confirmation or preference surface renders from a snapshot:
`available`, `honored`, `via` (`'signal'`, `'request'` or `null`), `lock`
(`'gpc-active'`, `'held-by-account'` or `null`), `categories`,
`decidingCategory` and `optInPromptAllowedAt`.
`resolveOptOutReceipt(snapshot, local)` derives the receipt fields (`optedOut`,
`scope`, `source`, `at`, `reference` and backend-confirmed `rights`), and
`resolveOptOutReceiptSentence(translations, receipt)` formats the matching
receipt sentence.
`resolveCategoryOptOutLock(snapshot, category)` returns `'gpc-active'`,
`'held-by-account'` or `null` for one category row.

## Build a preference form with a draft

Use `createPreferenceDraft(kernel)` from `@inth/sdk/preference-draft` to
stage unsaved category and vendor switches before saving:

<include src="../../shared/examples/javascript/preference-draft.mdx" />

`draft.getState()` exposes:

| Field | What it holds |
| --- | --- |
| `displayedCategories` | `necessary` plus policy-editable categories in canonical order. |
| `values` | Staged edit, else `false` when an active opt-out or GPC restriction denies it, else recorded choice, else policy default. GPC-restricted categories cannot be staged on or granted by `acceptAll()` or bulk `'all'` saves. |
| `vendors` | Declared vendor switches (empty under IAB). |
| `isDirty` | Whether any staged value differs from the stored record. |
| `isStale` | Whether policy, categories or vendors changed since edits began. |

Call `set(category, value)` and `setVendor(id, granted)` to stage changes,
`draft.save()` to record them, `draft.reset()` to discard them, or
`draft.save({ input: 'all' | 'none' })` for bulk actions. Stale drafts return
`{ ok: false }` until reset. Load the draft module only when rendering a
preference UI.

## Close surfaces the way the stock UI does

Wrap button handlers with `@inth/sdk/surface-actions` so banner and dialog
closing matches Inth's framework adapters:

| Function | What it does |
| --- | --- |
| `saveConsentSurface(kernel, saveFn, isClean?)` | Runs the save and closes the open surface immediately once recorded locally. |
| `saveConsentBlanket(kernel, 'all' \| 'none', runtime.iab)` | Runs Accept All or Reject All (routing through the CMP under IAB). |
| `saveIABConsentSurface(kernel, saveFn)` | Closes an IAB surface immediately and restores it if the CMP could not record. |
| `showConsentSurface(kernel, 'banner' \| 'dialog' \| 'none')` | Opens or closes a surface, restoring the banner if a prompt is still due. |
| `activateOptOutLink(kernel, variant, context?)` | Runs the rule for an opt-out link, banner link or trigger: `'privacy-choices'` opens the preference dialog without recording, `'do-not-sell'` opts out in one click. |
| `hasConsentUI(snapshot)` | Whether the resolved policy owes any Inth UI. |
| `hasConsentPreferences(snapshot)` | Whether a privacy settings link has a destination (Inth UI or external CMP). |

With a preference draft, pass
`saveConsentSurface(kernel, () => draft.save(), () => !draft.getState().isDirty)`.
See [when a choice is saved](/docs/concepts/consent-state#when-a-choice-is-saved).

## What your UI must handle

- **Every prompt kind.** Handle `choice`, `notice` and `none` cleanly.
- **Policy-required actions and rights.** Render every action returned by
  `resolveConsentPresentation`, including opt-out rights.
- **A way back.** Provide a persistent privacy settings control on every
  page.
- **Visitor actions only.** Never call `save()` or `dismissNotice()` during
  page load or render.
- **Accessibility.** Manage focus, keyboard navigation, ARIA labels and
  narrow screens (the example uses a native `<dialog>`).
- **Localized copy.** Read `snapshot.translations` via the copy helpers; see
  [translations](/docs/frameworks/javascript/translations).

Review [how consent works](/docs/concepts/how-consent-works) and run the
[verification checklist](/docs/guides/verify-consent).

## Use Inth with Solid

Create one shared runtime and expose its snapshot as a Solid signal:

{/* example: fragment */}

```ts title="src/use-consent.ts"
import { createSignal, onCleanup } from 'solid-js';

import { runtime } from './consent-runtime';

export function useConsentSnapshot() {
	const [snapshot, setSnapshot] = createSignal(runtime.kernel.getSnapshot());
	onCleanup(runtime.kernel.subscribe((next) => setSnapshot(() => next)));
	return snapshot;
}
```

Call `runtime.start()` once after `render()`. Read
`snapshot().effectivePermissions` inside components and invoke
`runtime.kernel.commands` from event handlers.

## Use the browser client without its UI

`@inth/sdk/headless` gives you `init()`, `data-inth-action` hooks and the
`ui` event with zero stock UI or CSS:

{/* example: fragment */}

```ts
import { init, manifest } from '@inth/sdk/headless';

const consent = init({ mode: manifest(), scripts });
consent.on('ui', (surface) => {
	banner.hidden = surface !== 'banner';
});
```

## Check it works

Open your app in a private window with DevTools Network open:

1. Your banner mounts once the policy resolves with policy-required actions,
   and no vendor requests fire.
2. Reject and reload. Your banner stays closed and vendors stay blocked.
3. Open preferences, allow Measurement only and save. Measurement loads while
   marketing stays blocked.
4. Tab through every control and verify Escape closes your dialog.
