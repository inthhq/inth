Replace Inth's stock banner and dialog with your own Vue components while
keeping policy resolution, script gating, and consent storage.

## When to go headless

Check [customize](/docs/frameworks/vue/customize) first if you only need
different colors, layout, or classes. Go headless when the consent UI must use
your own markup or design system components.

Headless replaces only the UI. `inth` still resolves policies, stores
choices, loads `scripts`, and gates iframes.

## Write the consent UI

Render a banner while `activeUI` is `'banner'` and a preference form while it
is `'manager'`:

<include src="../../shared/examples/vue/headless-prompt.mdx" />

`useConsentSave()` records Accept All or Reject All and closes the banner by
setting `activeUI` to `null`. `useConsentDraft()` holds preference switches in
`values`, lists selectable categories in `displayedCategories`, and records
them on `save()`. Close preferences yourself after `save()` resolves. See
[build a preference form](/docs/frameworks/vue/composables#build-a-preference-form)
for every draft property.

Add focus trapping, a close button, and styles before shipping.

## Show the buttons the policy requires

Policies vary in which buttons they require or forbid. A notice prompt, for
example, requires a dismiss action instead of Accept and Reject. Read
`primaryActions` and `actionGroups` from `useConsentPolicyActions('prompt')`
instead of hard-coding buttons, and call `useDismissNotice()` to dismiss a
notice (recording an acknowledgement, not consent).

Use `usePromptRequirement()` to check whether the policy requires a `'choice'`,
a `'notice'`, or `'none'`. For an opt-out link in custom markup, call
`useOptOut()` to record the opt-out in one step and open `OptOutConfirmation`
under an opt-out policy, or open the preference dialog otherwise. Use
`resolveOptOutLink` from `@inth/vue` with `presentation.optOutLink` to resolve
the statutory link title and icon requirement.

## Verify the custom UI

Run through [verify consent](/docs/guides/verify-consent). Confirm Reject All
is as easy to reach as Accept All, preferences list the policy's categories,
and rejections persist across reloads.
