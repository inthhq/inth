## Before the policy resolves

`inth` starts with every optional category denied and no recorded choice
loaded. Composables update once the browser reads stored choices and resolves
the policy. Until then, `useConsentSnapshot().value.policyPending` is `true`
and `usePolicyResolution().value.status` is not `'matched'`, so you can wait
before showing state-dependent UI.
