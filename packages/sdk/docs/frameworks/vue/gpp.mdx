Enable `window.__gpp` (GPP 1.1 CMP API) in your Vue app so ad tech such as
Prebid.js and Google Ad Manager can read US state privacy signals and TCF EU
consent strings.

## Turn on GPP

Pass `gpp: true` to `inth` in `src/main.ts`:

{/* example: fragment */}

```ts title="src/main.ts"
import { inth, hosted } from '@inth/vue/vue-plugin';
import { createApp } from 'vue';

import App from './app.vue';

createApp(App)
	.use(inth, {
		// Loads @inth/sdk/iab/gpp and installs `__gpp` once the app mounts.
		gpp: true,
		mode: hosted(),
	})
	.mount('#app');
```

The plugin lazy-loads `@inth/sdk/iab/gpp` on mount, so apps without `gpp`
never download it. `@inth/vue` already depends on `@inth/sdk/iab`, so no
extra package is needed. Unmounting the app removes `window.__gpp`.

The GPP string follows the policy and location resolved by Inth for the
visitor, including US state detection.

If you pass a custom `runtime` created with `createConsentRuntime()`,
`inth` ignores `gpp`. Configure `gpp` and
`loadGPP: () => import('@inth/vue/gpp')` directly on that runtime instead.

To include the TCF EU section for visitors under an `iab` policy, also enable
[IAB TCF](/docs/frameworks/vue/iab).
