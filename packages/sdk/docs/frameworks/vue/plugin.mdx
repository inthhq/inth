Install `inth` from `@inth/vue/vue-plugin` in `src/main.ts` to create the
consent runtime and provide it to every Vue component.

## Install the plugin

<include src="../../shared/examples/vue/main.mdx" />

Nuxt apps use `@inth/nuxt` instead of `app.use()`. The
[quickstart](/docs/frameworks/vue/quickstart) sets up `consentManifest()`, the
Vite plugin that passes your project URL to `hosted()`.

## What the plugin does

`app.use(inth, options)` creates one consent runtime for the app, provides
it to every component, and injects `tokens` into `document.head` in a
`<style id="inth-css-vars">` element before the first render. Once the root
component mounts, the plugin runs these steps in order:

1. Reads the visitor's stored choice from the `inth` cookie and localStorage.
2. Applies Global Privacy Control when the browser sends it.
3. Starts the script loader for `scripts`, `clearOnRevocation`, the network
   blocker, and the iframe blocker.
4. Resolves the visitor's policy using `mode`: `/v1/consent/init` with `hosted()`, the
   manifest in the browser with `manifest()`, or local rules with `testing()`.
5. Loads the IAB TCF module when `iab` is set and the matched policy uses the
   `iab` model.

Until the policy resolves, optional categories stay denied so gated scripts
and iframes wait. On Vue 3.5+, `app.unmount()` stops every module and removes
the token style element. Calling composables outside this app throws
`[inth] Kernel not found`.

## Options

Pass `mode` unless you supply a `runtime`; every other option is optional.
Options containing functions, such as `scripts` and `callbacks`, work here
because the plugin runs in the browser.

### Policy source

| Option | Default | What it does |
| --- | --- | --- |
| `mode` | Required (`hosted()` recommended) | Policy source: `hosted()` or `manifest()` from `@inth/vue/vue-plugin`, or `testing()` from `@inth/vue/testing`. See [rendering](/docs/frameworks/vue/rendering). |
| `consentCategories` | Policy categories | Limits which categories the dialog and widget display within the policy's scope. |
| `vendors` | Unset | Lists declared vendors under their category with per-vendor switches. See [vendor consent](/docs/frameworks/vue/vendor-consent). |
| `storageConfig` | `{ storageKey: 'inth' }` | Configures cookie and localStorage key name, `crossSubdomain`, `defaultDomain`, and `defaultExpiryDays` (default 365). |

Configure the project URL, custom `fetch`, and save `domain` on the mode
factory rather than the plugin:

| Mode | Options |
| --- | --- |
| `hosted()` | `projectUrl` (defaults to what `consentManifest()` read from `VITE_INTH_PROJECT_URL` or `VITE_C15T_BACKEND_URL`), `headers`, `fetch`, `domain`. |
| `manifest()` | `projectUrl` and build snapshot from `consentManifest()`, plus `source: 'runtime'`, `manifestUrl`, `snapshot`, `geoUrl`, `inputs`, `initFallback`, `headers`, `credentials`, `fetch`, `domain`. |
| `testing()` | From `@inth/vue/testing` for tests only. `policy` overrides Inth's recommended rules. Throws in production builds. |

`hosted()` and `manifest()` throw without a project URL. Add
`consentManifest()` to `vite.config.ts` and set `VITE_INTH_PROJECT_URL` (or
`VITE_C15T_BACKEND_URL`), or pass `projectUrl`.

### Scripts and blocking

| Option | Default | What it does |
| --- | --- | --- |
| `scripts` | Unset | Vendor scripts gated by consent category. See [scripts](/docs/frameworks/vue/scripts). |
| `networkBlocker` | Off | Rules holding matching `fetch` and XHR requests until allowed. See [network blocker](/docs/frameworks/vue/network-blocker). |
| `iframeBlocker` | On | Gates iframes carrying `data-src` and `data-category`. Set `false` to disable. See [embeds](/docs/frameworks/vue/embeds). |
| `nonce` | Unset | CSP nonce added to every loaded script and to `<style id="inth-css-vars">`. See [Content Security Policy](/docs/frameworks/vue/content-security-policy). |
| `reloadOnConsentRevoked` | `true` | Reloads the page when a save or one-click opt-out withdraws a granted category or vendor. Privacy signals and backend-synced opt-outs do not reload. With `persistence: false`, nothing reloads because a reload would discard the choice it was for. |
| `clearOnRevocation` | Unset | Deletes first-party cookies and storage keys for withdrawn categories. See [clear on revocation](/docs/frameworks/vue/clear-on-revocation). |
| `iab` | Off | Enables IAB TCF (`{}` is enough) and accepts publisher settings such as `publisherRestrictions`. Unset, `false`, or `{ enabled: false }` leaves IAB off, causing an `IABUnavailableError` on IAB policies with a vendor list. See [IAB TCF](/docs/frameworks/vue/iab). |

### Events

| Option | Default | What it does |
| --- | --- | --- |
| `callbacks` | Unset | Registers `onChoiceRecorded`, `onPermissionsChanged`, `onError`, and `onBeforeConsentRevocationReload`. See [callbacks](/docs/frameworks/vue/callbacks). |

### Appearance

| Option | Default | What it does |
| --- | --- | --- |
| `tokens` | Default theme | CSS variables written to `<style id="inth-css-vars">` in `document.head`. See [customize](/docs/frameworks/vue/customize#set-theme-tokens). |
| `presentation` | Policy defaults | The banner's `container`, `edgeStyle`, `blockUntilChoice` and action layout, under `presentation.prompt`. |
| `components` | Unset | Vue attributes such as `class` and `style` for named component parts. |
| `legalLinks` | None shown | Links to your privacy and cookie policies. |
| `bannerLegalLinks`, `dialogLegalLinks` | Each surface's stock links | Which `legalLinks` the banner and the dialog show. A list shows only the links it names, so `[]` shows none. |
| `hideBranding`, `bannerHideBranding`, `dialogHideBranding`, `iabBannerHideBranding`, `iabDialogHideBranding` | `false` | Hides the "Consent by" tag. |
| `showTrigger` and `trigger*` | `false` | Configures the floating trigger. See [ConsentDialogTrigger](/docs/frameworks/vue/components/consent-dialog-trigger). |
| `disableAnimation` | `false` | Turns off banner and dialog transitions. |
| `models`, `bannerModels`, `iabBannerModels`, `iabDialogModels` | Every model | Limits which policy models render each surface. |

### Advanced

| Option | What it does |
| --- | --- |
| `runtime` | Uses an existing runtime from `createConsentRuntime()` instead of `mode`. The plugin renders it without starting or stopping it and ignores `callbacks`, blockers, `scripts`, and `tokens`. |
| `prefetch`, `initialRecords` | Pre-resolved policy and stored records for the first render. Plain Vue provides no server helper to generate these. |

## Verify

Open the app with the Network tab open. `hosted()` requests `/v1/consent/init`,
`manifest()` with a build snapshot sends no policy request unless location is
required, and `manifest({ source: 'runtime' })` requests
`${projectUrl}/v1/consent/manifest`. After accepting or rejecting, confirm an `inth`
cookie appears in the Application panel.
