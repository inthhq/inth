Serve consent banner and dialog copy in each visitor's language and keep it
synced with your Vue app's locale switcher.

## Where the text comes from

Banner, dialog, and IAB text comes from the translations in your Inth project
and arrives with the resolved policy. Edit copy in Inth rather than in Vue
code; `inth` has no message override option.

See [copy and translations](/docs/customization/translations) for message keys
and guidance on button labels.

## How Inth picks the language

By default, the browser's language decides:

- With `hosted()`, the browser sends `Accept-Language` on the `/v1/consent/init` request.
- With `manifest()`, Inth reads `navigator.language` and resolves copy from
  the manifest. The bundle includes English base copy and loads other
  languages on demand from your site so visitors download only their own
  language.

When your project has no translation for the visitor's language, the policy's
fallback language applies. Right-to-left languages such as Arabic and Hebrew
render with `dir="rtl"` while keeping the banner in the same corner.

## Follow your site's language

Bind `InthProvider`'s `language` prop to your app's current locale. When the
prop changes, `InthProvider` stores the locale and re-resolves the policy to
load text in that language:

{/* example: fragment */}

```vue
<InthProvider :language="locale" />
```

Without `InthProvider`, assign the locale to `useConsentLanguage()`. Assigning
a new language fetches updated copy; assigning the current language does
nothing:

The assignment alone fetches the new copy. The extra `kernel.commands.init()`
call in the snippet repeats the request and is not required.

## Text that does not come from translations

`ConsentDialogLink` and the `ConsentGate` placeholder read their defaults from
translations (English until init finishes). One Vue option must be localized
in code when your site supports multiple languages:

| Text | Where | How to change it |
| --- | --- | --- |
| "Open privacy settings" | `ConsentDialogTrigger` label | Set `triggerAriaLabel` in `inth` options. |

## Verify

Set your browser's preferred language to a translated locale, open the app in
a private window, and confirm the banner displays that language. Change the
locale in your app switcher and confirm banner and dialog copy updates without
a page reload.
