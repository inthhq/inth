## Where the text comes from

The banner, dialog and IAB text comes from the translations in your Inth
project. The backend sends the
text for the visitor's language with the policy. Edit copy there, not in your
Vue code. The Vue plugin has no option for message overrides.

[Copy and translations](/docs/customization/translations) lists the message
keys and how to write labels that describe each action.

## How Inth picks the language

By default the browser's own language decides. With `hosted()`, the browser
sends it as `Accept-Language` with the policy request to `/init`. With
`manifest()`, Inth reads `navigator.language` and resolves the text from the
manifest. When your project has no text for that language, the policy's
fallback language applies.

`manifest()` bundles English base copy only. When a visitor resolves to
another language, the browser loads that language's base copy from your site
the first time it is needed. Each visitor downloads their own language only,
and English visitors download no extra copy.

The text direction follows the resolved language. Arabic, Hebrew and other
right-to-left languages render the banner and dialog with `dir="rtl"`. The
banner stays in the same corner.

## Follow your site's language

Bind the `language` prop of `ConsentRoot` to your site's current language.
When the prop changes, `ConsentRoot` stores the language and resolves the
policy again, which fetches the text in that language:

{/* example: fragment */}

```vue
<ConsentRoot :language="locale" />
```

Without `ConsentRoot`, assign the language to `useConsentLanguage()`. A new
language runs init again, which fetches the banner and dialog text in that
language. Assigning the current language does nothing:

The assignment alone loads the new text. The example's extra
`kernel.commands.init()` call repeats the request and is not needed.

## Trigger labels

`ConsentDialogLink`, the `ConsentGate` placeholder and `ConsentDialogTrigger`
read their default text from the translations, in English until init has
delivered copy. The trigger's accessible name is `trigger.label`; the
`triggerAriaLabel` option overrides it in every language.

## Verify

Set your browser's preferred language to one your project translates, open
the app in a private window and confirm the banner uses it. Switch the
language with your switcher and confirm the banner and dialog text change
without a page reload.
