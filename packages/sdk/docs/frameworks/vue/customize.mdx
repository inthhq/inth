Customize the Inth banner and preference dialog in Vue by passing theme
tokens, layout options, and component part attributes to `inth`.

## Pick the right option

| You want to change | Use |
| --- | --- |
| Colors, fonts, radius, spacing, or motion | `tokens` |
| Banner shape, position, button order, or blocking | `presentation` |
| Classes or attributes on a component part | `components` |
| Light or dark palette | `colorScheme` and `theme.dark` |
| Banner and dialog text | Your Inth project's translations |
| Full markup | [Headless](/docs/frameworks/vue/headless) |

Pass these options to `app.use(inth, ...)`. See
[customize the interface](/docs/customization/overview) for cross-framework
concepts and [banner designs](/docs/customization/recipes) for five ready-made
designs with Vue code.

## Set theme tokens

`tokens` configures Inth's CSS variables using variable names without the
leading `--`. See [theme tokens](/docs/customization/tokens) for the full
list.

`inth` writes every token, including defaults, into a
`<style id="inth-css-vars">` element in `document.head` before the first
render. Because a `:root` rule in your own CSS can lose on stylesheet order,
set values through `tokens` instead. `defineTheme` from `@inth/vue/vue-plugin`
only types a theme object; it does not apply styles on its own.

## Change the banner layout

`presentation.prompt` configures the banner's `container`, `edgeStyle`,
`blockUntilChoice`, `layout`, `primaryActions`, `direction`, and `uiProfile`.
`presentation.preferences` sets the layout options for the dialog.

`container` is a Card (`position`: `start`, `end`, or `center`), a Banner
(`edge`: `bottom` or `top`), or a Drawer (`side`: `bottom`, `top`, `start`,
or `end`). `start` and `end` follow the writing direction. A policy rule's
`surface.container` applies when you set none. The policy always has final
authority: a centred Card always blocks, a notice never blocks, and the
policy restores required buttons omitted from `layout`.

[`ConsentBanner`](/docs/frameworks/vue/components/consent-banner#props) also
accepts `container`, `edgeStyle`, and `blockUntilChoice` props when composed
directly.

## Style one part of a component

`components` binds Vue attributes such as `class` and `style` (using `v-bind`,
not React's `className`) to named
[component parts](/docs/customization/slots). Style the `ConsentGate`
placeholder through `components['consent-gate'].root`, `.title`, and
`.button`. See [Tailwind CSS](/docs/customization/tailwind) and
[class names and CSS-in-JS](/docs/customization/class-names).

## Turn on dark mode

Set `colorScheme` in `inth` to `'light'`, `'dark'`, `'system'`, or leave it
unset to follow a `dark` class on `<html>`. Inth ships a built-in dark
palette, so a `dark` class turns the banner dark automatically. Pass `theme`
(including `theme.dark`) to override tokens per scheme; `theme` takes
precedence over `tokens` where both define a variable. See
[dark mode](/docs/customization/dark-mode).

## Change the copy

Edit banner and dialog text in your Inth project's translations. Add links to
legal pages with `legalLinks` and `bannerLegalLinks`:

{/* example: fragment */}

```ts title="src/main.ts"
app.use(inth, {
	bannerLegalLinks: ['privacyPolicy'],
	legalLinks: { privacyPolicy: { href: '/privacy' } },
	mode: hosted(),
	scripts,
});
```

See [translations](/docs/frameworks/vue/translations) and
[copy and translations](/docs/customization/translations).

## Other display options

| Option | What it does |
| --- | --- |
| `showTrigger` | Renders the floating [`ConsentDialogTrigger`](/docs/frameworks/vue/components/consent-dialog-trigger) from `InthProvider`. |
| `triggerDefaultPosition`, `triggerSize`, `triggerIcon`, `triggerShowWhen` | Positions and styles the floating trigger. |
| `hideBranding`, `bannerHideBranding`, `dialogHideBranding` | Hides the "Consent by" tag. |
| `disableAnimation` | Disables banner and dialog animations. See [motion and animation](/docs/customization/motion). |
| `consentCategories` | Limits categories shown in preferences within the policy's scope. |

## Check the result

Run `vite` and open the app in a private window. Inspect `<head>` in Elements
and confirm `<style id="inth-css-vars">` contains your token values.
