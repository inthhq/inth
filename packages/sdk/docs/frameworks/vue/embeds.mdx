Hold back third-party iframes in Vue until the visitor allows their consent
category, using either `ConsentGate` or the built-in iframe blocker.

## Pick a method

| Method | Use it when |
| --- | --- |
| `ConsentGate` | You render the iframe in a Vue component and want a placeholder with a button to open preferences. |
| Iframe blocker | The iframe comes from raw HTML such as CMS content, or you want no wrapper component. |

Both approaches omit the iframe's `src` until permission is granted, so the
embed host receives no requests before consent.

## Gate an embed with ConsentGate

Wrap the iframe in [`ConsentGate`](/docs/frameworks/vue/components/consent-gate)
from `@inth/vue/vue-plugin`:

<include src="../../shared/examples/vue/embed.mdx" />

The iframe stays out of the DOM until the visitor allows `measurement`. Until
then, the `placeholder` slot displays a message and a
[`ConsentDialogLink`](/docs/frameworks/vue/components/consent-dialog-link).
When the visitor withdraws `measurement`, Vue removes the iframe.

Match the category to what the embed does: use `measurement` for YouTube's
player, or `functionality` or `experience` for maps and chat widgets.

## Gate an iframe with the iframe blocker

`inth` enables the iframe blocker by default. Replace `src` with `data-src`
and add `data-category`:

{/* example: fragment */}

```vue title="src/MapEmbed.vue"
<template>
	<iframe
		data-src="https://www.google.com/maps/embed?pb=YOUR_EMBED_ID"
		data-category="functionality"
		title="Store map"
	/>
</template>
```

Inth copies `data-src` to `src` when the category is allowed and clears it on
revocation. It observes DOM mutations, so iframes added after route navigation
are gated too. While blocked, the empty `<iframe>` element stays in the DOM.
Add `data-vendor` with a vendor ID to also block the iframe when that vendor
is switched off.

Pass `iframeBlocker: false` to `inth` to disable the blocker.

## Verify

Open the page in a private window with the Network tab open under an opt-in
policy. Confirm no requests go to `youtube-nocookie.com` or `google.com/maps`.
Allow the category and save to load the iframe, then withdraw it and save to
confirm the page reloads without the embed. See the
[YouTube](/docs/integrations/youtube) and
[Google Maps](/docs/integrations/google-maps) guides for sizing and titles.
