## Import the IAB dialog when you compose surfaces

`InthProvider` lazy-loads `IABConsentDialog` automatically when `iab` is
enabled, the visitor matches an IAB policy, and preferences open. Import it
from `@inth/vue/vue-plugin` only when composing surfaces yourself:
