Import `IABConsentBanner` directly only when every policy on your site uses
IAB TCF and you compose surfaces yourself instead of mounting `InthProvider`.

## Import the IAB banner in place of `InthProvider`

`InthProvider` renders `IABConsentBanner` automatically when `iab` is set and
the visitor matches an IAB policy. To compose it directly, import it from
`@inth/vue/vue-plugin`:

<include src="../../../shared/examples/vue/iab-surfaces.mdx" />

Mount this in place of `InthProvider` and enable `iab` in `inth` (see
[IAB TCF](/docs/frameworks/vue/iab)). Visitors under non-IAB policies see
nothing from these components. If `iab` is unset, an IAB policy throws
`IABUnavailableError`.
