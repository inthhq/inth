Mount `ConsentDevTools` in development to inspect live consent state, matched
policies, script status, and events without shipping debug code to production.

## Load DevTools only in development

Dynamically import `ConsentDevTools` from `@inth/vue/devtools` behind
`import.meta.env.DEV`:

<include src="../../../shared/examples/vue/devtools.mdx" />

Render this component inside the app that installed
[the inth plugin](/docs/frameworks/vue/plugin). Because
`import.meta.env.DEV` evaluates to `false` in production builds, Vite strips
the dynamic import and panel completely. A static import ships DevTools to
visitors even if hidden with `v-if`.

## Verify

Run `vite`, click the DevTools launcher, and open the Policy tab to inspect
the matched policy. Then run `vite build` and `vite preview` and confirm the
DevTools button is absent.
