Import `ConsentBanner` directly when composing surfaces yourself instead of
using `InthProvider`.

## Import the banner into your root component

`InthProvider` already renders `ConsentBanner`. Import it from
`@inth/vue/vue-plugin` only when you want to set its variant in the template
or manage surface placement yourself:

<include src="../../../shared/examples/vue/consent-surfaces.mdx" />

Mount this in `src/App.vue` instead of `InthProvider`, alongside
`ConsentManager` so Customize opens the dialog. Statically importing
`ConsentManager` includes it in your main bundle, whereas `InthProvider`
code-splits it. Direct composition does not switch to IAB surfaces under an
IAB policy. `inth` still injects your `tokens`.

<import src="../../../shared/vue/components/consent-banner.mdx#behavior" />

<import src="../../../shared/vue/components/consent-banner.mdx#props" />

To configure the banner variant globally without importing `ConsentBanner`,
set `presentation.prompt` in `inth`. See
[change the banner layout](/docs/frameworks/vue/customize#change-the-banner-layout).
