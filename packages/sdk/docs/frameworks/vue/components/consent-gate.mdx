Wrap third-party embeds in `ConsentGate` so they stay out of the DOM until the
visitor allows their consent category.

## Import `ConsentGate` and wrap an embed

Import `ConsentGate` from `@inth/vue/vue-plugin`, put your embed in the
default slot, and add an optional `placeholder` slot:

<include src="../../../shared/examples/vue/embed.mdx" />

The iframe stays absent until `measurement` is granted. The placeholder uses
`ConsentDialogLink` so visitors can open preferences right from the embed
spot.

<import src="../../../shared/vue/components/consent-gate.mdx#props" />

## Verify

Open the page in a private window with the Network tab open. Confirm the
placeholder renders with zero requests to the embed host. Allow the category
and save to load the iframe, then withdraw it and save to confirm the page
reloads without the embed.
