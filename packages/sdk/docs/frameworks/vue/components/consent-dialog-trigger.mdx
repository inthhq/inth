Enable a persistent floating button in Vue so visitors can reopen privacy
preferences from any page.

## Turn on the trigger in the plugin options

Enable `showTrigger` in `inth` so `InthProvider` renders the trigger
automatically:

{/* example: fragment */}

```ts title="src/main.ts"
app.use(inth, {
	mode: hosted(),
	scripts,
	showTrigger: true,
	triggerDefaultPosition: 'bottom-left',
});
```

If you compose surfaces without `InthProvider`, import `ConsentDialogTrigger`
from `@inth/vue/vue-plugin` and render it directly:
