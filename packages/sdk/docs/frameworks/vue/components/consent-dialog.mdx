Render `ConsentDialog` when composing consent surfaces yourself, or open it
programmatically via `useConsentActiveUI()`.

## Import the dialog when you compose surfaces

`InthProvider` already mounts `ConsentDialog` when preferences open. Import it
from `@inth/vue/vue-plugin` only when composing surfaces in place of
`InthProvider`:

<include src="../../../shared/examples/vue/consent-surfaces.mdx" />

## Open the dialog from your code

Set `activeUI` to `'dialog'` using `useConsentActiveUI()` from
`@inth/vue/vue-plugin`:

{/* example: fragment */}

```ts
const activeUI = useConsentActiveUI();
activeUI.value = 'dialog';
```

For a footer button that automatically hides when the policy offers no
preferences, use
[ConsentDialogLink](/docs/frameworks/vue/components/consent-dialog-link).
