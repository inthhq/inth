## Declare the vendors

Declaring at least one vendor turns on per-vendor switches. Built-in
`@inth/integrations` helpers then appear automatically by name, so you only
declare vendors for custom scripts or to override a helper's name or privacy
policy URL.

Declare vendors alongside your scripts in `src/scripts.ts`, matching each
script's `vendor` slug:

{/* example: fragment */}

```ts title="src/scripts.ts (partial)"
import type { Vendor } from '@inth/vue';

export const vendors: Vendor[] = [
	{
		id: 'x-pixel',
		name: 'X Pixel',
		category: 'marketing',
		privacyPolicyUrl: 'https://x.com/privacy',
	},
];
```

Pass `vendors` to `inth` in `src/main.ts`:

{/* example: fragment */}

```ts title="src/main.ts (partial)"
import { scripts, vendors } from './scripts';

createApp(App).use(inth, { mode: hosted(), scripts, vendors }).mount('#app');
```

## What the preference dialog shows

`ConsentDialog` (rendered by `InthProvider`) and `ConsentWidget` list each
declared vendor under its category with its own switch.

## Build your own vendor switch

`useConsentDraft()` from `@inth/vue/vue-plugin` manages category and vendor
switches for a custom preference form. Read `vendors`, update a switch with
`setVendor(id, granted)`, and call `save()`:

{/* example: fragment */}

```vue title="src/components/x-pixel-switch.vue (partial)"
<script setup lang="ts">
import { useConsentDraft } from '@inth/vue/vue-plugin';

const { vendors, setVendor, save } = useConsentDraft();
</script>

<template>
	<input
		type="checkbox"
		:checked="vendors['x-pixel'] ?? true"
		@change="setVendor('x-pixel', ($event.target as HTMLInputElement).checked)"
	/>
	<button type="button" @click="save()">Save</button>
</template>
```

`save()` resolves `{ ok: false }` without saving while `isStale` is `true`.
See [composables](/docs/frameworks/vue/composables) for the full draft API.

## Check whether a vendor may run

`useVendorAllowed(id)` from `@inth/vue/vue-plugin` returns a computed boolean
that is `true` when the vendor is declared, its category is allowed, and the
visitor has not switched it off:

{/* example: fragment */}

```vue title="src/components/x-pixel-status.vue (partial)"
<script setup lang="ts">
import { useVendorAllowed } from '@inth/vue/vue-plugin';

const xPixelAllowed = useVendorAllowed('x-pixel');
</script>
```
