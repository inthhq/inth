Delete cookies and storage keys left behind by a vendor when its category is
denied, using `clearOnRevocation` in `inth`.

## Configure cleanup

Script gating stops new requests, not cookies or storage keys a vendor already
wrote. List the keys each optional category owns in `src/main.ts` so Inth
removes them when that category is denied:

{/* example: fragment */}

```ts title="src/main.ts (partial)"
createApp(App)
	.use(inth, {
		mode: hosted(),
		scripts,
		clearOnRevocation: {
			measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
			marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
		},
	})
	.mount('#app');
```

The plugin reads `clearOnRevocation` once on mount.
