## What GPP does

With `gpp` set, the `inth()` integration installs `window.__gpp`, the GPP 1.1 CMP API, when the page boots and keeps its GPP string in step with the visitor's choices. Prebid.js, Google Ad Manager, and other ad tech read US privacy signals from it.

## Turn on GPP

Add `gpp` to the integration options from the [quickstart](/docs/frameworks/astro/quickstart):

{/* example: fragment */}

```js title="astro.config.mjs (partial)"
inth({ gpp: true });
```

`gpp: true` uses the defaults. Pass an object to change them, such as `gpp: { usFallback: 'none' }`. The [GPP options](#gpp-options) table lists each field. All of them are plain data, so they belong in `inth({ ... })`, not in `clientEntrypoint`.

`@inth/astro` includes the GPP code. The browser loads it only when `gpp` is set, so sites without GPP download none of it.

The GPP string follows the policy and location Inth resolves for the visitor. With `manifest()`, the server reads a US visitor's state from the request's geography headers; see [Geography headers](/docs/frameworks/astro/geography-headers) to confirm your host sends them. With `hosted()`, Inth's `/v1/consent/init` resolves it.

The `tcfeuv2` section also needs IAB TCF. Set `iab` as described in [IAB TCF](/docs/frameworks/astro/iab).

GPP stays off when a `consentSource` from `clientEntrypoint` owns consent decisions.
