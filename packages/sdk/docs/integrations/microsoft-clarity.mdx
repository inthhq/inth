The `clarity` helper keeps Microsoft Clarity off the page until `measurement` consent is granted, then sends `clarity('consentv2', ...)` signals mapped from `measurement` and `marketing`. On withdrawal, Clarity stays on the page with `analytics_Storage: 'denied'`, and Inth reloads the page by default.

## Configure Microsoft Clarity

Copy the project ID that follows `https://www.clarity.ms/tag/` in your Clarity snippet, then remove the original snippet from your app so Clarity loads only through Inth.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `id` | Required | Clarity project ID, trimmed automatically. Without `scriptUrl`, an empty ID logs an error and skips loading. |
| `defaultConsent` | Inth state | Consent V2 value queued once before load. `true` or `false` sets both channels; an object sets `ad_Storage` or `analytics_Storage`, or aliases `marketing` and `measurement`, with omitted channels following Inth. Later updates always follow Inth. Setting `true` grants ad storage even while `marketing` is denied. |
| `scriptUrl` | `https://www.clarity.ms/tag/<id>` | Loader URL override. |

## Loading and revocation

`clarity` gates on the `measurement` category. Before the loader runs, the helper queues `clarity('consentv2', ...)` with `analytics_Storage` from `measurement` and `ad_Storage` from `marketing`. While Clarity is mounted, every permission change sends a new `consentv2` call, so granting `marketing` later enables `ad_Storage` without reloading Clarity.

On `measurement` withdrawal, the helper keeps Clarity mounted and sends `consentv2` with `analytics_Storage: 'denied'`. Re-allowing `measurement` before reload sends `granted`. Turning off the `microsoft-clarity` vendor denies both channels. Denied storage limits what Clarity stores rather than blocking all requests. See Microsoft's [Consent V2 API](https://learn.microsoft.com/en-us/clarity/setup-and-installation/clarity-consent-api-v2).

## Verify Microsoft Clarity

Allow only `marketing` first and confirm Clarity does not load. Then allow `measurement` and confirm `www.clarity.ms/tag/<id>` loads without a page reload.
