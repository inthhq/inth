The bundled Adjust helper in `InthApple`, `inth-android`, and `@inth/react-native/integrations` keeps Adjust disabled until the visitor grants its category, `marketing` by default, then enables Adjust and sends [third-party sharing](https://dev.adjust.com/en/sdk/android/features/privacy) with Google's `google_dma` options. Your app installs Adjust separately. There is no web helper.

## What the helper changes

| Consent | Adjust calls |
| --- | --- |
| Category denied or pending | `disable()` |
| Category granted | `enable()` once per grant, then third-party sharing |
| Marketing changes while category stays granted | Third-party sharing only |

Adjust sends nothing while disabled, drops calls made while disabled, and persists the disabled state across launches. The helper enables Adjust before sending sharing and skips sharing on withdrawal.

DMA values come from the [Consent Mode mapping](/docs/integrations/google-tag#how-categories-map-to-google-consent-types):

| Third-party sharing field | Source |
| --- | --- |
| Sharing enabled | `adUserData` |
| `google_dma` `eea` | Your app |
| `google_dma` `ad_personalization` | `adPersonalization` |
| `google_dma` `ad_user_data` | `adUserData` |

Supply `eea` from your own region logic because Inth's policy model controls how you prompt, not where the user is located. Send `"1"` only for EEA users.

## Before you start

Complete the [Swift](/docs/frameworks/swift/quickstart), [Android](/docs/frameworks/android/quickstart), or [React Native](/docs/frameworks/react-native/quickstart) quickstart and add `marketing` to your Inth policy and native config. Install Adjust SDK v5 using its [iOS](https://dev.adjust.com/en/sdk/ios/features/privacy), [Android](https://dev.adjust.com/en/sdk/android/features/privacy), or [React Native](https://dev.adjust.com/en/sdk/react-native/features/privacy) guide.

Connect the helper **before** `Adjust.initSdk`. Adjust queues pre-init `disable`, `enable`, and third-party sharing calls and applies them at startup so the first session follows consent.

## Connect a Swift app

```swift title="AdjustConsentOwner.swift"
import AdjustSdk
import InthApple
import InthCore

final class AdjustConsentOwner {
    private let integration: AdjustIntegration

    init(core: ConsentCore, inEEA: Bool) {
        integration = AdjustIntegration(
            core: core,
            enable: { Adjust.enable() },
            disable: { Adjust.disable() },
            trackThirdPartySharing: { consent in
                guard let sharing = ADJThirdPartySharing(isEnabled: NSNumber(value: consent.adUserData)) else { return }
                sharing.addGranularOption("google_dma", key: "eea", value: inEEA ? "1" : "0")
                sharing.addGranularOption("google_dma", key: "ad_personalization", value: consent.adPersonalization ? "1" : "0")
                sharing.addGranularOption("google_dma", key: "ad_user_data", value: consent.adUserData ? "1" : "0")
                Adjust.trackThirdPartySharing(sharing)
            }
        )
    }

    func stop() { integration.cancel() }
    func syncAfterReset() { integration.sync() }
}
```

Create and retain the owner for the app lifetime before calling `Adjust.initSdk`.

## Connect an Android app

```kotlin title="AdjustConsent.kt"
import com.adjust.sdk.Adjust
import com.adjust.sdk.AdjustThirdPartySharing
import com.inth.android.integrations.AdjustIntegration
import com.inth.core.Inth

fun connectAdjustConsent(inEea: Boolean, onError: (Exception) -> Unit): AdjustIntegration {
	val core = checkNotNull(Inth.current) { "Install Inth before connecting Adjust" }
	val flag = { granted: Boolean -> if (granted) "1" else "0" }
	return AdjustIntegration(
		core = core,
		enable = Adjust::enable,
		disable = Adjust::disable,
		trackThirdPartySharing = { consent ->
			val sharing = AdjustThirdPartySharing(consent.adUserData)
			sharing.addGranularOption("google_dma", "eea", flag(inEea))
			sharing.addGranularOption("google_dma", "ad_personalization", flag(consent.adPersonalization))
			sharing.addGranularOption("google_dma", "ad_user_data", flag(consent.adUserData))
			Adjust.trackThirdPartySharing(sharing)
		},
		onError = onError,
	)
}
```

Call this in `Application.onCreate` before `Adjust.initSdk(config)` and retain the returned helper on the `Application`.

Wrap `react-native-adjust` in `adjust-vendor.ts`:

```ts title="adjust-vendor.ts"
import { Adjust, AdjustThirdPartySharing } from 'react-native-adjust';

import { connectAppAdjust } from './adjust-consent';

const flag = (granted: boolean) => (granted ? '1' : '0');

export const connectAdjustVendor = (
	inEea: boolean,
	onError: (error: unknown) => void
) =>
	connectAppAdjust(
		{
			disable: () => Adjust.disable(),
			enable: () => Adjust.enable(),
			trackThirdPartySharing: ({ adUserData, adPersonalization }) => {
				const sharing = new AdjustThirdPartySharing(adUserData);
				sharing.addGranularOption('google_dma', 'eea', flag(inEea));
				sharing.addGranularOption(
					'google_dma',
					'ad_personalization',
					flag(adPersonalization)
				);
				sharing.addGranularOption(
					'google_dma',
					'ad_user_data',
					flag(adUserData)
				);
				Adjust.trackThirdPartySharing(sharing);
			},
		},
		onError
	);
```

Call this before `Adjust.initSdk`. Because JavaScript runs after native startup, Adjust relies on its persisted disabled state from prior launches until JS connects. Expo requires a custom native build, not Expo Go.

## Handle reset and teardown

Call `syncAfterReset()` on Swift, `sync()` on Android, or `await adjustConsent.sync()` on React Native to re-enable Adjust when allowed and resend third-party sharing. Calling `stop()`, `close()`, or `disconnect()` disables Adjust without deleting data. For permanent erasure, call Adjust's `gdprForgetMe`.

## Check the integration

1. Launch with no saved choice. Confirm `Adjust.isEnabled` returns `false` and no session reaches Adjust.
2. Grant `marketing`. Confirm a third-party sharing package with `google_dma` values set to `1`, followed by session requests.
3. Withdraw `marketing`. Confirm Adjust disables and sends nothing further.
4. Relaunch after withdrawal. Confirm Adjust starts disabled.

Checked against `react-native-adjust` `5.8.1`, `adjust-android` `5.8.1`, and Adjust iOS `5.8.1`. Complete [mobile verification](/docs/guides/mobile-verify) on real devices.
