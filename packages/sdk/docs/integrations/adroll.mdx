The `adrollPixel` helper blocks AdRoll until the visitor grants `marketing` consent, then sets AdRoll globals, queues one `pageView`, and loads the v2 pixel. AdRoll has no stop API, so Inth leaves the loader mounted on withdrawal and removes it with the default page reload.

## Configure AdRoll

Copy your advertiser ID and pixel ID from **Analytics > Insights > Website > View Pixel**. Under **Settings > Data Collection > Visitor Consent**, select **Use your existing Consent Banner** so AdRoll does not display its own banner. AdRoll's existing-banner instructions expect affirmative consent, so use an opt-in policy where required. Remove direct pixel snippets and tag-manager copies so they cannot bypass Inth.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `advertiserId` | Required | Public advertiser ID from the v2 snippet. Trimmed and URL-encoded into the loader path. Missing or blank values log an error and skip loading. |
| `pixelId` | Required | Public pixel ID from the v2 snippet. Trimmed. Missing or blank values log an error and skip loading. |
| `scriptUrl` | `https://s.adroll.com/j/<advertiserId>/roundtrip.js` | Account-specific v2 loader URL override. Blank values use the default. |

## Loading and revocation

On `marketing` grant, Inth sets `adroll_adv_id`, `adroll_pix_id`, `adroll_version`, and `__adroll_loaded`, creates the `window.adroll` array queue with `setProperties`, `identify`, and `track` stubs while preserving existing `window.adroll` methods, calls `track('pageView')` once, and appends the async v2 loader. Do not replace it with `https://s.adroll.com/j/roundtrip.js`, which is the legacy v1 loader.

The helper runs only in the browser script loader, never in SSR HTML, and sends no email or identity data. Guard your own AdRoll API calls on current `marketing` and vendor permission.

On withdrawal, Inth sends no command and leaves the loader element in the DOM. Keep `reloadOnConsentRevoked` enabled so loaded code, partner pixels, and timers stop. Regranting before reload reuses the loader without sending a second `pageView`.

## Cookies and storage

NextRoll's privacy notice lists `__adroll`, `__ar_v4`, `__adroll_shared`, and `__adroll_fpc` tracking cookies. The served pixel also writes consent cookies, localStorage keys such as `__adroll_consent_data`, sessionStorage keys such as `adroll_tpc` and `adroll_flgs`, and an `adroll` IndexedDB database. Account and partner settings can add more entries, and storage writes immediately on load.

## Verify AdRoll

In a fresh browser profile, filter Network by `adroll.com`:

1. Deny consent and allow an unrelated category. Confirm no requests, globals, cookies, Web Storage, or `adroll` IndexedDB appear.
2. Allow `marketing`. Confirm your account's v2 loader URL loads and fires a `pageView`.
3. Withdraw `marketing`. Confirm the page reloads and AdRoll stays blocked on the next page.
