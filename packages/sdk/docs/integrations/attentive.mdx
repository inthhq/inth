The `attentiveTag` helper blocks Attentive signup units and on-site tracking until the visitor grants `marketing` consent. Attentive has no documented API to stop a running tag, so Inth relies on its default page reload on withdrawal.

## Configure Attentive

Copy the site slug from your Attentive tag URL at `https://cdn.attn.tv/<siteSlug>/dtag.js` and remove any direct tag snippet from your site.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `siteSlug` | Required | Site slug from the tag URL. Trimmed, and must contain only ASCII letters, digits, `_`, and `-`. URLs, paths, or blank values log an error and never load even when `scriptUrl` is set. |
| `category` | `'marketing'` | Consent condition for the loader. |
| `scriptUrl` | `https://cdn.attn.tv/<siteSlug>/dtag.js` | Exact tag URL from Attentive or your proxy. Blank values use the default. |

## Loading and revocation

On `marketing` grant, Inth appends `dtag.js` at the end of `document.body` without creating globals or queues. Attentive then downloads its own bundles, creates iframes, shows signup units, and tracks events.

On withdrawal, Inth leaves the script element in the DOM and reuses it if the visitor regrants `marketing` before reload. Keep `reloadOnConsentRevoked` enabled because removing the tag cannot unload running code, cancel requests, or clear iframes, and the helper avoids Attentive's undocumented enable and disable methods. The reloaded page does not load Attentive while denied.

## Cookies and storage

Attentive sets `_attn_`, `__attentive_id` with up to 390 days retention, `__attentive_dv`, `__attentive_ss_referrer`, `__attentive_pv`, `__attentive_cco`, `attntv_mstore_email`, `attntv_mstore_phone`, `__attentive_ceid`, `__attentive_domain`, and `__attentive_client_user_id`. Reloading does not delete them. Inspect cookies and Web Storage in DevTools before configuring cleanup.

## Verify Attentive

Filter DevTools Network by `attn.tv` using your own Attentive account:

1. Before choosing and after allowing an unrelated category, confirm no `dtag.js` request, global, iframe, cookie, or Web Storage entry appears.
2. Allow `marketing` and confirm `dtag.js` and its child bundles load.
3. Withdraw `marketing` and confirm the reloaded page sends no Attentive requests.

Sources: [Attentive tag setup](https://help.attentive.com/hc/en-us/articles/10905920909460-The-Attentive-tag) and [Attentive cookies](https://help.attentive.com/hc/en-us/articles/14615673918484-Attentive-cookies).
