The `clay` helper blocks Clay web intent until the visitor grants `marketing` consent. Clay resolves visitor IP addresses to companies and can use device fingerprints and third-party identifiers for sales profiling.

## Configure Clay

Copy your `id` from **Settings > Web intent > JavaScript Snippet** in Clay and remove any direct Clay snippet or tag-manager copy so it cannot bypass Inth.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `siteId` | Required | Public ID from Clay's snippet. Trimmed and URL-encoded. Non-string, blank, or invalid IDs log an error and skip loading. |
| `scriptUrl` | `https://static.claydar.com/init.v1.js?id=<siteId>` | Proxy or pinned loader override. Keep the `id` query parameter because Clay reads `document.currentScript.src`. Blank values use the default. |

## Loading and revocation

On `marketing` grant, Inth appends the loader script element to `document.body`, which fetches `cdn.claydar.com/releases/latest/radar.min.js` and sends data to `api.claydar.com`. Allow those hosts in your Content Security Policy directives. `measurement` consent alone loads nothing, and Clay's own CMP detection does not cover Inth.

On load, the helper queues `giveCookieConsent`. On withdrawal, it calls `denyCookieConsent` when available. Both methods exist in the served tracker, though Clay does not document them. Denial moves identifiers from persistent storage to session storage without stopping requests, and removing the loader cannot unload the tracker or its child scripts. Keep `reloadOnConsentRevoked` enabled so Clay stops sending events on revocation.

## Cookies and storage

Clay sets `claydar_*` cookies and local storage entries, including a device ID cookie with a one-year lifetime, plus `radar_sn_*` session keys for fingerprints, `spotter_data` for company lookup, and a temporary `__sn_tld_probe` cookie. Account settings and vendor updates can change this list.

## Verify Clay

Filter DevTools Network by `claydar.com` using your own Clay site ID:

1. Deny consent and allow `measurement` only. Confirm no requests, `Claydar` global, or vendor storage appear.
2. Allow `marketing`. Confirm one `init.v1.js?id=<siteId>` loader and the tracker load.
3. Withdraw `marketing`. Confirm the page reloads and Clay stays blocked on the new page.
