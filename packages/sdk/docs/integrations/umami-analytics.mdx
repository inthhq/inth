The `umamiAnalytics` helper keeps the Umami tracker off the page until a visitor grants `measurement` consent. It sends no consent signal to Umami. On revocation, Inth removes the script element and reloads the page by default.

## Configure Umami Analytics

Copy the website ID from your Umami tracking code and remove any existing Umami script tag. If you run a custom Umami server, set `scriptUrl` to your instance's tracker script.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { umamiAnalytics } from '@inth/integrations/umami-analytics';

export const scripts = [umamiAnalytics({ websiteId: 'YOUR_WEBSITE_ID' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `websiteId` | Required | Set as `data-website-id`. Empty or whitespace-only values log an error and skip loading. |
| `hostUrl` | None | Ingestion host set as `data-host-url`. |
| `autoTrack` | None | `false` sets `data-auto-track="false"` and disables automatic tracking. |
| `domains` | None | Domains to track, set as `data-domains`. Pass a comma-separated string or an array; arrays join with commas. |
| `tag` | None | Tag attached to events, set as `data-tag`. |
| `beforeSend` | None | Name of a global function set as `data-before-send`. Function values are not supported. |
| `scriptUrl` | `https://cloud.umami.is/script.js` | Loader URL override. |

## Loading and revocation

`umamiAnalytics` gates on `measurement`. Although Umami sets no cookies, Inth waits for `measurement` permission before loading the script. On revocation, Inth removes the script element without calling an Umami API.

A `beforeSend` hook transforms events before Umami sends them and does not check consent. Define the named global before the tracker loads.

## Verify Umami Analytics

Allow `measurement` and confirm the tracker script loads with your `data-website-id` and sends a request to `/api/send` on Umami or your `hostUrl`. If your app calls `window.umami.track`, check `measurement` permission before each call.
