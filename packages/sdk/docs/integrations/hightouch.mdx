The `hightouch` helper keeps `window.htevents` undefined and `events.min.js` off the page until visitors grant `measurement` consent, then removes the loader and reloads the page on withdrawal.

## Configure Hightouch

Copy the write key from your Hightouch Event Source and remove any existing Hightouch snippet.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { hightouch } from '@inth/integrations/hightouch';

export const scripts = [hightouch({ writeKey: 'YOUR_WRITE_KEY' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `writeKey` | Required | Event Source write key passed to `htevents.load`. Trimmed automatically; blank values log an error and skip loading. |
| `apiHost` | None | Load-option API host override. Defaults to `us-east-1.hightouch-events.com` when omitted or blank. Set only for another region or a first-party tracking host. |
| `trackPageView` | `true` | Queues `htevents.page()` after `load`. Set `false` when your router sends page calls. |
| `scriptUrl` | `https://cdn.hightouch-events.com/browser/release/v1-latest/events.min.js` | Loader URL override. Blank values use the default. |

## Loading and revocation

`hightouch` gates on `measurement`. On grant, Inth creates the `window.htevents` queue with the snippet's methods, stores the write key and load options, queues `load` and optional `page`, and loads `events.min.js` to replay the queue.

On withdrawal, Inth removes the script element without calling a Hightouch API and reloads the page by default. Because an Event Source can forward events to downstream destinations, verify each destination's consent purpose in Hightouch too.

## Verify Hightouch

Filter DevTools Network by `hightouch`:

1. Allow `measurement` and confirm `events.min.js` loads and a page event reaches your API host.
2. Navigate between routes and confirm each route change sends one page event, not two.
3. Because `window.htevents` remains defined after revocation before reload, guard your own `htevents.track` calls on current `measurement` permission.
