The `liveIntentTag` helper waits for `marketing` consent before creating `window.liQ` and loading LiveIntent's LiveConnect tag. Because LiveConnect has no stop API, Inth keeps the loader element on withdrawal and relies on its default page reload to stop tracking.

## Configure LiveIntent

Copy the tag ID from your LiveConnect base tag as the filename without `.min.js`. Do not test with the public `a-00xx` example tag; it is live production code, not a sandbox. Remove any direct base tag and tag manager copy so LiveConnect loads only through Inth.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `tagId` | Required | Public tag ID, trimmed and URL-encoded into the filename. Missing or blank values log an error and skip loading. |
| `events` | None | Plain event objects such as `{ event: 'conversion', name: 'purchase' }`, queued once on first grant. Strings including `{{...}}` remain literal event data. |
| `scriptUrl` | `https://b-code.liadm.com/<tagId>.min.js` | Loader URL override. Blank values use the default. |

## Loading and revocation

`liveIntentTag` gates on the `marketing` category. When `marketing` is allowed, the helper creates `window.liQ` (or reuses an existing array), pushes any `events` in order, and inserts one async loader. Once loaded, LiveConnect replaces `window.liQ` with its own client.

For later events, pass a plain object to `window.liQ.push` only while `marketing` and vendor consent stay granted. Function queues and method-argument tuples do not match LiveConnect's event format.

Where GDPR, GPP, or legacy US privacy signals apply, Inth's `marketing` category does not replace a TC string. Confirm your account's production tag and TCF purpose requirements with LiveIntent. Zeta's guide lists purposes 1 to 4, while the public example bundle required extra purposes and special features; do not request extra purposes just to match the public example.

LiveIntent documents no stop or withdrawal command for the full runtime. On withdrawal, the helper leaves the loader element mounted and sends no withdrawal event. Keep `reloadOnConsentRevoked` enabled so existing clients, listeners, and sync frames stop. Re-granting consent on the same page reuses the loader without pushing `events` again.

## Cookies, storage, and CSP

LiveConnect writes `_lc2_fpi`, `_lc2_fpi_js`, `_li_dcdm_c`, `_li_ss`, and `lidids.*` cookies (requesting up to 730 days, which browsers can shorten), plus `_li_duid` and `_li_ss` in `localStorage`. Account and partner settings can add storage.

Main CSP hosts are `b-code.liadm.com`, `idx.liadm.com`, `rp.liadm.com`, `rpr.liadm.com`, and `i.liadm.com`.

## Verify LiveIntent

In a fresh profile, deny consent and allow only an unrelated category. Filter Network by `liadm.com` and confirm no requests, globals, cookies, `localStorage`, or `sessionStorage` entries appear. Grant `marketing` and check the loader URL against your base tag. Withdraw consent and confirm the page reloads with LiveIntent blocked in both Network and Application storage.
