The `logRocket` helper keeps LogRocket session replay off the page until `measurement` consent is granted, then loads `LogRocket.min.js` and calls `LogRocket.init`. On withdrawal, Inth removes the script element and reloads the page by default to stop recording.

## Configure LogRocket

Copy your app ID (`org-slug/app-slug`) from LogRocket Project Setup and remove any existing LogRocket installation.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { logRocket } from '@inth/integrations/logrocket';

export const scripts = [logRocket({ appId: 'your-org/your-app' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `appId` | Required | Trimmed and passed to `LogRocket.init`. Values that are not two non-empty segments separated by `/` log an error and skip loading. |
| `initOptions` | `{}` | Second argument to `LogRocket.init`. JSON-serializable values only, so functions such as request sanitizers cannot pass through. |
| `scriptUrl` | `https://cdn.logrocket.io/LogRocket.min.js` | Loader URL override. Blank values use the default. |
| `asyncScriptUrl` | None | Proxied URL for LogRocket's logger bundle, assigned to `window._lrAsyncScript` before the loader runs. Set only when proxying through your own domain. |

## Loading and revocation

`logRocket` gates on the `measurement` category. When `measurement` is allowed, the helper loads `LogRocket.min.js` with `crossorigin="anonymous"` and calls `LogRocket.init(appId, initOptions)` after load.

On withdrawal, the helper removes the script element without calling a LogRocket API because the web SDK documents no consent or stop-recording method. Recording continues until unload, so keep `reloadOnConsentRevoked` enabled. Configure LogRocket's privacy and sanitization settings before deploying so recordings omit sensitive DOM, input, and network data.

## Verify LogRocket

Filter DevTools Network by `logrocket`. After you allow `measurement`, confirm `LogRocket.min.js` loads and `window.LogRocket` exists. With `asyncScriptUrl`, verify the logger bundle loads from your proxy URL.
