The `adobeAnalytics` helper blocks your Adobe Data Collection Tags property until the visitor grants `measurement` consent. It sends no consent signal to Adobe, so every extension in the property runs under `measurement`. On withdrawal, Inth removes the script element and reloads the page by default.

## Configure Adobe Analytics

Copy the full embed URL for your property environment from Adobe Data Collection and remove the original embed snippet. Adobe has no shared loader keyed by account ID alone.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { adobeAnalytics } from '@inth/integrations/adobe-analytics';

export const scripts = [
	adobeAnalytics({
		scriptUrl:
			'https://assets.adobedtm.com/YOUR_ORG/YOUR_PROPERTY/launch-production.min.js',
	}),
];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `scriptUrl` | Required unless the IDs are set | Full `https:` embed URL for your Tags property environment. Custom-hosted embed URLs work. Trimmed automatically. Blank, invalid, or non-`https:` URLs log an error and skip loading. Wins over the IDs. |
| `companyId`, `propertyId`, `environmentId` | None | The parts of an Adobe-hosted embed URL, `https://assets.adobedtm.com/{companyId}/{propertyId}/launch-{environmentId}.min.js`. Set all three instead of `scriptUrl`; a remote integration uses these. |
| `async` | `true` | Loads the Tags library asynchronously. Set `false` only for legacy synchronous deployments. |
| `seedAdobeDataLayer` | `true` | Initializes `window.adobeDataLayer` to `[]` before loading when undefined. |

## Loading and revocation

`adobeAnalytics` gates on `measurement` and loads your property embed only while allowed. On withdrawal, Inth removes the script element without calling any Adobe API.

Because Inth controls only the embed loader, every extension enabled in the property, including Analytics and Web SDK, runs under `measurement`. If a rule loads an advertising or non-measurement tool, configure that rule in Adobe Tags to check your consent state too.

## Verify Adobe Analytics

Filter DevTools Network by your embed host, such as `assets.adobedtm.com`. Allow `measurement` and confirm your embed URL loads, `window._satellite` is defined, and extension requests fire only for measurement tools.
