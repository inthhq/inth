The `fathomAnalytics` helper keeps Fathom's `script.js` off the page until visitors grant `measurement` consent, then removes the loader and reloads the page on withdrawal.

## Configure Fathom Analytics

Copy the `data-site` value from your Fathom embed code. Pass `spa` if your app navigates client-side; otherwise Fathom's SPA tracking stays off.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { fathomAnalytics } from '@inth/integrations/fathom-analytics';

export const scripts = [fathomAnalytics({ site: 'YOUR_SITE_ID', spa: 'auto' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `site` | Required | Site ID written to `data-site`. Trimmed automatically; blank values log an error and skip loading. |
| `spa` | None | `'auto'`, `'history'`, or `'hash'`, written to `data-spa`. Omit it, or pass `'off'`, to leave SPA route tracking off. |
| `auto` | None | `false` sets `data-auto="false"` and stops automatic page views. `true` is Fathom's default and writes nothing. |
| `canonical` | None | `false` sets `data-canonical="false"` and tracks the page URL instead of the canonical URL. `true` is Fathom's default and writes nothing. |
| `honorDnt` | None | `true` sets `data-honor-dnt="true"` to honor Do Not Track. `false` is Fathom's default and writes nothing. |
| `scriptUrl` | `https://cdn.usefathom.com/script.js` | Loader URL override. Blank values use the default. |

## Loading and revocation

Although Fathom states it sets no cookies, `fathomAnalytics` still waits for `measurement` consent and loads `script.js` with `defer` once allowed. On withdrawal, Inth removes the script element without calling `window.fathom.blockTrackingForMe` and reloads the page by default.

## Verify Fathom Analytics

1. Allow `measurement` and confirm `cdn.usefathom.com/script.js` loads with your `data-site` and `data-spa` attributes.
2. Navigate between routes and confirm each change sends one page view, not two.
3. Guard your own `window.fathom?.trackEvent` calls on current `measurement` permission.
