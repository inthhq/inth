The `vercelAnalytics` helper keeps Vercel Web Analytics off the page and leaves `window.va` undefined until a visitor grants `measurement` consent. It sends no consent signal to Vercel. On revocation, Inth removes the script element and reloads the page by default.

## Configure Vercel Analytics

Enable Web Analytics for your project in Vercel, then remove any `Analytics` component or `inject()` call from `@vercel/analytics` so Inth loads the script once.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { vercelAnalytics } from '@inth/integrations/vercel-analytics';

export const scripts = [vercelAnalytics()];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `dsn` | None | Project DSN for deployments outside Vercel, set as `data-dsn`. |
| `disableAutoTrack` | None | `true` sets `data-disable-auto-track="1"` and disables automatic page views. |
| `mode` | None | `'development'` loads the debug script. `'auto'` and `'production'` load the production script. The helper does not detect your environment. |
| `debug` | None | `true` loads `https://va.vercel-scripts.com/v1/script.debug.js`. |
| `endpoint` | None | Custom ingestion endpoint set as `data-endpoint`. |
| `scriptUrl` | `https://va.vercel-scripts.com/v1/script.js` | Loader URL override. Takes precedence over `mode` and `debug`. |

The helper also sets `data-sdkn="inth"` on the script element.

## Loading and revocation

`vercelAnalytics` gates on `measurement`. On grant, the helper defines `window.vaq` and `window.va` if absent, then inserts the script. Calls queued in `window.vaq` before the script loads flush once it runs.

On revocation, Inth removes the script element without calling a Vercel API. Because `window.va` stays defined until reload, check `measurement` permission before sending custom events.

## Verify Vercel Analytics

Allow `measurement` and confirm `script.js` loads from `va.vercel-scripts.com` with `data-sdkn="inth"`, and each client-side navigation sends one page view. With `debug: true` or `mode: 'development'`, the helper loads `script.debug.js` instead, so verify your production configuration separately.
