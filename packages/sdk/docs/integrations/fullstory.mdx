The `fullStory` helper waits for `measurement` consent before creating FullStory globals or downloading the SDK, then calls `shutdown` and reloads the page on withdrawal.

## Configure FullStory

Copy your organization ID from FullStory setup and remove any existing FullStory snippet so no other installer creates `window.FS`. Regional IDs such as `o-ABC123-eu1` automatically select `eu1.fullstory.com` and `edge.eu1.fullstory.com/s/fs.js`; legacy IDs and `na1` use the US defaults.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `orgId` | Required | FullStory organization ID. Blank values log an error and skip loading. |
| `host` | Regional host | `fullstory.com` for US and legacy IDs; `eu1.fullstory.com` for EU IDs. |
| `script` | Regional edge | Script host and path without scheme, such as `edge.eu1.fullstory.com/s/fs.js`. |
| `elementConsent` | `false` | Syncs consent for elements marked capture-with-consent through `setIdentity`. |
| `category` | `'measurement'` | Consent condition for the entire loader. |
| `scriptUrl` | Derived HTTPS URL with `org` | Exact download URL override. Trimmed and kept unchanged without appending `org`. Blank values use the derived URL. |

Inth trims organization and endpoint values and treats blank overrides as unset. FullStory-owned `host` and `script` values adopt the organization's region, while custom proxy or Relay hosts stay unchanged. `host` and `script` resolve independently, and `scriptUrl` chooses only the downloaded file without changing the SDK's `script` environment value.

## Loading and revocation

Before consent, Inth creates no FullStory globals or requests. On grant, it creates FullStory's v2 callable queue with six-field command records so async calls such as `FS('getSessionAsync')` return promises before and after the dispatcher loads, configures `captureOnStartup: false`, and downloads the SDK.

- **Start, shutdown, and restart.** An uninterrupted allowed load calls `start`. If a visitor denies consent or your app removes the last registration before load completes, Inth calls `shutdown`. After any helper-issued `shutdown`, regranting or remounting calls `restart`, even if `start` never ran.
- **Shared registrations.** Equivalent effective `orgId`, `host`, `script`, and `scriptUrl` values share one download and recorder. Every active registration must permit the mapped consent before capture starts or resumes, including registrations that have not loaded yet. Removing a denying registration reapplies the remaining registrations' consent, including differing `elementConsent` flags. Removing the last registration shuts down capture; remounting the same config resumes with `restart` without redownloading.
- **Fixed settings per page.** Once bootstrap starts, changing effective `orgId`, `host`, `script`, or `scriptUrl` throws until a page reload because FullStory does not support replacing an initialized recorder in place.
- **Pending downloads.** Because removing an async script does not stop an in-flight download from executing, Inth retains the pending bootstrap so remounts reuse it instead of loading twice. Without `MutationObserver`, a setup interrupted before script insertion can require a reload; a nested synchronous mount still shares the retained recorder.
- **Keep `reloadOnConsentRevoked` enabled.** `shutdown` stops capture but does not erase cookies or unload FullStory. Capture state reapplies on each page load.

## Cookies and storage

FullStory can write `fs_uid` and `fs_cid` cookies for 1 year, `fs_lua` for 30 minutes, and `_fs_tab_id` in `sessionStorage`. Check your account settings for additional storage.

## Verify FullStory

1. Before consent and after granting an unrelated category, confirm no FullStory requests, `FS` global, config globals, cookies, or browser storage exist.
2. Grant `measurement` and confirm the v2 dispatcher installs and capture starts.
3. Revoke `measurement` and confirm capture shuts down, then regrant to confirm it restarts once.
