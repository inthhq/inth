The Meta App Events helper in `InthApple`, `inth-android`, and `@inth/react-native/integrations` enables Facebook SDK automatic App Events and advertiser ID collection only while consent allows them, and enables [Limited Data Use](https://developers.facebook.com/docs/app-events/guides/ccpa) otherwise. It defaults to `marketing` and adds no Meta dependency. For websites, use the [Meta Pixel helper](/docs/integrations/meta-pixel).

## What the helper changes

| Consent | Meta SDK settings, in order |
| --- | --- |
| Category denied or pending | Automatic App Events off, advertiser ID collection off, Limited Data Use on |
| Category granted | Limited Data Use off, advertiser ID collection on, automatic App Events on |

Limited Data Use passes country `0` and state `0`, so Meta applies it by user location for covered US states.

The helper does not set ATT. On iOS 17 and later, Meta SDK 17+ [reads ATT status itself](https://developers.facebook.com/documentation/app-events/guides/advertising-tracking-enabled). Request ATT separately from Inth consent.

## Before you start

Complete the [Swift](/docs/frameworks/swift/quickstart), [Android](/docs/frameworks/android/quickstart), or [React Native](/docs/frameworks/react-native/quickstart) quickstart with `marketing` in your Inth policy and native configuration. Install the Facebook SDK via Meta's [Android](https://developers.facebook.com/docs/app-events/getting-started-app-events-android/) or iOS guide, or `react-native-fbsdk-next` for React Native.

Disable both settings in your native build so nothing collects before Inth connects. On iOS, in `Info.plist`:

{/* example: fragment */}

```xml title="Info.plist"
<key>FacebookAutoLogAppEventsEnabled</key>
<false/>
<key>FacebookAdvertiserIDCollectionEnabled</key>
<false/>
```

On Android, inside the manifest's `application`:

{/* example: fragment */}

```xml title="AndroidManifest.xml"
<meta-data
	android:name="com.facebook.sdk.AutoLogAppEventsEnabled"
	android:value="false" />
<meta-data
	android:name="com.facebook.sdk.AdvertiserIDCollectionEnabled"
	android:value="false" />
```

To block every Meta request until consent, also set `com.facebook.sdk.AutoInitEnabled` to `false` and initialize the SDK yourself after the first grant, as Meta's [GDPR guide](https://developers.facebook.com/docs/app-events/gdpr-compliance/) describes. Because that initialization is one-way, the helper does not call it. If automatic event logging is off in Events Manager, Meta keeps it off even when the helper enables it.

## Connect a Swift app

```swift title="MetaAppEventsOwner.swift"
import InthApple
import InthCore
import FBSDKCoreKit

final class MetaAppEventsOwner {
    private let integration: MetaAppEventsIntegration

    init(core: ConsentCore) {
        integration = MetaAppEventsIntegration(
            core: core,
            setAutoLogAppEventsEnabled: { Settings.shared.isAutoLogAppEventsEnabled = $0 },
            setAdvertiserIDCollectionEnabled: { Settings.shared.isAdvertiserIDCollectionEnabled = $0 },
            setLimitedDataUse: { limited in
                if limited {
                    Settings.shared.setDataProcessingOptions(["LDU"], country: 0, state: 0)
                } else {
                    Settings.shared.setDataProcessingOptions([])
                }
            }
        )
    }

    func stop() { integration.cancel() }
    func syncAfterReset() { integration.sync() }
}
```

## Connect an Android app

```kotlin title="MetaAppEventsConsent.kt"
import com.inth.android.integrations.MetaAppEventsIntegration
import com.inth.core.Inth
import com.facebook.FacebookSdk

fun connectMetaAppEventsConsent(onError: (Exception) -> Unit): MetaAppEventsIntegration {
	val core = checkNotNull(Inth.current) { "Install Inth before connecting Meta" }
	return MetaAppEventsIntegration(
		core = core,
		setAutoLogAppEventsEnabled = FacebookSdk::setAutoLogAppEventsEnabled,
		setAdvertiserIDCollectionEnabled = FacebookSdk::setAdvertiserIDCollectionEnabled,
		setLimitedDataUse = { limited ->
			if (limited) FacebookSdk.setDataProcessingOptions(arrayOf("LDU"), 0, 0)
			else FacebookSdk.setDataProcessingOptions(arrayOf())
		},
		onError = onError,
	)
}
```

Retain the returned helper on your `Application`.

## Connect React Native or Expo

Copy the connection function into `meta-app-events-consent.ts`:

<include src="../shared/examples/react-native-bare/rn-meta-app-events-integration.mdx" />

Then pass `react-native-fbsdk-next`:

{/* example: fragment */}

```ts title="meta-vendor.ts"
import { Settings } from 'react-native-fbsdk-next';

import { connectAppMetaAppEvents } from './meta-app-events-consent';

export const connectMetaVendor = (onError: (error: unknown) => void) =>
	connectAppMetaAppEvents(
		{
			setAdvertiserIDCollectionEnabled: (enabled) =>
				Settings.setAdvertiserIDCollectionEnabled(enabled),
			setAutoLogAppEventsEnabled: (enabled) =>
				Settings.setAutoLogAppEventsEnabled(enabled),
			setLimitedDataUse: (limited) =>
				limited
					? Settings.setDataProcessingOptions(['LDU'], 0, 0)
					: Settings.setDataProcessingOptions([]),
		},
		onError
	);
```

Expo requires a development build with the `react-native-fbsdk-next` config plugin, not Expo Go.

## Events your app logs

The helper controls automatic events and identifiers. Guard events you log with `AppEventsLogger` or `AppEvents` on current consent yourself.

## Handle reset and teardown

Call `sync()` to reapply current consent after app code changes these settings. Teardown via `stop()`, `close()`, or `disconnect()` disables collection and enables Limited Data Use, without deleting data Meta already received.

On withdrawal, the helper runs all three calls even if one fails and reports failures to `onError`.

## Verify Meta App Events

1. Launch with no saved choice. Confirm no automatic `fb_mobile_activate_app` event and no advertiser ID appear in requests.
2. Grant `marketing`. Confirm automatic events start and Limited Data Use turns off.
3. Grant or withdraw `measurement` only. Confirm nothing changes.
4. Withdraw `marketing`. Confirm automatic events stop.

Use Meta's App Events debugging in Events Manager. Unit tests cover call order, withdrawal during a grant, and category changes with recorded calls rather than live Meta SDK runs.
