Gate Google Maps iframe embeds on consent with `ConsentGate` or `data-category` so the browser connects to Google only after permission.

## Configure the map

Inth does not ship a dedicated Google Maps helper. Copy your map's iframe embed URL and pick the consent category matching your use, such as `functionality` below:

```ts title="src/embed-config.ts"
export const embedCategory = 'functionality' as const;
export const embedURL =
	'https://www.google.com/maps/embed?pb=YOUR_EMBED_PARAMETERS';
export const embedTitle = 'Map showing our office location';
export const embedAspectRatio = '4 / 3';
```

Replace the placeholder URL with your full embed URL. Keep the street address and a directions link outside the gated iframe so visitors who decline consent can still find your location.

## Loading and revocation

Before consent, the browser makes no request to Google Maps. On withdrawal, `ConsentGate` removes the iframe, and the HTML blocker moves the URL back from `src` to `data-src`.

If your app uses the JavaScript Maps SDK instead of an iframe, register a category-gated script and handle widget cleanup yourself; this iframe pattern does not block an independently loaded Maps SDK.

## Verify before and after permission

1. In a private window with an opt-in policy, open DevTools Network and confirm no request goes to Google Maps.
2. Grant the configured category and confirm the map iframe mounts and loads.
3. Revoke the category and confirm the iframe returns to its blocked placeholder while the fallback address and directions link remain visible.
