The `amazonAdsTag` helper keeps Amazon Ads off the page until `marketing` consent is granted. Remove direct snippets and tag-manager copies so they cannot bypass Inth. When you pass a visitor `countryCode`, the helper also loads Amazon Consent Signal, ACS, and forwards ad storage and user data permissions.

Pass `countryCode` from your server or trusted geography source to enable ACS. Inth trims and uppercases it and never defaults to `US`. Omit `countryCode` if unknown to load only the main tag. `region` selects your Amazon Ads account region, not the visitor's country.

Amazon's [consent-signal requirements](https://advertising.amazon.com/en-gb/resources/ad-policy/consent-signal-requirements) require TCF, GPP, or ACS when sending personal data from EEA and UK users.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `tagId` | Required | Amazon Ads tag ID for `amzn('addTag', ...)`. Blank values log an error and load nothing. |
| `region` | `'NA'` | `'NA'` or `'EU'` for `amzn('setRegion', ...)`. `'NA'` covers North America, South America, Japan, and Australia. |
| `trackPageView` | `true` | Sends one initial `amzn('trackEvent', 'PageView', ...)`. Set `false` if your app sends it. |
| `pageViewAttributes` | `{}` | Initial PageView attributes such as `value`, `currencyCode`, or `clientDedupeId`. |
| `countryCode` | None | Visitor two-letter ISO 3166-1 code. Enables ACS; blank disables ACS. |
| `ipAddress` | None | Optional visitor IP passed to ACS when `countryCode` is set. |
| `gpp` | None | Existing IAB GPP string passed to ACS when `countryCode` is set. Not created or validated by Inth. |
| `scriptUrl` | `https://c.amazon-adsystem.com/aat/amzn.js` | Main loader URL override. Blank values use the default. |
| `consentScriptUrl` | `https://c.amazon-adsystem.com/aat/amzn-consent.js` | ACS loader URL override. Blank values use the default. |

The script defaults to `marketing`. Overriding `category` updates the permission forwarded to ACS too. `enableAdStorage` and `enableUserData` follow the script's effective permission and vendor switch together.

The helper does not set advanced matching data or create a TCF string. Use your IAB implementation when required; TCF takes priority over ACS when both are present.

## Loading and revocation

Before consent, Inth creates no `window.amzn`, `amzn.q`, or `amznConsent`, loads neither script, and writes no storage.

On grant, Inth preserves any existing `amzn` function or creates Amazon's `[arguments, Date.now()]` queue:

- **With ACS enabled:** Inth inserts `amzn-consent.js` before `amzn.js` with ordered execution, calls `amznConsent` with `countryCode` and both permissions `true`, then queues `setRegion`, `addTag`, and optional `PageView`. If `amzn-consent.js` fails to load, Inth withholds tag registration and PageView until reload.
- **Without ACS:** Inth queues `setRegion`, `addTag`, and optional `PageView` before inserting `amzn.js`. The helper does not track client-side route changes.

On withdrawal, Inth removes its unconsumed initialization entries while keeping app-queued commands, retains both loaders, and calls `amznConsent` with `enableAdStorage: false` and `enableUserData: false`. Withdrawal during `amzn-consent.js` download forwards `false` and skips initialization.

Regrant before reload reuses both scripts and restores ACS without repeating completed init or PageView. On disposal, Inth detaches listeners and removes its ACS element once no active registration uses it; ACS stays granted while any active config with `countryCode` passes consent.

Amazon has no unload API, and ACS denial does not stop all traffic from a running tag. Guard your own `amzn` calls on current category and vendor permission, and keep `reloadOnConsentRevoked` enabled.

## Cookies and storage

Observed in Amazon's scripts reviewed on 21 October 2026:

| Name | Source | Lifetime |
| --- | --- | --- |
| `amzn_consent` | First-party ACS cookie written denied on eval (`Path=/`, `SameSite=Strict`, `Secure`). | 28 days |
| `amznAref` | First-party measurement-token cookie from `amzn.js`. | 30 days |
| `aatToken` | First-party token cookie from `amzn.js`. | From token response |
| `AMZN-NoCookieConsent` | First-party cached no-consent cookie from `amzn.js`. | From token response |

Neither reviewed script accessed Web Storage. Reloading does not delete cookies, and your page cannot clear cookies on Amazon's domains.

## Verify Amazon Ads

Test in a private window with an opt-in policy and your account's real `tagId`, filtering Network by `amazon-adsystem.com`:

1. Before choosing and after rejecting and reloading, confirm neither script nor any event request fires and no Amazon cookies appear.
2. Allow `marketing`. Confirm one `amzn.js` load and initial PageView. With `countryCode`, confirm `amzn-consent.js` executes first with granted signals.
3. Toggle an unrelated category and confirm no second load or PageView occurs.
4. Withdraw `marketing`. With ACS, verify both signals turn `false`. After reload, confirm neither script loads.
