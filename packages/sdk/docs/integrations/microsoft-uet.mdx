The `microsoftUet` helper loads Microsoft Advertising UET on every page before a visitor chooses, queues `uetq.push('consent', 'default', { ad_storage })` from `marketing` consent, and sends `update` calls as consent changes. On withdrawal, UET stays on the page with `ad_storage: 'denied'`, and Inth reloads the page by default.

## Configure Microsoft UET

Copy your UET tag ID from Microsoft Advertising. Remove the original UET snippet and any tag-manager entry that loads the same tag so Inth owns the `uetq` queue and UET initialization.

export const scripts = [microsoftUet({ id: 'YOUR_UET_TAG_ID' })];

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `id` | Required | UET tag ID passed as `ti`, trimmed automatically. Empty or whitespace-only values log an error and skip loading. |
| `scriptSrc` | `//bat.bing.com/bat.js` | Loader URL override. Blank values use the default. |

## Loading and revocation

`microsoftUet` uses `marketing` with `alwaysLoad`, so `bat.js` loads on every page regardless of consent. Before load, the helper calls `uetq.push('consent', 'default', { ad_storage })` with `granted` or `denied` from `marketing`. After `bat.js` loads, it constructs UET with `enableAutoSpaTracking: true` and pushes `pageLoad`. This signals consent mode rather than blocking requests; Microsoft's consent mode controls what UET does while `ad_storage` is denied.

The helper never removes UET. When `marketing` changes, it calls `uetq.push('consent', 'update', { ad_storage })` with the new value. Because automatic SPA tracking sends page loads on client-side navigation, do not push `pageLoad` from your router.

## Verify Microsoft UET

1. In a private window with an opt-in policy, load the page. `bat.js` loads from `bat.bing.com` before any choice and sends its initial page load.
2. Click Reject and reload. `bat.js` still loads and starts with `ad_storage` denied.
3. Open Privacy settings and allow `marketing`. Inth sends a consent update to the running tag without loading a second `bat.js`.
4. Navigate to another SPA route and confirm UET sends one page load, not two.
5. Turn `marketing` off and save. Inth reloads the page with `ad_storage` denied.

See [consent verification](/docs/guides/verify-consent) for navigation and hosting checks.
