The `openaiPixel` helper keeps the OpenAI ChatGPT Ads Measurement Pixel and `window.oaiq` off the page until `marketing` consent is granted. On grant, it queues `oaiq('consent', false)`, `init`, and `oaiq('consent', true)` before loading `oaiq.min.js`. On withdrawal, it calls `oaiq('consent', false)`, keeps the SDK mounted, and Inth reloads the page by default.

## Configure the OpenAI Pixel

Copy your pixel ID from the conversions tab in OpenAI Ads Manager and remove any standalone OpenAI snippet so Inth owns the `oaiq` queue and pixel initialization.

```ts title="src/consent-scripts.ts"
import { openaiPixel } from '@inth/integrations/openai-pixel';

export const scripts = [openaiPixel({ pixelId: 'YOUR_PIXEL_ID' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `pixelId` | Required | Pixel ID passed to `oaiq('init', ...)`, trimmed automatically. Empty or whitespace-only values log an error and skip loading. |
| `debug` | `false` | Logs SDK activity, including queued and dropped events, to the browser console. |
| `user` | None | User matching fields passed to `init`: `email_sha256`, `phone_number_sha256`, `external_id_sha256`, `first_name_sha256`, `last_name_sha256`, `country`, `city`, `region`, and `postal_code`. |
| `scriptSrc` | `https://bzrcdn.openai.com/sdk/oaiq.min.js` | SDK URL override. Blank values use the default. |

Inth forwards `user` unchanged. Normalize and hash identifiers per OpenAI's [user data rules](https://developers.openai.com/ads/measurement-pixel#send-user-data). If user data arrives after initialization, call `window.oaiq('init', { pixelId, user })` again with the complete object.

## Loading and revocation

`openaiPixel` gates on the `marketing` category; `measurement` alone does not load it. On grant, the helper queues `oaiq('consent', false)`, `init`, and `oaiq('consent', true)` before loading `oaiq.min.js`, overriding the SDK's default consent of `true`.

On withdrawal, the helper keeps the SDK mounted and calls `oaiq('consent', false)`. Re-allowing `marketing` before reload calls `oaiq('consent', true)` without reinitializing. OpenAI drops events sent while consent is denied and never replays them, though the SDK can still send diagnostic pings.

## Guard your own oaiq calls

The helper sends no automatic page views or conversions. Because `window.oaiq` stays defined after withdrawal, check `marketing` permission before calling `oaiq`:

```ts title="src/track-order.ts"
export function trackOrder(marketingAllowed: boolean, orderId: string) {
	if (!marketingAllowed || typeof window.oaiq !== 'function') return;
	window.oaiq(
		'measure',
		'order_created',
		{ type: 'contents', amount: 2599, currency: 'USD' },
		{ event_id: orderId }
	);
}
```

Pass the current `marketing` permission from your framework, such as `useConsent('marketing')` in React. `amount` is an integer in minor currency units, so `2599` is `$25.99`. Reuse `event_id` on server events to deduplicate them.

`@inth/integrations/openai-pixel` also exports `openaiPixelEvent`, a typed wrapper around `oaiq('measure', ...)`. It drops calls before the queue exists and does not check permission, so guard it the same way. A `custom` event requires `custom_event_name` in its options. With multiple pixels, call `window.oaiq('measureSingle', pixelId, ...)` to target one pixel.

## Verify the OpenAI Pixel

Set `debug: true` while testing. Allow `marketing` and confirm `oaiq.min.js` loads from `bzrcdn.openai.com`. Trigger a guarded event and verify `https://bzr.openai.com/v1/sdk/events` succeeds and the event appears in Event Stream in Ads Manager. An accepted request confirms delivery, not ChatGPT ad attribution. Revoke `marketing` and confirm `trackOrder` sends nothing before reload. Remove `debug: true` before shipping.

For Content Security Policy, allow `https://bzrcdn.openai.com` in `script-src`, both `https://bzr.openai.com` and `https://bzrcdn.openai.com` in `connect-src`, and `https://bzr.openai.com` in `img-src`.
