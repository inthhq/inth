The `xPixel` helper keeps the X Pixel off the page and leaves `window.twq` undefined until a visitor grants `marketing` consent. Because X exposes no consent update API, the helper sends no consent signal to X. On revocation, Inth removes the script element and reloads the page by default.

## Configure the X Pixel

Copy your X Pixel ID from X Ads Manager and remove any existing pixel snippet or tag manager entry. Conversion event IDs like `tw-xxxx-xxxx` are separate from the pixel ID.

```ts title="src/consent-scripts.ts"
import { xPixel } from '@inth/integrations/x-pixel';

export const scripts = [xPixel({ pixelId: 'YOUR_PIXEL_ID' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `pixelId` | Required | Pixel ID passed to `twq('config', ...)`. Trimmed automatically; blank values log an error and skip loading. |
| `scriptSrc` | `https://static.ads-twitter.com/uwt.js` | Loader URL override. Blank values fall back to the default. |

## Loading and revocation

`xPixel` gates on `marketing`. Before a visitor allows `marketing`, Inth defines no `window.twq` and makes no X request. Once allowed, the helper queues `twq('config', pixelId)` and loads `uwt.js`.

On revocation, Inth removes the script element without calling an X API, so `window.twq` stays defined until the default page reload unloads the pixel.

## Guard your own twq calls

Because `window.twq` stays defined after revocation, check current `marketing` permission from your framework, such as `useConsent('marketing')` in React, before sending conversion events:

```ts title="src/track-purchase.ts"
export function trackPurchase(marketingAllowed: boolean, orderId: string) {
	if (!marketingAllowed || typeof window.twq !== 'function') return;
	window.twq('event', 'tw-xxxx-xxxx', {
		conversion_id: orderId,
		currency: 'USD',
		value: 99.99,
	});
}
```

Set `conversion_id` to deduplicate events. `@inth/integrations/x-pixel` also exports `xPixelEvent`, a typed wrapper around `twq('event', ...)`. It no-ops while `window.twq` is undefined and does not check consent itself, so guard it with your permission check too.

## Verify the X Pixel

Allow `marketing` and confirm `uwt.js` loads from `static.ads-twitter.com`. Trigger a guarded event and verify its request to X appears, then revoke `marketing` and confirm `trackPurchase` sends nothing before reload.
