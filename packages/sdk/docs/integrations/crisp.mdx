The `crisp` helper keeps the Crisp chat widget off the page and `window.CRISP_WEBSITE_ID` unset until visitors grant `functionality` consent.

## Configure Crisp

Copy the `CRISP_WEBSITE_ID` value from your Crisp installation snippet.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { crisp } from '@inth/integrations/crisp';

export const scripts = [crisp({ websiteId: 'YOUR_WEBSITE_ID' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `websiteId` | Required | Written to `window.CRISP_WEBSITE_ID`. Trimmed automatically; blank values log an error and skip loading. |
| `locale` | None | Widget locale written to `window.CRISP_RUNTIME_CONFIG.locale`. |
| `sessionMerge` | None | Merges anonymous sessions into token-backed sessions via `CRISP_RUNTIME_CONFIG.session_merge`. |
| `tokenId` | None | Session continuity token written to `window.CRISP_TOKEN_ID`. |
| `cookieDomain` | None | Cookie domain written to `window.CRISP_COOKIE_DOMAIN`. |
| `cookieExpiry` | None | Cookie lifetime in seconds written to `window.CRISP_COOKIE_EXPIRE`. |
| `safeMode` | `false` | Pushes `['safe', true]` onto `$crisp` before loading. |
| `scriptSrc` | `https://client.crisp.chat/l.js` | Loader URL override. Blank values use the default. |

## Loading and revocation

`crisp` gates on `functionality`, so provide an alternative support link for visitors who deny it. Before loading, Inth creates `window.$crisp` as an empty array if absent, preserving commands your app queued earlier so Crisp replays them once loaded. Nothing reaches Crisp while `functionality` is denied.

On withdrawal, Inth removes the script element without calling a Crisp API. The running widget stays visible until Inth reloads the page by default.

## Verify Crisp

1. Before granting consent, confirm `window.CRISP_WEBSITE_ID` is `undefined`.
2. Allow `functionality` and confirm `client.crisp.chat/l.js` loads and the chat launcher appears.
