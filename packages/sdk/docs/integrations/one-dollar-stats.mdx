The `oneDollarStats` helper keeps `stonks.js` off the page until `measurement` consent is granted. On withdrawal, Inth removes the script element without calling a OneDollarStats API and reloads the page by default.

## Configure OneDollarStats

OneDollarStats needs no API key. Remove any existing `stonks.js` tag from your app, then install `@inth/integrations` and pass any tracker settings without the `data-` prefix.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { oneDollarStats } from '@inth/integrations/one-dollar-stats';

export const scripts = [oneDollarStats()];
```

## Options

Every setting is a string without the `data-` prefix. Names must use lowercase letters, digits, and hyphens; invalid names or non-string values throw. Unknown names pass through so newer tracker settings work.

| Option | Default | Behavior |
| --- | --- | --- |
| `hostname` | None | Bare host, optionally with a port. Overrides the event hostname everywhere, including production. Schemes, paths, queries, and fragments throw. |
| `devmode` | None | `'true'` records local visits. Local testing also requires `hostname`. |
| `autocollect` | None | `'false'` disables automatic page view and click collection. |
| `hash-routing` | None | `'true'` tracks hash routes. `'false'` omits the attribute because the tracker enables hash routing whenever the attribute is present. |
| `url` | None | Custom collection endpoint. |

The helper always loads `https://assets.onedollarstats.com/stonks.js` and has no loader URL override. The tracker follows client-side navigation automatically; see the [OneDollarStats reference](https://docs.onedollarstats.com/installation).

## Loading and revocation

`oneDollarStats` gates on the `measurement` category. On withdrawal, Inth removes the script element and calls no OneDollarStats API.

Removing the script element cannot undo the tracker's history hooks and event listeners, so keep `reloadOnConsentRevoked` enabled.

## Verify OneDollarStats

Allow `measurement` and confirm `stonks.js` loads with the `data-*` attributes you passed. Navigate between routes and confirm each route sends a page view.
