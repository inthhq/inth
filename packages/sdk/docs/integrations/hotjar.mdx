The `hotjar` helper keeps Hotjar off the page until `measurement` consent is granted. Before consent, Inth does not define `window._hjSettings` or `window.hj` and loads nothing from Hotjar. On withdrawal, Inth reloads the page by default to stop active recordings.

## Configure Hotjar

Copy your site ID (`hjid`) from the Hotjar tracking code, then remove that snippet from your app so Hotjar loads only through Inth.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { hotjar } from '@inth/integrations/hotjar';

export const scripts = [hotjar({ siteId: 1234567 })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `siteId` | Required | Site ID as a number or string, assigned to `window._hjSettings.hjid` and the default loader URL. Missing, empty, or `0` values log an error and skip loading. |
| `version` | `6` | Script version, assigned to `window._hjSettings.hjsv` and the `sv` query parameter on the default loader URL. |
| `scriptUrl` | `https://static.hotjar.com/c/hotjar-<siteId>.js?sv=<version>` | Loader URL override. |

## Loading and revocation

`hotjar` gates on the `measurement` category. When `measurement` is allowed, the helper defines `window._hjSettings` and a queueing `window.hj` stub, then inserts the Hotjar script. If your page already defines either global, the helper leaves it untouched.

On withdrawal, Inth sends no consent signal to Hotjar and removes the script element. Removing the element does not stop a running recording, so keep `reloadOnConsentRevoked` enabled. With `reloadOnConsentRevoked: false`, Hotjar keeps recording until the visitor leaves the page.

`window.hj` stays defined after withdrawal, so check `measurement` permission before calling `hj()`.

## Verify Hotjar

Filter DevTools Network by `hotjar`. After you allow `measurement`, `hotjar-<siteId>.js` loads from `static.hotjar.com` (or your `scriptUrl`) and `window._hjSettings.hjid` matches your site ID. If `_hjSettings.hjid` holds another ID, find and remove the code that set `_hjSettings` before Inth.

Watch one recording of a real screen to confirm Hotjar masks the fields you expect. Hotjar controls masking, not Inth.
