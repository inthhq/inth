The `marketoMunchkin` helper waits for `marketing` consent before loading Adobe Marketo Munchkin or calling `Munchkin.init`. Before consent, it creates no Munchkin global, cookie, or browser storage. On withdrawal, Inth removes the loader and reloads the page by default to end tracking.

Copy your Munchkin account ID from Marketo's snippet and remove the original tag from your site so Inth controls loading.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `munchkinId` | Required | Public account ID, trimmed automatically. Missing or blank values log an error and skip loading. |
| `initOptions` | `{}` | Passed to `Munchkin.init`, such as `cookieAnon`, `anonymizeIP`, `apiOnly`, and `cookieLifeDays`. |
| `category` | `marketing` | Consent condition that gates the loader. |
| `scriptUrl` | `https://munchkin.marketo.net/munchkin.js` | Custom or proxied loader URL. Blank values use the default; other Munchkin requests need separate proxy config. |

`cookieAnon: false` stops Munchkin from creating cookies for new anonymous visitors, not visitors who already have a tracking cookie. It is not a consent switch.

## Loading and revocation

When the configured category is allowed, Inth downloads the SDK and calls `Munchkin.init` once with `munchkinId` and `initOptions`. If consent is withdrawn while downloading, the helper skips initialization. Changes to other categories do not reinitialize Munchkin.

Because removing the script element does not stop the running SDK or its listeners, keep `reloadOnConsentRevoked` enabled so the next page loads without Munchkin.

## Cookies and storage

Munchkin writes `_mkto_trk` for two years by default, and reloading does not delete it. The helper does not trigger Marketo's `marketo_opt_out=true` URL flow (`mkto_opt_out`), because that cookie would also block tracking after a later consent grant.

## Verify Marketo Munchkin

Filter DevTools Network by `munchkin.marketo.net`. Before consent, confirm no loader request, `window.Munchkin`, `_mkto_trk` cookie, or vendor storage appears. Allow the configured `category` (default `marketing`) and confirm the SDK loads and initializes. Reject that category and confirm the reloaded page makes no Munchkin request.
