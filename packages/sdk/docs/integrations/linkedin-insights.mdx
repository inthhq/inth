The `linkedinInsights` helper keeps `insight.min.js` off the page and sets no LinkedIn globals until `marketing` consent is granted. On withdrawal, Inth removes the script element without calling a LinkedIn API and reloads the page by default.

## Configure the LinkedIn Insight Tag

Copy your partner ID from LinkedIn Campaign Manager under **Data > Signals manager > Insight Tag**. Remove the original Insight Tag snippet and its `<noscript>` tracking image.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { linkedinInsights } from '@inth/integrations/linkedin-insights';

export const scripts = [linkedinInsights({ id: 'YOUR_PARTNER_ID' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `id` | Required | Partner ID. Trimmed, assigned to `_linkedin_partner_id`, and appended to `_linkedin_data_partner_ids`. Blank values log an error and skip loading. |
| `scriptSrc` | `https://snap.licdn.com/li.lms-analytics/insight.min.js` | Loader URL override. Blank values use the default. |

## Loading and revocation

`linkedinInsights` gates on the `marketing` category. When `marketing` is allowed, the helper sets the partner ID globals, defines the `lintrk` queue, and loads `insight.min.js`.

On withdrawal, the helper removes the script element without calling a LinkedIn API. `window.lintrk` stays defined until Inth reloads the page.

## Guard your own lintrk calls

The Insight Tag tracks page views automatically. Conversions sent with `lintrk('track', ...)` need their own consent check because `window.lintrk` stays defined after withdrawal:

```ts title="src/track-signup.ts"
export function trackSignup(marketingAllowed: boolean) {
	if (!marketingAllowed || typeof window.lintrk !== 'function') return;
	window.lintrk('track', { conversion_id: 1234567 });
}
```

Pass the current `marketing` permission from your framework, such as `useConsent('marketing')` in React, and replace `1234567` with your LinkedIn conversion ID. `@inth/integrations/linkedin-insights` exports no event wrapper.

## Verify the LinkedIn Insight Tag

Allow `marketing` and confirm `insight.min.js` loads from `snap.licdn.com` and `window._linkedin_data_partner_ids` contains your partner ID. Trigger a guarded conversion and verify its request to LinkedIn fires. Revoke `marketing` and confirm `trackSignup` sends nothing before reload.
