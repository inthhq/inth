The `ahrefsAnalytics` helper blocks `analytics.js` until the visitor grants `measurement` consent, even though Ahrefs reports that its script sets no cookies. It sends no consent signal to Ahrefs. On withdrawal, Inth removes the script element and reloads the page by default.

## Configure Ahrefs Analytics

Copy your project key from the Ahrefs installation snippet and remove any direct `<script>` tag. Inth passes the key as `data-key`.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { ahrefsAnalytics } from '@inth/integrations/ahrefs-analytics';

export const scripts = [ahrefsAnalytics({ key: 'YOUR_PROJECT_KEY' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `key` | Required | Project key passed as `data-key`. Blank values log an error and skip loading. |
| `scriptUrl` | `https://analytics.ahrefs.com/analytics.js` | Loader URL override. |

## Loading and revocation

`ahrefsAnalytics` gates on `measurement` and loads `analytics.js` only while allowed. On revocation, Inth removes the script element without calling any Ahrefs API. Guard your own `window.AhrefsAnalytics?.sendEvent` calls on current `measurement` permission.

## Verify Ahrefs Analytics

Filter DevTools Network by `analytics.ahrefs.com`. Allow `measurement` and confirm `analytics.js` loads with your `data-key` attribute on its script element.
