Load `gtag.js` for Google Analytics or Google Ads with Google Consent Mode v2 signals managed by Inth. With the default `loadMode: 'always'`, `gtag.js` loads on every page and sends `gtag('consent', 'default', ...)` before `config`. Set `loadMode: 'after-consent'` to send nothing to Google until your chosen category is allowed.

## Configure the Google tag

Copy your tag ID, such as `G-XXXXXXXXXX` for Google Analytics or `AW-XXXXXXXXX` for Google Ads. Remove any existing `gtag.js` snippet or tag manager entry loading the same tag, then install `@inth/integrations`:

<CommandTabs command="@inth/integrations" mode="install" />

```ts title="src/consent-scripts.ts"
import { gtag } from '@inth/integrations/google-tag';

export const scripts = [gtag({ id: 'G-XXXXXXXXXX', category: 'measurement' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `id` | Required | Tag ID passed to `gtag('config', ...)` and the loader URL. Trimmed automatically; blank values log an error and skip loading. |
| `category` | Required | `measurement` for Analytics, `marketing` for Ads and Floodlight. Delays loading in `'after-consent'` mode; sets callback permission in `'always'` mode. |
| `loadMode` | `'always'` | `'always'` or `'after-consent'`. See [choose when Google loads](#choose-when-google-loads). |
| `config` | None | Extra parameters passed as the third argument to `gtag('config', id, config)`. |
| `consentMapping` | Standard mapping below | Replaces the category-to-Google consent type table. |

## Choose when Google loads

| `loadMode` | Before the category is allowed | After the category is allowed |
| --- | --- | --- |
| `'always'` | Loads `gtag/js` and sends `consent` `default` with current permissions before `config`. | Sends `consent` `update` with mapped types granted. |
| `'after-consent'` | Sends nothing to Google and creates no `dataLayer` or `gtag`. | Loads `gtag/js` once with `consent` `default` carrying current permissions before `config`. Later changes send `update`. |

Use `'after-consent'` when your policy forbids any request to Google before opt-in:

{/* example: fragment */}

```ts title="src/consent-scripts.ts (partial)"
gtag({ id: 'G-XXXXXXXXXX', category: 'measurement', loadMode: 'after-consent' }),
```

Key differences in `'after-consent'` mode:

- **Policy behavior.** Under `opt-out` or `none`, optional categories start allowed, so `gtag/js` loads on the first page unless restricted by a saved refusal or privacy signal. See [policies](/docs/concepts/policies). Do not use `category: 'necessary'`, which is always allowed.
- **No cookieless modeling.** Denied visitors send zero requests to Google, so Google cannot model conversions for them.
- **Revocation.** Withdrawing the category triggers Inth's default page reload so `gtag/js` does not load on the next page. With `reloadOnConsentRevoked: false`, the running tag stays mounted and receives a denied `update`.

## Verify the Google tag

On a plain HTML page using the Inth script tag, gate Google's snippet directly; see [HTML scripts](/docs/frameworks/html/scripts#google-consent-mode-and-tag-managers).

Test in a private window with an opt-in policy:

**With `loadMode: 'always'`**
1. Load the page. `gtag/js` loads, and Google Tag Assistant shows `consent` `default` before `config` with `analytics_storage` and `ad_storage` set to `denied`.
2. Allow the tag's category in Privacy settings. Tag Assistant shows an `update` granting the mapped types.
3. Withdraw the category and save. Inth reloads the page with those types denied.

**With `loadMode: 'after-consent'`**
1. Filter DevTools Network by `google` and load the page. Zero requests appear, and `window.dataLayer` is `undefined`.
2. Allow the tag's category. `gtag/js` loads once with `consent` `default` granting the mapped types before `config`.
3. Withdraw the category and save. Inth reloads the page with zero requests to Google.

With client-side routing, confirm each navigation sends one `page_view`, not two. See [consent verification](/docs/guides/verify-consent) for full checks.
