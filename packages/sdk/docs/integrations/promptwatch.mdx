The `promptwatch` helper keeps the Promptwatch client script off the page until `measurement` is granted. It sends no consent signal to Promptwatch. On withdrawal, Inth removes the script element and reloads the page by default.

## Configure Promptwatch

Copy the project ID from your Promptwatch dashboard. The helper passes it to the script as `data-project-id`.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { promptwatch } from '@inth/integrations/promptwatch';

export const scripts = [promptwatch({ projectId: 'YOUR_PROJECT_ID' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `projectId` | Required | Project ID from the Promptwatch dashboard. Blank values log an error and skip loading. |
| `scriptUrl` | `https://ingest.promptwatch.com/js/client.min.js` | Loader URL override. Blank values use the default. |

## Loading and revocation

`promptwatch` uses the `measurement` category and loads only while measurement is allowed. On revocation, the helper removes the script element and calls no Promptwatch API.

The helper gates only the browser client. If your server also sends events to Promptwatch, check the visitor's `measurement` permission on the server too.

## Verify Promptwatch

Allow `measurement` and confirm `client.min.js` loads from `ingest.promptwatch.com` with your `data-project-id` attribute on the script element.
