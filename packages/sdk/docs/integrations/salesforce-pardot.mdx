The `pardotTracking` helper waits for `marketing` consent before creating Pardot globals or downloading Salesforce Account Engagement, formerly Pardot. It defaults to `consent` mode for the Tracking and Consent API and also supports `classic` mode for the `pd.js` snippet. On withdrawal, `consent` mode calls `pdt('revokeConsent')`, and Inth reloads the page by default in both modes.

## Configure Salesforce Account Engagement

Enable the Tracking and Consent API in Account Engagement before using `consent` mode, and use your verified tracker domain. Copy `piAId` and `piCId` exactly from the generated snippet; they already include Salesforce's +1000 offset, and the helper does not add it again. Remove the original tracking snippet.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `piAId` | Required | Account ID from the tracking snippet, as a string or positive integer. |
| `piCId` | Required | Campaign ID from the tracking snippet, as a string or positive integer. |
| `piDomain` | Required in `consent` mode | Verified tracker hostname without scheme or path. |
| `mode` | `'consent'` | `'consent'` uses the Tracking and Consent API. `'classic'` loads `pd.js`, which has no revoke call. |
| `piHostname` | `'pi.pardot.com'` | Tracker hostname in `classic` mode, set as `window.piHostname`. |
| `category` | `'marketing'` | Consent condition for the loader. |
| `scriptUrl` | `https://<piDomain>/pdt.js?aid=<piAId>` | Loader URL override. Classic mode defaults to `https://pi.pardot.com/pd.js`; blank values use the default. |

The helper logs an error and skips loading if a required value is blank, an ID is not a safe positive integer, a tracker domain is not a hostname, or `mode` is neither `'consent'` nor `'classic'`.

## Loading and revocation

Consent mode starts after hydration, even when `marketing` was granted on an earlier visit, waiting for the client loader to confirm the SDK is ready before enabling tracking. Classic mode can start from server-rendered HTML.

After consent, the helper creates the `pdt.cq` queue with numeric IDs, hides Salesforce's built-in consent banner without changing consent, and starts with `setOptIn(false)`. Once `pdt.js` loads, it calls `setOptIn(true)` and sends one page view. Changes to unrelated categories do not trigger extra page views, and a detached in-flight load cannot enable tracking.

- **Revocation in consent mode.** The helper calls `pdt('revokeConsent')`. It never calls `clearTrackingCookies`, because that deletes the refusal cookie and could allow later tracking. The loader stays in the DOM because reloading `pdt.js` replaces its configured dispatcher. On regrant, or when `pardotTracking` is called again with equal options, the helper reuses the configuration and sends a new page view.
- **Revocation in classic mode.** Classic `pd.js` has no stop or revoke call.
- **Keep reload enabled.** Keep `reloadOnConsentRevoked` enabled in both modes. Clearing consent makes vendor requests, late in-flight responses can restore cookies, and removing a script element does not stop pending requests.

## Cookies and storage

Pardot sets `visitor_id<id>`, `visitor_id<id>-hash`, `pi_opt_in<id>`, `lpv<id>`, and `pardot` cookies, where `<id>` can be the account ID minus 1000. Reloading does not erase existing vendor cookies.

## Verify Salesforce Account Engagement

1. Before consent and after allowing only an unrelated category, confirm no `pdt.js` or `pd.js` request, `pdt` or `piAId` global, cookies, or browser storage appear.
2. Allow `marketing` and confirm the consent dispatcher loads and sends one page view.
3. Withdraw `marketing` and confirm `pdt('revokeConsent')` runs and the refusal cookie persists until cleanup or expiry.
4. Allow `marketing` again and confirm one new page view fires with your account.

Sources: Salesforce's [setup guide](https://developer.salesforce.com/docs/marketing/pardot/guide/tracking-and-consent-getting-started.html), [consent functions](https://developer.salesforce.com/docs/marketing/pardot/guide/tracking-and-consent-functions.html), and [classic snippet](https://help.salesforce.com/s/articleView?id=000381476\&language=en_US\&type=1).
