By default, `rudderstack` keeps the RudderStack JavaScript SDK off the page until `measurement` is granted and sends no consent signal. With `consentManagement`, it loads the SDK immediately in RudderStack's buffered, cookieless pre-consent mode and calls `rudderanalytics.consent()` with allowed and denied consent IDs mapped from Inth categories.

## Configure RudderStack

Copy the source write key and HTTPS data plane URL from your RudderStack source. Never expose control-plane credentials in the browser.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { rudderstack } from '@inth/integrations/rudderstack';

export const scripts = [
	rudderstack({
		writeKey: 'YOUR_SOURCE_WRITE_KEY',
		dataPlaneUrl: 'https://your-data-plane.example.com',
	}),
];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `writeKey` | Required | Source write key, trimmed. Blank values log an error and skip loading. |
| `dataPlaneUrl` | Required unless `dataPlaneHost` is set | HTTPS data plane URL. Missing, invalid, or non-HTTPS URLs log an error and skip loading. Wins over `dataPlaneHost`. |
| `dataPlaneHost` | None | Data plane hostname, such as `example.dataplane.rudderstack.com`, with no scheme, port or path. Events go to `https://<dataPlaneHost>`. A remote integration uses this. Anything other than a hostname logs an error and skips loading. |
| `consentManagement` | None | `{ mapping }` from Inth categories to RudderStack consent IDs. Switches to destination consent mode. |
| `loadOptions` | `{}` | Third argument to `rudderanalytics.load()`. Must be JSON-serializable. |
| `trackPageView` | `true` | Queues `rudderanalytics.page()` before the loader. |
| `scriptUrl` | `https://cdn.rudderlabs.com/v3/modern/rsa.min.js` | Loader URL override. Non-HTTPS URLs throw; blank values use the default. |

## Loading and revocation

`rudderstack` uses the `measurement` category, and `consentManagement` selects the mode:

| Mode | When it loads | On consent change | On revocation |
| --- | --- | --- | --- |
| Default | After `measurement` is granted, with `load` and `page` queued | Nothing | Removes the script element and calls no RudderStack API |
| `consentManagement` | On every page in pre-consent state | Calls `rudderanalytics.consent()` with mapped IDs | Keeps the SDK and calls `consent()` with revoked IDs denied |

## Map destination consent

`consentManagement` loads the SDK before the visitor chooses. Use it only when every destination in your workspace carries a consent ID from your mapping, because Inth cannot inspect workspace destination settings from the browser:

{/* example: fragment */}

```ts
rudderstack({
	writeKey: 'YOUR_SOURCE_WRITE_KEY',
	dataPlaneUrl: 'https://your-data-plane.example.com',
	consentManagement: {
		mapping: {
			measurement: ['YOUR_ANALYTICS_CONSENT_ID'],
			marketing: ['YOUR_ADVERTISING_CONSENT_ID'],
		},
	},
});
```

The helper configures `preConsent.enabled`, buffered event delivery, and `consentManagement.provider: 'custom'` in `loadOptions`. Storage defaults to `{ strategy: 'none' }` unless overridden by `preConsent.storage` in `loadOptions`. Before `load`, it queues `consent()` placing allowed category IDs in `allowedConsentIds` and denied IDs in `deniedConsentIds`. Turning off the `rudderstack` vendor denies every mapped ID. An empty mapping or a category with no non-blank IDs throws.

## Verify RudderStack

In default mode, allowing `measurement` loads `rsa.min.js` with `data-rsa-write-key` and sends a page event to your data plane URL.

<include src="../shared/integrations/vendor-revocation-and-verify.mdx" />

In `consentManagement` mode, verify destinations in a private window with an opt-in policy:

1. Load the page. `rsa.min.js` loads before a choice, and destinations mapped to denied categories receive no events.
2. Open Privacy settings and allow `measurement`. Without a reload, `measurement` destinations start receiving events while `marketing`-only destinations still receive none.
3. Turn `measurement` off and save. Inth reloads the page, and `measurement` destinations receive no events on the new page.

See [consent verification](/docs/guides/verify-consent) for navigation and hosting checks.
