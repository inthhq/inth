Load your Google Tag Manager container, `gtm.js`, with Google Consent Mode v2 signals driven by Inth. With the default `loadMode: 'always'`, `gtm.js` loads on every page under `necessary` and sends `gtag('consent', 'default', ...)` before the container starts. Set `loadMode: 'after-consent'` to send nothing to Google until `measurement` or `marketing` is allowed.

## Configure Google Tag Manager

Copy your `GTM-` container ID from GTM. Remove any existing GTM snippet, `<noscript>` iframe, or framework plugin loading the same container, then install `@inth/integrations`:

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { googleTagManager } from '@inth/integrations/google-tag-manager';

export const scripts = [googleTagManager({ id: 'GTM-XXXXXXX' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `id` | Required | Container ID such as `GTM-1234XXX`. Trimmed automatically; blank values log an error and skip loading. |
| `dataLayer` | `'dataLayer'` | Custom queue name. Appends `&l=<name>` to the container URL and renames the queue helper to `<name>Gtag`. |
| `updateEventName` | `'consent-update'` | `dataLayer` event pushed after every consent update for use as a GTM trigger. |
| `consentMapping` | Standard mapping below | Replaces the category-to-Google consent type table. |
| `loadMode` | `'always'` | `'always'` or `'after-consent'`. See [choose when the container loads](#choose-when-the-container-loads). |
| `category` | `'necessary'`, or `{ or: ['measurement', 'marketing'] }` with `'after-consent'` | Consent condition for loading in `'after-consent'` mode, or callback permission in `'always'` mode. |

## Choose when the container loads

| `loadMode` | Before the category is allowed | After the category is allowed |
| --- | --- | --- |
| `'always'` | Loads `gtm.js` and sends `consent` `default` with current permissions before `gtm.js` starts. | Sends `consent` `update`, then pushes `consent-update`. |
| `'after-consent'` | Sends nothing to Google and creates no `dataLayer` or `gtag`. | Loads `gtm.js` once with `consent` `default` carrying current permissions. Later changes send `update` and `consent-update`. |

Use `'after-consent'` when your policy forbids any request to Google before opt-in:

{/* example: fragment */}

```ts title="src/consent-scripts.ts (partial)"
googleTagManager({ id: 'GTM-XXXXXXX', loadMode: 'after-consent' }),
```

Key differences in `'after-consent'` mode:

- **Policy behavior.** Under `opt-out` or `none`, optional categories start allowed, so `gtm.js` loads on the first page unless restricted by a saved refusal or privacy signal. See [policies](/docs/concepts/policies).
- **Category default.** Because `necessary` is always allowed, `'after-consent'` defaults to `{ or: ['measurement', 'marketing'] }`. Pass `category: 'measurement'` if your container holds only Analytics tags.
- **No cookieless modeling.** Denied visitors send zero requests to Google, so Google cannot model conversions for them.
- **First-page triggers.** On the page where the visitor accepts, `gtm.js` starts with `default` already granted and does not push `consent-update`. Use built-in tag consent checks rather than waiting only on `consent-update`.
- **Revocation.** Withdrawing the category triggers Inth's default page reload so `gtm.js` does not load on the next page. With `reloadOnConsentRevoked: false`, the running container stays mounted and receives a denied `update`.

## Configure consent inside the container

Google tags with built-in Consent Mode respect `default` and `update` automatically. Non-Google tags, such as Custom HTML pixels, ignore Consent Mode signals and fire on their triggers.

For every non-Google tag, add a consent requirement in its GTM consent settings, or trigger it from a Custom Event on `consent-update`. If a vendor must make zero requests before consent, move it out of GTM into its own Inth helper.

## Use the GTM template instead

Prefer the `googleTagManager` helper whenever you control site code. Use the GTM Community Template only on sites managed entirely inside GTM, and never run both on the same page.

1. In GTM, open **Templates**, search for **Inth Consent Management**, and add it. If unlisted, download [`template.tpl`](https://github.com/inthhq/inth/blob/main/packages/sdk/browser/gtm-template/template.tpl) and import it under **Tag Templates > New**.
2. Create a tag with GTM's **Consent Initialization** trigger for all pages.
3. Set **Inth script URL** to `https://your-project.inth.app/inth.js` for your Inth project, or pin an exact jsDelivr version `https://cdn.jsdelivr.net/npm/@inth/sdk@<version>/lib/browser/dist/inth.js` with **Project URL** set to your Inth project URL. Do not use `latest` or version ranges.
4. Tick your required **Consent categories** and configure **Default consent state** rows. Include a blank **Region** fallback row if you add region-specific rows.
5. If your page already loads the Inth script tag directly, untick **Load Inth from this tag** so the template subscribes to the existing instance.

When Inth starts, the template sends `update` and pushes `consent-update`. Give every non-Google tag a consent check, a `consent-update` Custom Event trigger, and **Once per page** firing if needed.

For banner experiment tracking in GTM, forward `onSurfaceShown` and `onChoiceRecorded` as shown in [banner experiments](/docs/guides/banner-experiments#send-the-events-to-your-own-analytics-too).

## Verify Google Tag Manager

Test in a private window with an opt-in policy:

**With `loadMode: 'always'`**
1. Load the page. `gtm.js` loads, and Google Tag Assistant shows `consent` `default` first with `analytics_storage` and `ad_storage` set to `denied`.
2. Click Reject and reload. Optional types remain `denied`, and no non-Google tag fires in DevTools Network.
3. Allow `measurement` in Privacy settings. Tag Assistant shows `update` granting `analytics_storage`, followed by `consent-update`.
4. Withdraw `measurement` and save. Inth reloads the page with `analytics_storage` denied.

**With `loadMode: 'after-consent'`**
1. Filter DevTools Network by `google` and load the page. Zero requests appear, and `window.dataLayer` is `undefined`.
2. Allow `measurement`. `gtm.js` loads once with `consent` `default` granting `analytics_storage` before container start.
3. Allow `marketing`. Tag Assistant shows an `update` granting ad types and `consent-update`, with no second `gtm.js` load.
4. Turn both off and save. Inth reloads the page with zero requests to Google.

See [consent verification](/docs/guides/verify-consent) for navigation checks.
