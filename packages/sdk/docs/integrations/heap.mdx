The `heap` helper keeps `window.heap` undefined and `heap_config.js` off the page until visitors grant `measurement` consent, then reloads the page on withdrawal to stop `heap.js`.

## Configure Heap

Copy the environment ID from your Heap snippet and remove the original Heap snippet from your site.

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { heap } from '@inth/integrations/heap';

export const scripts = [heap({ envId: 'YOUR_ENVIRONMENT_ID' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `envId` | Required | Environment ID assigned to `heap.envId`, `heap.appid`, and the default loader URL. Trimmed automatically; blank values log an error and skip loading. |
| `clientConfig` | `{}` | Assigned to `heap.clientConfig`. Must be JSON-serializable with finite numbers or throws `TypeError`. Inth always forces `shouldFetchServerConfig: false`. |
| `scriptUrl` | `https://cdn.us.heap-api.com/config/<envId>/heap_config.js` | Config loader URL override. Blank values use the default. |

## Loading and revocation

`heap` gates on `measurement`. On grant, Inth creates `window.heap` with heap.js v5 queue stubs backed by `window.heapReadyCb`, then loads `heap_config.js`, which loads `heap.js` and replays queued calls.

On withdrawal, Inth removes the config script element without calling `heap.stopTracking`, so `heap.js` keeps capturing until the default reload. If a visitor regrants `measurement` before reload, Inth keeps the live `heap.js` methods instead of overwriting them with stubs. With `reloadOnConsentRevoked: false`, register a callback-only script whose `onConsentChange` calls `window.heap.stopTracking()`; see [custom integrations](/docs/integrations/building-integrations).

## Verify Heap

Filter DevTools Network by `heap`:

1. Allow `measurement` and confirm `heap_config.js` loads for your environment ID, followed by the `heap.js` runtime.
2. Confirm `window.heap.envId` matches your environment ID.
