The `adobeTarget` helper waits for `experience` consent before creating Adobe globals or loading Adobe Target. Choose one mode per page: your own hosted copy of `at.js` or Adobe Experience Platform Web SDK.

On withdrawal, Inth denies Target through Adobe's Opt-in service for `at.js` or calls `setConsent` with `'out'` for Web SDK. Neither reverts already-applied page changes, so keep `reloadOnConsentRevoked` enabled.

## Configure Adobe Target

Remove existing Adobe Target loaders, Adobe Tags rules, and Web SDK prehiding snippets so nothing runs before consent. Without prehiding, visitors see the original page before Target updates it.

<CommandTabs command="@inth/integrations" mode="install" />

### at.js

Download `at.js` from **Administration > Implementation** in Adobe Target and serve it from your site; Adobe offers no shared CDN. Use `at.js` `1.7.0` or `2.1.0+` for Opt-in support (`2.0.0` and `2.0.1` lack it).

<include src="../shared/examples/javascript/adobe-target-atjs.mdx" />

Inth writes `window.targetGlobalSettings` before loading `at.js`, replacing any prior settings object and forcing `optinEnabled: true`. When Adobe's Experience Cloud ID Opt-in service is present, Inth calls `adobe.optIn.approve(adobe.OptInCategories.TARGET)` on grant and `adobe.optIn.deny(adobe.OptInCategories.TARGET)` on revocation without altering other Adobe products. Without it, only a page reload stops `at.js`.

### Web SDK

Enable Adobe Target on your datastream in Adobe Data Collection, copy the datastream ID and org ID, and pick an exact stable version `2.21.0+` from Adobe's [Web SDK release notes](https://experienceleague.adobe.com/en/docs/experience-platform/collection/js/release-notes).

<include src="../shared/examples/javascript/adobe-target-websdk.mdx" />

Versions below `2.21.0`, ranges, aliases, and prereleases log an error and skip loading. After `alloy.min.js` loads, Inth runs `alloy('configure')` with `defaultConsent: 'pending'`, then sequentially sends `alloy('setConsent')` using Adobe 1.0 consent. Failed configuration or stalled commands require a page reload because Web SDK rejects duplicate `configure` calls.

Gate your own [`sendEvent` personalization calls](https://experienceleague.adobe.com/en/docs/experience-platform/collection/js/commands/sendevent/personalization) on the same consent condition after configuration. Use a Target-only datastream with `experience`, or widen `category` if it also sends analytics or ads. Do not share `window.alloy` with another initializer.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `mode` | Required | `'atjs'` or `'websdk'`. Register one mode per page. |
| `category` | `'experience'` | Inth category or condition. Widen if the SDK serves other purposes. |
| `nonce` | None | CSP nonce for the loader. Provider nonces also apply. |
| `scriptUrl` | Required for `at.js` | URL of your hosted `at.js` file. Root-relative URLs work. |
| `targetGlobalSettings` | `{ optinEnabled: true }` | `at.js` settings: `cookieDomain`, `secureOnly`, `bodyHidingEnabled`, `bodyHiddenStyle`, `pageLoadEnabled`, `viewsEnabled`, `timeout`, `visitorApiTimeout`, `cspScriptNonce`, `cspStyleNonce`. `optinEnabled` is forced `true`. |
| `datastreamId` | Required for Web SDK | Public ID of the Target-enabled datastream. |
| `orgId` | Required for Web SDK | Organization ID including `@AdobeOrg`. |
| `version` | Required for Web SDK | Exact stable version `2.21.0+` from `https://cdn1.adoberesources.net/alloy/<version>/alloy.min.js`. |

Missing or blank required values log an error and skip loading while keeping Adobe Target listed.

## Loading and revocation

Before the first grant, neither mode creates globals, requests scripts, or writes storage. The vendor switch can block loading inside an allowed category, and shared loaders require every registration to permit Adobe Target.

After the first grant, both modes stay installed so revocation sends Target deny or `value.general: 'out'` and regrant opts back in without reloading. If consent is withdrawn during initial Web SDK download, configuration waits until a later grant.

- **Remounts and changes.** Removing the last registration sends denial if available, but cannot unload Adobe. Reload before remounting or changing IDs, versions, or mode.
- **Consent persistence.** `defaultConsent: 'pending'` does not replace Inth's loading gate. Web SDK persists consent in `kndctr_<orgId>_consent`, replacing `@` with `_`.
- **Adobe Tags overlap.** When using [Adobe Analytics](/docs/integrations/adobe-analytics) for Adobe Tags, remove Target and Web SDK rules from that property.

## Cookies and storage

| Cookie | Purpose |
| --- | --- |
| `mbox` | `at.js` visitor and session values, up to two years from last login. |
| `at_check` | Temporary `at.js` cookie-support check. |
| `mboxEdgeCluster` | Edge routing when `overrideMboxEdgeServer` is enabled. |
| `<clientcode>!mboxPC`, `<clientcode>!mboxSession` | HttpOnly third-party cookies on `tt.omtrdc.net` for cross-domain support; your site cannot delete them. |
| `kndctr_<orgId>_consent` | Web SDK persisted consent, plus identity and cluster cookies. |

Revocation does not delete cookies. Check Adobe's [Target cookie reference](https://experienceleague.adobe.com/en/docs/core-services/interface/data-collection/cookies/target) and DevTools Application before configuring cleanup.

## Verify Adobe Target

- **at.js:** Filter Network by your `at.js` URL and `tt.omtrdc.net`. After grant, verify `targetGlobalSettings.optinEnabled` is `true` and Target activities load. With Opt-in, confirm only Target permission changes on withdrawal.
- **Web SDK:** Filter Network by `cdn1.adoberesources.net` and `edge.adobedc.net`. Confirm no `alloy` global before consent, verify `alloy.q.push` is replaced after grant, and test offer delivery against your datastream.
