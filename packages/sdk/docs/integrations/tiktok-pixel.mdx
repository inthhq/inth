The `tiktokPixel` helper keeps the TikTok Pixel off the page and leaves `window.ttq` undefined until a visitor grants `marketing` consent. Once allowed, it queues `ttq.grantConsent()` and `ttq.page()` before loading `events.js`. On withdrawal, it calls `ttq.revokeConsent()`, leaves the script mounted, and reloads the page by default.

## Configure the TikTok Pixel

Copy your TikTok Pixel ID and remove any existing pixel snippet or tag manager entry, then install `@inth/integrations`:

<CommandTabs command="@inth/integrations" mode="install" />

{/* example: fragment */}

```ts title="src/consent-scripts.ts"
import { tiktokPixel } from '@inth/integrations/tiktok-pixel';

export const scripts = [tiktokPixel({ pixelId: 'YOUR_PIXEL_ID' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `pixelId` | Required | Pixel ID appended to the loader URL as `sdkid`. Trimmed automatically; blank values log an error and skip loading. |
| `scriptSrc` | `https://analytics.tiktok.com/i18n/pixel/events.js` | Loader base URL override. Inth appends `?sdkid=<pixelId>&lib=ttq`. Blank values fall back to the default. |

## Loading and revocation

`tiktokPixel` gates on `marketing`. Before a visitor allows `marketing`, Inth defines no `window.ttq` queue and makes no TikTok request. Once allowed, the helper initializes `ttq` matching TikTok's base code, queues `ttq.grantConsent()` and `ttq.page()`, and loads `events.js`.

On revocation, the script stays mounted and calls `ttq.revokeConsent()`. Re-enabling `marketing` before the default reload calls `ttq.grantConsent()`.

## Guard your own ttq calls

Because `window.ttq` stays defined after revocation, check current `marketing` permission from your framework, such as `useConsent('marketing')` in React, before calling `ttq.track` or `ttq.identify`:

```ts title="src/track-purchase.ts"
export function trackPurchase(marketingAllowed: boolean, value: number) {
	if (!marketingAllowed || typeof window.ttq?.track !== 'function') return;
	window.ttq.track('CompletePayment', { currency: 'USD', value });
}
```

`@inth/integrations/tiktok-pixel` exports no event wrapper.

## Verify the TikTok Pixel

Allow `marketing` and confirm `analytics.tiktok.com/i18n/pixel/events.js` loads with your pixel ID in `sdkid` and fires one page event. Trigger a guarded event and verify its request appears, then revoke `marketing` and confirm `trackPurchase` sends nothing before reload.
