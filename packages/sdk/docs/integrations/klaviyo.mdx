The `klaviyo` helper keeps `Klaviyo.js` off the page and `window.klaviyo` undefined until both `marketing` and `measurement` are granted. On withdrawal, Inth removes the loader and reloads by default. Use `mode: 'forms-only'` to show signup forms under `marketing` alone while turning onsite tracking off.

## Configure Klaviyo

Copy your six-character public API key from **Settings > Account > API keys** in Klaviyo. Never pass a private key (`pk_...`); the helper logs an error and loads nothing.

<CommandTabs command="@inth/integrations" mode="install" />

```ts title="src/consent-scripts.ts"
import { klaviyo } from '@inth/integrations/klaviyo';

export const scripts = [klaviyo({ publicApiKey: 'YOUR_PUBLIC_API_KEY' })];
```

Remove Klaviyo's snippet and disable automatic `Klaviyo.js` injection on Shopify, BigCommerce, or WooCommerce so Klaviyo loads only through Inth.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `publicApiKey` | Required | Six-character alphanumeric public API key. Invalid, missing, or private keys log an error and skip loading. |
| `mode` | `'full'` | `'full'` loads forms and tracking. `'forms-only'` sets `__kla_off=true` before running; see [Forms-only mode](#forms-only-mode). |
| `category` | `{ and: ['marketing', 'measurement'] }`, or `'marketing'` in forms-only mode | Consent condition required before `Klaviyo.js` loads. |
| `scriptUrl` | `https://static.klaviyo.com/onsite/js/<publicApiKey>/klaviyo.js` | `https:` loader URL override. Blank values use the default. |

## Why Klaviyo needs two categories

`Klaviyo.js` bundles signup forms and Active on Site tracking in one script with no split option, and Klaviyo classifies `__kla_id` as a targeting cookie. Override `category` if your legal review uses another mapping:

{/* example: fragment */}

```ts
klaviyo({ publicApiKey: 'YOUR_PUBLIC_API_KEY', category: 'marketing' });
```

## Forms-only mode

`mode: 'forms-only'` waits for `marketing` and sets Klaviyo's `__kla_off=true` session cookie before loading:

{/* example: fragment */}

```ts
klaviyo({ publicApiKey: 'YOUR_PUBLIC_API_KEY', mode: 'forms-only' });
```

Active on Site, `identify`, and `track` send nothing in this mode, with these limits:

- **Not cookieless.** `Klaviyo.js` still writes `__kla_id`, Web Storage keys, and form-analytics events carrying `__kla_id`.
- **No visitor targeting.** Forms cannot hide from existing subscribers, and submissions create profiles without identifying the browser for later tracking.
- **Fixed per page load.** Granting `measurement` later does not enable tracking; switch to `mode: 'full'` instead. Inth never deletes `__kla_off`, so visitors moving from forms-only to full mode keep tracking off until they close the browser.
- **No measurement-only mode.** Klaviyo cannot suppress published forms while tracking visitors.

## Vendor switches, opt-out regions, and IAB mode

The vendor slug is `klaviyo`; declare it so preference dialogs show its switch. See [vendor consent](/docs/integrations/overview#vendor-switches-and-cookie-cleanup).

- Turning the switch off blocks loading or reloads on revocation. Because `clearOnRevocation` runs per category, a vendor-only toggle leaves existing storage untouched.
- In opt-out regions like most of the US, `Klaviyo.js` loads on first view unless Global Privacy Control denies both categories.
- In IAB TCF mode, vendor switches are ignored; Klaviyo loads once TCF purposes 2, 3, and 4 and 7, 8, and 9 are granted.

## Send your own events

`window.klaviyo` exists only after consent, so optional chaining drops unconsented calls when `reloadOnConsentRevoked` is enabled:

{/* example: fragment */}

```ts
window.klaviyo?.track('Added to Cart', {
	ProductName: product.name,
	Price: product.price,
});
```

With `reloadOnConsentRevoked: false`, check Inth consent before each call. Cookie consent and email or SMS subscription consent are separate records; keep collecting channel opt-ins in your Klaviyo forms.

## Account settings and storage

Account settings that affect collection after load: **Anonymous visitor activity backfill** (`kl-post-identification-sync`, 14 days, under **Settings > Account > Data**), **Extended ID** and **First-Party ID** (`__kle_id`), and account-wide **Email and SMS click tracking** (`_kx`).

Observed storage names, including DataDome bot protection (`datadome`, `dd*`):

| Storage | Names |
| --- | --- |
| Cookies | `__kla_id` (up to 2 years), `__kle_id`, `__kla_off`, `datadome` |
| Local storage | `klaviyoOnsite`, `__kl_key`, `$referrer`, `$last_referrer`, `kl-post-identification-sync`, `ddSession` |
| Session storage | `klaviyoPagesVisitCountV2`, `klaviyoFormSubmit`, `_kx`, `ddCookieCandidateDomain` |

Add these to `clearOnRevocation` under both `marketing` and `measurement`, or `marketing` only in forms-only mode. See [clear on revocation](/docs/integrations/overview#vendor-switches-and-cookie-cleanup):

{/* example: fragment */}

```ts
const klaviyoStorage = {
	cookies: ['__kla_id', '__kle_id', 'datadome'],
	localStorage: [
		'klaviyoOnsite',
		'__kl_key',
		'$referrer',
		'$last_referrer',
		'kl-post-identification-sync',
		'ddSession',
	],
	sessionStorage: [
		'klaviyoPagesVisitCountV2',
		'klaviyoFormSubmit',
		'_kx',
		'ddCookieCandidateDomain',
	],
};

const clearOnRevocation = {
	marketing: klaviyoStorage,
	measurement: klaviyoStorage,
};
```

## Content Security Policy

`Klaviyo.js` injects module scripts without a nonce. Default popup forms require:

| Directive | Hosts |
| --- | --- |
| `script-src` | `https://static.klaviyo.com`, `https://static-tracking.klaviyo.com` |
| `connect-src` | `https://a.klaviyo.com`, `https://fast.a.klaviyo.com`, `https://static-forms.klaviyo.com` |
| `style-src` | `https://static.klaviyo.com`, `https://fonts.googleapis.com` |
| `img-src` | `https://d3k81ch9hvuctc.cloudfront.net` |
| `frame-src` | `https://geo.captcha-delivery.com` (DataDome bot challenge) |

## Verify Klaviyo

Filter DevTools Network by `klaviyo`:

1. Allow `marketing` only. Nothing loads and no `__kla_id` cookie is set.
2. Allow `measurement` too. `klaviyo.js` loads from `static.klaviyo.com/onsite/js/<your key>/`, followed by Klaviyo modules.
3. Run `await klaviyo.account()` in the console. Expect your public key in full mode and `null` in forms-only mode.
4. Confirm a published form requests `static-forms.klaviyo.com/forms/api/v7/<your key>/full-forms`.
5. In forms-only mode, confirm the console warns that tracking is disabled and `identify` sends nothing to `a.klaviyo.com/client/`.
