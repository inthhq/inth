## How setup works

Install your `@inth/*` package, set your Inth project URL, mount the consent components near your app root, and register tracking scripts to wait for permission. Then [verify consent](/docs/guides/verify-consent) in DevTools Network.

## Using a coding agent

Point your agent at `node_modules/@inth/<package>/AGENTS.md` and `SKILL.md` for version-matched guides. Every page also serves Markdown at its `.md` URL, indexed in [llms.txt](https://inth.com/docs/llms.txt). Install `@inth/cli` to manage projects and codemods from the terminal with the `inth` command.
