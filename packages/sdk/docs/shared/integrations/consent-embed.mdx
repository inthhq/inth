## Add the embed to your framework

Create `src/embed-config.ts` with the values from this page, then pick your framework. Keep your existing [consent setup](/docs/frameworks), policy, and preferences UI. None of these examples create a second consent provider.

    ```tsx title="src/consent-embed.tsx"
    'use client';

    import { ConsentGate } from '@inth/nextjs';
    import { embedCategory, embedURL, embedTitle, embedAspectRatio } from './embed-config';

    export function ConsentEmbed() {
      return (
        <ConsentGate category={embedCategory}>
          <iframe

            title={embedTitle}
            loading="lazy"
            allowFullScreen
    ```

    `ConsentGate` keeps the iframe unmounted while permission is denied and removes it on revocation.

  <Tab value="Astro">
    Pair the shared helper below with Astro's existing page runtime and render this component inside your consent-enabled base layout:

    ```astro title="src/components/ConsentEmbed.astro"
    <inth-consent-embed style="display: block"></inth-consent-embed>

    <script>
      import { getConsentClient } from '@inth/astro/client';
      import { mountConsentEmbed } from '../consent-embed';

      class ConsentEmbed extends HTMLElement {
        dispose?: () => void;

        connect = () => {
          if (this.dispose) return;
          const client = getConsentClient();
          if (!client) return;
          // Wait for the runtime to finish booting on pages that show a banner.
          void client.ready.then(() => {
            if (this.dispose || !client.runtime) return;
            this.dispose = mountConsentEmbed(
              this,
              client.runtime.kernel,
              () => { void client.openDialog(); },
            );
          });
        };

        connectedCallback() {
          document.addEventListener('DOMContentLoaded', this.connect, { once: true });
          this.connect();
        }

        disconnectedCallback() {
          document.removeEventListener('DOMContentLoaded', this.connect);
          this.dispose?.();
          this.dispose = undefined;
        }
      }

      if (!customElements.get('inth-consent-embed')) {
        customElements.define('inth-consent-embed', ConsentEmbed);
      }
    </script>
    ```

    The component waits for Inth's boot script on first mount, reuses the existing runtime across `ClientRouter` navigation, and cleans up on removal. Do not create a second consent runtime.

## Browser helper for Astro and JavaScript

Only the Astro and JavaScript tabs need this helper. It creates the iframe when permitted, preserves the mounted element across unrelated consent updates, and removes it on revocation.

```ts title="src/consent-embed.ts"
import {
	embedCategory,
	embedURL,
	embedTitle,
	embedAspectRatio,
} from './embed-config';

type EmbedKernel = {
	getSnapshot: () => {
		effectivePermissions: Record<typeof embedCategory, boolean>;
	};
	subscribe: (listener: () => void) => () => void;
};

export function mountConsentEmbed(
	container: HTMLElement,
	kernel: EmbedKernel,
	openPreferences: () => void
) {
	const render = () => {
		if (kernel.getSnapshot().effectivePermissions[embedCategory]) {
			if (container.querySelector('iframe')) return;
			const frame = document.createElement('iframe');
			frame.src = embedURL;
			frame.title = embedTitle;
			frame.loading = 'lazy';
			frame.allowFullscreen = true;
			Object.assign(frame.style, {
				width: '100%',
				aspectRatio: embedAspectRatio,
				minHeight: '200px',
				border: '0',
			});
			container.replaceChildren(frame);
		} else {
			if (container.querySelector('button')) return;
			const button = document.createElement('button');
			button.type = 'button';
			button.textContent = 'Open privacy settings to view this content';
			button.onclick = openPreferences;
			container.replaceChildren(button);
		}
	};

	render();
	const unsubscribe = kernel.subscribe(render);
	return () => {
		unsubscribe();
		container.replaceChildren();
	};
}
```

Keep a text alternative, such as a transcript or address, outside the gated iframe. A policy may keep a category denied even after the visitor opens preferences.

## Gate existing iframe markup

`createIframeBlocker` from `@inth/sdk/modules/iframe-blocker` promotes `data-src` to `src` only when the `data-category` is allowed and the URL resolves to HTTP or HTTPS. Malformed URLs and non-HTTP schemes such as `javascript:`, `data:`, and `blob:` stay in `data-src` without loading. Fix the URL and call `processAllIframes()` to retry.

Always omit `src` in the initial HTML so the browser does not fetch the embed before the blocker runs. The module ignores iframes without `data-category`.
