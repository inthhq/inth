## Google loads before a choice by default

With the default `loadMode: 'always'`, `googleTagManager` and `gtag` set `alwaysLoad: true`. Before the visitor chooses, the helper creates the `dataLayer` queue, sends `gtag('consent', 'default', ...)` with the current permissions, and loads Google's script. Each later permission change sends `gtag('consent', 'update', ...)`. Google tags adjust what they store and send based on those signals; see Google's [Consent Mode overview](https://developers.google.com/tag-platform/security/concepts/consent-mode).

Because the browser contacts Google before a choice in `'always'` mode, set `loadMode: 'after-consent'` if your policy requires zero requests to Google until the visitor allows the category. In `'after-consent'` mode, the helper creates nothing and sends no requests until the category is allowed. Once allowed, it sends `default` with the current permissions before starting Google, then `update` on later changes. Under an `opt-out` or `none` policy, optional categories start allowed, so the helper loads on the first page.

## How categories map to Google consent types

| Inth category | Google consent types |
| --- | --- |
| `necessary` | `security_storage` |
| `functionality` | `functionality_storage` |
| `measurement` | `analytics_storage` |
| `marketing` | `ad_storage`, `ad_user_data`, `ad_personalization` |
| `experience` | `personalization_storage` |

Each Google type is `granted` when its category is allowed and `denied` otherwise. If a visitor switches the helper's vendor off, every optional type is sent as `denied`. The `consentMapping` option replaces the full table, so include every category you want signaled.

Under an `opt-out` policy, the `default` command can grant types before the visitor chooses. That reflects an effective permission, not a recorded choice.

Swift, Android, and React Native use the same table with no custom override. Pending policies deny every optional type. [Firebase Analytics](/docs/integrations/firebase-analytics) sends four of these types: `analytics_storage`, `ad_storage`, `ad_user_data`, and `ad_personalization`. Swift exposes the mapping as `GoogleConsentMode` and `GoogleConsentType` in `InthApple`, Android in `com.inth.android.integrations`, and React Native as `resolveGoogleConsentMode` in `@inth/react-native/integrations`.
