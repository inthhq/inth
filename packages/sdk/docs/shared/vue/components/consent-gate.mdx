<section id="behavior">
  ## What ConsentGate renders

  `ConsentGate` renders its default slot while the effective permission for
  `category` is granted, and its `placeholder` slot otherwise. It adds no
  wrapper element. While denied, the default slot stays out of the DOM so
  iframes or widgets inside it send no requests. When the visitor withdraws
  permission, Vue removes the slot content.

  Permission matches `useConsent()` for that category: it may be granted under
  an opt-out policy before a visitor acts, and Global Privacy Control can deny
  a category the visitor granted.

  Without a `placeholder` slot, `ConsentGate` renders a default card showing
  `consentGate.title` with the category name and a button labeled
  `consentGate.actionButton` that opens preferences. Under a policy that
  forbids the category, it shows `consentGate.policyBlocked` with no button.
  Copy uses the visitor's language once init delivers translations, defaulting
  to English until then. Theme tokens and `--consent-gate-placeholder-*`
  variables style the card. Providing a `placeholder` slot replaces it
  completely.

  To restyle the default placeholder, configure `components['consent-gate']`
  parts (`root`, `title`, and `button`) using Vue attribute names such as
  `class` and `style`, or use the `consentGate`, `consentGateTitle`, and
  `consentGateButton` theme slots. The elements carry
  `data-testid="consent-gate-placeholder"`, `data-testid="consent-gate-title"`,
  and `data-testid="consent-gate-button"`.

  `ConsentGate` also ensures `category` appears in the preference dialog so
  the visitor can allow it.
</section>

<section id="props">
  ## Props and slots

  | Name | Kind | Type | Behavior |
  | --- | --- | --- | --- |
  | `category` | Prop, required | `'necessary' \| 'functionality' \| 'measurement' \| 'experience' \| 'marketing'` | Category whose permission gates the default slot. |
  | `default` | Slot | | Gated content, such as an iframe. |
  | `placeholder` | Slot | | Content shown while the category is denied. |
</section>

<section id="accessibility">
  ## Accessibility

  Give every iframe a descriptive `title`. Provide an alternative way to reach
  the content, such as a link or transcript, for visitors who decline the
  category or visit under a policy that blocks it.
</section>
