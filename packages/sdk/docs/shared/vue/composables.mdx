<section id="rules">
  ## Where composables work

  Call composables inside `setup` of a component rendered in the app where
  Inth is installed. Calling them elsewhere throws `[inth] Kernel not found`.
  Most composables return a Vue `computed`, so read them with `.value` in
  `<script setup>` and directly in templates. They update whenever consent
  state changes.
</section>

<section id="permission">
  ## Permission or recorded choice

  `useConsent()` and `useHasConsent()` answer whether code may run right now.
  Under an opt-out policy a category can be allowed before the visitor acts,
  and Global Privacy Control can deny a category the visitor allowed. Use them
  to gate code or optional content.

  `useExplicitChoice()` answers what the visitor decided. It stays `null`
  until the visitor accepts, rejects, or saves. Use it to display a visitor's
  choice or report consent rates. Page loads never change it, and dismissing a
  notice does not set it.

  Never record a choice on the visitor's behalf just because a permission is
  `true`. See
  [a permission is not a recorded choice](/docs/concepts/how-consent-works#a-permission-is-not-a-recorded-choice).
</section>

<section id="read-state">
  ## Read consent state

  | Composable | Returns | Use it to |
  | --- | --- | --- |
  | `useConsent()` | Computed `Record<category, boolean>` | Read each category's current permission, such as `consent.value.marketing`. |
  | `useHasConsent()` | Computed array of allowed categories | List what may run now. The array keeps its identity until a category changes. |
  | `useEffectivePermissions()` | Computed permissions | Read the same values as `useConsent()` from the snapshot field. |
  | `useVendorAllowed(id)` | Computed `boolean` | Check whether a declared vendor may run: its category is allowed and the visitor has not switched it off. Returns `false` for undeclared IDs. |
  | `useExplicitChoice()` | Computed recorded choice, or `null` | Read what the visitor decided. |
  | `useStoredConsent()` | Computed recorded choice, or `null` | Read the same value as `useExplicitChoice()`. |
  | `useNoticeDismissal()` | Computed dismissal record, or `null` | Check whether the visitor dismissed a notice. |
  | `useOptOutState()` | Computed opt-out display state | Check whether an opt-out is honored, how it was recorded and whether GPC or an account locks it. |
  | `usePrivacySignals()` | Computed privacy signals | Read whether Global Privacy Control was detected and applied. |
  | `useConsentRestrictions()` | Computed restrictions | Inspect why a policy or privacy signal limits a permission. |
  | `usePolicyRule()` | Computed policy rule | Read the `model`, `prompt`, `scope`, and `rights` of the matched policy. |
  | `usePolicyResolution()` | Computed resolution | Check that a policy matched. `status` is `'matched'` when one applies. |
  | `useRequestRegion()` | Computed `{ country, region }` | Read the location the policy resolved for. |
</section>

<section id="act">
  ## Record a choice

  `useConsentSave()` returns a function that records a choice and resolves to
  `{ ok }` once Inth responds. Inth applies the choice in the page before the
  request completes, so gated scripts start immediately.

  | Argument | Records |
  | --- | --- |
  | `'all'` | Every category the policy covers allowed. |
  | `'none'` | Every optional category denied. |
  | `['measurement']` | The listed categories allowed and every other optional category denied. |

  `useDismissNotice()` returns a function that dismisses a notice. It records
  an acknowledgement, grants nothing, and leaves earlier refusals in place.
  Use it only for a policy whose prompt is `notice`.

  `useOptOut()` returns a function that records a durable opt-out in one click
  and opens `OptOutConfirmation` under an opt-out policy regardless of
  `presentation.optOutLink`. Under other policy models it opens the preference
  dialog.

  ## Open the banner or preferences

  `useConsentActiveUI()` returns a writable computed with value `'banner'`,
  `'manager'`, or `null`. Set it to `'manager'` to open preferences, to
  `'banner'` to show the banner again, or to `null` to close both. Vue uses
  `'manager'` where React uses `'dialog'`. `ConsentDialogLink` sets
  `'manager'` and hides itself when the policy offers no preferences.

  ## Change the language

  `useConsentLanguage()` returns a writable computed holding the language
  override, or `null`. Assigning a new language code stores it and runs init
  again, fetching banner and dialog text in that language. Assigning the
  current language or `null` does nothing.
</section>

<section id="headless">
  ## Build a preference form

  `useConsentDraft()` holds preference form switches separately from the
  recorded choice, so nothing saves until the visitor clicks Save.

  | Field | Type | Meaning |
  | --- | --- | --- |
  | `displayedCategories` | `ComputedRef<category[]>` | Categories the policy lets the visitor choose, in the order necessary, functionality, measurement, experience, marketing. |
  | `values` | `Ref<Partial<Record<category, boolean>>>` | One value per category. Bind switches with `v-model`; writes to `necessary` or unoffered categories snap back. |
  | `vendors` | `ComputedRef<Record<string, boolean>>` | One value per declared vendor. Update them with `setVendor(id, granted)`. |
  | `isDirty` | `ComputedRef<boolean>` | `true` while any value differs from the recorded choice. |
  | `isStale` | `ComputedRef<boolean>` | `true` when the policy, displayed categories, or vendor list changed while the draft held unsaved edits. |
  | `save()` | `() => Promise<{ ok: boolean }>` | Records `values` and changed vendors. Resolves `{ ok: false }` without saving while `isStale` is `true`. |
  | `reset()` | `() => void` | Refills the draft from the recorded choice and policy. |

  The draft starts from the recorded choice, or from the policy's defaults
  before any choice (on under an opt-out policy or for preselected categories,
  otherwise off). A choice saved elsewhere updates untouched switches.
  `save()` does not close the UI; set `activeUI` to `null` afterward.

  ## Render the actions the policy requires

  | Composable | Returns | Use it to |
  | --- | --- | --- |
  | `usePromptRequirement()` | Computed `{ kind }` (`'choice'`, `'notice'`, or `'none'`) | Decide whether to show a banner. |
  | `useConsentPolicyActions(surface)` | Computed `actionGroups`, `primaryActions`, `variant`, `position`, `blocking`, `direction`, and `preferenceControls` | Render the required buttons for `'prompt'` or `'preferences'` in order. |
  | `useHasConsentPolicy()` | Computed boolean | Check that a policy matched the visitor. |
  | `useHasConsentUi()` | Computed boolean | Check whether the policy requires any consent UI. Stock surfaces hide while `false`. |
  | `useHasConsentPreferences()` | Computed boolean | Check whether to render a preferences control. |

  Under a notice, `actionGroups` holds `dismiss` instead of accept and reject.
  `preferenceControls` lists extra controls (`'opt-out'` or `'preferences'`)
  that open preferences under policies granting those rights.
</section>

<section id="iab">
  ## IAB TCF

  | Composable | Returns | Use it to |
  | --- | --- | --- |
  | `useConsentIabSelection()` | Writable computed with purpose, legitimate-interest, vendor, and special-feature maps, plus `preferenceCenterTab` | Read and update the visitor's IAB selection in a custom preference center. Writes update gating live without saving. |
  | `useConsentIabSave()` | `(input, tab?) => Promise<void>` | Save `'all'`, `'none'`, or a selection. Waits for the Global Vendor List before writing the TC String. |
  | `useIabTranslations()` | Computed IAB copy | Read IAB banner and dialog text in the visitor's language. |
</section>

<section id="advanced">
  ## Advanced

  | Composable | Returns | Use it to |
  | --- | --- | --- |
  | `useConsentSnapshot()` | `Ref<ConsentSnapshot>` | Read any snapshot field, such as `policyPending`, `vendors`, or `iab`. |
  | `useConsentKernel()` | The consent kernel | Call `commands.init()`, `commands.save()`, `commands.identify(user)`, subscribe with `events.on(type, listener)`, or read `getSnapshot()`. |
  | `useConsentConfig()` | Computed merged options | Read the active configuration options. |
  | `useConsentInit()` | Computed `{ translations, location, branding, gvl, cmpId, customVendors }`, or `undefined` before resolution | Read display data from the resolved policy. |
  | `useConsentComponent(name)` | Computed slot attributes | Read the `components` option for a named surface to reuse in custom markup. |

  `useConsentKernel().events.on()` returns an unsubscribe function; call it in
  `onUnmounted`. For choice and permission events, use the `callbacks` option,
  which Inth wires once for the whole app.
</section>
