<section id="props">
  | Prop | Type | Default | Description |
  | --- | --- | --- | --- |
  | `title` | `ReactNode` | translation | Overrides the title. Under a notice, defaults to `cookieBanner.noticeTitle`. |
  | `description` | `ReactNode` | translation | Overrides the description. Under a notice, defaults to `cookieBanner.noticeDescription`. |
  | `acceptButtonText` | `ReactNode` | `common.acceptAll` | Accept button label. |
  | `rejectButtonText` | `ReactNode` | `common.rejectAll` | Reject button label. |
  | `customizeButtonText` | `ReactNode` | `common.customize` | Customize button label. |
  | `dismissButtonText` | `ReactNode` | `common.acknowledge` | Label for the notice acknowledgement button. |
  | `variant` | `PromptVariant` | `floating` | Shape of the prompt. See [Variants](#variants). |
  | `position` | `PromptPosition` | per variant | Where the prompt sits. Must be valid for the chosen variant. |
  | `blocking` | `boolean` | `true` on `wall` | Enables backdrop, scroll lock, focus trap, and disables outside dismissal together. |
  | `layout` | `ConsentBannerLayout` | policy default | Orders and groups actions. Restores any required action the layout omits. |
  | `primaryButton` | `ConsentBannerButton \| ConsentBannerButton[]` | `'customize'` | Marks which actions get primary styling. On a notice, dismiss is primary when it is the only action. |
  | `direction` | `'row' \| 'column'` | `'row'` | Sets how action groups flow. |
  | `legalLinks` | `(keyof LegalLinks)[] \| null` | none | Lists which configured legal links render inline. |
  | `hideBranding` | `boolean` | `false` | Hides the "Secured by" tag. |
  | `scrollLock` | `boolean` | unset | Deprecated. Use `blocking` to control scroll lock, focus trap, and backdrop together. |
  | `trapFocus` | `boolean` | unset | Deprecated. Use `blocking`. |
  | `disableAnimation` | `boolean` | `false` | Skips enter and exit animations. |
  | `noStyle` | `boolean` | `false` | Removes built-in styling from every part. |
</section>
