Apply CSS Modules, vanilla-extract, StyleX, Emotion, or plain class names to any Inth component part without `!important`.

## Pass a class to a part

Inth places its stock rules inside `@layer components`. Any unlayered class rule you pass through your framework's part API outranks Inth's rule for the same property regardless of load order.

| Framework | Part API | Class key | Inline `style` | Where CSS must load |
| --- | --- | --- | --- | --- |
| Next.js, TanStack Start, React | `components.<component>.<part>` or `theme.slots` | `className` | Yes | Anywhere on the page |
| Nuxt, Vue | `components.<component>.<part>` or `theme.slots` | `class`, or `className` in `theme.slots` | Yes | Anywhere on the page |
| Svelte, SvelteKit | `theme.slots` or `class` on a component | String or `className` | Yes | Global stylesheet or `:global()` |
| Astro | `theme.slots` in `inth()` or `class` on `ConsentBanner` | String or `className` | Yes | Global stylesheet |
| HTML, JavaScript | `ui.theme.slots` | String or `className` | Yes | Inside shadow root via `ui.stylesheetUrls`, or anywhere with `shadow: false` |

See [Component parts](/docs/customization/slots) for every part key. Each example below adds a 3px colored border and 4px corners to the banner card.

## Framework differences

- **Vue and Nuxt.** Part objects bind with `v-bind`, so write `class` instead of `className`. CSS Modules, vanilla-extract, and Emotion strings work directly; with StyleX, map `stylex.props().className` to `class`.
- **Svelte and SvelteKit.** Scoped `<style>` blocks do not reach Inth parts. Define classes in a global stylesheet or with `:global(.your-class)`.
- **Astro.** Integration options in `astro.config.mjs` must serialize, so `theme.slots` accepts plain class strings from global CSS or Tailwind rather than imported CSS Module bindings.

## Style the script tag shadow root

The HTML script tag and `init()` from `@inth/sdk` render inside a shadow root, so page stylesheets do not apply automatically. Choose one approach:

- **`ui.stylesheetUrls`.** Links your compiled CSS Modules or Tailwind stylesheet inside the shadow root after Inth's stylesheet.
- **`::part()`.** Styles any part with a slot key from page CSS using `[data-inth-ui]::part(consentBannerCard)`.
- **`ui.css`.** Injects a raw CSS string inside the shadow root.
- **`ui: { shadow: false }`.** Renders into the light DOM so all page CSS, including Emotion, applies directly.

## Check the result

1. Open the site in a private window so the consent banner renders.
2. Inspect the banner card in DevTools Elements and confirm your class is on the element.
3. Check DevTools Styles to verify your border applies and Inth's rule for the same property is crossed out. If your class is present without a matching rule, check the "Where CSS must load" column in [Pass a class to a part](#pass-a-class-to-a-part).
