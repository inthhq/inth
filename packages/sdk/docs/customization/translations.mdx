Edit consent banner and dialog copy in your Inth project or override strings in code, with 53 built-in languages and automatic right-to-left layout support.

## Override copy in your Inth project or in code

Your Inth project supplies base translations via your manifest or `/v1/consent/init`. Edit wording in your project first so changes ship without redeploying.

To override strings site-wide in code, pass `i18n.messages` in provider options:

{/* example: fragment */}

```tsx
i18n: {
  messages: {
    en: {
      common: {
        acceptAll: 'Accept all',
        rejectAll: 'Reject optional',
        customize: 'Choose cookies',
        acknowledge: 'Got it',
      },
    },
  },
}
```

Inth merges `i18n.messages` key by key onto project copy for the active language, checking exact tags like `de-AT` before primary tags like `de`. A code key overrides project copy only when its text differs from Inth's built-in wording for that language, so passing stock bundles never hides edits from your Inth project.

- Use component props like `dismissButtonText` only for one-off banner overrides.
- Astro serializes integration options, so match Astro's `i18n` shape rather than a React object.
- Vue and Nuxt have no `i18n` option and read copy from your Inth project.

## Detect and select the visitor language

- **Server-rendered frameworks.** Server helpers read the request `Accept-Language` header so initial HTML renders in the visitor's language. Pass `language` explicitly to match a route locale like `/[lang]`.
- **Browser-resolved setups.** Browser `/v1/consent/init` requests send the browser `Accept-Language` header, or use `overrides.language` from provider options.
- **Local testing.** `testing()` reads `i18n.locale`, defaulting to `en`, and ignores browser language.

Unmatched languages fall back to your Inth project's default language.

## Load built-in languages

Inth bundles English. Every other built-in language ships as a separate `translations/<code>` subpath so unused locales stay out of your bundle. Import the locales you need alongside your provider config so `testing()` can switch to them and Inth recognizes their built-in wording:

{/* example: fragment */}

```ts
import '@inth/react/translations/de';
import '@inth/react/translations/fr';
```

Each entry also exports `translations` if you want to extend built-in strings:

{/* example: fragment */}

```ts
import { translations as de } from '@inth/react/translations/de';
```

Available entries: `ar`, `bg`, `bn`, `cs`, `cy`, `da`, `de`, `el`, `es`, `et`, `fi`, `fr`, `ga`, `gu`, `he`, `hi`, `hr`, `ht`, `hu`, `id`, `is`, `it`, `ja`, `kn`, `ko`, `lb`, `lt`, `lv`, `ml`, `mr`, `ms`, `mt`, `nb`, `nl`, `nn`, `pa`, `pl`, `pt`, `rm`, `ro`, `ru`, `sk`, `sl`, `sv`, `ta`, `te`, `th`, `tr`, `ur`, `vi`, `yi`, and `zh`. Import `translations/all` to load every locale at once, or use `@inth/sdk/translations/<code>` without a framework.

## Write labels that describe the action

Match every label to its action. Accept and Reject record a consent decision. Customize opens preferences. Acknowledge dismisses a notice without recording a grant. Do not label a notice dismissal "Accept all" or word a preferences link like an opt-out submission.

Notice acknowledgement reads `common.acknowledge` and falls back to `common.dismiss` for older bundles.

## Translate the ConsentGate placeholder

| Key | Purpose |
| --- | --- |
| `consentGate.title` | Placeholder heading; `{category}` expands to the category title. |
| `consentGate.actionButton` | Preferences button label, with the same `{category}` token. |
| `consentGate.policyBlocked` | Replaces the title in React and Vue with no button when strict policy excludes the category. |

Legacy `frame` keys still fall back to `consentGate` with a one-time development warning. Rename `frame` to `consentGate` to clear it.

## Show right-to-left languages

Inth sets `dir="rtl"` for Arabic, Hebrew, Yiddish, Persian, Urdu, Pashto, Sindhi, Central Kurdish `ckb`, Uyghur, Dhivehi, Syriac, and N'Ko, including regional tags like `ar-EG` and legacy codes `iw` and `ji`. Script subtags take precedence: `ku-Arab` and `pa-Arab` are RTL, while `sd-Deva` and plain `ku` are LTR. Built-in RTL translations ship for `ar`, `he`, `ur`, and `yi`.

- Banner, dialog, and widget text and buttons flow right to left.
- Banner and `ConsentDialogTrigger` corners stay pinned so `bottom-left` does not jump when language changes.
- The script tag, `@inth/sdk`, and Astro's banner set both `dir` and `lang`; React, Vue, and Svelte set `dir` only, so set `lang` on `<html>`.
- The IAB TCF dialog still left-aligns several internal labels, indents, and borders.

## Test more than English

Test your longest labels at narrow widths, with browser zoom, and in right-to-left locales. Check banner actions, category descriptions, legal links, and the preferences save button, and translate explanations alongside buttons so visitors can make an informed choice.
