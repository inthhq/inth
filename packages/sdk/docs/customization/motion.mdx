Adjust Inth's transition timing with motion tokens, turn animations off globally or per surface with `disableAnimation`, and respect `prefers-reduced-motion` automatically.

## Customize duration and easing tokens

Inth uses three durations and six easing curves. Override them in your theme's `motion` object or as `--inth-*` CSS variables:

| CSS variable | Theme key | Default | Used by |
| --- | --- | --- | --- |
| `--inth-duration-fast` | `motion.duration.fast` | `80ms` | Banner fade out, buttons, tabs |
| `--inth-duration-normal` | `motion.duration.normal` | `150ms` | Dialog, late banner fade in, switches, accordions |
| `--inth-duration-slow` | `motion.duration.slow` | `200ms` | Legal links, floating trigger |
| `--inth-easing` | `motion.easing` | `cubic-bezier(0.4, 0, 0.2, 1)` | Switches, accordions |
| `--inth-easing-out` | `motion.easingOut` | `cubic-bezier(0.215, 0.61, 0.355, 1)` | Dialog, late banner fade in, trigger hover |
| `--inth-easing-out-strong` | `motion.easingOutStrong` | `cubic-bezier(0.23, 1, 0.32, 1)` | Reserved for the Privacy Choices surfaces; no stock component uses it yet |
| `--inth-easing-in` | `motion.easingIn` | `cubic-bezier(0.55, 0.055, 0.675, 0.19)` | Banner fade out |
| `--inth-easing-in-out` | `motion.easingInOut` | `cubic-bezier(0.645, 0.045, 0.355, 1)` | Trigger corner snap |
| `--inth-easing-spring` | `motion.easingSpring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | Dialog scale in |

This theme slows the preference dialog and removes spring overshoot:

{/* example: fragment */}

```ts title="consent-theme.ts"
export const theme = {
	motion: {
		duration: { fast: '120ms', normal: '220ms' },
		easingSpring: 'cubic-bezier(0.215, 0.61, 0.355, 1)',
	},
};
```

Banners never slide in. Initial-paint and server-rendered banners appear on frame one. Banners arriving over 100ms late fade in over `--inth-duration-normal` with `data-entry="late"`. Vue, Svelte, and the script tag fade banners out over `--inth-duration-fast`. Pass `motion` tokens through your framework's theme API, documented in [theme tokens](/docs/customization/tokens); Vue and Nuxt `tokens` omit `--`, such as `'inth-duration-normal': '220ms'`.

## Turn animations off with `disableAnimation`

`disableAnimation` removes banner fades, dialog transitions, and trigger hover or snap transitions. Per-surface props override the global setting:

| Framework | Global | Per surface |
| --- | --- | --- |
| Next.js, TanStack Start | `options.disableAnimation` in `inth.config.ts` or `InthProvider` | `disableAnimation` prop |
| React | `disableAnimation` in `InthProvider` options | `disableAnimation` prop |
| Nuxt | `inth.disableAnimation` in `nuxt.config.ts` | `disableAnimation` prop on mounted surfaces |
| Vue | `disableAnimation` in `inth` options | `disableAnimation` prop on mounted surfaces |
| Astro | `disableAnimation` in `inth()` options | `disableAnimation` prop |
| Svelte, SvelteKit | `disableAnimation` on `InthProvider` | `disableAnimation` prop |
| Angular | `disableAnimation` in `provideInth()` | `[disableAnimation]` input |
| HTML | `data-disable-animation` or `ui.disableAnimation` | `ui.banner` or `ui.dialog` `disableAnimation` |
| JavaScript | `ui.disableAnimation` in `init()` | `ui.banner` or `ui.dialog` `disableAnimation` |

In Vue and Nuxt, `InthProvider` renders surfaces without props, so per-surface overrides require mounting the banner and dialog components directly.

## Respect `prefers-reduced-motion`

Inth stops animations on banners, dialogs, triggers, switches, tabs, and accordions when `prefers-reduced-motion: reduce` matches. The CSS rule works across all frameworks, updates live, and cannot be overridden by `disableAnimation: false`.

## Animate your own rules on dialog state

The preference dialog sets `data-state="open"` or `data-state="closed"` for custom transitions:

| Framework | Elements with `data-state` |
| --- | --- |
| HTML, JavaScript | Dialog overlay, positioner, and content |
| Svelte, SvelteKit | Dialog backdrop, positioner, and content |
| Vue, Nuxt | Dialog content and overlay. Unmounts on close, so only `open` appears |
| Angular | Dialog primitives: overlay, content, trigger, and close |
| React, Next.js, TanStack Start | `Dialog` primitive trigger, overlay, content, and close parts, not `ConsentDialog` |

Banners do not set `data-state`. Use `data-prompt`, `data-variant`, and other attributes from [component parts](/docs/customization/slots).

## Pause transitions during theme switches

Add `.inth-no-transitions` to `<html>` while swapping themes, force layout, then remove it:

{/* example: fragment */}

```ts
const root = document.documentElement;
root.classList.add('inth-no-transitions');
applyYourTheme();
root.getBoundingClientRect();
root.classList.remove('inth-no-transitions');
```

If theme updates commit in a later render, run the last two lines after commit.

## Verify motion settings

1. Open DevTools Rendering, emulate `prefers-reduced-motion: reduce`, clear site data, and reload.
2. Confirm the banner appears without animating and dialog switches toggle immediately.
3. Disable emulation, increase `motion.duration.normal`, and reopen the dialog to confirm slower animation.
