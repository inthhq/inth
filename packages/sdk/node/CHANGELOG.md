## @inth/node@0.0.0-alpha.0 (alpha)

### First alpha of the Inth server client

`@inth/node` calls the Inth `/v1` API from your server: check what a user consents to, link a browser to your user, mint identity tokens, and publish, check and record acceptance of legal documents. It runs on Node.js 20.3 or later, Vercel Functions and Cloudflare Workers. Install it with the tag: `npm install @inth/node@alpha`.
