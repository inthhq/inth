### Account opt-out lifts stay with the account that asked, and a retried early tap hides the banner again

- When a visitor allows the sale of their data over an opt-out their account holds, and the site identifies another account on the same browser before the backend answers, the answer no longer lifts the new account's opt-out or replaces it. The same holds for the lift that follows a save granting the deciding category: it is sent only while the account that saved is still the identified one, and its answer applies only then. The new account's own opt-out, from `identify()`, applies whenever it arrives.
- The inline script of a server-rendered banner hides the banner again on a retry tap after a failed load brought it back. It used to add its hiding style only once, so the banner stayed visible while the code loaded again.
