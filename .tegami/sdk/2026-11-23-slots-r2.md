### Svelte, Angular and the script tag: dialog slots, and early taps in Angular

- The `consentDialogOverlay` theme slot now styles the consent dialog's root in Svelte, Angular and the script tag, as it already does in React and Vue. The root is the dialog's backdrop and surface, so the slot that styled the backdrop of earlier releases applies there with `consentDialog`. A `noStyle` on either slot drops only the stock backdrop classes, not the other slot's.
- In the script tag, the dialog's intro now takes the `consentDialogDescription` slot, and page CSS can reach it through `::part(consentDialogDescription)`.
- Angular: a tap on the server-rendered banner before the app hydrates is now held and replayed. Before, the stock banner buttons opted out of the early-tap script, so the tap did nothing.
- Angular: if the banner's container chunk fails to load after a held tap, the banner is no longer hidden for good. The next consent update, such as the engine starting, loads the banner again, and it replays the tap.
