### Vue and Nuxt: a banner whose chunk fails to load after a server render

- If the banner's container chunk fails to load while the page hydrates, the banner the server rendered stays on the page. If the visitor tapped it before it hydrated, it shows again instead of staying hidden.
- The next tap on that banner loads the chunk again. When it loads, the banner records the visitor's newest tap, and it replaces the server's banner, so the page no longer shows two banners.
- A chunk that fails while the page hydrates no longer causes an unhandled promise rejection. Vue still reports the error to your app.
- Nuxt with `features.inlineStyles` (the default): a server-rendered banner no longer shifts when the page loads. The server inlined the container's styles (Card, Banner or Drawer) ahead of the shared banner styles, while the browser applies them after, so the banner changed size once the browser's stylesheets arrived. The server now inlines them in the browser's order.
