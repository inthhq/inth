### React, Vue, Svelte and Angular: focus returns to a control that can take it

- Closing the consent dialog returns focus to the control that opened it only when that control can still take focus. If the page has hidden it, for example a footer "Your Privacy Choices" link hidden with CSS, focus moves on to the next visible control, such as the floating trigger, instead of staying on the page body. The script tag already did this.
- After a choice on the banner, focus skips a hidden "Your Privacy Choices" link in the same way.
