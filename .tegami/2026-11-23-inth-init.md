### Set up the Inth SDK with `inth init`

`inth init` sets up the `@inth/*` packages in an app. It takes the same actions and options as `inth c15t`: start a coding agent, print a setup prompt, or scaffold the framework quickstart files. It selects an Inth project or creates one with Inth branding. The agent prompt points at the Inth docs and the project URL.

Scaffolds from `inth init` and `inth c15t` now install the `@inth` packages on the 0.1 release line instead of `@3`.
